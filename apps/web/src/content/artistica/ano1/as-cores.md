# As cores: primárias e arco-íris 🎨

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **três cores primárias** (as que não se podem fazer) e as **cores do arco-íris**! 🌈

As cores estão por toda a parte e servem para criar coisas lindas. Vamos brincar com elas! 🖍️

## As 3 cores primárias 🔴🟡🔵

São as cores **mágicas**: não se fazem misturando nenhumas outras. Mas, misturadas, fazem todas as outras!

```keyvalue
[
  { "k": "Vermelho", "v": "como um morango 🍓" },
  { "k": "Amarelo", "v": "como o sol ☀️" },
  { "k": "Azul", "v": "como o céu 🌤️" }
]
```

> **Truque:** são só **3** — Vermelho, Amarelo e Azul. Conta pelos dedos! ✌️👆

## Misturar para criar cores novas 🪄

Quando juntas duas cores primárias, nasce uma cor **nova**! Estas chamam-se cores **secundárias**. Experimenta com os teus lápis:

```keyvalue
[
  { "k": "Azul + Amarelo", "v": "fica Verde, como a relva 🟢" },
  { "k": "Vermelho + Amarelo", "v": "fica Laranja, como uma laranja 🟠" },
  { "k": "Vermelho + Azul", "v": "fica Roxo, como uma uva 🟣" }
]
```

E há ainda duas cores especiais que não estão no arco-íris: o **branco** ☁️ e o **preto** ⚫. O branco clareia as cores e o preto escurece-as!

## O arco-íris 🌈

Quando chove e há sol ao mesmo tempo, aparece o **arco-íris**, com as suas cores sempre pela mesma ordem:

```steps
[
  { "title": "Quentes", "body": "vermelho, laranja e amarelo — fazem lembrar o sol e o fogo 🔥" },
  { "title": "Frias", "body": "verde, azul e roxo — fazem lembrar o mar e o gelo 🧊" }
]
```

## Um exemplo passo a passo 🔍

Imagina que queres pintar a relva de **verde**, mas só tens lápis azul e amarelo. Não faz mal — tu consegues fazer o verde!

```steps
[
  { "title": "1. Escolhe as cores certas", "body": "para o verde precisas de azul 🔵 e amarelo 🟡" },
  { "title": "2. Pinta de amarelo", "body": "passa o lápis amarelo no papel, devagarinho 🟡" },
  { "title": "3. Pinta o azul por cima", "body": "passa agora o azul no mesmo sítio 🔵" },
  { "title": "4. Olha — apareceu o verde!", "body": "as duas cores misturaram-se e nasceu o verde 🟢" }
]
```

> [!TIP] **Para saberes mais** 🌱 O arco-íris nasce porque a luz do sol é, na verdade, **muitas cores juntas**! As gotas de chuva separam-nas, como um pequeno prisma. 💧
