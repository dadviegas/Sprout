# As cores: primárias e arco-íris 🎨

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **três cores primárias** (as que não se podem fazer), aprender a **misturá-las** para criar cores novas, descobrir as cores **quentes e frias** e dizer as **sete cores do arco-íris** pela ordem certa! 🌈

As cores estão por toda a parte: no céu, nas flores, na fruta, nos teus lápis. Elas deixam tudo mais bonito e até nos fazem sentir coisas diferentes. Vamos brincar com elas e descobrir os seus segredos? 🖍️😄

## As 3 cores primárias 🔴🟡🔵

São as cores **mágicas**: não se fazem misturando nenhumas outras. Mas, quando as misturas, conseguem fazer **todas** as outras cores!

> **Truque:** são só **3** e começam por **V-A-A**: **V**ermelho, **A**marelo e **A**zul. Conta-as pelos dedos! ✌️👆

## Misturar para criar cores novas 🪄

Quando juntas **duas** cores primárias, nasce uma cor **nova**! A essas cores chamamos **secundárias**. Experimenta com os teus lápis ou tintas:

```keyvalue

  { "k": "Azul + Amarelo", "v": "fica Verde, como a relva 🟢" },

```

Olha que giro: com apenas **3 cores** consegues fazer **3 cores novas**! Os pintores fazem isto a toda a hora na sua paleta. 🎨

## O arco-íris 🌈

Quando chove e há sol ao mesmo tempo, aparece o **arco-íris**! Ele tem sempre **sete cores** e sempre pela **mesma ordem**, do lado de fora para dentro:

```steps
[
  { "title": "1. Vermelho", "body": "fica sempre por fora, em cima 🔴" },
  { "title": "2. Laranja", "body": "vem logo a seguir 🟠" },
  { "title": "3. Amarelo", "body": "no meio, bem brilhante 🟡" },
  { "title": "4. Verde", "body": "como as folhas das árvores 🟢" },
  { "title": "5. Azul", "body": "como o céu de dia 🔵" },
  { "title": "6. Anil", "body": "um azul mais escurinho 🔷" },
  { "title": "7. Violeta", "body": "fica por dentro, em baixo 🟣" }
]
```

> São **7 cores**, sempre pela mesma ordem! Vermelho, Laranja, Amarelo, Verde, Azul, Anil e Violeta. 🌈

## Um exemplo passo a passo 🔍

Imagina que queres pintar a relva de **verde**, mas só tens lápis **azul** e **amarelo**. Não faz mal — tu consegues fazer o verde sozinho!

```steps
[
  { "title": "1. Escolhe as cores certas", "body": "para o verde precisas de azul 🔵 e amarelo 🟡", "icon": "🎨" },
  { "title": "2. Pinta de amarelo", "body": "passa o lápis amarelo no papel, devagarinho 🟡" },
  { "title": "3. Pinta o azul por cima", "body": "passa agora o azul no mesmo sítio, sem carregar muito 🔵" },
  { "title": "4. Olha — apareceu o verde!", "body": "as duas cores misturaram-se e nasceu o verde 🟢", "icon": "✨" }
]
```

> **Truque:** para te lembrares de misturar, pensa nas frutas! Laranja + nada? Não! **Vermelho + amarelo = laranja** 🟠. E uva roxa? **Vermelho + azul = roxo** 🟣.

> [!TIP] **Para saberes mais** 🌱 O arco-íris nasce porque a luz do sol, que parece branca, é na verdade **muitas cores juntas**! Quando passa pelas gotas de chuva, elas separam as cores, como faz um **prisma** de vidro. Por isso só vês arco-íris quando há **sol e chuva** ao mesmo tempo. 💧🌈
