# Linhas e formas no desenho ✏️

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que **todos** os desenhos começam por **linhas** e **formas** simples — vais aprender os nomes delas, onde se escondem à tua volta e como juntá-las para desenhar o que quiseres! ✏️

Pegar num lápis e desenhar é uma das coisas mais antigas e divertidas que existe! E sabes uma coisa fixe? Mesmo o desenho mais bonito do mundo começa por uma simples **linha**. 〰️ Vem comigo descobrir os segredos das linhas e das formas — vais ver que é mais fácil do que pensas! 🌟

## Formas que vês em tudo 🔺

Quando uma linha dá a volta e se fecha, nasce uma **forma**! Estas três são as que mais vês por aí:

```steps
[
  { "title": "Círculo", "body": "redondo, sem pontas — uma roda, o sol, uma bola 🔵", "icon": "🔵" },
  { "title": "Quadrado", "body": "4 lados todos iguais — uma janela, um dado ◻️", "icon": "◻️" },
  { "title": "Triângulo", "body": "3 lados e 3 pontas — o telhado de uma casa, uma fatia de pizza 🔺", "icon": "🔺" }
]
```

E há mais uma muito útil: o **retângulo** ▭, que é como um quadrado esticado — tem 4 lados, mas dois são mais compridos. É a forma de uma porta, de um livro ou de um telemóvel! 📱

## Um exemplo passo a passo 🔍

Vamos desenhar uma **casa** só com linhas e formas simples. Segue comigo, passo a passo:

```steps
[
  { "title": "1. Faz o quadrado", "body": "desenha 4 linhas retas que se juntam — é a parede 🟫", "icon": "◻️" },
  { "title": "2. Põe o telhado", "body": "em cima do quadrado, desenha um triângulo 🔺", "icon": "🔺" },
  { "title": "3. Janela e porta", "body": "um quadrado pequenino para a janela e um retângulo para a porta 🚪", "icon": "🚪" },
  { "title": "4. Acrescenta um sol", "body": "no canto, um círculo com linhas retas à volta — pronto, é o sol! ☀️", "icon": "☀️" },
  { "title": "5. Já está uma casa!", "body": "só com formas simples fizeste um desenho a sério 🏠", "icon": "🏠" }
]
```

> **Truque:** olha para um objeto e procura a **forma escondida** lá dentro. Uma casa = um quadrado + um triângulo no telhado. Um camião = retângulos + dois círculos para as rodas! 🚚

> [!TIP] **Para saberes mais** 🌱 Os artistas fazem primeiro um **esboço** — um desenho leve, só com linhas, para planear — e só depois pintam por cima com força. Errar no esboço faz parte: por isso é que se desenha primeiro fininho, para se poder apagar! ✏️
