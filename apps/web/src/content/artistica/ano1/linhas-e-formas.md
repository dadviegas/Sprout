# Linhas e formas no desenho ✏️

> [!NOTE] **O que vais aprender** 👀 Vais ver que todos os desenhos começam por **linhas** e **formas** simples — e vais aprender os nomes delas! ✏️

Pegar num lápis e desenhar é uma das formas mais antigas de arte. E tudo começa com uma **linha**! 〰️

## Formas que vês em tudo 🔺

```steps
[
  { "title": "Círculo", "body": "uma roda, o sol, uma bola 🔵" },
  { "title": "Quadrado", "body": "uma janela, um dado ◻️" },
  { "title": "Triângulo", "body": "o telhado de uma casa, uma fatia 🔺" }
]
```

> **Truque:** olha para um objeto e procura a forma escondida. Uma casa = um quadrado + um triângulo no telhado! 🏠

> [!TIP] **Para saberes mais** 🌱 Os artistas fazem primeiro um **esboço** — um desenho leve, só com linhas, para planear — e só depois pintam por cima. Errar no esboço faz parte! ✏️
