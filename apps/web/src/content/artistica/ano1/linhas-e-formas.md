# Linhas e formas no desenho ✏️

> [!NOTE] **O que vais aprender** 👀 Vais ver que todos os desenhos começam por **linhas** e **formas** simples — e vais aprender os nomes delas! ✏️

Pegar num lápis e desenhar é uma das formas mais antigas de arte. E tudo começa com uma **linha**! 〰️

## Formas que vês em tudo 🔺

```steps
[
  { "title": "Círculo", "body": "uma roda, o sol, uma bola 🔵" },
  { "title": "Quadrado", "body": "uma janela, um dado ◻️" },
  { "title": "Triângulo", "body": "o telhado de uma casa, uma fatia 🔺" }
]
```

## Procura as formas à tua volta 🔎

As formas estão escondidas em quase tudo o que vês! Olha bem para estes objetos do dia a dia:

```keyvalue
[
  { "k": "Relógio ⏰", "v": "tem a forma de um círculo 🔵" },
  { "k": "Livro 📕", "v": "tem a forma de um retângulo ▭" },
  { "k": "Sinal de stop 🛑", "v": "tem muitos lados, é um octógono" },
  { "k": "Fatia de bolo 🍰", "v": "tem a forma de um triângulo 🔺" }
]
```

## Linhas que mostram sentimentos 💛

Uma linha não serve só para o contorno — também conta como te sentes! Repara:

```compare
[
  { "title": "Linhas calmas 😌", "rows": [
    { "label": "Como são", "value": "curvas e suaves, como ondas 〰️" },
    { "label": "Sentem-se", "value": "tranquilas e doces" }
  ] },
  { "title": "Linhas agitadas ⚡", "rows": [
    { "label": "Como são", "value": "ziguezague, a picos" },
    { "label": "Sentem-se", "value": "cheias de energia" }
  ] }
]
```

> **Truque:** olha para um objeto e procura a forma escondida. Uma casa = um quadrado + um triângulo no telhado! 🏠

## Um exemplo passo a passo 🔍

Vamos desenhar uma **casa** só com linhas e formas simples. Segue comigo:

```steps
[
  { "title": "1. Faz o quadrado", "body": "desenha 4 linhas retas que se juntam — é a parede 🟫" },
  { "title": "2. Põe o telhado", "body": "em cima, desenha um triângulo 🔺" },
  { "title": "3. Janela e porta", "body": "um quadrado pequenino para a janela e um retângulo para a porta 🚪" },
  { "title": "4. Já está uma casa!", "body": "só com formas simples fizeste um desenho a sério 🏠" }
]
```

> [!TIP] **Para saberes mais** 🌱 Os artistas fazem primeiro um **esboço** — um desenho leve, só com linhas, para planear — e só depois pintam por cima. Errar no esboço faz parte! ✏️
