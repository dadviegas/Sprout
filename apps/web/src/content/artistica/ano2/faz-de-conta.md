# Faz de conta: o teatro 🎭

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é o **teatro**, conhecer as pessoas e os objetos de uma peça, mostrar **emoções** com a cara e o corpo, contar uma história com **mímica** e dar vida a um **fantoche**! 🎭

Quando brincas ao "faz de conta" — médico, super-herói, mãe ou pai — já estás a fazer **teatro**! 🎬 Vestes uma personagem e finges ser outra pessoa, num mundo inventado por ti. O melhor de tudo? Não precisas de saber ler para ser um grande ator: precisas só do teu **corpo**, da tua **cara** e da tua **imaginação**. Vamos a isto! ✨

## O que é o teatro? 🎬

## As emoções na cara 😊😢😡

Um bom ator mostra o que a personagem **sente** só com a cara. Olha como muda:

```keyvalue
[
  { "k": "Alegre", "v": "sorri, olhos a brilhar 😄" },
  { "k": "Triste", "v": "boca para baixo, olhos a fechar 😢" },
  { "k": "Zangado", "v": "sobrancelhas franzidas, boca apertada 😡" },
  { "k": "Surpreso", "v": "boca e olhos muito abertos 😮" },
  { "k": "Com medo", "v": "encolhido, a tremer um bocadinho 😨" }
]
```

## Contar sem falar: a mímica 🤫

Às vezes não dizes nada — falas só com o corpo. Isso chama-se **mímica**:

```steps
[
  { "title": "A cara fala", "body": "sorri (alegre), franze (zangado), boca aberta (surpresa) 😮" },
  { "title": "O corpo fala", "body": "encolhido (com medo), saltar (feliz), arrastar os pés (cansado) 🙆" },
  { "title": "As mãos falam", "body": "podes fingir que abres uma porta ou que comes uma maçã 🚪🍎" },
  { "title": "Sem palavras", "body": "consegues mostrar uma emoção só com o corpo? Experimenta! 🎭" }
]
```

## Fantoches: bonecos que ganham vida 🧦

Nem sempre és tu a personagem! Às vezes pões a mão num **fantoche** e é ele que representa. Há fantoches de vários tipos:

```keyvalue
[
  { "k": "Fantoche de mão (de luva)", "v": "metes a mão dentro e mexes a boca 🧤" },
  { "k": "Fantoche de dedo", "v": "pequenino, encaixa só num dedo ☝️" },
  { "k": "Marioneta de fios", "v": "mexe-se puxando fios lá de cima 🪀" },
  { "k": "Sombras chinesas", "v": "a mão faz uma sombra na parede com a luz 🌙" }
]
```

> **Truque:** para fazer de uma personagem (ou de um fantoche), pensa sempre em três coisas: *como anda? como fala? como se sente?* 🎭

## Um exemplo passo a passo 🔍

Vamos fingir que és um **leão** no palco, sem dizeres uma única palavra. Faz assim:

```steps
[
  { "title": "1. Pensa no leão", "body": "é grande, forte e anda devagar pela savana 🦁" },
  { "title": "2. Põe a cara", "body": "olhar sério e firme, como um rei dos animais 😼" },
  { "title": "3. Usa o corpo", "body": "anda em quatro patas, devagar e com cuidado 🐾" },
  { "title": "4. Faz a ação", "body": "abre muito a boca num grande bocejo… e depois um rugido silencioso! 🦁" },
  { "title": "5. O público percebe", "body": "sem falares, toda a gente sabe que és um leão. É teatro! 👏" }
]
```

> [!TIP] **Para saberes mais** 🌱 Há muito tempo, no teatro antigo da **Grécia**, os atores usavam **máscaras** grandes para mostrar se a personagem estava alegre ou triste — e até para a voz se ouvir mais longe. Eram sempre **homens** a representar, mesmo as personagens de mulher! As máscaras 🎭 — uma a rir e outra a chorar — ainda hoje são o símbolo do teatro no mundo inteiro.
