# Faz de conta: o teatro 🎭

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é o **teatro**, o que faz um **ator**, e como contar uma história só com o **corpo e a cara** (mímica)! 🎭

Quando brincas ao "faz de conta" — médico, super-herói, mãe ou pai — já estás a fazer **teatro**! 🎬 Vestes uma personagem e finges ser outra pessoa, num mundo inventado por ti.

## O que é o teatro? 🎬

No teatro, alguém finge ser outra pessoa para contar uma história a quem está a ver. Cada palavra abaixo é uma peça desse jogo:

```keyvalue
[
  { "k": "Ator", "v": "a pessoa que finge ser uma personagem 🧑‍🎤" },
  { "k": "Personagem", "v": "quem o ator finge ser (um rei, um animal…) 👑" },
  { "k": "Palco", "v": "o sítio onde se representa 🎭" },
  { "k": "Público", "v": "quem assiste e aplaude no fim 👏" },
  { "k": "Cenário", "v": "o que está atrás, a fingir o lugar (uma floresta, um castelo) 🌳" },
  { "k": "Adereço", "v": "um objeto que ajudas a fingir (uma espada, uma coroa) ⚔️" }
]
```

## As emoções na cara 😊😢😡

Um bom ator mostra o que a personagem **sente** só com a cara. Olha como muda:

```keyvalue
[
  { "k": "Alegre", "v": "sorri, olhos a brilhar 😄" },
  { "k": "Triste", "v": "boca para baixo, olhos a fechar 😢" },
  { "k": "Zangado", "v": "sobrancelhas franzidas, boca apertada 😡" },
  { "k": "Surpreso", "v": "boca e olhos muito abertos 😮" },
  { "k": "Com medo", "v": "encolhido, a tremer um bocadinho 😨" }
]
```

## Contar sem falar: a mímica 🤫

Às vezes não dizes nada — falas só com o corpo. Isso chama-se **mímica**:

```steps
[
  { "title": "A cara fala", "body": "sorri (alegre), franze (zangado), boca aberta (surpresa) 😮" },
  { "title": "O corpo fala", "body": "encolhido (com medo), saltar (feliz), arrastar os pés (cansado) 🙆" },
  { "title": "As mãos falam", "body": "podes fingir que abres uma porta ou que comes uma maçã 🚪" },
  { "title": "Sem palavras", "body": "consegues mostrar uma emoção só com o corpo? Experimenta! 🎭" }
]
```

> **Truque:** para fazer de uma personagem, pensa: *como anda? como fala? como se sente?* 🎭

## Um exemplo passo a passo 🔍

Vamos fingir que és um **leão** no palco, sem dizeres uma única palavra. Faz assim:

```steps
[
  { "title": "1. Pensa no leão", "body": "é grande, forte e anda devagar pela savana 🦁" },
  { "title": "2. Põe a cara", "body": "olhar sério e firme, como um rei dos animais 😼" },
  { "title": "3. Usa o corpo", "body": "anda em quatro patas, devagar e com cuidado 🐾" },
  { "title": "4. Faz a ação", "body": "abre muito a boca num grande bocejo… e depois um rugido silencioso! 🦁" },
  { "title": "5. O público percebe", "body": "sem falares, toda a gente sabe que és um leão. É teatro! 👏" }
]
```

> [!TIP] **Para saberes mais** 🌱 Há muito tempo, no teatro antigo da **Grécia**, os atores usavam **máscaras** grandes para mostrar se a personagem estava alegre ou triste — e até para a voz se ouvir mais longe. As máscaras 🎭 ainda hoje são o símbolo do teatro!
