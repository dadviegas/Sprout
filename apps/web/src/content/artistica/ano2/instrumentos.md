# Os instrumentos musicais 🥁

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **famílias** de instrumentos — sopro, corda e percussão — descobrir como cada uma faz som, ouvir muitos exemplos e até reconhecer instrumentos portugueses! 🎶

Alguma vez bateste numa panela com uma colher e fizeste música? Pois então já tocaste um instrumento! 😄 Há instrumentos no mundo inteiro, de todos os tamanhos e feitios. Para os arrumarmos, juntamo-los em **famílias**, conforme a maneira como fazem som. Vem comigo descobrir! 🎵

## Como nasce o som? 🔊

Em todos os instrumentos, o som nasce de algo a **vibrar** — quer dizer, a tremer muito depressa. A vibração faz mexer o ar e o ar leva o som até aos teus ouvidos. 👂

```steps
[
  { "title": "Sopro", "body": "o ar que sopras anda às voltas lá dentro do tubo e faz o som 💨" },
  { "title": "Corda", "body": "a corda treme depressa para cima e para baixo e faz o som 〰️" },
  { "title": "Percussão", "body": "a pele do tambor (ou o metal) treme quando bates — é a família mais antiga do mundo! 👏" }
]
```

## Grave ou agudo? 🐘🐭

Os sons podem ser **graves** (grossos, fortes, como um elefante 🐘) ou **agudos** (finos, altos, como um passarinho 🐭). Os instrumentos grandes fazem sons mais graves; os pequenos fazem sons mais agudos.

## Um exemplo passo a passo 🔍

Tens uma **pandeireta** na mão e queres descobrir a sua família. Faz como um detetive de instrumentos 🕵️:

```steps
[
  { "title": "1. Olha bem para ela", "body": "vês um aro redondo com chapinhas de metal à volta 🪘" },
  { "title": "2. Pergunta: será de sopro?", "body": "não tem nenhum buraco para soprar lá para dentro 🚫" },
  { "title": "3. Pergunta: tem cordas?", "body": "não! Não há cordas para dedilhar nem para passar um arco 〰️" },
  { "title": "4. O que faço, então?", "body": "dás-lhe pancadinhas com a mão ou sacodes para chocalhar 👋" },
  { "title": "5. Já descobriste!", "body": "como se bate e se sacode, a pandeireta é de PERCUSSÃO 🥁" }
]
```

> **Truque:** pensa sempre no que **fazes** com as mãos para tocar — *sopras*, *tocas as cordas* ou *bates/sacodes*? A resposta dá-te logo a família! 🎼

> [!TIP] **Para saberes mais** 🌱 Numa **orquestra** podem juntar-se mais de 80 músicos ao mesmo tempo! 🎻 Há uma pessoa, o **maestro**, que fica à frente com uma varinha (a batuta) e marca o ritmo para que todos toquem juntinhos, sem se atrapalharem. 🪄
