# Os instrumentos musicais 🥁

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **famílias** de instrumentos — sopro, corda e percussão — e como cada uma faz som! 🎶

Há muitos instrumentos no mundo. Para os arrumar, juntamo-los em **famílias**, conforme a forma como fazem som. 🎵

## Como fazem som? 🔊

Em todos os instrumentos, o som nasce de algo a **vibrar** (a tremer muito depressa):

```steps
[
  { "title": "Sopro", "body": "o ar a passar lá dentro faz o som 💨" },
  { "title": "Corda", "body": "a corda a vibrar faz o som 〰️" },
  { "title": "Percussão", "body": "a pancada faz o som — é a família mais antiga! 👏" }
]
```

> **Truque:** pensa no que **fazes** para tocar — *sopras*, *dedilhas as cordas* ou *bates*? Assim descobres a família! 🎼

## Um exemplo passo a passo 🔍

Tens uma **pandeireta** na mão e queres descobrir a sua família. Faz assim:

```steps

  { "title": "3. Tem cordas?", "body": "não! Não há cordas para dedilhar 〰️" },

  { "title": "5. Já sabes!", "body": "como se bate e sacode, a pandeireta é de percussão 🥁" }

```

> [!TIP] **Para saberes mais** 🌱 Em Portugal há a **guitarra portuguesa**, com um som muito especial e doze cordas, usada no **fado** — uma música nossa, reconhecida no mundo inteiro! 🇵🇹🎶
