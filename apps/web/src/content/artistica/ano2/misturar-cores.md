# Misturar cores 🟢

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que, misturando as **cores primárias**, nascem as **cores secundárias** — e como deixar uma cor mais clara, mais escura, quente ou fria! 🎨

Lembras-te das 3 cores primárias (vermelho, amarelo, azul)? Chamam-se primárias porque não se conseguem fazer misturando outras — são o ponto de partida de todas as cores. Quando as juntas, acontece magia! ✨ Pega nos teus lápis ou tintas e vamos pintar juntos. 🖌️

## As 3 cores primárias 🔴🟡🔵

Estas três são as cores-mãe. Não nascem de nenhuma mistura — todas as outras nascem delas:

```keyvalue
[
  { "k": "Vermelho", "v": "como um morango 🍓" },
  { "k": "Amarelo", "v": "como o sol ☀️" },
  { "k": "Azul", "v": "como o céu 🔵" }
]
```

> **Porque «primárias»?** «Primária» quer dizer **primeira**. São as primeiras de todas — sem elas, não havia nenhuma outra cor! 🥇

## Nascem as cores secundárias 🪄

Junta **duas** primárias em partes iguais e aparece uma cor nova — uma **secundária**:

```keyvalue
[
  { "k": "Amarelo + Azul", "v": "= Verde 🟢" },
  { "k": "Vermelho + Amarelo", "v": "= Laranja 🟠" },
  { "k": "Vermelho + Azul", "v": "= Roxo (violeta) 🟣" }
]
```

São só **três** as secundárias: verde, laranja e roxo. Cada uma é filha de duas primárias. 👨‍👩‍👧

## Mais claro ou mais escuro 🌗

A mesma cor pode ter muitos **tons**. Só tens de juntar branco ou preto:

```steps
[
  { "title": "Mais claro", "body": "junta branco → fica um tom suave, como o rosa ou o azul-bebé 🤍", "icon": "🤍" },
  { "title": "Mais escuro", "body": "junta um pouquinho de preto → a cor fica mais forte e funda 🖤", "icon": "🖤" },
  { "title": "Muitos tons", "body": "com mais ou menos branco, a mesma cor dá-te imensos tons diferentes 🎨", "icon": "🎨" }
]
```

> [!WARNING] Cuidado com o **preto**: basta uma pinga! Se puseres muito, a cor escurece de mais e fica quase preta. 🖤

## A roda das cores 🎡

Os pintores arrumam as cores numa **roda das cores**. As cores que ficam **em frente** uma da outra chamam-se **complementares** — lado a lado, ficam ainda mais vivas! 🌈

```keyvalue
[
  { "k": "Vermelho ↔ Verde", "v": "ficam fortes lado a lado ❤️💚" },
  { "k": "Azul ↔ Laranja", "v": "fazem-se notar muito 💙🧡" },
  { "k": "Amarelo ↔ Roxo", "v": "saltam à vista 💛💜" }
]
```

## Um exemplo passo a passo 🔍

Imagina que queres pintar a **relva** de um desenho, mas só tens tintas das cores primárias. Como fazes **verde**? Segue os passos:

```steps
[
  { "title": "1. Pensa na regra", "body": "verde nasce de amarelo + azul 🟡🔵" },
  { "title": "2. Põe amarelo", "body": "começa com uma boa pincelada de amarelo no prato ☀️" },
  { "title": "3. Junta azul", "body": "acrescenta um bocadinho de azul e mistura bem com o pincel 🔵" },
  { "title": "4. Já tens verde!", "body": "olha — apareceu verde, pronto para a relva 🟢" },
  { "title": "5. Queres mais claro?", "body": "junta uma pinga de branco e fica um verde suave, como erva nova 🤍🌱" }
]
```

> **Truque:** as **secundárias** fazem-se sempre com **duas primárias**. Para te lembrares: **VerMelho + Azul = Roxo**, **Amarelo + Azul = verde** (as duas cores do mar e do sol fazem a relva!) e **vermelho + amarelo = laranja** (as duas mais quentes). 🟢🟠🟣

> [!TIP] **Para saberes mais** 🌱 Os pintores às vezes usam só **3 ou 4 cores** e **misturam-nas** para criar dezenas de tons — chamam **paleta** a essa caixa de cores escolhidas. E sabias que num ecrã de televisão ou de telemóvel as cores nascem de só **3 luzinhas**: vermelho, verde e azul? Por isso lhe chamam **RGB** (do inglês *red, green, blue*). 📺🎨
