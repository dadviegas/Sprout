# Misturar cores 🟢

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que, misturando as **cores primárias**, nascem as **cores secundárias** — e como fazer cores mais claras ou mais escuras! 🎨

Lembras-te das 3 cores primárias (vermelho, amarelo, azul)? Chamam-se primárias porque não se conseguem fazer misturando outras — são o ponto de partida. Quando as juntamos, acontece magia! ✨

## As 3 cores primárias 🔴🟡🔵

Estas três são as cores-mãe. Todas as outras nascem delas:

## Nascem as cores secundárias 🪄

Junta duas primárias e aparece uma cor nova — uma **secundária**:

```keyvalue
[
  { "k": "Amarelo + Azul", "v": "= Verde 🟢" },
  { "k": "Vermelho + Amarelo", "v": "= Laranja 🟠" },
  { "k": "Vermelho + Azul", "v": "= Roxo 🟣" }
]
```

> **Truque:** as **secundárias** fazem-se sempre com **duas primárias**. Verde, laranja e roxo são as três secundárias. 🟢🟠🟣

Imagina que queres pintar a relva de um desenho, mas só tens tintas das cores primárias. Como fazes **verde**? Segue os passos:

```steps

  { "title": "1. Pensa na regra", "body": "verde nasce de amarelo + azul 🟡🔵" },
  { "title": "2. Põe amarelo", "body": "começa com uma pincelada de amarelo no prato ☀️" },
  { "title": "3. Junta azul", "body": "acrescenta um bocadinho de azul e mistura bem 🔵" },
  { "title": "4. Já tens verde!", "body": "olha — apareceu verde, pronto para a relva 🟢" },
  { "title": "5. Queres mais claro?", "body": "junta uma pinga de branco e fica um verde suave 🤍" }
]
```

> [!TIP] **Para saberes mais** 🌱 Os pintores às vezes usam só 3 ou 4 cores e **misturam-nas** para criar dezenas de tons. Chama-se a essa caixa de cores escolhidas a **paleta**. 🎨
