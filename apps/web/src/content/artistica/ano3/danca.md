# A dança e o movimento 💃

> [!NOTE] **O que vais aprender** 👀 Vais ver como o **corpo conta histórias** a dançar, e que há muitas formas de mover — depressa, devagar, alto, baixo! 💃🕺

Dançar é mover o corpo ao som da música. Toda a gente pode dançar — basta sentir o ritmo! 🎶

## Dançar uma história 🎭

```steps
[
  { "title": "Ouve a música", "body": "é rápida ou lenta? alegre ou calma? 🎵" },
  { "title": "Deixa o corpo responder", "body": "música alegre → saltos; música calma → movimentos suaves 💫" },
  { "title": "Conta algo", "body": "podes ser uma folha ao vento ou uma onda do mar 🍃🌊" }
]
```

> **Truque:** não há passos "errados" na dança livre — o importante é seguir o **ritmo** e divertires-te! 🎉

> [!TIP] **Para saberes mais** 🌱 Cada povo tem as suas danças. Em Portugal há o **folclore** — danças tradicionais com trajes coloridos, diferentes em cada região e nos Açores! 💃🇵🇹
