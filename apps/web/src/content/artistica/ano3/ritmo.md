# O ritmo e a pulsação 🥁

> [!NOTE] **O que vais aprender** 👀 Vais sentir a **pulsação** (a batida certinha da música) e o **ritmo**, e criar padrões com palmas! 👏

Toda a música tem uma batida que se repete — como o teu **coração**. Chama-se **pulsação**. ❤️

> Quando bates o pé numa música, estás a sentir a **pulsação**! 🦶

## Cria um ritmo com palmas 👏

```steps
[
  { "title": "Bate uma pulsação", "body": "palmas iguais: 1 – 2 – 3 – 4, sempre igual 👏" },
  { "title": "Junta um padrão", "body": "forte-fraco-fraco, forte-fraco-fraco 🔁" },
  { "title": "Repete", "body": "um ritmo é um padrão que se repete! 🎶" }

```

> **Truque:** diz palavras no ritmo! "Cho-co-la-te" tem 4 batidas; "pão" tem 1. As palavras ajudam a sentir o ritmo. 🍫

> [!TIP] **Para saberes mais** 🌱 Os músicos contam a velocidade com uma máquina chamada **metrónomo**, que faz "tic-tic-tic" sempre igual, para não acelerarem nem abrandarem. ⏱️
