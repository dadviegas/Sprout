# O ritmo e a pulsação 🥁

> [!NOTE] **O que vais aprender** 👀 Vais sentir a **pulsação** (a batida certinha da música) e o **ritmo**, e criar padrões com palmas! 👏

Toda a música tem uma batida que se repete — como o teu **coração**. Chama-se **pulsação**. Quando sentes essa batida no corpo, já estás a entrar na música! ❤️

> Quando bates o pé numa música, estás a sentir a **pulsação**! 🦶

## A pulsação está em todo o lado 🌍

## Sílabas viram ritmo 🍫

O segredo para sentir o ritmo é dizer **palavras**! Cada sílaba é uma batida. Conta as batidas destas palavras batendo palmas:

## Um exemplo passo a passo 🔍

Vamos criar um ritmo só nosso, passo a passo. Tens só de bater palmas e contar:

```steps
[
  { "title": "1. Marca a pulsação", "body": "bate palmas iguais e conta: 1 – 2 – 3 – 4, sempre à mesma velocidade 👏" },
  { "title": "2. Acentua a primeira", "body": "bate mais FORTE no 1: FORTE-fraco-fraco-fraco 💥" },
  { "title": "3. Junta um padrão de palavras", "body": "diz 'pi-za, pi-za, ba-na-na, pão' a bater em cada sílaba 🍕🍌" },
  { "title": "4. Repete sem parar", "body": "voltas ao início e repetes — é isso que faz dele um ritmo! 🔁" }
]
```

Repara: a **pulsação** é a batida sempre igual por baixo; o **ritmo** é o padrão de palmas que puseste por cima. 🎶

> **Truque:** diz palavras no ritmo! "Cho-co-la-te" tem 4 batidas; "pão" tem 1. As palavras ajudam o teu corpo a sentir o ritmo sem teres de pensar. 🍫

> [!TIP] **Para saberes mais** 🌱 Os músicos contam a velocidade com uma máquina chamada **metrónomo**, que faz "tic-tic-tic" sempre igual, para não acelerarem nem abrandarem. Hoje há metrónomos no telemóvel, mas os antigos eram de madeira, com um ponteiro a baloiçar! ⏱️
