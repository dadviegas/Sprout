# Pintar, colar, recortar 🖌️

> [!NOTE] **O que vais aprender** 👀 Vais conhecer várias **técnicas** das artes visuais — desenho, pintura, colagem, carimbo e textura — e descobrir como as **cores** se misturam e quando usar cada material! 🎨

Há muitas maneiras de fazer arte com as mãos. Cada uma chama-se uma **técnica**. Aprender técnicas é como ganhar superpoderes: quanto mais souberes, mais coisas consegues criar! E o melhor é que não há jeito "errado" — só o teu jeito. Vamos a isto! ✋

## A linha, a forma e a mancha ✏️

Antes de qualquer técnica, há três coisas que aparecem em quase toda a arte. São os **elementos** do desenho e da pintura:

  { "k": "Forma", "v": "quando a linha se fecha, faz uma forma: círculo, quadrado, triângulo ⬜" },

> **Repara:** com uma linha desenhas o **contorno** de um gato; com uma mancha pintas o gato todo por dentro. Linha e mancha trabalham juntas! 🐱

## Um exemplo passo a passo 🔍

Vamos fazer uma **paisagem em colagem**, do princípio ao fim. Segue a ordem certinha:

```steps
[
  { "title": "1. Pensa na ideia", "body": "imagina o que queres: céu, sol, montes e um campo verde 🏞️" },
  { "title": "2. Escolhe os papéis", "body": "azul para o céu (cor fria), amarelo para o sol (cor quente), verde para o campo 🟦🟨🟩" },
  { "title": "3. Recorta as formas", "body": "corta com a tesoura, com cuidado — um círculo para o sol, montes às ondas ✂️" },
  { "title": "4. Arruma antes de colar", "body": "põe os papéis no sítio e vê se gostas, ANTES de colar 👀" },
  { "title": "5. Cola e deixa secar", "body": "passa cola atrás de cada papel e espera secar bem 🖼️" }
]
```

O segredo é o passo 4: **arrumar antes de colar**. Assim podes mudar de ideias sem estragar o trabalho! 💡

> **Truque:** para fazeres uma cor nova, lembra-te da palavra "VAA" — **V**ermelho, **A**marelo, **A**zul são as primárias. Misturando duas delas, sai sempre uma cor secundária! E não há técnica errada — podes **misturar** desenho, pintura e colagem na mesma obra. É a tua arte! 🎨

> [!TIP] **Para saberes mais** 🌱 Um artista chamado **Henri Matisse**, já muito velhinho e sem poder pintar de pé, criou obras lindíssimas só com **recortes de papel de cor**. Chamou-lhes "pintar com tesoura". E o pintor **Georges Seurat** fez quadros inteiros só com **milhares de pontinhos** de cor, lado a lado — chama-se **pontilhismo**! De longe, os pontos juntam-se e parecem uma imagem inteira. ✂️🔵
