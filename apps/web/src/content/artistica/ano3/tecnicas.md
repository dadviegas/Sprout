# Pintar, colar, recortar 🖌️

> [!NOTE] **O que vais aprender** 👀 Vais conhecer várias **técnicas** de artes visuais — desenho, pintura, colagem e textura — e quando usar cada uma! 🎨

Há muitas maneiras de fazer arte com as mãos. Cada uma chama-se uma **técnica**. Aprender técnicas é como ganhar superpoderes: quanto mais souberes, mais coisas consegues criar! ✋

## Que técnica usar? 🤔

Não há uma técnica melhor do que as outras — há a técnica **certa para o que queres fazer**. Olha estes exemplos:


## Um exemplo passo a passo 🔍

Vamos fazer uma **paisagem em colagem**, do princípio ao fim. Segue a ordem certinha:

```steps
[
  { "title": "1. Pensa na ideia", "body": "imagina o que queres: céu, sol, montes e um campo verde 🏞️" },
  { "title": "2. Escolhe os papéis", "body": "azul para o céu, amarelo para o sol, verde para o campo 🟦🟨🟩" },
  { "title": "3. Recorta as formas", "body": "corta com a tesoura, com cuidado — um círculo para o sol, montes às ondas ✂️" },
  { "title": "4. Arruma antes de colar", "body": "põe os papéis no sítio e vê se gostas, ANTES de colar 👀" },
  { "title": "5. Cola e deixa secar", "body": "passa cola atrás de cada papel e espera secar bem 🖼️" }
]
```

O segredo é o passo 4: **arrumar antes de colar**. Assim podes mudar de ideias sem estragar o trabalho! 💡

> **Truque:** não há técnica "errada"! Podes **misturar** — desenhar, pintar por cima e colar um bocadinho. É a tua arte! 🎨

> [!TIP] **Para saberes mais** 🌱 Um artista chamado **Henri Matisse**, já muito velhinho e sem poder pintar de pé, criou obras lindíssimas só com **recortes de papel de cor**. Chamou-lhes "pintar com tesoura". A colagem pode ser arte a sério, exposta em museus do mundo inteiro! ✂️
