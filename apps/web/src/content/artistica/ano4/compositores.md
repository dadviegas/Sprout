# A música e os compositores 🎼

> [!NOTE] **O que vais aprender** 👀 Vais saber o que faz um **compositor**, o que é uma **orquestra** e conhecer música famosa — do mundo e de Portugal! 🎼

Alguém tem de **inventar** as músicas. Essa pessoa chama-se **compositor** (ou compositora). Ela imagina as melodias na cabeça e depois escreve-as para os músicos poderem tocar. 🎶

## Os instrumentos da música 🎻

Os músicos da orquestra agrupam-se por **famílias** de instrumentos. E o fado tem um instrumento só dele:

```keyvalue
[
  { "k": "Cordas", "v": "violino, viola, violoncelo — tocam-se com um arco 🎻" },
  { "k": "Sopro", "v": "flauta, trompete, clarinete — sopra-se para dentro 🎺" },
  { "k": "Percussão", "v": "tambores, bombo, pratos — bate-se para fazer o ritmo 🥁" },
  { "k": "Guitarra portuguesa 🇵🇹", "v": "tem forma redonda e som choroso — acompanha o fado 🪕" }
]
```

> **Truque:** a música escreve-se com **notas** numa pauta — é como uma escrita secreta que os músicos do mundo inteiro sabem ler! São sempre sete: **dó, ré, mi, fá, sol, lá, si**. 🎼
