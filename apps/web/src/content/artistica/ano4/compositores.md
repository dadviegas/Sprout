# A música e os compositores 🎼

> [!NOTE] **O que vais aprender** 👀 Vais saber o que faz um **compositor**, como se escreve a música em **notas**, o que é uma **orquestra** e as suas famílias de instrumentos — e vais conhecer música famosa do mundo e de Portugal, do fado a Amália! 🎶

Sabias que alguém tem de **inventar** as músicas que ouves? Essa pessoa chama-se **compositor** (ou **compositora**). Ela imagina as melodias na cabeça, decide se a música é alegre ou triste, depressa ou devagar, e depois escreve tudo em **notas**, para que os músicos do mundo inteiro a possam tocar. Vamos descobrir como funciona este mundo cheio de som! 🎵

## Como se escreve a música 🎼

A música escreve-se numa **pauta** (cinco linhas) com sinais chamados **notas**. As notas musicais são sempre **sete**, e repetem-se sempre na mesma ordem:

```steps
[
  { "title": "As 7 notas", "body": "dó, ré, mi, fá, sol, lá, si — depois volta tudo ao dó, mais agudo 🎶" },
  { "title": "A pauta", "body": "são cinco linhas onde se desenham as notas; quanto mais alta na pauta, mais aguda 🎼" },
  { "title": "A clave de sol", "body": "é o sinal no início da pauta que diz aos músicos onde fica cada nota 🎵" },
  { "title": "O ritmo", "body": "algumas notas duram muito tempo, outras muito pouco — é isso que faz o ritmo da música 🥁" }
]
```

## Um exemplo passo a passo 🔍

Imagina que vais a um concerto ouvir uma **orquestra** tocar pela primeira vez. Como percebes o que está a acontecer? Vamos com calma:

```steps
[
  { "title": "1. O compositor já fez o trabalho", "body": "a música que vais ouvir foi inventada e escrita há muito tempo por um compositor 🎼" },
  { "title": "2. O maestro sobe ao palco", "body": "vira-se para os músicos, levanta a batuta — e faz-se silêncio na sala 🤫" },
  { "title": "3. A batuta dá o sinal", "body": "com um gesto, o maestro diz a todos quando começar e se é depressa ou devagar 🪄" },
  { "title": "4. As famílias entram", "body": "ouves as cordas, depois os sopros, e a percussão a marcar o ritmo — tudo junto! 🎻🎺🥁" },
  { "title": "5. No fim, o aplauso", "body": "quando a música acaba, o maestro vira-se e tu bates palmas bem alto 👏" }
]
```

> **Truque:** para nunca te esqueceres das **7 notas**, canta-as a subir uma escadinha: **dó, ré, mi, fá, sol, lá, si** — sobes degrau a degrau e no topo voltas ao dó! 🎵🪜

> [!TIP] **Para saberes mais** 🌱 **Amália Rodrigues** foi a maior cantora de **fado** de sempre. A voz dela levou a música portuguesa a todo o mundo, e quando morreu, em 1999, Portugal parou para a chorar. Hoje está no **Panteão Nacional**, onde repousam as grandes figuras do país. E sabias que o fado é **Património da Humanidade** desde 2011? 🇵🇹🎶
