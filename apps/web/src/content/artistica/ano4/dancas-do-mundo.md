## O que faz uma dança tradicional ✨

Uma dança tradicional não é só mexer os pés. Tem sempre estas partes:

```keyvalue
[
  { "k": "Música", "v": "tocada por instrumentos da terra, como a concertina ou a guitarra 🎶" },
  { "k": "Trajes", "v": "roupas coloridas e bonitas, próprias de cada região 👗" },
  { "k": "Passos", "v": "movimentos que se repetem e que toda a gente conhece 👣" },
  { "k": "Pares ou roda", "v": "dança-se a dois ou todos juntos, de mãos dadas 🤝" }
]
```

> **Truque:** uma dança tradicional conta como vivia um povo — o trabalho no campo, as festas, o namoro. É história a dançar! 📖

> [!TIP] **Para saberes mais** 🌱 Muitas danças tradicionais passam de **avós para netos**, sem estarem escritas em lado nenhum — aprendem-se a ver e a imitar. Por isso há **ranchos folclóricos**: grupos que se juntam só para as manter vivas e não as deixar acabar! 💞
