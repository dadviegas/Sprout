# Pintores famosos 🖼️

> [!NOTE] **O que vais aprender** 👀 Vais conhecer alguns **pintores famosos** — do mundo e de Portugal — e perceber que cada um tem o seu **estilo**! 🖼️

Ao longo da história, houve artistas que pintaram quadros tão especiais que ainda hoje os admiramos em **museus**. Cada um pintava à sua maneira. 🏛️

Por isso, às vezes, basta olhar para um quadro para adivinhar quem o pintou! 👀

## As cores na pintura 🌈

Os pintores misturam **cores primárias** para fazer todas as outras. São só três:

```keyvalue
[
  { "k": "Vermelho", "v": "como um morango 🍓" },
  { "k": "Azul", "v": "como o céu limpo 🔵" },
  { "k": "Amarelo", "v": "como o sol ☀️" },
  { "k": "Truque", "v": "azul + amarelo = verde · vermelho + amarelo = laranja 🎨" }
]
```

> **Truque:** quando vires um quadro, pergunta: *o que sinto ao olhar?* A arte serve para sentir, não há resposta errada. 💭
