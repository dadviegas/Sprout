# Os meus direitos e deveres ⚖️

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é um **direito** (algo a que tens direito) e um **dever** (algo que deves fazer), e que andam sempre **juntos**! 🤝

Todas as crianças têm **direitos** — coisas importantes para crescerem felizes. E também têm **deveres** — coisas que ajudam todos a viver bem.

## E os deveres? 🙋

Um **dever** é a outra metade. Por exemplo: tens direito a uma escola limpa → tens o dever de **não sujar**.

```steps
[
  { "title": "Respeitar os outros", "body": "tratar todos com gentileza 😊" },
  { "title": "Ajudar em casa", "body": "arrumar os teus brinquedos 🧹" },
  { "title": "Cumprir as regras", "body": "esperar pela tua vez, ouvir os outros ✋" }
]
```

> **Truque:** a cada **direito** corresponde um **dever**. Tens direito a ser respeitado → tens o dever de respeitar! 🔁

> [!TIP] **Para saberes mais** 🌱 Há um documento muito importante chamado a **Convenção dos Direitos da Criança**, assinado por quase todos os países do mundo, só para proteger as crianças! 🌍
