> [!NOTE] **O que vais aprender** 👀 Vais aprender a **separar o lixo** nos ecopontos certos e pequenos truques para **cuidar do planeta**! 🌍

A Terra é a nossa casa grande. Se cuidarmos dela, fica bonita e saudável para todos. 🌱

## Um exemplo passo a passo 🔍

Acabaste de beber um sumo na caixinha de cartão. Para onde vai? Vamos pensar juntos:

```steps
[
  { "title": "1. Olha bem", "body": "é uma embalagem de bebida (cartão com plástico por dentro) 🧃" },
  { "title": "2. Esvazia", "body": "bebe até ao fim para não ficar a pingar 💧" },
  { "title": "3. Espalma", "body": "achata a caixinha para ocupar menos espaço 🤏" },
  { "title": "4. Ecoponto amarelo", "body": "as embalagens de bebidas vão para o amarelo! 🟡" }
]
```

> [!TIP] **Para saberes mais** 🌱 Há a regra dos **3 R**: **Reduzir** (gastar menos), **Reutilizar** (usar outra vez) e **Reciclar** (transformar em algo novo). Reduzir é o mais importante! ♻️
