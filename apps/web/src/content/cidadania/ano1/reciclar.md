# Reciclar e cuidar da Terra ♻️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **separar o lixo** nos ecopontos certos, a regra dos **3 R** e pequenos truques para **cuidar do planeta** todos os dias! 🌍

A Terra é a nossa casa grande. Tem terra para plantar, água para beber e ar para respirar. Se cuidarmos dela, fica bonita e saudável para todos — para ti, para os teus amigos e até para os animais! 🌱 E o mais giro é que tu, mesmo sendo pequenino, já podes ajudar muito. Vamos a isso? 💪

## O que é reciclar ♻️

Reciclar é dar uma **nova vida** ao lixo. Em vez de deitar tudo fora, separamos as coisas para que possam ser transformadas em objetos novos! 🪄


> **Truque:** *reciclar* tem a palavra **ciclo** lá dentro — é como uma roda que dá voltas: o lixo volta a ser uma coisa nova! 🔄

## A regra dos 3 R 🔁

Antes de reciclar, há duas coisas ainda melhores! São os **3 R**, por ordem de importância:

```steps
[
  { "title": "1. Reduzir", "body": "gastar menos: o melhor lixo é o que não fazemos 🌱", "icon": "🌱" },
  { "title": "2. Reutilizar", "body": "usar outra vez: um frasco vazio vira um porta-lápis ✏️", "icon": "🔁" },
  { "title": "3. Reciclar", "body": "transformar em algo novo, separando no ecoponto certo ♻️", "icon": "♻️" }
]
```

> **Truque:** os 3 R começam todos por **RE**, como em *RE-petir*. E lembra-te da ordem: primeiro **Reduzir**, depois **Reutilizar** e só no fim **Reciclar**. 🥇

## Um exemplo passo a passo 🔍

Acabaste de beber um sumo na caixinha de cartão. Para onde vai? Vamos pensar juntos:

```steps

  { "title": "1. Olha bem", "body": "é uma embalagem de bebida (cartão com plástico por dentro) 🧃", "icon": "🧐" },
  { "title": "2. Esvazia", "body": "bebe até ao fim para não ficar a pingar 💧", "icon": "💧" },
  { "title": "3. Espalma", "body": "achata a caixinha para ocupar menos espaço 🤏", "icon": "🤏" },
  { "title": "4. Ecoponto amarelo", "body": "as embalagens de bebidas vão para o amarelo! 🟡", "icon": "🟡" }

```

> **Truque:** antes de pôres uma coisa no ecoponto, faz duas perguntas: **«de que é feito?»** (papel, plástico, vidro?) e **«está vazio e limpo?»**. Assim acertas sempre! ✅

> [!TIP] **Para saberes mais** 🌱 Sabias que com **garrafas de plástico recicladas** se fabricam **camisolas** e até **mochilas**? E com o vidro fazem-se garrafas novas, vezes sem conta, sem nunca estragar! Reciclar é mesmo magia. 🪄
