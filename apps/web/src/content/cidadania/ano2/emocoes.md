# As emoções e resolver zangas 😊

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **dar nome** ao que sentes e a resolver **zangas com palavras**, sem bater nem gritar. 💬

Todos sentimos coisas: alegria, tristeza, medo, raiva… As emoções não são más — só precisam de ser **compreendidas**. 💛

## Resolver uma zanga 🤝

```steps
[
  { "title": "1. Para e respira", "body": "respira fundo 3 vezes antes de fazer nada 🌬️" },
  { "title": "2. Usa palavras", "body": "diz como te sentes: 'Fiquei triste quando…' 💬" },
  { "title": "3. Ouve o outro", "body": "deixa o outro também explicar 👂" },
```

> **Truque do semáforo:** 🔴 **para**, 🟡 **pensa**, 🟢 **age** com calma. 🚦

> [!TIP] **Para saberes mais** 🌱 Quando estamos muito zangados, o coração bate mais depressa. **Respirar devagar** acalma o corpo de verdade — os cientistas já provaram! 🧠
