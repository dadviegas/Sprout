# As emoções e resolver zangas 😊

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **dar nome** ao que sentes e a resolver **zangas com palavras**, sem bater nem gritar. 💬

Todos sentimos coisas: alegria, tristeza, medo, raiva… As emoções não são más — só precisam de ser **compreendidas**. Até os crescidos as sentem! 💛

## Dar nome ao que sinto 🎭

Cada emoção tem um nome. Quando sabes qual é, fica muito mais fácil de lidar com ela:

```keyvalue
[
  { "k": "Alegria", "v": "quando algo corre bem 😄" },
  { "k": "Tristeza", "v": "quando perdemos algo ou alguém 😢" },
  { "k": "Medo", "v": "quando algo nos assusta 😨" },
  { "k": "Raiva", "v": "quando algo nos parece injusto 😠" },
  { "k": "Surpresa", "v": "quando acontece algo que não esperavas 😲" },
  { "k": "Vergonha", "v": "quando ficas com as bochechas quentes 😳" }
]
```

> Quando sabes **dar nome** ao que sentes, fica mais fácil de controlar. Dizer "estou zangado" já ajuda! 🗣️

## O que o corpo sente 🫀

As emoções não estão só na cabeça — sentem-se no corpo todo. Aprende a reconhecê-las:

```keyvalue
[
  { "k": "Quando tens medo", "v": "o coração bate forte e a barriga aperta 💓" },
  { "k": "Quando tens raiva", "v": "a cara fica quente e os punhos cerram-se 🔥" },
  { "k": "Quando estás triste", "v": "apetece chorar e o peito fica pesado 😢" },
  { "k": "Quando estás feliz", "v": "sorris e tens vontade de saltar 🤗" }
]
```

## Resolver uma zanga 🤝

Quando te zangas com alguém, há um caminho calmo para resolver tudo:

```steps
[
  { "title": "1. Para e respira", "body": "respira fundo 3 vezes antes de fazer nada 🌬️" },
  { "title": "2. Usa palavras", "body": "diz como te sentes: 'Fiquei triste quando…' 💬" },
  { "title": "3. Ouve o outro", "body": "deixa o outro também explicar 👂" },
  { "title": "4. Encontrem solução", "body": "pedir desculpa ou combinar uma regra 🤝" }
]
```

> **Truque do semáforo:** 🔴 **para**, 🟡 **pensa**, 🟢 **age** com calma. 🚦

## Um exemplo passo a passo 🔍

Imagina que estavas a brincar e um colega tirou-te o brinquedo das mãos. Sentes raiva! O que fazes?

```steps
[
  { "title": "1. Sinal vermelho 🔴", "body": "paras. Não bates nem gritas — respiras fundo 3 vezes 🌬️" },
  { "title": "2. Sinal amarelo 🟡", "body": "pensas: 'Estou com raiva porque queria continuar a brincar' 🤔" },
  { "title": "3. Sinal verde 🟢", "body": "falas com calma: 'Fiquei zangado. Era a minha vez do brinquedo' 💬" },
  { "title": "4. Ouve", "body": "deixas o colega explicar — talvez ele não tenha percebido 👂" },
  { "title": "5. Resolvem juntos", "body": "combinam dividir o tempo: um bocado cada um 🤝" }
]
```

> [!TIP] **Para saberes mais** 🌱 Quando estamos muito zangados, o coração bate mais depressa e o corpo fica tenso. **Respirar devagar** envia um sinal de calma ao cérebro e acalma o corpo de verdade — os cientistas já provaram! 🧠
