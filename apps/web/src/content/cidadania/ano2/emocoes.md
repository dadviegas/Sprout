# As emoções e resolver zangas 😊

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **dar nome** ao que sentes, a perceber o que o teu **corpo** te diz e a resolver **zangas com palavras**, sem bater nem gritar. 💬

Todos nós sentimos coisas: alegria, tristeza, medo, raiva… As emoções não são boas nem más — só precisam de ser **compreendidas**. Até os crescidos as sentem todos os dias! O segredo é aprender a reconhecê-las e a lidar com elas com calma. Vamos a isso juntos? 💛

## Dar nome ao que sinto 🎭

Cada emoção tem um nome. Quando sabes qual é, fica muito mais fácil de lidar com ela. Vamos conhecer as principais:

> Quando sabes **dar nome** ao que sentes, fica mais fácil de controlar. Dizer "estou zangado" já ajuda muito! 🗣️

## O que o corpo sente 🫀

As emoções não estão só na cabeça — sentem-se no **corpo todo**. O corpo dá-te pistas! Aprende a reconhecê-las:

```keyvalue
[
  { "k": "Quando tens medo", "v": "o coração bate forte e a barriga aperta 💓" },
  { "k": "Quando tens raiva", "v": "a cara fica quente e os punhos cerram-se 🔥" },
  { "k": "Quando estás triste", "v": "apetece chorar e o peito fica pesado 😢" },
  { "k": "Quando estás feliz", "v": "sorris e tens vontade de saltar 🤗" },
  { "k": "Quando tens vergonha", "v": "as bochechas ficam quentes e vermelhas 😳" }

```

> Estas pistas do corpo são como um **alarme amigo**: avisam-te do que estás a sentir antes mesmo de pensares nisso. 🔔

## Emoções que ajudam, emoções que custam 😄😢

## Resolver uma zanga 🤝

Quando te zangas com alguém, há um caminho calmo para resolver tudo. Não é com gritos nem com força — é com **palavras**:

```steps
[
  { "title": "1. Para e respira", "body": "respira fundo 3 vezes antes de fazer ou dizer nada 🌬️" },
  { "title": "2. Usa palavras", "body": "diz como te sentes: 'Fiquei triste quando…' 💬" },
  { "title": "3. Ouve o outro", "body": "deixa o outro também explicar o que sentiu 👂" },
  { "title": "4. Encontrem solução", "body": "pedir desculpa, fazer as pazes ou combinar uma regra 🤝" }
]
```

> **Truque do semáforo:** 🔴 **para**, 🟡 **pensa**, 🟢 **age** com calma. 🚦

## Palavras que acalmam e palavras que ferem 💬

As palavras têm muita força. Umas ajudam a fazer as pazes, outras só aumentam a zanga. Escolhe bem!

```keyvalue
[
  { "k": "Palavras que acalmam", "v": "'desculpa', 'eu senti…', 'podemos combinar?' 🕊️" },
  { "k": "Palavras que ferem", "v": "insultos, gritos, 'a culpa é tua!' ⚡" },
  { "k": "O melhor começo", "v": "falar de ti — 'EU fiquei triste' — em vez de acusar 💙" },
  { "k": "Pedir ajuda", "v": "se não conseguem resolver, chamem um adulto de confiança 🙋" }
]
```

> [!WARNING] Bater, empurrar ou chamar nomes **nunca** resolve uma zanga — só a torna maior. As palavras calmas são muito mais fortes! 💪

## Um exemplo passo a passo 🔍

Imagina que estavas a brincar e um colega tirou-te o brinquedo das mãos. Sentes raiva! O que fazes?

```steps
[
  { "title": "1. Sinal vermelho 🔴", "body": "paras. Não bates nem gritas — respiras fundo 3 vezes 🌬️" },
  { "title": "2. Sinal amarelo 🟡", "body": "pensas: 'Estou com raiva porque queria continuar a brincar' 🤔" },
  { "title": "3. Sinal verde 🟢", "body": "falas com calma: 'Fiquei zangado. Era a minha vez do brinquedo' 💬" },
  { "title": "4. Ouve", "body": "deixas o colega explicar — talvez ele não tenha percebido 👂" },
  { "title": "5. Resolvem juntos", "body": "combinam dividir o tempo: um bocadinho cada um 🤝" }
]
```

> **Truque:** quando a raiva chegar, conta devagar **até 5** a respirar fundo. Quase sempre, ao chegares ao 5, já estás mais calmo para falar. 🖐️

> [!TIP] **Para saberes mais** 🌱 Quando estamos muito zangados, o coração bate mais depressa e o corpo fica tenso. **Respirar devagar** envia um sinal de calma a uma parte do cérebro chamada **amígdala** — é ela que liga o "alarme" da raiva. Os cientistas já provaram que respirar fundo acalma o corpo de verdade! 🧠
