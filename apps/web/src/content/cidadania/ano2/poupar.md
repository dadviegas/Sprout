# Poupar e gastar bem 🐷

> [!NOTE] **O que vais aprender** 👀 Vais perceber a diferença entre **querer** e **precisar**, de onde vem o dinheiro, e como **poupar** no mealheiro para aquilo que é mesmo importante. 💰

O dinheiro não cai do céu nem nasce nas árvores — **ganha-se com trabalho**! Por isso vale a pena aprender a usá-lo com cabeça. 🧠 Quando aprendes a poupar e a escolher bem, ficas com poder para ter aquilo de que precisas e, aos poucos, também aquilo que mais queres. Bora lá! 🚀

## De onde vem o dinheiro? 💼

O dinheiro não aparece sozinho na carteira. As pessoas crescidas **trabalham** e, em troca, recebem dinheiro para comprar o que a família precisa.

## Querer ou precisar? 🤔

Há coisas de que mesmo **precisamos** para viver e há coisas que só nos **apetecem**. Saber a diferença ajuda-te a escolher bem:

```keyvalue
[
  { "k": "Precisar", "v": "coisas mesmo importantes: comida, água, roupa, escola, casa 🍎" },
  { "k": "Querer", "v": "coisas que apetecem mas dá para viver sem: um brinquedo novo, doces 🍬" },
  { "k": "A regra de ouro", "v": "primeiro o que precisamos, só depois o que queremos ✅" }
]
```

> Não há mal nenhum em **querer** coisas! Só vem **depois** do que é mesmo preciso.
