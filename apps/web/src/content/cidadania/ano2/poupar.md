# Poupar e gastar bem 🐷

> [!NOTE] **O que vais aprender** 👀 Vais perceber a diferença entre **querer** e **precisar**, e como **poupar** no mealheiro para o que é importante. 💰

O dinheiro não cai do céu — ganha-se com trabalho. Por isso aprendemos a usá-lo com cabeça! 🧠

## Querer ou precisar? 🤔

Há coisas de que mesmo precisamos para viver e há coisas que só nos apetecem. Aprender a diferença ajuda-te a escolher bem:

```keyvalue
[
  { "k": "Precisar", "v": "coisas mesmo importantes: comida, roupa, escola 🍎" },
  { "k": "Querer", "v": "coisas que apetecem: um brinquedo novo, doces 🍬" },
  { "k": "A regra", "v": "primeiro o que precisamos, depois o que queremos ✅" }
]
```

> Não há mal em **querer** coisas! Só vem **depois** do que é mesmo preciso.

## Poupar no mealheiro 🐷

Poupar é guardar um bocadinho em vez de gastar tudo. Faz-se assim:

```steps
[
  { "title": "Guarda um bocadinho", "body": "sempre que tens dinheiro, guarda uma parte 🪙" },
  { "title": "Tem um objetivo", "body": "poupa para algo especial que queres muito 🎯" },
  { "title": "Espera e junta", "body": "aos poucos, o mealheiro enche! 🐷" }
]
```

> **Truque:** antes de gastar, pergunta: *"Preciso mesmo disto ou só me apetece agora?"* 💭

## Um exemplo passo a passo 🔍

Imagina que queres muito um carrinho que custa **5 moedas**. Tu só tens **1 moeda** por semana. Como fazes?

```steps
[
  { "title": "1. Vê quanto custa", "body": "o carrinho custa 5 moedas 🚗" },
  { "title": "2. Vê quanto tens", "body": "recebes 1 moeda por semana 🪙" },
  { "title": "3. Faz as contas", "body": "5 moedas a 1 por semana = 5 semanas a juntar 🗓️" },
  { "title": "4. Guarda no mealheiro", "body": "cada semana metes a moeda e não gastas 🐷" },
  { "title": "5. Chegaste ao objetivo!", "body": "na 5.ª semana já tens 5 moedas — compras o carrinho! 🎉" }
]
```

> [!TIP] **Para saberes mais** 🌱 As pessoas crescidas guardam dinheiro num **banco**, que o mantém seguro. Às vezes o banco até dá um bocadinho a mais por o guardarmos lá — chamam-lhe **juros**. É como se o teu dinheiro crescesse sozinho! 🏦
