# Bullying: reconhecer, parar e pedir ajuda 🛡️

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é **bullying**, como distinguir uma zanga normal de uma situação repetida que magoa, o que fazer se acontecer contigo ou com um colega, e porque pedir ajuda é um ato de coragem.

Às vezes, as pessoas zangam-se. Isso pode acontecer numa brincadeira, num jogo ou numa conversa. Mas **bullying** é diferente: acontece quando alguém magoa, goza, ameaça ou exclui outra pessoa **de propósito** e **muitas vezes**.

## Zanga ou bullying? 🤔

Uma zanga pode acontecer uma vez e depois resolver-se. O bullying repete-se e deixa a pessoa com medo, triste ou envergonhada.

## O que fazer se acontecer? 🧭

Se fores vítima ou vires acontecer, há passos simples que ajudam.

```steps

  { "title": "2. Diz com firmeza", "body": "usa uma frase curta: 'Para. Isso magoa.'" },
  { "title": "3. Guarda provas", "body": "se for online, não apagues logo: mostra a um adulto" },
  { "title": "4. Conta a alguém", "body": "professor, família, assistente, psicólogo ou direção" },
  { "title": "5. Não fiques sozinho", "body": "pede a um colega de confiança para estar contigo" }
```

> **Truque:** se é **repetido**, **magoa** e alguém usa força, grupo ou medo para mandar no outro, pode ser bullying. A palavra-chave é: **ajuda**.
