# Consumir com cabeça 🛒

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é a **publicidade**, porque é que ela tenta convencer-te, e como fazer **escolhas espertas** quando compras. 🧠

Vês anúncios na TV, nos jogos, na rua… Muitos querem que **queiras** comprar. Vamos aprender a pensar antes! 🤓

## Comprar com cabeça 🧠

```steps
[
  { "title": "Pensa se precisas", "body": "queres mesmo ou é só o anúncio a falar? 💭" },
  { "title": "Compara", "body": "vê se há outro parecido, melhor ou mais barato ⚖️" },
  { "title": "Vê a validade e o preço", "body": "lê o rótulo e quanto custa mesmo 🏷️" }

```

> **Truque:** quando ouvires *"compra já, só hoje!"*, desconfia — é um truque para não pensares. Respira e decide com calma. 🛑

## Um exemplo passo a passo 🔍

A Maria viu na TV uns ténis com luzes que "fazem correr mais depressa". Quis logo! Vamos pensar com ela, passo a passo:

```steps
[
  { "title": "1. Preciso ou só quero?", "body": "a Maria já tem ténis bons. Isto é um 'quero', não um 'preciso' 🤔" },
  { "title": "2. O anúncio é verdade?", "body": "luzes não te fazem correr mais depressa — isso é exagero 💡" },
  { "title": "3. Comparar", "body": "há outros ténis parecidos, sem luzes, mais baratos 💰" },
  { "title": "4. Decidir com calma", "body": "a Maria espera, pensa uns dias e já não quer tanto. Poupou dinheiro! 🎉" }
]
```

> [!TIP] **Para saberes mais** 🌱 Quem compra tem **direitos de consumidor**: se algo vier estragado, pode ser **trocado ou devolvido**. Por isso se guarda o talão (recibo)! Em Portugal há até o **Livro de Reclamações** para quando uma loja não te trata bem. 🧾
