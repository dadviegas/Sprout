# Internet segura 💻

> [!NOTE] **O que vais aprender** 👀 Vais aprender regras para usares a **internet** e os **ecrãs** em segurança, a guardar os teus **dados secretos**, a desconfiar de **estranhos** e de **mensagens enganosas**, e a pedir ajuda sempre que algo te deixar desconfortável. 🛡️

A internet é fantástica: dá para aprender, jogar, ver vídeos e falar com a família que está longe. Mas, tal como na rua, há **regras** que te protegem. Não tenhas medo — só tens de seres esperto e saber pedir ajuda. Vamos aprender juntos a navegar em segurança! 🌐

## Regras de ouro 🛡️

Estas são as quatro regras mais importantes. Decora-as bem, porque te protegem em qualquer site, jogo ou aplicação:

```keyvalue
[
  { "k": "Dados secretos", "v": "nunca dês nome, morada ou escola a estranhos online 🤐" },
  { "k": "Palavra-passe", "v": "é como a chave de casa — só tu e os pais a sabem 🔑" },
  { "k": "Estranhos", "v": "não falas com quem não conheces na vida real 🙅" },
  { "k": "Pede ajuda", "v": "se algo te assustar, conta logo a um adulto de confiança 🗣️" }
]
```

> A internet não é boa nem má — depende de como a usas. Com estas regras, ela fica do teu lado! 😊

## Dados que se guardam 🤐

Há informações sobre ti que são **só tuas** e da tua família. Chamam-se **dados pessoais**. Nunca os dês a quem não conheces:

```keyvalue
[
  { "k": "O teu nome completo", "v": "guarda-o para ti 🙊" },
  { "k": "Onde moras", "v": "morada e nome da escola são segredo 🏠" },
  { "k": "Fotografias", "v": "pergunta sempre a um adulto antes de partilhar 📸" },
  { "k": "Número de telemóvel", "v": "não se dá a estranhos online 📵" },
  { "k": "Onde estás agora", "v": "não digas em que sítio estás neste momento 📍" }
]
```

> Na internet, nem toda a gente é quem diz ser. Alguém pode escrever "tenho 9 anos" e ser um adulto. Por isso, cuidado com estranhos! 🕵️

## Uma palavra-passe forte 🔐

A **palavra-passe** é a chave que tranca as tuas coisas. Se for fraca, qualquer pessoa entra; se for forte, fica tudo seguro. Compara estas duas:

```compare

```

> **Sabias?** Uma boa palavra-passe pode ser uma frase divertida que só tu te lembras, como *"O meu cão come 3 bolachas!"*. É comprida, fácil para ti e difícil para os outros. 🐶

## Estranhos e segredos online 🚨

Na internet podes receber mensagens de pessoas que não conheces. Aprende a reconhecer os **sinais de alarme** e o que deves fazer:

```keyvalue
[
  { "k": "Pede dados teus", "v": "morada, escola ou fotografias — não dás 🤐" },
  { "k": "Quer falar em segredo", "v": "'não contes aos pais' é um grande aviso 🚩" },
  { "k": "Diz coisas más", "v": "mensagens que magoam são bullying — conta a um adulto 💔" },
  { "k": "Quer encontrar-se", "v": "nunca te encontras com estranhos da internet 🙅" }
]
```

> [!WARNING] Se alguém te pedir para guardar um **segredo dos teus pais**, isso é um sinal de perigo! Os adultos de confiança nunca te pedem para esconderes coisas da tua família. Conta sempre. 🗣️

## Verdade ou mentira na internet? 🧐

Nem tudo o que aparece online é verdade. Há notícias falsas, fotografias trocadas e jogos que prometem prendas só para te enganar. Antes de acreditares, **pensa**:

```steps
[
  { "title": "Quem disse isto?", "body": "vê se vem de um sítio de confiança ou de um estranho 🔎" },
  { "title": "Parece bom demais?", "body": "'ganhaste um telemóvel!' é quase sempre mentira 🎁" },
  { "title": "Pergunta a um adulto", "body": "na dúvida, mostra a um adulto antes de carregares 🗣️" },
  { "title": "Não carregues em tudo", "body": "links e botões a piscar podem ser uma armadilha 🖱️" }
]
```

> **Imagina** que um jogo diz: *"Carrega aqui e ganhas 1000 moedas grátis!"*. Quase sempre é só um truque para te enganar ou pedir dados. Desconfia e pergunta a um adulto. 🤔

## Tempo de ecrã ⏰

Os ecrãs são divertidos, mas o teu corpo também precisa de se mexer, dormir e brincar lá fora. Combina o tempo com os teus pais:

```steps
[
  { "title": "Combina um tempo", "body": "com os pais, combina quanto tempo usas 🕐" },
  { "title": "Faz pausas", "body": "levanta-te e mexe-te de vez em quando 🤸" },
  { "title": "Nada de ecrãs na cama", "body": "antes de dormir, o ecrã atrapalha o sono 😴" },
  { "title": "Há vida lá fora", "body": "brincar na rua e ler também são divertidos! 🌳" }
]
```

```meters
[
  { "label": "📱 Pouco ecrã, muito brincar", "value": 9, "max": 10, "tone": "ok" },
  { "label": "🛋️ Ecrã o dia todo", "value": 2, "max": 10, "tone": "danger" }
]
```

> Os olhos e o corpo agradecem quando fazes pausas. Olha pela janela e mexe-te! 👀

> **Truque:** antes de carregares em "publicar" ou "enviar", pensa: *"Mostraria isto à minha avó?"* Se não, não envias. 👵

## Um exemplo passo a passo 🔍

Estás a jogar online e aparece uma mensagem: *"Olá! Onde moras? Mandas-me uma foto tua?"*. O que fazes, passo a passo?

```steps
[
  { "title": "1. Parar", "body": "não respondes logo — paras e pensas 🛑" },
  { "title": "2. Reconhecer o perigo", "body": "um estranho a pedir morada e foto? Isso é um sinal de alarme 🚨" },
  { "title": "3. Não dar nada", "body": "não dás a morada nem a foto, nem dizes onde estudas 🤐" },
  { "title": "4. Não responder", "body": "não falas com o estranho nem mandas mensagens de volta 🙅" },
  { "title": "5. Contar a um adulto", "body": "chamas logo um adulto de confiança para ver contigo 🗣️" }
]
```

> [!TIP] **Para saberes mais** 🌱 Tudo o que pões na internet pode lá ficar **para sempre**, mesmo que apagues — é a tua **pegada digital**. Até as fotografias podem ser copiadas por outros antes de as apagares. Em Portugal e na Europa há até uma lei (o **RGPD**) que protege os teus dados pessoais, e há uma linha de ajuda gratuita, a **Linha Internet Segura**, para quando algo corre mal online. Por isso pensa bem antes de publicar! 👣
