# Regras, votar e decidir juntos 🗳️

> [!NOTE] **O que vais aprender** 👀 Vais perceber porque existem **regras**, o que é **votar** e como um grupo pode **decidir junto**, de forma justa. 🤝

Quando muita gente vive junta, são precisas **regras** para todos viverem bem e em paz. E há uma forma justa de decidir: **votar**! 🗳️

## Porquê regras? 📏

As regras não aparecem por acaso — cada uma tem um motivo. Olha para o que elas fazem por nós:

> As regras não são para chatear — são para todos estarem bem e seguros.

## Um exemplo passo a passo 🔍

A tua turma vai escolher o nome do peixinho da sala. Há três ideias: **Bolha**, **Nemo** e **Risca**. Como decidir de forma justa?

```steps
[
  { "title": "1. Ouvir as ideias", "body": "cada um diz qual o nome de que mais gosta 🗣️" },
  { "title": "2. Votar uma vez cada", "body": "põe-se o dedo no ar por cada nome, sem repetir ✋" },
  { "title": "3. Contar os votos", "body": "Bolha 8, Nemo 6, Risca 4 — escreve-se no quadro 🔢" },
  { "title": "4. Ganha a maioria", "body": "Bolha teve mais votos: o peixe fica Bolha! 🐠" },
  { "title": "5. Respeitar a decisão", "body": "quem queria Nemo ou Risca também aceita 🤝" }
]
```

> Repara: ninguém gritou nem fez birra. Contaram-se os votos e a decisão foi de **toda a turma** — por isso é justa.

> **Truque:** se a turma não chega a acordo, **votem**! É a forma mais justa: ganha o que a **maioria** quer. ✋

> [!TIP] **Para saberes mais** 🌱 Quando um país decide as coisas votando e ouvindo o povo, chama-se **democracia**. Em Portugal, as pessoas crescidas votam para escolher quem governa — e a Assembleia da República é onde os deputados, escolhidos por nós, fazem as leis! 🇵🇹
