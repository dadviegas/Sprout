# Cuidar dos recursos do planeta 🌍

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que são **recursos naturais**, porque é que alguns se podem **acabar**, e hábitos para os poupar. 🌱

A água, a energia, as árvores… vêm da natureza. Chamam-se **recursos**. Alguns são preciosos e temos de os usar com cuidado! 💧⚡

## Um exemplo passo a passo 🔍

Vais lavar os dentes. Vamos ver como poupar **muita** água com um gesto simples:

```steps

  { "title": "1. Molha a escova", "body": "abre a torneira só um instante 💧" },
  { "title": "2. Fecha a torneira", "body": "enquanto escovas, a água NÃO precisa de estar a correr 🚱" },
  { "title": "3. Escova com calma", "body": "dois minutos, sem pressa e sem água a correr 🪥" },
  { "title": "4. Abre só para bochechar", "body": "no fim, abres outra vez por um instante 🥤" },
  { "title": "5. Resultado", "body": "poupaste muitos litros — só por fechar a torneira! 🎉" }

```

> Repara: não fizeste nada de difícil. Só fechaste a torneira no momento certo. É assim que se cuida do planeta — com pequenos gestos.

> **Truque:** "**Se não estás a usar, podes desligar.**" Vale para a luz, a água e a TV! 🔁

> [!TIP] **Para saberes mais** 🌱 A marca que cada pessoa deixa no planeta com o que gasta chama-se **pegada ecológica**. Quanto mais poupamos e menos lixo fazemos, mais pequena (e melhor!) fica essa pegada. 👣🌍
