# Educação ambiental 🌱

> [!NOTE] **O que vais aprender** 👀 Porque é que o nosso planeta precisa de **cuidados**, o que são as **alterações climáticas**, como funcionam os **3 R** (Reduzir, Reutilizar, Reciclar), como **poupar água e energia**, e como pequenos gestos teus podem fazer uma **grande** diferença. 🌍💚

A Terra é a nossa **única casa** — não há outra para onde mudar! 🌍 Ela dá-nos ar para respirar, água para beber, comida e abrigo. Mas, às vezes, sem querer, fazemos-lhe mal: deitamos lixo, gastamos demais, poluímos. A boa notícia? Tu já podes ajudar a cuidar dela, todos os dias. Vem ver como! 💚

## As alterações climáticas 🌡️

Quando queimamos muito carvão, petróleo e gás (nos carros, nas fábricas), libertamos gases que ficam à volta da Terra como um **cobertor grosso** e a aquecem a mais. A isso chamamos **alterações climáticas** — e trazem problemas:

```steps

  { "title": "Gases a mais", "body": "carros e fábricas libertam gases para o ar 🏭", "icon": "💨" },
  { "title": "Um 'cobertor' à volta", "body": "esses gases prendem o calor do Sol 🌡️", "icon": "🛏️" },
  { "title": "O planeta aquece", "body": "o gelo derrete e o tempo fica mais maluco 🧊", "icon": "🔥" },
  { "title": "Problemas", "body": "secas, cheias e animais a perder a sua casa 🐻‍❄️", "icon": "⚠️" }
]
```

> [!WARNING] As **árvores** são heroínas: respiram o gás que nos faz mal (o dióxido de carbono) e devolvem **oxigénio**. Por isso plantar árvores e não as deitar abaixo ajuda mesmo o planeta a arrefecer! 🌳

## Os 3 R: Reduzir, Reutilizar, Reciclar ♻️

A melhor arma contra o lixo são os **3 R** — e a ordem importa! Primeiro tentar **reduzir**, depois **reutilizar**, e só por fim **reciclar**:

```keyvalue
[
  { "k": "1. Reduzir", "v": "usar menos: levar saco de pano, recusar plástico que não precisas 🛍️" },
  { "k": "2. Reutilizar", "v": "dar nova vida: garrafa que volta a encher, roupa que passa a outro 🔁" },
  { "k": "3. Reciclar", "v": "separar no ecoponto para fazer coisas novas ♻️" }
]
```

> **Truque para a ordem dos 3 R:** *o melhor lixo é o que **não** se faz.* Por isso **Reduzir** vem primeiro, **Reutilizar** depois, e **Reciclar** é o último recurso — não o primeiro! 🥇
