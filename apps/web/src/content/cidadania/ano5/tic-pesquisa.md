# Pesquisar na internet com cabeça 💻

> [!NOTE] **O que vais aprender** 👀 Vais aprender a fazer uma pesquisa na internet sem te perderes: escolher palavras-chave, comparar fontes, perceber se uma informação é fiável, guardar o que interessa e respeitar imagens e textos de outras pessoas.

A internet é uma biblioteca gigante. Mas, como é gigante, tem de tudo: coisas úteis, anúncios, erros, opiniões e até mentiras. Pesquisar bem é como usar uma lanterna: ajuda-te a encontrar o que interessa.

## Como saber se uma fonte é fiável? ✅

Não basta parecer bonito. Uma página pode ter imagens e mesmo assim estar errada.

```keyvalue
[
  { "k": "Autor", "v": "sei quem escreveu ou que instituição publicou?" },
  { "k": "Data", "v": "a informação é recente quando isso importa?" },
  { "k": "Objetivo", "v": "quer ensinar, vender, convencer ou assustar?" },

```

> **Truque:** pergunta sempre: **Quem disse? Quando? Para quê? Outros confirmam?**

## Copiar não é fazer um trabalho ✍️

## Imagens também têm dono 🖼️

Uma imagem encontrada online pode ter direitos de autor. Para trabalhos da escola, procura imagens permitidas, usa fontes indicadas pelo professor ou escreve de onde veio a imagem.

> [!TIP] **Para saberes mais** 🌱 Existem sites com imagens de uso livre, como bancos de imagens educativas ou bibliotecas públicas. Mesmo assim, é boa ideia guardar o nome do site e o autor quando aparece.
