# Media e mundo digital 📱

> [!NOTE] **O que vais aprender** 👀 O que são os **media**, como distinguir uma **notícia verdadeira** de uma **fake news**, como ficar **seguro** na internet, o que **não** se publica nem partilha, e como travar o **cyberbullying**. Ser esperto online é tão importante como olhar para os dois lados antes de atravessar! 🚦

A internet é como uma cidade gigante: tem bibliotecas, parques e amigos — mas também tem becos onde é melhor não entrar. Saber andar nela com cabeça torna-te livre **e** seguro. Vem aprender a ser um verdadeiro detetive digital! 🕵️

## O que são os media? 📰

**Media** são todos os meios que usamos para passar informação a muita gente: televisão, jornais, rádio, sites, redes sociais. Hoje, qualquer pessoa pode publicar — o que é fixe, mas obriga-nos a ter **espírito crítico**.

## Verdade ou fake news? 🔍

Uma **fake news** é uma notícia **falsa** que se espalha como se fosse verdadeira — às vezes para enganar, vender ou só para fazer barulho. Antes de acreditar (e de partilhar!), faz o **teste do detetive**:


> **Truque do detetive:** antes de partilhar, faz **STOP** — *Será verdade? Tem fonte? Onde mais aparece? Pensa antes de carregar.* Se não tens a certeza, **não partilhes**. Espalhar uma mentira sem querer também faz mal. ✋

## Travar o cyberbullying ✋

**Cyberbullying** é fazer bullying pela internet — mensagens más, gozar, espalhar mentiras ou excluir alguém. Magoa tanto como ao vivo, e pode chegar a muita gente depressa. Mas tu podes ser parte da **solução**:

```steps
[
  { "title": "1. Não respondas na mesma moeda", "body": "responder com maldade só piora 🙅", "icon": "✋" },
  { "title": "2. Guarda provas", "body": "tira uma captura de ecrã do que aconteceu 📸", "icon": "🧾" },
  { "title": "3. Bloqueia e denuncia", "body": "usa os botões de bloquear/denunciar 🚫", "icon": "🛑" },
  { "title": "4. Conta a um adulto", "body": "pais ou professores — não tens de resolver sozinho ❤️", "icon": "🗣️" }
]
```

> Se vires alguém a ser maltratado online, **não fiques calado**. Manda uma mensagem simpática à vítima ou avisa um adulto. Um só amigo faz toda a diferença para quem está a sofrer. 🤝

## Um exemplo passo a passo 🔍

*«Recebes uma mensagem: "ESTE VÍDEO É VERDADE, PARTILHA JÁ ANTES QUE APAGUEM!!!" — de um site que nunca viste. O que fazes?»* Vamos pensar como detetives:

```steps
[
  { "title": "1. Pausa", "body": "tanto drama e pressa? Acende-se a luz vermelha 🚩", "icon": "✋" },
  { "title": "2. Quem diz?", "body": "site desconhecido, sem autor → desconfiança 🔎", "icon": "👻" },
  { "title": "3. Confirma", "body": "jornais sérios dizem o mesmo? Não → provável fake 📰", "icon": "🌐" },
  { "title": "4. NÃO partilhas", "body": "não espalhas o que não tens a certeza ❌", "icon": "🙅" },
  { "title": "5. Avisa", "body": "contas a um adulto e até alertas quem to enviou 🗣️", "icon": "❤️" }
]
```

> Repara: a **pressa** e o **drama** ('partilha JÁ!') são quase sempre sinais de fake news. Quem tem razão não precisa de te apressar. 😌

> [!TIP] **Para saberes mais** 🌱 Hoje há programas de **inteligência artificial** que criam fotos, vozes e vídeos **falsos** que parecem reais — chamam-se **deepfakes**. Já houve vídeos falsos de presidentes a dizer coisas que nunca disseram! Por isso, no futuro, ver **não** vai chegar para acreditar — vamos ter de verificar **sempre** a fonte. Os jornalistas já usam ferramentas que detetam estas falsificações. Seres um bom detetive digital vai valer ainda mais! 🤖🕵️
