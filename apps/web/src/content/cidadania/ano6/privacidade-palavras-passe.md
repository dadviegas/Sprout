# Privacidade e palavras-passe 🔒

> [!NOTE] **O que vais aprender** 👀 Vais aprender a proteger contas e dados pessoais: criar palavras-passe fortes, reconhecer informação privada, usar autenticação em dois passos e pensar antes de publicar.

Na vida digital, a privacidade é como a porta de casa. Não deixamos a porta aberta para qualquer pessoa entrar. As palavras-passe, as regras e o cuidado ajudam a proteger essa porta.

## Autenticação em dois passos 🧩

Algumas contas usam um segundo passo além da palavra-passe: um código no telemóvel, app ou email. Isso chama-se **autenticação em dois passos**.

```keyvalue
[
  { "k": "1.º passo", "v": "palavra-passe" },
  { "k": "2.º passo", "v": "código temporário ou confirmação" },
  { "k": "Porquê?", "v": "mesmo que alguém descubra a palavra-passe, ainda falta o código" }
]
```

> [!TIP] **Para saberes mais** 🌱 Adultos também usam gestores de palavras-passe para guardar palavras-passe fortes. O importante é não repetir a mesma em todo o lado.
