# Proteger os seres vivos 🌍

> [!NOTE] **O que vais aprender** 👀 O que é um **ecossistema** e uma **cadeia alimentar**, porque é que tudo na natureza está **ligado**, o que ameaça os seres vivos (poluição, desflorestação, espécies em **perigo**) e o que **tu podes fazer** para ajudar o planeta. 🌳🐝♻️

Imagina a natureza como uma **teia gigante** onde tudo está ligado por fios invisíveis: a abelha, a flor, o pássaro, a chuva, tu… Se mexeres num fio, a teia inteira sente! Cuidar dos seres vivos não é só "ser simpático" — é proteger a **casa** onde todos vivemos. Vamos descobrir como. 🕸️🌱

## O que é um ecossistema? 🌳

Um **ecossistema** é um lugar onde os **seres vivos** (plantas, animais, micróbios) vivem juntos e se relacionam com o **ambiente** à volta (água, ar, solo, luz, temperatura). Pode ser enorme ou pequenino:

Num ecossistema, **ninguém vive sozinho**: cada ser vivo precisa dos outros e do ambiente para sobreviver. É um trabalho de equipa gigante.

## A cadeia alimentar: quem come quem 🍃→🐛→🐦

Numa cadeia alimentar, a **energia** passa de um ser vivo para o seguinte, como uma corrente de mãos dadas. Tudo começa sempre nas **plantas** (que fazem o seu alimento com o Sol):

```steps
[
  { "title": "1. Produtores 🌿", "body": "as plantas — fabricam o alimento com a luz do Sol", "icon": "sun" },
  { "title": "2. Consumidores 1.º 🐛", "body": "os herbívoros — comem as plantas (lagarta, coelho)", "icon": "leaf" },
  { "title": "3. Consumidores 2.º 🐦", "body": "comem os herbívoros (pássaro come a lagarta)", "icon": "feather" },
  { "title": "4. Decompositores 🍄", "body": "fungos e micróbios — reciclam os restos e devolvem-nos à terra", "icon": "sparkles" }
]
```

Repara: a seta aponta para **quem come** — `relva → coelho → raposa` quer dizer "a relva é comida pelo coelho, que é comido pela raposa". A energia do **Sol** acaba a alimentar até a raposa! ☀️

> **Truque para não te enganares na seta:** a seta é uma **colher** que aponta para a **boca** de quem come. `🌿 → 🐛 → 🐦` lê-se "a planta alimenta a lagarta, que alimenta o pássaro". 🥄

## Tudo está ligado 🕸️

Quando tiramos uma peça da natureza, muitas outras sofrem. Olha o que acontece se desaparecerem as **abelhas**:

```steps
[
  { "title": "1. Sem abelhas", "body": "ninguém leva o pólen de flor em flor 🐝" },
  { "title": "2. Menos flores polinizadas", "body": "muitas plantas não fazem fruto nem semente 🌸" },
  { "title": "3. Menos frutos e plantas", "body": "os herbívoros ficam com menos comida 🍎" },
  { "title": "4. Toda a teia abana", "body": "faltam alimentos a muitos animais… e a nós! 😟" }

```

> [!WARNING] As **abelhas** parecem pequeninas, mas são **gigantes** importantes: cerca de **1 em cada 3 garfadas** da nossa comida só existe porque uma abelha (ou outro polinizador) ajudou a planta a fazer fruto. Sem abelhas, faltariam maçãs, morangos, melancias e tanta coisa boa! 🐝🍓

> [!TIP] **Para saberes mais** 🌱 Há uma palavra mágica para tudo isto: **biodiversidade** — a enorme **variedade** de seres vivos do planeta, dos micróbios às baleias. Quanto **mais variedade** um ecossistema tem, mais **forte e saudável** ele é, porque há sempre alguém para cada tarefa (polinizar, limpar, adubar). É como uma equipa de futebol cheia de jogadores diferentes: ganha melhor do que uma equipa só com guarda-redes! Proteger a biodiversidade é proteger a vida toda. 🌍🐝🐠🌳
