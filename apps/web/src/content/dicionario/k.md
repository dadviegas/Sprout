# A letra K 🥝

A letra **K** é rara em português! Aparece sobretudo em palavras que vieram de outras línguas. 🌍

```dictionary
    { "word": "kart", "emoji": "🏎️", "meaning": "Um carrinho de corrida pequeno e muito rápido." },
    { "word": "karaté", "emoji": "🥋", "meaning": "Um desporto em que se aprende a defender o corpo." },
    { "word": "ketchup", "emoji": "🍅", "meaning": "Um molho vermelho de tomate para pôr na comida." }
  ]
}
```

> [!TIP] A **K** não está nas palavras portuguesas mais antigas. Por isso é uma letra «visitante»! ✈️
