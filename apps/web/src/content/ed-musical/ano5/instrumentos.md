# Instrumentos da orquestra 🎻

> [!NOTE] **O que vais aprender** 👀 O que é uma **orquestra sinfónica**, as suas quatro **famílias** (cordas, sopros de **madeira**, sopros de **metal** e percussão), exemplos de cada **naipe**, como o som nasce em cada uma, e o papel do **maestro** que põe toda a gente a tocar junta. 🎻🎺🥁🪄

Imagina **mais de 80 músicos** sentados juntos, cada um com o seu instrumento, todos a tocar a mesma música ao mesmo segundo, sem se atrapalharem. 😮 Isso é uma **orquestra sinfónica** — a maior «máquina de fazer música» do mundo! Para não ser uma confusão, os instrumentos arrumam-se em **famílias** e há um chefe com uma varinha mágica: o **maestro**. Vem conhecer todos! 🎶

## O que é uma orquestra? 🎼

Uma **orquestra** é um grande grupo de músicos que tocam juntos. A orquestra **sinfónica** organiza-se em **quatro famílias**, conforme a maneira como cada instrumento faz som. Cada grupo de instrumentos iguais dentro da orquestra chama-se um **naipe**.

## As quatro famílias 🎻🎷🎺🥁

A regra é sempre a mesma: a família depende do **que fazes** para o instrumento soar. Repara bem:

```keyvalue
[
  { "k": "Cordas 🎻", "v": "tens cordas — tocas com um arco ou com os dedos: violino, viola, violoncelo, contrabaixo, harpa" },
  { "k": "Sopros de madeira 🎷", "v": "sopras (muitos têm uma palheta de madeira): flauta, clarinete, oboé, fagote" },
  { "k": "Sopros de metal 🎺", "v": "sopras 'fazendo trombeta' com os lábios num tubo de metal: trompete, trombone, trompa, tuba" },
  { "k": "Percussão 🥁", "v": "bates, sacodes ou raspas: tímbales, bombo, pratos, triângulo, xilofone" }
]
```

> [!NOTE] Atenção: a **flauta** moderna é de **metal**, mas pertence à família dos sopros de **madeira**! 🤔 Porquê? Porque as famílias agrupam-se pela **maneira de tocar** e pela tradição, não só pelo material. Antigamente as flautas eram mesmo de madeira, e o nome ficou. O que conta é **como** sopras, não de que é feito o tubo.

## Como nasce o som em cada família? 🔊

Em todas, o som nasce de algo a **vibrar** — mas o que vibra é diferente em cada uma:

```steps
[
  { "title": "Cordas", "body": "a CORDA vibra quando passas o arco ou a dedilhas — e a caixa de madeira amplia o som 〰️", "icon": "music" },
  { "title": "Sopros de madeira", "body": "o AR vibra dentro do tubo; numa palheta de madeira, é ela que treme ao soprares 💨", "icon": "wave2" },
  { "title": "Sopros de metal", "body": "os teus LÁBIOS vibram (como uma 'pedorreta') e o som corre pelo tubo de metal 👄", "icon": "🎺" },
  { "title": "Percussão", "body": "a PELE ou o metal vibra quando bates — é a família mais antiga do mundo! 👏", "icon": "🥁" }
]
```

> **Truque para acertar sempre na família:** faz três perguntas, por esta ordem. **1)** Tem **cordas**? → família das **cordas**. **2)** Tem de **soprar**? → é de **sopro** (madeira se tem palheta/buracos; metal se 'fazes trombeta' com os lábios). **3)** **Bates ou sacodes**? → **percussão**. A primeira resposta «sim» dá-te logo a família! ✅

## Onde se sentam? 🪑

Numa orquestra, cada família tem o seu lugar, sempre à volta do maestro, como numa fotografia de família:

## O maestro: o chefe da orquestra 🪄

Com tanta gente a tocar, alguém tem de mandar! É o **maestro** (ou maestrina), que fica de pé à frente, virado para os músicos, com uma varinha chamada **batuta**. Ele não toca nenhum instrumento — o seu instrumento é… **a orquestra inteira**!

## Um exemplo passo a passo 🔍

Estás num concerto e ouves um instrumento **grave** e **bonito**, tocado por alguém **sentado** que o segura **encostado ao corpo**, passando um **arco**. Qual será? Vamos descobrir como detetives! 🕵️

```steps
[
  { "title": "1. Tem arco e cordas?", "body": "sim! Logo é da família das CORDAS 🎻" },
  { "title": "2. É soprado ou batido?", "body": "não — não se sopra nem se bate, descartamos sopros e percussão 🚫" },
  { "title": "3. É grande ou pequeno?", "body": "é grande e o som é grave — não é o violino (pequeno e agudo) 🦣" },
  { "title": "4. Como se segura?", "body": "sentado, encostado ao corpo, entre os joelhos — não é o contrabaixo (que é de pé) 🪑" },
  { "title": "5. Já está!", "body": "cordas + arco + grave + sentado encostado ao corpo = VIOLONCELO 🎉" }
]
```

> [!TIP] **Para saberes mais** 🌱 Há uma peça mágica feita de propósito para conheceres a orquestra: **«O Guia dos Jovens para a Orquestra»**, do compositor inglês **Benjamin Britten**. 🎼 Nela, cada família toca a mesma melodia à sua vez, para ouvires bem o **timbre** de cada uma — primeiro as cordas, depois as madeiras, os metais e a percussão, e no fim **todos juntos** num grande final! E sabias que a maior família, a das cordas, pode ter mais de **60 instrumentos** só ela? É quase uma orquestra dentro da orquestra! 🎻
