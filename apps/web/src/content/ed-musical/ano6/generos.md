# Géneros musicais 🎵

> [!NOTE] **O que vais aprender** 👀 O que é um **género musical** (uma «família» de músicas parecidas), os grandes grupos — **clássica**, **popular** e **tradicional** —, géneros que ouves todos os dias como **pop**, **rock**, **hip-hop**, **jazz** e **eletrónica**, como **reconhecer** um género pelos instrumentos e pelo ritmo, e porque é que os géneros se **misturam** e nascem novos. 🎶

Se entrares numa loja de gelados, há tabuleiros: morango, chocolate, baunilha… 🍦 Na música é igual! As músicas arrumam-se em **géneros** — famílias de músicas que se parecem umas com as outras. Quando ouves rock, sabes logo que é rock; quando ouves fado, sabes que é fado. Hoje vais ficar a **distinguir** os sabores da música! 🎧

## O que é um género musical? 🏷️

Um **género** é um conjunto de músicas que **partilham características** — os instrumentos que usam, o tipo de ritmo, o ambiente, a forma de cantar. É uma etiqueta que ajuda a arrumar e a falar sobre música. Uma mesma música pode até pertencer a **mais do que um** género!

> **Truque do detetive:** para adivinhar o género, faz **3 perguntas** à música — *«Que instrumentos ouço?»* (guitarra elétrica? saxofone? computador?), *«Como é o ritmo?»* (calmo? a marcar para dançar?), *«Como cantam?»* (a cantar? a fazer rap?). Junta as três pistas e tens o género! 🕵️🔍

## Os géneros misturam-se 🤝

Os géneros não são caixas fechadas! Quando dois se juntam, nasce um **terceiro**. Foi assim que apareceram quase todos os estilos novos — alguém misturou o que já existia de forma diferente.

## Um exemplo passo a passo 🔍

Vamos descobrir o género de uma música misteriosa, como detetives, só com os ouvidos 🎧:

```steps

  { "title": "1. Que instrumentos ouço?", "body": "ouço uma batida feita em computador e sintetizadores 🎛️" },
  { "title": "2. Como é o ritmo?", "body": "é uma batida regular, forte, mesmo para dançar 💃" },
  { "title": "3. Como cantam (ou não)?", "body": "quase não há voz, é mais a batida a mandar 🔊" },
  { "title": "4. Junta as pistas", "body": "computador + batida de dança + pouca voz… 🤔" },
  { "title": "5. Conclusão", "body": "é música ELETRÓNICA! 🎉" }
]
```

> [!TIP] **Para saberes mais** 🌱 O **hip-hop** nasceu nos anos 1970, em festas de rua em Nova Iorque, quando os **DJ** descobriram que podiam pegar só na parte mais ritmada de um disco (o *break*) e repeti-la em dois gira-discos, enquanto alguém falava por cima em ritmo. 🎧 Desse «truque» nasceram **quatro artes** ligadas: o **DJ**, o **MC** (quem faz rap), o **breakdance** e os **graffiti**! E muitos êxitos de hoje usam **samples** — pedacinhos de músicas antigas reaproveitados numa música nova. ♻️🎶
