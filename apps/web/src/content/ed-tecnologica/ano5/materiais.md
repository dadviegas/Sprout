# Materiais e propriedades 🧰

> [!NOTE] **O que vais aprender** 👀 De que são feitas as coisas à tua volta — **madeira, metal, plástico, vidro, papel, têxteis** — e as suas **propriedades** (duro/mole, leve/pesado, flexível, transparente, resistente). Vais perceber porque é que **cada objeto usa o material certo** e o que significa **reciclar**. 🪵🔩

Olha à tua volta. A mesa é de **madeira**, a janela de **vidro**, a garrafa de **plástico**, a camisola de **algodão**, a colher de **metal**… Nada disto é por acaso! Quem fez cada objeto **escolheu** o material certo para a tarefa. Vamos aprender a "ler" os materiais como um verdadeiro engenheiro. 🔍

## O que são propriedades? 🧐

As **propriedades** são as **características** de um material — a maneira como ele *é* e *se comporta*. São elas que nos dizem para que serve cada material.

```keyvalue
[
  { "k": "💪 Resistência", "v": "aguenta força sem partir? (o metal aguenta muito)", "icon": "shield" },
  { "k": "🪶 Leveza", "v": "é leve ou pesado? (o plástico é leve; a pedra é pesada)", "icon": "wave" },
  { "k": "🤸 Flexibilidade", "v": "dobra sem partir? (a borracha dobra; o vidro não)", "icon": "refresh" },
  { "k": "👀 Transparência", "v": "deixa passar a luz? (o vidro deixa; a madeira não)", "icon": "search" },
  { "k": "💧 Impermeável", "v": "deixa passar a água? (o plástico não deixa; o papel deixa)", "icon": "drop" }
]
```

> **Truque para escolher o material:** pensa primeiro **no que o objeto precisa de fazer**, e só depois escolhes. *Janela* → preciso de **ver através** → **vidro**. *Guarda-chuva* → preciso que **a água escorra** → **plástico/tecido impermeável**. *Martelo* → preciso de **bater com força** → **metal**. O material segue a função! 🎯

## Reciclar: dar uma nova vida ♻️

Muitos materiais podem **voltar a ser usados** em vez de irem para o lixo. Reciclar **poupa recursos** e ajuda o planeta — e cada material vai ao seu ecoponto:

```keyvalue
[
  { "k": "🟡 Amarelo", "v": "plástico e metal (garrafas, latas, embalagens)" },
  { "k": "🔵 Azul", "v": "papel e cartão (jornais, caixas)" },
  { "k": "🟢 Verde", "v": "vidro (garrafas e frascos, sem tampas)" },
  { "k": "♻️ Vantagem", "v": "menos lixo, menos árvores cortadas, menos energia gasta" }
]
```

> [!TIP] **Para saberes mais** 🌱 Há uma palavra de gente grande para isto: **biodegradável**. Um material **biodegradável** é aquele que a natureza consegue **desfazer** sozinha (a casca de banana apodrece em poucas semanas, e os micróbios "comem-na" e devolvem-na à terra). Já o **plástico** é **não biodegradável**: a natureza não o sabe desfazer, por isso uma simples garrafa atirada para o chão pode demorar **mais de 400 anos** a desaparecer — e entretanto parte-se em pedacinhos minúsculos (os **microplásticos**) que vão parar ao mar e aos peixes! É por isso que o plástico tem de ir **sempre** ao ecoponto amarelo, para ser reciclado em coisas novas em vez de poluir durante séculos. 🐢🌊
