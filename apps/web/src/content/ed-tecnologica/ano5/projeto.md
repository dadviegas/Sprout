# Do projeto ao objeto 🛠️

> [!NOTE] **O que vais aprender** 👀 Como se vai de uma **ideia** na cabeça até um **objeto** nas mãos — passando pela **pesquisa**, pelo **esboço/projeto**, pela escolha de **materiais**, pela **construção** e pela **avaliação**. Vais conhecer a **metodologia de projeto**, o mapa que os inventores seguem! 💡➡️🔨

Já alguma vez tiveste uma ideia gira e não soubeste por onde começar? Os engenheiros e designers também tinham esse problema — por isso inventaram um **caminho passo a passo** para transformar **qualquer ideia** num objeto a sério. Chama-se **metodologia de projeto** e é como uma **receita**: se seguires a ordem, chegas lá. Vamos aprender a inventar como os profissionais! 🚀

## O que é um projeto? 📐

Um **projeto** é o **plano** que fazes **antes** de construir: o que vais fazer, para quê, com que materiais e por que ordem. Projetar **primeiro** evita desperdiçar material e tempo depois.

## As etapas da metodologia de projeto 🗺️

Este é o **mapa** que todos os inventores seguem. Decora bem a ordem — é o segredo de fazer as coisas sem confusão:

```steps
[
  { "title": "1. Identificar o problema 🤔", "body": "o que é preciso resolver? 'Os meus lápis andam espalhados!'", "icon": "info" },
  { "title": "2. Pesquisar 🔎", "body": "vê como outros resolveram; junta ideias e medidas", "icon": "search" },
  { "title": "3. Projetar (esboçar) ✏️", "body": "desenha a ideia, com formas e medidas", "icon": "pencil" },
  { "title": "4. Escolher materiais 🧰", "body": "decide do que vai ser feito (cartão? madeira?)", "icon": "shapes" },
  { "title": "5. Construir 🔨", "body": "medir, cortar, juntar — mãos à obra com segurança!", "icon": "gear" },
  { "title": "6. Avaliar 🧐", "body": "funciona? é seguro? o que melhorar para a próxima?", "icon": "check" }
]
```

> **Truque para decorares a ordem:** pensa em **«Pensar → Desenhar → Fazer → Ver»**. 🧠✏️🔨👀 Primeiro **pensas** no problema e pesquisas, depois **desenhas** o projeto, a seguir **fazes** (constróis) e no fim **vês** se resultou. Nunca comeces pelo "fazer" — quem corta antes de pensar, corta ao contrário! 😅

## O esboço: desenhar a ideia ✍️

O **esboço** é o desenho do teu projeto. Não precisa de ser uma obra de arte — precisa de mostrar a **forma**, as **partes** e as **medidas**, para te guiar na construção.

## Avaliar: o objeto ficou bom? 🧐

A última etapa é **pôr à prova** e ser **honesto**. Avaliar não é "estar mal" — é descobrir o que **melhorar**. Os melhores inventores fazem **muitas tentativas**!

```compare

```

> [!WARNING] Errar à primeira é **completamente normal** — faz parte de projetar! Quase nenhuma invenção do mundo ficou perfeita logo na primeira tentativa. O importante é **avaliar, corrigir e tentar de novo**. A esta repetição — fazer, testar, melhorar, fazer outra vez — os engenheiros chamam **prototipagem**, e é assim que nascem os melhores objetos. 🔁

> [!TIP] **Para saberes mais** 🌱 As grandes empresas de tecnologia constroem primeiro um **protótipo** — um modelo de teste, muitas vezes feito de cartão, esferovite ou impresso numa **impressora 3D** — só para ver se a ideia funciona, **antes** de gastarem dinheiro a fabricar a sério. O primeiro rato de computador foi um bloco de **madeira** com uma roda! E os engenheiros desenham tudo primeiro num programa de computador chamado **CAD** (desenho assistido por computador), que até calcula se a estrutura aguenta o peso **antes** de a construírem. Ou seja: projetar bem no início **poupa** montanhas de trabalho e material no fim. Pensar primeiro é mesmo o superpoder dos inventores! 🖥️🪵🖱️
