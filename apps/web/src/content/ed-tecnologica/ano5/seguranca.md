# Higiene e segurança 🦺

> [!NOTE] **O que vais aprender** 👀 Como trabalhar **em segurança** numa oficina ou na cozinha, o que é o **equipamento de proteção** (óculos, luvas, avental), as **regras de oiro** para não te magoares, e porque é que a **higiene e a arrumação** também fazem parte de trabalhar bem. 🧤🥽

Trabalhar com ferramentas e materiais é divertido — mas só é **divertido se for seguro**! Tesouras, agulhas, fontes de calor e máquinas podem magoar quem não tem cuidado. A boa notícia: com **regras simples** e **atenção**, evitas quase todos os acidentes. Os melhores técnicos são os que trabalham com **cabeça**. 🧠✋

## As regras de oiro da oficina 📜

Há regras que **nunca** se quebram. Decora-as bem — são o teu escudo:

```steps
[
  { "title": "1. Pede ajuda a um adulto", "body": "ferramentas perigosas só com um adulto por perto 🧑‍🏫", "icon": "people" },
  { "title": "2. Mãos longe da lâmina", "body": "corta sempre na direção contrária ao teu corpo ✂️", "icon": "warn" },
  { "title": "3. Bancada arrumada", "body": "sem desordem ninguém tropeça nem se pica 🧹", "icon": "check" },
  { "title": "4. Arruma ao acabar", "body": "guarda as ferramentas e limpa o que sujaste 🧽", "icon": "trash" }
]
```

> **Truque para não te esqueceres:** antes de pegar numa ferramenta, faz a pergunta mágica **«Para onde vai isto se escorregar?»**. Se a resposta for "para a minha mão" ou "para o meu olho", **muda a posição**. Corta e fura sempre **para longe do corpo** — assim, se escorregar, a ferramenta vai para o lado seguro. 🛡️

## Higiene: trabalhar limpo também é segurança 🧼

A **higiene** não é só "estar limpo" — é evitar que micróbios, pó ou produtos entrem no corpo. É ainda mais importante na **cozinha**, onde lidamos com comida:

```steps
[
  { "title": "Antes de começar 🧴", "body": "lava bem as mãos com água e sabão", "icon": "drop" },
  { "title": "Durante o trabalho 🧽", "body": "mantém a bancada e as ferramentas limpas", "icon": "check" },
  { "title": "Com alimentos 🍎", "body": "não tocar na comida com mãos sujas; lavar a fruta", "icon": "plant" },
  { "title": "No fim 🚮", "body": "limpa tudo, arruma e lava as mãos outra vez", "icon": "refresh" }
]
```

> [!WARNING] Um acidente comum nas oficinas é **tropeçar em fios e mochilas no chão**! Por isso a regra "**bancada e chão arrumados**" não é uma chatice dos professores — é mesmo segurança. Uma oficina **arrumada** é uma oficina **segura**: vês onde pisas, encontras as ferramentas e ninguém se magoa. A arrumação é a primeira ferramenta de segurança! 🧹

## E se acontecer um acidente? 🚑

Mesmo com cuidado, às vezes algo corre mal. O importante é **manter a calma** e **avisar logo** um adulto:

> [!TIP] **Para saberes mais** 🌱 Há um conjunto de símbolos espalhados pelo mundo inteiro que avisam de perigos **sem precisar de palavras** — chamam-se **pictogramas de segurança**. Um triângulo amarelo com um raio quer dizer "perigo elétrico ⚡"; uma chama dentro de um losango quer dizer "inflamável 🔥". Foram inventados assim **de propósito** para que qualquer pessoa — fale a língua que falar, saiba ler ou não — perceba o aviso num instante. É design a salvar vidas: um bom símbolo explica-se **sozinho**! ⚠️🌍
