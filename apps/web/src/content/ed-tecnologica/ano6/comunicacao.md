# Tecnologias de comunicação 📡

> [!NOTE] **O que vais aprender** 👀 Como as pessoas **comunicam à distância**, a viagem dos sinais (**emissor → mensagem → recetor**), a história das tecnologias (do correio à Internet), a diferença entre **analógico** e **digital**, e como usar tudo isto com **segurança**. 📶💬

Comunicar é **partilhar uma mensagem**: um aceno, uma carta, uma chamada, uma mensagem no telemóvel. Hoje conseguimos falar com alguém do outro lado do mundo num segundo — mas isso é uma invenção recente, fruto de muita tecnologia. Vamos ver como a mensagem viaja. 📨

## O caminho de uma mensagem 🔁

Toda a comunicação, da mais antiga à mais moderna, tem sempre as mesmas três partes:

```steps
[
  { "title": "Emissor 🗣️", "body": "quem envia a mensagem (tu, a falar ao telemóvel)", "icon": "user" },
  { "title": "Mensagem / canal 📨", "body": "o que se diz e o caminho que percorre (a voz, o sinal, os fios, o ar)", "icon": "send" },
  { "title": "Recetor 👂", "body": "quem recebe a mensagem (o teu amigo, do outro lado)", "icon": "user-check" }
]
```

> **Truque para nunca trocares emissor e recetor:** o **E**missor **E**nvia, o **R**ecetor **R**ecebe — começam pela mesma letra! E entre os dois viaja sempre uma **mensagem** por um **canal** (o ar, um fio, ondas de rádio). 📡

## Analógico ou digital? 🔢

A grande mudança moderna foi passar de **analógico** para **digital**. Esta é a ideia mais "de 6.º ano" da lição.

## Um problema passo a passo 🔍

*«Envias uma fotografia do telemóvel para a tua avó pela Internet. Quem é o emissor, qual é o canal e quem é o recetor?»* Vamos seguir a mensagem. 🔍📱

```steps
[
  { "title": "1. Quem envia?", "body": "tu, com o telemóvel → EMISSOR 🗣️" },
  { "title": "2. O que viaja?", "body": "a foto, em forma digital (zeros e uns) → MENSAGEM" },
  { "title": "3. Por onde?", "body": "por ondas Wi-Fi e cabos de fibra ótica → CANAL 📡" },
  { "title": "4. Quem recebe?", "body": "a avó, no telemóvel dela → RECETOR 👂. Comunicação feita! ✅" }
]
```

> [!TIP] **Para saberes mais** 🌱 Quando carregas num botão para enviar uma mensagem, ela viaja por **cabos de fibra ótica** no fundo dos oceanos — há mais de **1 milhão de km** desses cabos a ligar os continentes! E os **satélites** lá em cima ajudam onde não há cabos. A mensagem dá a volta ao mundo em **menos de um segundo**, partida em pequenos pacotes que se voltam a juntar no fim. 🌍🛰️
