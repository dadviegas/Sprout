# Materiais e reciclagem ♻️

> [!NOTE] **O que vais aprender** 👀 De que são feitas as coisas (**materiais** e as suas **propriedades**), de onde vêm as **matérias-primas**, a regra dos **3 R** (reduzir, reutilizar, reciclar), como **separar** o lixo pelos ecopontos, e porque a reciclagem ajuda o planeta. 🌍🗑️

Tudo o que tens à volta foi feito de algum **material**: a mesa de madeira, a garrafa de plástico, a janela de vidro, a colher de metal. Escolher bem o material é o primeiro segredo de quem fabrica — e dar-lhe uma segunda vida é o segredo de quem cuida do planeta. ♻️

## A regra dos 3 R ♻️

Para gastar menos e poluir menos, há uma ordem certa de três passos. **A ordem importa** — começa sempre pelo primeiro!

```steps
[
  { "title": "1. Reduzir 🚫", "body": "o melhor lixo é o que não fazes — compra só o que precisas, recusa o que é descartável", "icon": "minus" },
  { "title": "2. Reutilizar 🔁", "body": "dá nova vida ao que já tens — um frasco vira caneta, uma t-shirt vira pano", "icon": "refresh" },
  { "title": "3. Reciclar ♻️", "body": "quando já não dá para usar, separa-o para virar matéria-prima nova", "icon": "recycle" }
]
```

> **Truque para a ordem dos 3 R:** pensa numa escada de cima para baixo — **R**eduzir está no topo (o melhor), **R**eutilizar no meio, **R**eciclar só no fim. *Reciclar é bom, mas reduzir é ainda melhor: poupa antes de chegar ao caixote.* 🪜

## Um problema passo a passo 🔍

*«Esta semana lá em casa juntaram 3 garrafas de plástico, 2 latas, 4 jornais e 1 frasco de vidro. Quantas embalagens vão para o ecoponto AMARELO?»* Vamos separar. 🧮🗑️

```steps
[
  { "title": "1. O que vai ao amarelo?", "body": "plástico e metal" },
  { "title": "2. Plástico", "body": "3 garrafas → amarelo" },
  { "title": "3. Metal", "body": "2 latas → amarelo" },
  { "title": "4. Soma", "body": "3 + 2 = 5 embalagens no amarelo (os jornais vão ao azul e o frasco ao verde) ✅" }
]
```

> [!TIP] **Para saberes mais** 🌱 O alumínio das latas é o campeão da reciclagem: pode ser reciclado **infinitas vezes** sem perder qualidade, e reciclar uma lata poupa **95% da energia** que seria precisa para fazer alumínio novo a partir da pedra! Já o plástico costuma reciclar-se em algo de **qualidade mais baixa** (uma garrafa pode virar um casaco polar, mas não outra garrafa para sempre) — por isso **reduzir** continua a ser melhor que reciclar. ♻️🥫
