# Comunicação visual 📢

> [!NOTE] **O que vais aprender** 👀 Como as **imagens falam** sem palavras! Vais distinguir **sinais**, **símbolos**, **pictogramas** e **logótipos**, perceber porque as **cores** dos sinais têm significado, e descobrir como um cartaz é feito para chamar a atenção e transmitir uma mensagem. 📢👀

Antes de saberes ler, já percebias muitas imagens: a seta a apontar, a cara feliz, o sinal de proibido. Isso é **comunicação visual** — passar uma mensagem só com **imagens, cores e formas**, sem precisar de palavras. É uma linguagem que toda a gente entende, em qualquer país! Vamos aprender a ler e a criar mensagens visuais. 🌍✨

## Sinal, símbolo, pictograma e logótipo 🔠

Estas quatro palavras parecem-se, mas são diferentes. Vê com calma cada uma:

```compare
[
  { "title": "Sinal 🚦", "rows": [
    { "label": "O que é", "value": "uma imagem que dá uma ordem ou um aviso direto" },
    { "label": "Exemplo", "value": "o sinal de STOP, o de proibido virar 🛑" }
  ] },
  { "title": "Símbolo ❤️", "rows": [
    { "label": "O que é", "value": "uma imagem que representa uma ideia maior", "highlight": true },
    { "label": "Exemplo", "value": "o coração = amor; a pomba = paz 🕊️", "highlight": true }
  ] }
]
```

```compare
[
  { "title": "Pictograma 🚻", "rows": [
    { "label": "O que é", "value": "um desenho simples que mostra uma coisa ou ação" },
    { "label": "Exemplo", "value": "o boneco da casa de banho, o garfo+faca de restaurante 🍴" }
  ] },
  { "title": "Logótipo 🍎", "rows": [
    { "label": "O que é", "value": "o desenho que identifica uma marca ou empresa", "highlight": true },
    { "label": "Exemplo", "value": "o símbolo de uma marca de telemóveis ou de ténis 👟", "highlight": true }
  ] }
]
```

> **Truque para os distinguir:** o **sinal** **manda** (para! atenção!) 🛑; o **símbolo** **representa uma ideia** (amor, paz) ❤️; o **pictograma** **mostra uma coisa** com um desenho simples 🚻; o **logótipo** **diz de quem é** (a marca) 🍎.

## As cores também falam 🚦

Nos sinais e avisos, a **cor** é uma mensagem! Aprendeste algumas sem dar conta:

```keyvalue
[
  { "k": "Vermelho", "v": "perigo, proibição, parar 🛑" },
  { "k": "Verde", "v": "pode-se, seguro, siga ✅" },
  { "k": "Amarelo / laranja", "v": "atenção, cuidado ⚠️" },
  { "k": "Azul", "v": "informação, obrigação 🅿️" }
]
```

> **Repara:** um sinal **redondo e vermelho** quase sempre **proíbe**; um **triângulo amarelo** **avisa**; um **quadrado azul** **informa**. A forma e a cor trabalham juntas! 🔺🟥🟦

## O que faz um bom sinal? ✅

Para uma imagem comunicar bem, tem de ser:

```steps

  { "title": "Simples", "body": "poucos traços, fácil de perceber num instante 👌", "icon": "✅" },
  { "title": "Clara", "body": "não deixa dúvidas sobre o que quer dizer 🔍", "icon": "🔍" },
  { "title": "Visível", "body": "cores fortes e contraste para se ver de longe 👀", "icon": "👀" },
  { "title": "Universal", "body": "qualquer pessoa percebe, fale a língua que falar 🌍", "icon": "🌍" }
]
```

## O cartaz: comunicar uma mensagem 🖼️

Um **cartaz** junta **imagem**, **cor** e **palavras** para chamar a atenção e passar uma mensagem (anunciar uma festa, avisar de um perigo, convidar para algo). Tem partes bem pensadas:

```figure
{ "emoji": "📋", "caption": "Um bom cartaz tem um título grande, uma imagem forte e a informação importante — tudo organizado para se ler de longe." }
```

```keyvalue
[
  { "k": "Título", "v": "grande e curto, lê-se de longe — a primeira coisa que vês 🔠" },
  { "k": "Imagem", "v": "forte e chamativa, conta logo o tema 🖼️" },
  { "k": "Informação", "v": "o quê, quando e onde — só o essencial 📅" },
  { "k": "Cores", "v": "poucas e com bom contraste, para saltar à vista 🎨" }
]
```

## Um exemplo passo a passo 🔍

Vais fazer um **cartaz para a festa da escola**. Segue os passos de um designer:

```steps
[
  { "title": "1. A mensagem", "body": "decide o essencial: «Festa de Primavera — sábado, no pátio» 🌼", "icon": "💬" },
  { "title": "2. O título", "body": "escreve «FESTA!» bem grande, no cimo, para se ler de longe 🔠", "icon": "🔠" },
  { "title": "3. A imagem", "body": "um desenho forte e alegre — balões, flores, música 🎈", "icon": "🎈" },
  { "title": "4. A informação", "body": "por baixo, em letra mais pequena: dia, hora e lugar 📅", "icon": "📅" },
  { "title": "5. As cores", "body": "duas ou três cores vivas com bom contraste — nada de carregado 🎨", "icon": "🎨" },
  { "title": "6. Vê de longe", "body": "afasta-te 3 passos: se ainda percebes tudo, o cartaz está bom! 👀", "icon": "👀" }
]
```

> **Truque do designer:** afasta-te do teu cartaz. Se de longe ainda percebes a mensagem **num segundo**, está bom. Se tens de chegar perto para entender, está cheio de mais — **tira** coisas! ✂️
