# A cor e o círculo cromático 🎨

> [!NOTE] **O que vais aprender** 👀 De onde vêm **todas** as cores! Vais conhecer as **primárias** e as **secundárias**, arrumá-las no **círculo cromático**, descobrir as cores **complementares** (as que estão frente a frente), e distinguir cores **quentes** de cores **frias**. 🌈

A cor é magia pura. Sabias que, com apenas **três** cores, consegues fazer **todas** as outras? E que há cores que, lado a lado, ficam mais vivas, enquanto outras se acalmam? Os artistas arrumam as cores numa roda chamada **círculo cromático** para nunca se perderem. Pega nos teus lápis ou tintas — vamos pintar e descobrir os segredos da cor! 🖌️✨

## As 3 cores primárias 🔴🟡🔵

Estas três são as **cores-mãe**. Chamam-se primárias porque **não** se conseguem fazer misturando outras — são o ponto de partida de tudo:

```keyvalue
[
  { "k": "Vermelho", "v": "quente como um morango 🍓" },
  { "k": "Amarelo", "v": "luminoso como o sol ☀️" },
  { "k": "Azul", "v": "fresco como o céu e o mar 🔵" }
]
```

> **Porquê «primárias»?** «Primária» quer dizer **primeira**. São as primeiras de todas — sem elas, não havia mais nenhuma cor! 🥇

## Nascem as cores secundárias 🪄

Junta **duas** primárias em partes iguais e aparece uma cor nova — uma **secundária**. São só **três**:

```keyvalue
[
  { "k": "Amarelo + Azul", "v": "= Verde 🟢" },
  { "k": "Vermelho + Amarelo", "v": "= Laranja 🟠" },
  { "k": "Vermelho + Azul", "v": "= Roxo (violeta) 🟣" }
]
```

> **Truque para decorares:** as duas cores do **sol e do mar** (amarelo + azul) fazem a **relva** (verde 🌱). As duas mais **quentes** (vermelho + amarelo) fazem o **fogo do pôr do sol** (laranja 🌅). E as duas que sobram (vermelho + azul) fazem o **roxo** da noite 🌌.

## O círculo cromático 🎡

Os pintores arrumam as cores numa roda — o **círculo cromático**. As primárias ficam afastadas; entre cada par, fica a secundária que elas formam. Olha:

## Cores complementares ↔️

No círculo, as cores que ficam **frente a frente** chamam-se **complementares**. Quando as pões lado a lado, ficam **muito mais vivas** — uma faz a outra saltar à vista!

```keyvalue
[
  { "k": "Vermelho ↔ Verde", "v": "ficam fortes lado a lado ❤️💚" },
  { "k": "Azul ↔ Laranja", "v": "fazem-se notar muito 💙🧡" },
  { "k": "Amarelo ↔ Roxo", "v": "saltam à vista 💛💜" }
]
```

> **Repara:** cada complementar de uma primária é a secundária feita pelas **outras duas** primárias. O complementar do **vermelho** é o **verde** (amarelo + azul) — as duas cores que o vermelho não tem! 🤓

> [!TIP] **Para saberes mais** 🌱 Misturar **tintas** não é igual a misturar **luz**! Com tintas, quanto mais cores juntas, mais **escuro** fica (junta as três e dá quase **castanho/preto**) — chama-se mistura **subtrativa**. Mas num **ecrã** de telemóvel ou TV, as cores nascem de três **luzinhas** — vermelho, verde e azul (**RGB**) — e quanto mais luz juntas, mais **claro** fica: as três acesas ao máximo dão **branco**! É a mistura **aditiva**. Por isso a cor da impressora e a cor do ecrã funcionam ao contrário uma da outra. 📺🖨️
