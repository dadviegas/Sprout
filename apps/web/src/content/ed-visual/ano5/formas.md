# Formas e contornos 🔷

> [!NOTE] **O que vais aprender** 👀 O que é uma **forma** e o seu **contorno**, a diferença entre formas **geométricas** e formas **orgânicas**, como nascem das linhas, e o segredo dos artistas: ver a **forma escondida** dentro de qualquer objeto. 🔷🌿

Olha à tua volta: uma janela, uma bola, uma folha de árvore. Tudo tem uma **forma**! Quando uma linha dá a volta e se **fecha**, nasce uma forma. A linha que marca o limite chama-se **contorno**. Saber ver formas é o maior segredo do desenho — porque tudo, mesmo o mais difícil, é feito de formas simples juntas. Vamos descobrir como! ✏️🌟

> **Sabias?** Uma forma fechada feita **só de linhas retas** chama-se **polígono** (do grego, «muitos ângulos»). O círculo **não** é polígono, porque é curvo! ⭕🚫

## Formas orgânicas 🌿

As formas **orgânicas** são as da **natureza**: irregulares, suaves, sem dois lados iguais. Pensa numa folha, numa nuvem, numa poça de água ou na silhueta de uma pessoa. Não têm uma régua que as faça — cada uma é única!

## Figura e fundo 🐦

Numa imagem, há a **figura** (a forma principal, em que reparas) e o **fundo** (o espaço à volta). É o contorno que separa uma da outra. Por vezes o fundo também tem uma forma escondida — os artistas adoram esse jogo!

```figure

```

## O segredo: a forma escondida 🕵️

Aqui está o truque que os artistas usam para desenhar **tudo**: antes de desenhar os pormenores, procuram as **formas geométricas simples** dentro do objeto. Depois é só juntá-las!

> [!TIP] **Para saberes mais** 🌱 Uma forma desenhada no papel é **plana** — tem só comprimento e largura (**2 dimensões**). Mas no mundo real as coisas têm **volume**: são **sólidos** com **3 dimensões** (comprimento, largura e altura). O **quadrado** é uma forma; o **cubo** é o sólido. O **círculo** é uma forma; a **esfera** (a bola) é o sólido. Os artistas usam a **luz e a sombra** para fazer uma forma plana **parecer** que tem volume — é como enganar o olho do papel para 3D! 🎨📦
