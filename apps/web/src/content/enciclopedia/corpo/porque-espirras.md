# Porque é que espirras? 🤧

> [!NOTE] **O que vais aprender** 👀 **Atchim!** O espirro é uma "limpeza de
> emergência" do teu nariz — e sai a uma velocidade incrível! Vais descobrir
> porquê. 🤧💨

Quando entra cócegas no nariz — pó, pólen, pimenta ou uma luz forte — o teu corpo
decide **limpar tudo de uma vez**: enche os pulmões de ar e dispara-o pelo nariz e
pela boca a grande velocidade. Isso é um **espirro**, e serve para expulsar aquilo
que não devia lá estar. 👃

```stats

  { "label": "Velocidade 💨", "value": "~160 km/h", "hint": "como um carro de corrida!" },

  { "label": "Olhos 👀", "value": "fecham-se", "hint": "é quase impossível espirrar de olhos abertos" }

```

> **Boa maneira:** espirra sempre para o **cotovelo** (ou para um lenço), nunca
> para a mão — assim não espalhas os micróbios e não os passas a tocar nas coisas.
> 💪🤧

> [!TIP] **Para saberes mais** 🌱 Há pessoas que espirram quando olham para uma
> **luz forte**, como o Sol! Chama-se "espirro do sol" e passa de pais para
> filhos. Será que acontece contigo? ☀️🤧
