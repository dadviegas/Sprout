# A minha família 👨‍👩‍👧‍👦

A **família** são as pessoas que gostam de ti e cuidam de ti. 💗

## Quem faz parte da família?

Cada família é diferente — e todas são especiais! Podes ter:

```keyvalue
[
  { "k": "Pais", "v": "mãe e/ou pai 👩👨", "icon": "people" },
  { "k": "Irmãos", "v": "mais velhos ou mais novos 🧒" },
  { "k": "Avós", "v": "os pais dos teus pais 👵👴" },
  { "k": "Tios e primos", "v": "também são família! 👪" }
]
```

> [!NOTE] Há famílias grandes e pequenas. Algumas têm uma mãe, outras dois pais, outras vivem com os avós. **Todas são família!** 💞

## A árvore da família 🌳

Os **avós** são os pais da tua mãe e do teu pai. Por isso vieram **antes**:

```steps
[
  { "title": "Avós", "body": "vieram primeiro 👵👴" },
  { "title": "Pais", "body": "são filhos dos avós 👩👨" },
  { "title": "Tu", "body": "és filho/a dos teus pais! 🧒" }
]
```

## Ajudar em casa 🤝

Numa família, todos ajudam: arrumar os brinquedos, pôr a mesa, dar miminhos. ❤️
