# Os dias da semana 📅

> [!NOTE] **O que vais aprender** 👀 Vais aprender os **7 dias da semana** pela ordem certa, saber quais são os **dias de escola** e o **fim de semana**, e descobrir o que vem **antes** e **depois** de cada dia. 🗓️

Sabias que o tempo anda sempre para a frente, como um comboio? 🚂 Cada dia é uma carruagem com o seu nome. Quando conheces os nomes dos dias, já sabes quando vais à escola, quando brincas e quando descansas! Vamos aprendê-los juntos, é muito fácil! 😊

## Os 7 dias, pela ordem certa 🗓️

## Ontem, hoje e amanhã 🔄

Os dias andam sempre em fila. Há sempre um dia **antes** e um dia **depois**. Estas três palavras ajudam-te muito!

```keyvalue
[
  { "k": "Hoje", "v": "é o dia em que estás agora 🌞" },
  { "k": "Ontem", "v": "foi o dia que já passou, mesmo antes de hoje 🌙" },
  { "k": "Amanhã", "v": "é o dia que ainda vem, logo a seguir a hoje ⏭️" },
  { "k": "Antes / depois", "v": "antes de terça vem segunda; depois de terça vem quarta 🔁" }
]
```

> [!TIP] Se **hoje** é quarta-feira, então **ontem** foi terça-feira e **amanhã** será quinta-feira. A roda dos dias nunca pára! 🔄

## Um exemplo passo a passo 🔍

Vamos resolver juntos esta pergunta: *«Se hoje é sexta-feira, que dia vem amanhã?»* Calma, vais conseguir! 😊

```steps
[
  { "title": "1. Vê em que dia estás", "body": "a pergunta diz que HOJE é sexta-feira 📅" },
  { "title": "2. Pensa na ordem dos dias", "body": "depois de sexta-feira vem o sábado 🗓️" },
  { "title": "3. «Amanhã» é o dia a seguir", "body": "amanhã é sempre o próximo dia, logo a seguir a hoje ⏭️" },
  { "title": "4. Junta as duas ideias", "body": "a seguir a sexta vem sábado, e sábado é o fim de semana 🥳" },
  { "title": "5. Resposta", "body": "amanhã será sábado — dia de brincar! ⚽✅" }
]
```

> **Truque:** canta os dias como uma cantiga, sempre pela mesma ordem: *«Segunda, terça, quarta, quinta, sexta, sábado, domingo!»* 🎵 Quando precisares de saber o dia a seguir, canta a partir do dia em que estás e o próximo aparece sozinho!

> [!TIP] **Para saberes mais** 🌱 Os nomes dos dias vêm do **latim**, a língua antiga dos romanos! Em português dizemos «**-feira**» (segunda-feira, terça-feira...), mas noutros países os dias têm o nome de **estrelas e planetas**: em espanhol, o sábado é *«sábado»* e a segunda é *«lunes»*, que vem da **Lua** 🌙. Curioso, não é?
