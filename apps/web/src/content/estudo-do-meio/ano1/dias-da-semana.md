# Os dias da semana 📅

Uma semana tem **7 dias**. Vamos aprendê-los pela ordem certa! 🗓️

```steps
  { "title": "Sexta-feira", "body": "Quase fim de semana! 🎉", "icon": "5️⃣" },
  { "title": "Sábado", "body": "Dia de brincar! ⚽", "icon": "6️⃣" },

```

**Sábado** e **domingo** são o **fim de semana** — não há escola! 🥳

> [!TIP] **Para saberes mais** 🌱 **7 dias** fazem uma **semana**, cerca de **4 semanas** fazem um **mês**, e **12 meses** fazem um **ano**! De segunda a sexta são os **dias úteis** (escola e trabalho). 📅
