# Os cinco sentidos 👀

> [!NOTE] **O que vais aprender** 👀 Vais conhecer os teus **cinco sentidos** — visão, audição, olfato, paladar e tato — e o **órgão** que cada um usa para te contar tudo sobre o mundo. 🌍

Tens cinco superpoderes para conheceres o mundo! 🌍 Chamam-se **sentidos** e ajudam-te o dia todo, mesmo quando não dás conta. Quando vês um amigo, ouves uma música, cheiras o pão quentinho ou fazes festas a um cão — estás a usar os teus sentidos. Vamos descobri-los um a um! 😊

## Os cinco sentidos e os seus órgãos 🧠

Cada sentido usa uma parte especial do teu corpo, a que chamamos **órgão dos sentidos**. Olha que fácil!

São cinco sentidos: **visão, audição, olfato, paladar e tato**. Todos juntos contam-te tudo sobre o mundo! 🌟

> [!TIP] Sabias que o **olfato** ajuda o **paladar**? Quando estás constipado e o nariz está tapado, a comida parece não ter quase sabor! 🤧

## Os sentidos protegem-te 🛡️

Os sentidos não servem só para te divertires — também te **mantêm em segurança**. Eles avisam-te quando há perigo!

```steps
[
  { "title": "A visão avisa 👀", "body": "Vês um carro a chegar e ficas no passeio, em segurança." },
  { "title": "A audição avisa 👂", "body": "Ouves uma buzina ou um alarme e ficas atento." },
  { "title": "O olfato avisa 👃", "body": "Cheiras fumo e percebes que algo pode estar a arder." },
  { "title": "O paladar avisa 👅", "body": "Sentes que a comida está estragada e cospes." },
  { "title": "O tato avisa ✋", "body": "Sentes que o tacho está muito quente e tiras a mão depressa." }
]
```

Por isso devemos **cuidar dos nossos sentidos**: não gritar ao ouvido dos outros, não olhar para o sol e lavar bem as mãos. 🧼

## Um exemplo passo a passo 🔍

Imagina que estás a comer uma maçã. Quantos sentidos usas? Vamos ver! 🍎

```steps
[
  { "title": "Vês a maçã 👀", "body": "Os teus olhos veem que ela é vermelha e redonda. Isto é a VISÃO.", "icon": "👀" },
  { "title": "Cheiras a maçã 👃", "body": "O teu nariz sente o cheiro fresco. Isto é o OLFATO.", "icon": "👃" },
  { "title": "Tocas na maçã ✋", "body": "A tua mão sente que ela é lisa e fresquinha. Isto é o TATO.", "icon": "✋" },
  { "title": "Trincas a maçã 👅", "body": "A tua língua sente que é doce. Isto é o PALADAR.", "icon": "👅" },
  { "title": "Ouves o crunch 👂", "body": "Os teus ouvidos ouvem o 'crec' quando trincas. Isto é a AUDIÇÃO.", "icon": "👂" }
]
```

Viste? Com uma só maçã usaste os **cinco sentidos** ao mesmo tempo! 🎉

> **Truque:** aponta para a tua cara com o dedo e conta — **olhos** (ver), **ouvidos** (ouvir), **nariz** (cheirar), **boca/língua** (saborear) e **mãos** (tocar). Cinco partes, cinco sentidos! ✋

> [!TIP] **Para saberes mais** 🌱 Os animais também têm sentidos, mas alguns são muito melhores que os nossos! O **cão** cheira milhares de vezes melhor do que tu, a **coruja** vê no escuro e o **morcego** "vê" com os ouvidos, mandando sons que voltam para trás. Cada animal tem o seu superpoder! 🦇
