# Os cinco sentidos 👀

Tens cinco superpoderes para conheceres o mundo! 🌍 Chamam-se sentidos e ajudam-te o dia todo, mesmo quando não dás conta.

## Os cinco sentidos e os seus órgãos

Cada sentido usa uma parte do teu corpo. Olha que fácil! 😊

São cinco sentidos: visão, audição, olfato, paladar e tato. Todos juntos contam-te tudo sobre o mundo! 🌟

## Truque 🪄

Para nunca te esqueceres, aponta para cada parte da cara com o dedo: **olhos** (ver), **ouvidos** (ouvir), **nariz** (cheirar), **boca** (saborear) e **mãos** (tocar). Cinco partes, cinco sentidos! ✋

## Vamos aplicar 🧩

Estás na praia. Vamos descobrir que sentido usas em cada momento! 🏖️

```steps

  { "title": "Ouves as ondas 🌊", "body": "O som 'chuáá' chega aos teus ouvidos → audição 👂." },
  { "title": "Vês o mar azul 💙", "body": "Os teus olhos veem o mar e a areia → visão 👀." },
  { "title": "Sentes a areia quente 🏝️", "body": "A pele dos teus pés sente o calor → tato ✋." },
  { "title": "Cheiras a maresia 🌬️", "body": "O teu nariz sente o cheiro do mar → olfato 👃." }

```

Boa! Já consegues identificar os sentidos em qualquer sítio! 🙌

> [!TIP] **Para saberes mais** 🌱 Os animais também têm sentidos, mas alguns são muito melhores que os nossos! O cão cheira muitíssimo melhor do que tu, e a coruja vê no escuro. Cada animal tem o seu superpoder!
