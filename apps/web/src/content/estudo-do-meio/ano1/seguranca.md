## Um exemplo passo a passo 🔍

Imagina que queres atravessar a rua para ir ao parque. Vamos fazer juntos, com calma!

```steps
[
  { "title": "1. Para", "body": "Para junto ao passeio. Nunca atravesses a correr!" },
  { "title": "2. Procura a passadeira", "body": "Vê as riscas brancas no chão, parecidas com uma zebra 🦓." },
  { "title": "3. Olha para os dois lados", "body": "Olha para a esquerda e para a direita. Não vem nenhum carro?" },
  { "title": "4. Escuta", "body": "Apura o ouvido: ouves algum carro a chegar? 👂" },
  { "title": "5. Atravessa devagar", "body": "Atravessa a andar, sem correr, e continua a olhar. Chegaste! 🎉" }
]
```

> **Truque:** para atravessar, lembra-te de três palavras: **PARA, OLHA, ATRAVESSA**. Diz baixinho na tua cabeça: "Para... olha... atravessa!" É como uma musiquinha que nunca esqueces. 🎵

> [!TIP] **Para saberes mais** 🌱 O número **112** é o mesmo em toda a Europa! Se fores de viagem a França, a Espanha ou a Itália, o 112 também pede ajuda lá. E sabias que, quando ligas, deves dizer com calma **o que se passa** e **onde estás**? Há sempre uma pessoa simpática do outro lado pronta a ajudar. 🌍
