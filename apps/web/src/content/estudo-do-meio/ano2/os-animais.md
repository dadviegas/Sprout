# Os animais 🐾

> [!NOTE] **O que vais aprender** 👀 Vais descobrir **onde vivem** os animais, **o que comem**, **como nascem**, de que estão **cobertos** e **como se deslocam**. No fim, vais saber agrupar qualquer animal como um verdadeiro cientista! 🔬

Olá, explorador! 🌟 O mundo está cheio de **animais** diferentes: uns voam, outros nadam, outros correm pela floresta. 🦁🐟🐦 Há tantos que os cientistas tiveram de os **agrupar** para os conhecer melhor. Hoje vamos aprender a fazer isso — e vais ver que é mesmo divertido! Vamos a isto? 🚀

> [!NOTE] Alguns animais vivem em **mais do que um sítio**! O sapo 🐸 nasce na água e depois vive na terra. A gaivota 🐦 voa, mas também pousa na praia. A natureza está cheia de surpresas!

## De que estão cobertos? 🧥

Toca num cão, num peixe e numa galinha: sentes coisas diferentes! O **corpo** dos animais pode estar coberto de várias maneiras:

```keyvalue
[
  { "k": "Pelo 🐈", "v": "macio e quente: cão, gato, coelho, leão" },
  { "k": "Penas 🪶", "v": "leves para voar: pássaro, galinha, pato" },
  { "k": "Escamas 🐟", "v": "pequenas e brilhantes: peixe, cobra, lagarto" },
  { "k": "Pele nua 🐸", "v": "lisa e húmida: sapo, rã, minhoca" }
]
```

> [!NOTE] A cobertura **protege** o animal! O pelo aquece o gato no inverno ❄️, as penas ajudam o pássaro a voar 🐦 e as escamas protegem o peixe dentro da água. 🐟

## Um exemplo passo a passo 🔍

Vamos resolver juntos: *«A galinha 🐔 — onde vive, o que come, como nasce e de que está coberta?»* Vamos com calma, parte a parte.

```steps

  { "title": "2. O que come?", "body": "Come milho, minhocas e restos de comida — come de tudo, é OMNÍVORA 🍎🍖", "icon": "🍽️" },
  { "title": "3. Como nasce?", "body": "Põe ovos e dos ovos saem os pintainhos — é OVÍPARA 🥚", "icon": "🐣" },
  { "title": "4. De que está coberta?", "body": "O corpo tem PENAS 🪶", "icon": "🧥" },
  { "title": "5. Resposta completa", "body": "A galinha vive na terra, é omnívora, é ovípara e tem penas! 🐔✅", "icon": "🌟" }

```

> **Truque:** para descreveres qualquer animal, faz sempre as **4 perguntas mágicas**: **Onde vive? O que come? Como nasce? De que está coberto?** 🗝️ Responde a estas quatro e já sabes quase tudo sobre ele!

> [!TIP] **Para saberes mais** 🌱 Os animais agrupam-se em famílias maiores. Os que têm o corpo coberto de **pelo** e cujas crias mamam o leite da mãe chamam-se **mamíferos** — o golfinho 🐬 e o morcego 🦇 também são mamíferos, apesar de um nadar e o outro voar! E os animais com **penas** são as **aves** 🐦. Que nomes giros, não são?
