# As profissões 👷

Sabias que à tua volta há muita gente com trabalhos diferentes? 🧑‍🍳👩‍⚕️ Vamos descobrir o que fazem e como nos ajudam!

## O que é uma profissão? 🧑‍🔧

Uma **profissão** é o trabalho que uma pessoa faz para ajudar os outros e ganhar a vida.

Cada profissão tem uma tarefa especial. Olha alguns exemplos:

Viste? Cada um faz algo importante para todos nós!

## Truque 🪄

Para lembrar o que cada profissão faz, pensa: **"O que é que esta pessoa me dá ou em que me ajuda?"**

- Estou doente? → **médico** 👩‍⚕️
- Quero aprender? → **professor** 👨‍🏫
- Tenho fome de pão? → **padeiro** 🧑‍🍳

Liga sempre a profissão à **ajuda** que ela dá!

## Vamos aplicar 🧩

Vamos descobrir quem ajuda em cada situação do dia a dia:

```steps
[
  { "title": "Há um incêndio na floresta! 🔥", "body": "Quem vem com a mangueira de água? O bombeiro! 👨‍🚒" },
  { "title": "O Tomás partiu o braço 🤕", "body": "Quem trata dele no hospital? O médico! 👩‍⚕️" },
  { "title": "Queres comer uma cenoura 🥕", "body": "Quem a plantou na terra? O agricultor! 🧑‍🌾" }
]
```

Já consegues ligar cada profissão à sua ajuda! 🎉

> [!TIP] **Para saberes mais** 🌱 Algumas profissões trabalham em equipa no mesmo sítio. Num hospital, há médicos, enfermeiros e auxiliares — todos juntos cuidam dos doentes!
