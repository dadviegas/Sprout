# Seres vivos e não vivos 🌱

Olá! 🌟 Sabias que à tua volta há coisas que estão VIVAS e outras que não estão? Vamos descobrir juntos como saber a diferença. Vais ver que é fácil!

## O que é um ser vivo?

Um **ser vivo** faz quatro coisas muito especiais. Olha bem para esta lista, é a chave de tudo! 🔑

```keyvalue

  { "k": "Nasce", "v": "começa a sua vida, como um bebé ou uma sementinha 👶🌱" },
  { "k": "Cresce", "v": "fica maior com o tempo, como tu! 📏" },
  { "k": "Alimenta-se", "v": "come ou bebe para ter energia 🍎💧" },
  { "k": "Morre", "v": "no fim da sua vida, deixa de viver 🍂" }

```

As **plantas** e os **animais** são seres vivos. Tu também és! 🙂

E os **não vivos**? São coisas como uma pedra, uma cadeira ou um carro. Não nascem, não crescem, não comem nem morrem. Estão simplesmente ali. 🪨🚗

## Truque 🪄

Para decorares, lembra-te das **4 letrinhas mágicas: N-C-A-M** 🪄

**N**asce, **C**resce, **A**limenta-se, **M**orre.

Se uma coisa faz TODAS estas quatro, é um **ser vivo**! Se não faz nenhuma, é **não vivo**.
