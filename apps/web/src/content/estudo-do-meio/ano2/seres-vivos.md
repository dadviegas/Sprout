# Seres vivos e não vivos 🌱

> [!NOTE] **O que vais aprender** 👀 Vais descobrir como saber se uma coisa está **viva** ou **não viva**, conhecer os dois grandes grupos de seres vivos (**plantas** e **animais**) e perceber de que precisam para viver. 🐱🌼

Olá! 🌟 Sabias que à tua volta há coisas que estão **VIVAS** e outras que **não estão**? Um cão é vivo, mas a tua mochila não. Uma árvore é viva, mas a pedra do jardim não. Hoje vais aprender um truque que serve para qualquer coisa do mundo. Vais ver que é fácil! 😄

As **plantas** e os **animais** são seres vivos. Tu também és! 🙂

E os **não vivos**? São coisas como uma pedra, uma cadeira ou um carro. Não nascem, não crescem, não comem nem morrem. Estão simplesmente ali. 🪨🚗

## Um exemplo passo a passo 🔍

Vamos pensar numa **macieira** (a árvore das maçãs). Será que é um ser vivo? Vamos usar a regra mágica para descobrir!

```steps
[
  { "title": "Nasce?", "body": "Sim! Nasce de uma pequenina semente que estava na terra. 🌱" },
  { "title": "Cresce?", "body": "Sim! A árvore vai ficando cada vez mais alta. 🌳" },
  { "title": "Alimenta-se?", "body": "Sim! Bebe a água da terra e apanha a luz do sol. ☀️💧" },
  { "title": "Morre?", "body": "Sim! Um dia, no fim da sua vida, deixa de viver. 🍂" },
  { "title": "Conclusão", "body": "Fez as quatro coisas! Então a macieira é um SER VIVO, do grupo das plantas. Boa! 🎉" }
]
```

> **Truque:** lembra-te das **4 letrinhas mágicas: N-C-A-M** 🪄 — **N**asce, **C**resce, **A**limenta-se, **M**orre. Se uma coisa faz TODAS estas quatro, é um **ser vivo**! Se não faz nenhuma, é **não vivo**.

> [!TIP] **Para saberes mais** 🌱 Sabias que os seres vivos também **respiram**? As plantas até respiram pelas folhas e, com a luz do sol, fabricam o seu próprio alimento — uma magia chamada **fotossíntese**. É por isso que as plantas não precisam de ir às compras! 🍃☀️
