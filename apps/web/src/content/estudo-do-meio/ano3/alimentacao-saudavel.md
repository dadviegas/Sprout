# Alimentação saudável 🥗

Olá! Sabias que aquilo que comes te dá energia para correr, brincar e pensar? Vou ensinar-te a comer bem. Vais ver que é fácil! 😋

## A roda dos alimentos 🍎

A **roda dos alimentos** é como um prato gigante dividido em fatias. Cada fatia é um grupo de alimentos.

A regra é simples: come de **todas** as fatias, mas as maiores são as que precisas de comer **mais**.

Comer **variado** é o segredo: um bocadinho de cada grupo, todos os dias!

## Truque 🪄

Pensa no **arco-íris** no prato! 🌈 Quantas mais **cores** de fruta e legumes tiveres (vermelho, laranja, verde, roxo), mais saudável é a refeição. Um prato colorido é um prato campeão!

## Vamos aplicar 🧩

A Maria tem na mochila: água, batatas fritas de pacote, uma maçã e um chocolate. Vamos ajudá-la a escolher bem.

```steps
[
  { "title": "O que é saudável?", "body": "A água 💧 e a maçã 🍎 — ótimos para todos os dias!" },
  { "title": "O que é só às vezes?", "body": "As batatas fritas e o chocolate — comem-se com moderação, só de vez em quando 🍫" },
  { "title": "A escolha da Maria", "body": "Bebe água, come a maçã agora e guarda o chocolate para um dia de festa. Bem pensado! 👏" }
]
```

> [!TIP] **Para saberes mais** 🌱 Os alimentos muito doces ou muito salgados não fazem mal de vez em quando, mas comer açúcar a mais pode dar cáries nos dentes. Por isso é que se diz "com moderação"!
