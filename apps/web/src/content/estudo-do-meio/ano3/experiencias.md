# Vamos fazer experiências! 🔬

> [!NOTE] **O que vais aprender** 👀 Vais ser um **cientista**: aprender os passos de uma experiência (pergunta → palpite → testar → observar → concluir) e fazer três experiências fáceis em casa — descobrir o que **flutua ou afunda**, o que se **dissolve** na água, e que o **ar ocupa espaço**! 🧪

Os cientistas não adivinham — eles **experimentam** para descobrir como as coisas funcionam. E o melhor é que tu também podes! Com coisas simples lá de casa, vais investigar como um verdadeiro detetive da ciência. 🕵️🔎 Vamos a isto?

## Experiência 2 — O que se dissolve na água? 🥄

Põe uma colher de **açúcar** num copo de água e mexe. O açúcar parece **desaparecer** — chama-se **dissolver**. Agora tenta com **areia**: por mais que mexas, ela não desaparece, fica no fundo.

> O açúcar não desapareceu de verdade — está lá, só ficou tão pequenino que não o vês. Prova a água: está doce! 😋

## Um exemplo passo a passo 🔍

Vamos fazer a experiência toda com uma pergunta: *«Uma chave de metal flutua ou afunda?»* Segue os cinco passos! 🗝️

```steps
[
  { "title": "1. Pergunta", "body": "a chave de metal flutua ou afunda? 🗝️" },
  { "title": "2. Palpite", "body": "acho que afunda, porque o metal costuma ser pesado 🤔" },
  { "title": "3. Experiência", "body": "ponho a chave com cuidado na bacia com água 🧪" },
  { "title": "4. Observar", "body": "a chave foi logo ao fundo! 🔴" },
  { "title": "5. Conclusão", "body": "a chave afunda. Acertei no palpite — o metal é pesado para o seu tamanho ✅" }
]
```

> **Truque:** **prevê primeiro, testa depois.** Fazer o palpite ANTES torna a experiência muito mais divertida — ficas curioso por saber se acertaste! E lembra-te: a forma também conta, não só o material. 🔮

> [!TIP] **Para saberes mais** 🌱 Então como é que um navio gigante de **metal** flutua, se uma simples moeda afunda?! 🚢 O segredo é a **forma**: o navio é oco e largo, por isso empurra muitíssima água para o lado — e essa água empurra-o de volta para cima. Foi um sábio da Grécia antiga, o **Arquimedes**, que descobriu este truque há mais de 2000 anos!
