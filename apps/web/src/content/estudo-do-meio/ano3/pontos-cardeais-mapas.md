# Os pontos cardeais e os mapas 🧭

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **orientar-te**: os 4 **pontos cardeais** (N, S, E, O), como o **Sol** te mostra o caminho e como desenhar o **itinerário** da tua casa à escola. E ainda vais explorar o chão que pisas — as **rochas e o solo** — e fazer experiências com o **som e a luz**! 🔦

Imagina que estás num sítio novo e queres explicar a um amigo onde fica a tua escola. «É para ali» não chega — para ali de quem? 🤷 Os exploradores inventaram direções que servem para toda a gente: os **pontos cardeais**. Hoje aprendes a usá-los no teu bairro — e de caminho investigas as rochas, o solo, o som e a luz do teu meio local. 🗺️

## Os 4 pontos cardeais 🧭

As **4 direções principais** chamam-se pontos cardeais. A **rosa dos ventos** mostra-os todos de uma vez — toca em cada ponto para ouvir:

> **Truque:** decora a volta no sentido dos ponteiros do relógio — **N**unca **E**stejas **S**em **O**lhar: **N**orte, **E**ste, **S**ul, **O**este! 🕐

## O mapa do teu bairro: o itinerário 🗺️

Um **mapa** é um desenho de um lugar visto **de cima**, como um passarinho o vê. 🐦 Um **itinerário** é o caminho que traças nesse mapa — por exemplo, de casa à escola:

```steps
[
  { "title": "1. Marca a partida e a chegada", "body": "a tua casa 🏠 e a escola 🏫 no desenho do bairro" },
  { "title": "2. Escolhe o caminho", "body": "que ruas usas? Passas pelo jardim ou pela padaria? 🌳🥖" },
  { "title": "3. Descreve com direções", "body": "«saio de casa para Norte, viro a Este na rua da escola…» 🧭" },
  { "title": "4. Marca pontos de referência", "body": "a igreja, o café, o parque — ajudam a não te perderes 📍" }
]
```

> **Experimenta em casa:** desenha o teu itinerário casa–escola numa folha, com os pontos de referência. Depois pede a alguém para o seguir só com o teu desenho! 🎯

## Um exemplo passo a passo 🔍

*«A padaria fica a Este da escola. De manhã, como chego lá?»* 🥖

```steps
[
  { "title": "1. Lembra-te do Sol da manhã", "body": "de manhã o Sol nasce a ESTE 🌅" },
  { "title": "2. Vira-te para o Sol", "body": "à porta da escola, vira-te para o lado onde está o Sol ☀️" },
  { "title": "3. É por aí!", "body": "estás virado para Este — caminha em frente até à padaria 🥖" },
  { "title": "4. E para voltar?", "body": "a escola fica do lado contrário: a OESTE da padaria 🌇 ✅" }
]
```

> [!TIP] **Para saberes mais** 🌱 Entre os pontos cardeais existem os pontos **colaterais** — Nordeste, Sudeste, Sudoeste e Noroeste — que vais usar no 4.º ano com os mapas a sério. E a **bússola**, inventada na China há mais de 1000 anos, aponta sempre para Norte porque a Terra é um íman gigante! 🧲
