Imagina esta pergunta: *«Quem chegou ao Brasil, e isso foi antes ou depois de Portugal nascer?»* Vamos resolver com calma.

```steps
  { "title": "3. Vê a data de nascimento", "body": "Portugal nasceu em 1143 👑" },
  { "title": "4. Compara os números", "body": "1500 é maior que 1143, por isso foi DEPOIS 📈" },
  { "title": "5. Resposta", "body": "foi Pedro Álvares Cabral, e aconteceu muito depois de Portugal nascer ✅" }

```

> **Truque:** para te lembrares da ordem, decora **3 datas-âncora**: **1143** (nasce Portugal), **1500** (Brasil) e **1974** (liberdade). Qualquer acontecimento encaixa entre estas três! 📌

> [!TIP] **Para saberes mais** 🌱 No **25 de abril de 1974**, os soldados puseram **cravos** (uma flor vermelha) nas espingardas em vez de lutar — por isso se chama a **Revolução dos Cravos**. Foi nesse dia que Portugal voltou a ser livre, com eleições e liberdade para todos. Por isso o **25 de Abril** é feriado! 🌹
