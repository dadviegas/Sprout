# Mapas e pontos cardeais 🧭

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é um **mapa** e como o ler (legenda, escala e rosa dos ventos), aprender os **4 pontos cardeais** e os **4 colaterais**, e até **orientar-te** sozinho com o Sol, com a bússola e com a estrela Polar! 🗺️

Já alguma vez te perguntaste como sabemos onde fica cada sítio? 🗺️ Os mapas são desenhos vistos **de cima**, como se fosses um passarinho a olhar para a Terra. E os **pontos cardeais** são as direções que nos dizem para onde ir. No fim desta aula vais saber orientar-te como um verdadeiro explorador! 🧭

## O que é um mapa 🗺️

Um **mapa** é um desenho da Terra (ou de um pedaço dela) visto **de cima** e mais **pequeno** do que a realidade. Existem mapas de muitos tamanhos.

## A legenda do mapa 🔑

Num mapa não cabe tudo desenhado como é na realidade. Por isso usamos **símbolos**, e a **legenda** explica o que cada símbolo quer dizer. É como um código secreto que tu consegues ler!

```keyvalue
[
  { "k": "Legenda", "v": "a tabela que explica o que cada cor ou símbolo significa 🔑" },
  { "k": "Linha azul", "v": "costuma ser um rio ou o mar 💧" },
  { "k": "Cor verde", "v": "florestas, jardins e campos 🌳" },
  { "k": "Cor castanha", "v": "as montanhas mais altas ⛰️" },
  { "k": "Ponto ou estrela", "v": "uma cidade ou a capital de um país 🏙️" }
]
```

> [!TIP] Antes de leres um mapa, procura sempre a **legenda** e a **rosa dos ventos** num canto. São as tuas duas melhores ajudas! 🔎

## A escala — pequeno no papel, grande na realidade 📏

Um mapa é muito mais pequeno do que o sítio verdadeiro. A **escala** diz-te quanto é que ele foi encolhido. Assim, um caminho curto no mapa pode ser uma estrada bem comprida na vida real!

## Os 4 pontos cardeais 🧭

Os **pontos cardeais** são as **4 direções principais** que nos ajudam a saber para onde vamos. Num mapa, o **Norte** está quase sempre **para cima**.

```keyvalue
[
  { "k": "Norte (N)", "v": "fica para cima, aponta para o frio do Polo Norte ❄️" },
  { "k": "Sul (S)", "v": "fica para baixo, do lado contrário ao Norte ☀️" },
  { "k": "Este (E)", "v": "fica à direita, é por onde o Sol nasce de manhã 🌅" },
  { "k": "Oeste (O)", "v": "fica à esquerda, é por onde o Sol se põe ao fim do dia 🌇" }
]
```

A **rosa dos ventos** é um desenho parecido com uma estrela que mostra todos os pontos cardeais de uma vez. 🌹 Vês quase sempre uma num canto do mapa. Toca em cada ponto para descobrires onde fica:

```compass
{ "title": "A rosa dos ventos 🌹" }
```

## Os 4 pontos colaterais 🪁

E quando uma coisa fica **entre** dois pontos cardeais? Aí usamos os **pontos colaterais**, que ficam mesmo no meio de dois cardeais. São mais 4!

```keyvalue
[
  { "k": "Nordeste (NE)", "v": "entre o Norte e o Este ↗️" },
  { "k": "Noroeste (NO)", "v": "entre o Norte e o Oeste ↖️" },
  { "k": "Sudeste (SE)", "v": "entre o Sul e o Este ↘️" },
  { "k": "Sudoeste (SO)", "v": "entre o Sul e o Oeste ↙️" }
]
```

> [!TIP] No nome colateral, o **Norte** ou o **Sul** vem sempre **primeiro**: dizemos *Nordeste* e *Sudoeste*, nunca «Estenorte». 😉

## Vamos ler um mapa a sério 🇵🇹

Agora junta tudo num mapa verdadeiro: o de **Portugal**! Lembra-te de que o **Norte fica para cima** e o **Sul para baixo**. Por isso, no cimo do mapa estão as terras do Norte (como **Braga** e **Viana do Castelo**) e, lá em baixo, o **Algarve** (Sul ☀️). À esquerda fica o **Oeste**, onde está o **mar** 🌊; à direita, o **Este**, onde fica a **Espanha**. Toca em cada ponto para ouvires onde fica e qual é a sua capital de distrito:

```mapapt
{ "title": "O mapa de Portugal 🇵🇹" }
```

> [!TIP] Repara: os **Açores** 🌋 e a **Madeira** 🏝️ ficam no **oceano**, a Oeste do Continente. São as nossas ilhas — por isso aparecem dentro do mar no mapa, e não coladas ao resto do país.

## Um exemplo passo a passo 🔍

Imagina que estás de manhã num campo, sem bússola, e queres descobrir todos os pontos cardeais só com o Sol. Vamos a isso!

```steps
[
  { "title": "1. Olha para o Sol da manhã", "body": "De manhã, o Sol nasce a ESTE. Vira-te de frente para ele. Agora estás a olhar para Este! 🌅" },
  { "title": "2. Atrás de ti está o Oeste", "body": "Se à tua frente está o Este, então atrás das tuas costas fica o OESTE. 🌇" },
  { "title": "3. À tua esquerda está o Norte", "body": "Estende o braço esquerdo. Esse lado aponta para NORTE. ❄️" },
  { "title": "4. À tua direita está o Sul", "body": "Estende o braço direito. Esse lado aponta para SUL. ☀️ Pronto, já tens os 4!" }
]
```

> **Truque:** para decorares a ordem **Norte, Este, Sul, Oeste** (a rodar como os ponteiros do relógio 🕐), usa a frase **N**unca **E**stejas **S**em **O**lhar → N - E - S - O. E lembra-te: o Sol nasce a **E**ste e põe-se a **O**este. 🌅➡️🌇

> [!TIP] **Para saberes mais** 🌱 A **bússola** funciona porque a Terra é como um **íman gigante** 🧲: tem um Polo Norte e um Polo Sul magnéticos, e a agulhinha da bússola é atraída por eles, apontando sempre para o Norte. Foi inventada na China há mais de 1000 anos e ajudou os marinheiros dos Descobrimentos a atravessar o mar sem se perderem! ⛵
