# Mapas e pontos cardeais 🧭

Já alguma vez te perguntaste como sabemos onde fica cada sítio? 🗺️ Hoje vais aprender a orientar-te como um verdadeiro explorador!

## Os 4 pontos cardeais

Os **pontos cardeais** são as 4 direções principais que nos ajudam a saber para onde vamos. São como as 4 setas de uma seta gigante!

  { "k": "Norte (N)", "v": "fica para cima, aponta para o frio do Polo Norte ❄️" },

  { "k": "Este (E)", "v": "fica à direita, é por onde o Sol nasce de manhã 🌅" },
  { "k": "Oeste (O)", "v": "fica à esquerda, é por onde o Sol se põe ao fim do dia 🌇" }
]
```

A **bússola** é uma ferramenta com uma agulha mágica que aponta sempre para o Norte! 🧲 Assim, onde quer que estejas, descobres logo as outras direções.

A **rosa dos ventos** é um desenho num mapa, parecido com uma estrela, que mostra todos os pontos cardeais de uma vez. 🌹

## Truque 🪄

Para decorares a ordem **Norte, Este, Sul, Oeste** (rodando como os ponteiros do relógio 🕐), usa esta frase:

**N**unca **E**stejas **S**em **O**lhar → N - E - S - O

Lembra-te também: o Sol nasce a **E**ste (de manhã) e põe-se a **O**este (à tarde). 🌅➡️🌇

  { "title": "O lago está à esquerda", "body": "À esquerda de quem olha para Este fica o NORTE → o lago está a Norte. 💧" },
  { "title": "Os baloiços estão à direita", "body": "À direita fica o SUL → os baloiços estão a Sul. Boa, conseguiste! 🎉" }

```

> [!TIP] **Para saberes mais** 🌱 Entre os 4 pontos cardeais existem os **pontos colaterais**: Nordeste (NE), Noroeste (NO), Sudeste (SE) e Sudoeste (SO). Servem para dar direções ainda mais certinhas, como "fica a Nordeste"!
