# Proteger o ambiente ♻️

> [!NOTE] **O que vais aprender** 👀 Vais descobrir a **política dos 3 R** (Reduzir, Reutilizar, Reciclar), aprender a separar o lixo nos **ecopontos** certos, perceber porque é importante **poupar água e energia** e ficar a saber pequenos gestos que ajudam a cuidar do planeta todos os dias. 🌍

O planeta Terra é a tua casa gigante! 🌍 É lá que vivem as pessoas, os animais, as plantas, os rios e o mar. Mas, tal como o teu quarto fica desarrumado se ninguém cuidar dele, a Terra também precisa de ajuda. A boa notícia? **Tu podes ajudar todos os dias** com gestos pequeninos. Vamos aprender os truques! 💪

## A política dos 3 R ♻️

Para ajudar a Terra há uma regra fácil com 3 palavras que começam todas por **R**. E há uma ordem certa: primeiro **Reduzir**, depois **Reutilizar** e só no fim **Reciclar**.

```keyvalue

```

> **Lixo** é tudo aquilo que deitamos fora. Mas grande parte do lixo **não é lixo de verdade** — é matéria-prima que pode voltar a servir. Por isso separamos! 🌱

## Poupar água e energia 💧💡

Cuidar do ambiente não é só separar o lixo. Também é **não gastar à toa** a água e a energia, que são preciosas.

```steps
[
  { "title": "Fecha a torneira", "body": "Enquanto lavas os dentes ou ensaboas as mãos, fecha a torneira. Poupas litros de água! 🚰" },
  { "title": "Banho rápido", "body": "Um duche curto gasta muito menos água do que encher a banheira 🚿" },
  { "title": "Apaga a luz", "body": "Quando sais de um quarto, apaga a luz. E aproveita a luz do sol de dia! ☀️" },
  { "title": "Desliga os aparelhos", "body": "A televisão e os carregadores gastam energia mesmo parados. Desliga-os! 🔌" }
]
```

> [!WARNING] A água doce que podemos beber é **muito pouca** comparada com toda a água da Terra. Quase toda a água do planeta é água salgada do mar. Por isso cada gota conta! 💧

## Um exemplo passo a passo 🔍

Imagina que acabaste de beber um sumo numa **garrafa de plástico**. Onde a colocas?

```steps
[
  { "title": "1. Olha bem", "body": "Vês que a garrafa é de plástico — é leve e dobra um bocadinho." },
  { "title": "2. Esvazia", "body": "Vê se ficou sumo lá dentro. Despeja tudo para não sujar o resto do ecoponto." },
  { "title": "3. Esmaga", "body": "Carrega na garrafa para a deixar mais pequenina. Assim cabe muito mais lixo no contentor!" },
  { "title": "4. Pensa na cor", "body": "Plástico vai sempre no AMARELO 🟡, junto com o metal." },
  { "title": "5. Ecoponto certo", "body": "Atira a garrafa para o contentor amarelo. Boa, conseguiste ajudar o planeta! ✅" }
]
```

> **Truque:** decora **uma imagem por cor**: 🔵 **Azul = céu** (o papel vem das árvores altas que tocam o céu); 🟡 **Amarelo = brilho** (plástico e metal têm cores vivas); 🟢 **V**erde e **V**idro começam pelo mesmo **V**! Verde-Vidro andam sempre de mãos dadas. 🤝

> [!TIP] **Para saberes mais** 🌱 Sabias que o vidro pode ser reciclado **infinitas vezes** sem perder qualidade? Uma garrafa antiga pode virar uma garrafa novinha vezes e vezes sem conta! E reciclar latas de alumínio gasta muito menos energia do que fabricá-las de novo — poupar uma só lata chega para ter uma luz acesa durante horas. 💡
