# As classes de palavras 🧩

> [!NOTE] **O que vais aprender** 👀
> As palavras não andam todas misturadas — cada uma tem o seu **grupo**, a sua
> **classe**! 🧩 Umas dizem **nomes** de coisas, outras dizem **ações**, outras
> ainda **enfeitam** as palavras. Aqui vais conhecer cada classe, ouvir um
> **exemplo numa frase** e treinar a adivinhar a que grupo pertence cada palavra.
> Toca no altifalante 🔊 para ouvires tudo!

## Cada palavra no seu grupo 📦

Imagina uma arrumação de brinquedos: os carrinhos numa caixa, os bonecos noutra,
as peças noutra. 🧸🚗 As palavras também se arrumam em **caixas** chamadas

## O truque das três perguntas 🕵️

Quando não souberes a classe de uma palavra, faz **três perguntas mágicas**! 🪄

```steps
[
  { "icon": "🏷️", "title": "É o NOME de uma coisa?", "body": "Se for o nome de uma coisa, pessoa ou animal, é um nome (bola, avó, peixe)." },
  { "icon": "⚡", "title": "Diz uma AÇÃO?", "body": "Se disser algo que se faz, é um verbo (saltar, ler)." },
  { "icon": "🎨", "title": "Diz COMO é?", "body": "Se disser como é uma coisa, é um adjetivo (azul, mole, rápido)." }
]
```

Repara nesta frase, palavra a palavra: **«A** *(determinante)* **menina**
*(nome)* **corre** *(verbo)* **muito** *(advérbio)* **depressa** *(advérbio)***!»**
🏃‍♀️💨

## As palavrinhas que ligam 🔗

Algumas classes são pequeninas mas muito importantes — são a **cola** das
frases! 🍯 Compara as preposições com as conjunções:

```compare
[
  { "title": "Preposição 🔗", "rows": [
    { "label": "O que faz", "value": "liga uma palavra a outra" },
    { "label": "Exemplos", "value": "de, em, para, com, por" },
    { "label": "Numa frase", "value": "o bolo é de chocolate" }
  ] },
  { "title": "Conjunção 🪢", "rows": [
    { "label": "O que faz", "value": "junta ideias ou frases" },
    { "label": "Exemplos", "value": "e, mas, ou, porque" },
    { "label": "Numa frase", "value": "corri muito, mas ganhei" }
  ] }
]
```

> [!TIP] Truque do **«e»** e do **«mas»** 🪢
> O **«e»** *junta* coisas que combinam (pão **e** manteiga 🥪). O **«mas»**
> mostra uma *surpresa* ou algo ao contrário (queria sair, **mas** choveu ☔).

## Treina: que classe é? 🎯

Lê a palavra (ou ouve!) e escolhe a **caixa** certa. Vê quantas acertas
seguidas! 🃏

> [!TIP] **Para saberes mais** 🌱
> Há uma classe que muda de roupa conforme o lugar na frase! A palavra **«a»**
> tanto pode ser **determinante** (em «**a** bola» 👈, antes do nome) como
> **pronome** (em «vi-**a** ontem» 👀, no lugar de uma pessoa). Por isso é que
> os detetives das palavras olham sempre para a **frase inteira** antes de
> decidir a classe! 🕵️‍♀️🔍
