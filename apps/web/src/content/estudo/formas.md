# As formas e os sólidos 🔷

> [!NOTE] **O que vais aprender** 👀
> As **formas planas** (2D) — círculo, triângulo, quadrado, retângulo,
> pentágono e hexágono — e os **sólidos** (3D) — cubo, esfera, cilindro,
> cone, prisma e pirâmide. Toca em cada um para ouvir o nome e treina no fim! 🎧

## Formas planas (2D) ✏️

Uma forma **plana** é lisa, como um desenho no papel — não tem grossura.
Toca em cada uma para ouvires o nome e quantos **lados** tem! 👆

```

> [!TIP] **Truque dos lados** 🔢
> O nome conta-te os lados! *Tri*ângulo = **3**, *quadr*ado = **4**,
> *penta* = **5** (como no futebol americano 🏈), *hexa* = **6** (como o
> favo das abelhas 🐝). E o **círculo** é redondo — não tem lados nem cantos!

  { "k": "Retângulo ▬", "v": "4 lados — 2 compridos e 2 curtos" },
  { "k": "Pentágono ⬠", "v": "5 lados e 5 cantos" },
  { "k": "Hexágono ⬡", "v": "6 lados e 6 cantos" }

```

> [!TIP] **Quadrado ou retângulo?** 🤔
> O quadrado tem os **4 lados iguais**; o retângulo tem **2 lados compridos
> e 2 curtos**. Um ecrã de televisão é um **retângulo** 📺; um azulejo
> certinho é um **quadrado** 🟧.

## Sólidos (3D) 📦

Um **sólido** é uma forma que ocupa espaço — dá para segurar na mão!
Tem **faces** (as paredes), **arestas** (onde duas faces se encontram) e
**vértices** (os bicos). 🧊

```compare
[
  { "title": "Sólidos com bicos e cantos 📦", "rows": [
    { "label": "Cubo 🧊", "value": "como um dado — 6 faces quadradas iguais" },
    { "label": "Prisma 📕", "value": "como uma caixa de sapatos comprida" },
    { "label": "Pirâmide ⛰️", "value": "base em baixo e sobe até um bico, como no Egito" }
  ] },
  { "title": "Sólidos redondos 🥤", "highlight": true, "rows": [
    { "label": "Esfera ⚽", "value": "redonda toda à volta, como uma bola" },
    { "label": "Cilindro 🥫", "value": "como uma lata — 2 tampas redondas" },
    { "label": "Cone 🍦", "value": "como um chapéu de festa ou um gelado" }
  ] }
]
```

> [!TIP] **Truque do mundo à tua volta** 🔎
> Os sólidos estão por todo o lado! Um **dado** é um cubo 🎲, uma **bola**
> é uma esfera ⚽, uma **lata** é um cilindro 🥫, um **gelado** acaba em
> cone 🍦, uma **caixa** é um prisma 📦 e a **tenda** parece uma pirâmide ⛺.

> [!TIP] **Para saberes mais** 🌱
> Há **mais de 2300 anos**, um sábio grego chamado **Euclides** descobriu que
> só existem **5 sólidos perfeitos** com todas as faces iguais — chamam-se os
> **sólidos platónicos**. O **cubo** é um deles! Os outros têm faces que são
> triângulos ou pentágonos, como uma bola de futebol antiga ⚽✨.
