# Juntar sílabas em palavras 🧩

> [!NOTE] **O que vais aprender** 👀 Vais juntar **duas** e **três** sílabas,
> descobrir a palavra que se forma e usar a imagem para confirmar se leste bem.

Uma palavra pode nascer de duas ou três pecinhas. Lê uma de cada vez, junta e
olha para a imagem.

## Plano de 5 minutos por dia 🌱

1. Ouve 5 cartões.
2. Repete cada palavra em voz alta.
3. Escolhe 3 cartões e tenta ler sem ouvir.
4. Faz um treino rápido.
5. Acaba com uma palavra favorita e desenha-a num papel.
