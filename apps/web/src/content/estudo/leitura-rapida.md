# Treino rápido de leitura 🚀

> [!NOTE] **O que vais aprender** 👀 Vais treinar todos os dias em passos
> pequenos: primeiro **sílabas**, depois **palavras com imagem**, depois
> **palavras parecidas**. A ideia é acertar depressa sem adivinhar.

Este treino é para fazer em **5 a 8 minutos**. Pouco tempo, todos os dias,
ajuda o cérebro a reconhecer as sílabas mais depressa. Lê assim:
**olhar**, **dizer devagar**, **juntar**, **confirmar na imagem**.

## Rotina simples para aprender mais depressa 🌱

1. Faz o **Nível 1** uma vez.
2. Escolhe **10 palavras** do Nível 2.
3. Faz **um treino**: imagem, sílaba em falta ou palavras parecidas.
4. Repete só as palavras erradas.
5. No dia seguinte, começa pelas palavras erradas de ontem.
