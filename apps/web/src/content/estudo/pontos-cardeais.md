# Os pontos cardeais 🧭

> [!NOTE] **O que vais aprender** 👀 Vais ficar a saber de cor os **4 pontos cardeais** — Norte (N), Sul (S), Este (E) e Oeste (O) — e os **4 colaterais** — Nordeste (NE), Noroeste (NO), Sudeste (SE) e Sudoeste (SO). Vais descobrir que o Sol **nasce a Este** 🌅 e **se põe a Oeste** 🌇, e treinar tudo com a rosa dos ventos. Toca nos botões para ouvires! 🎧

Os **pontos cardeais** são as direções que nos ajudam a saber para onde ir, como num jogo de tesouro escondido. 🗺️ São sempre os mesmos, em qualquer lugar do mundo. Vamos guardá-los na cabeça!

## A rosa dos ventos 🌹

A **rosa dos ventos** é um desenho em forma de estrela que mostra todos os pontos de uma só vez. Toca em cada ponta para a agulha rodar e ouvires o nome! 👇

```compass
{ "title": "Toca em cada ponto 🌹" }
```

### O segredo do Sol ☀️

O Sol é o nosso ajudante: faz sempre a mesma viagem no céu, todos os dias.

```steps

  { "title": "De manhã 🌅", "body": "o Sol NASCE a ESTE (Nascente). Se te viras de frente para ele, estás a olhar para Este!", "icon": "🌅" },

  { "title": "À tua esquerda ❄️", "body": "virado para Este, o teu braço esquerdo aponta para NORTE.", "icon": "🧭" },
```

> **Truque:** para decorares a ordem **Norte → Este → Sul → Oeste** (a rodar como os ponteiros do relógio 🕐), diz a frase **N**unca **E**stejas **S**em **O**lhar → **N - E - S - O**. E nunca te esqueças: o Sol nasce a **E**ste e põe-se a **O**este. 🌅➡️🌇

## Os 4 pontos colaterais 🪁

E quando uma coisa fica **entre** dois pontos cardeais? Usamos os **colaterais**, que ficam mesmo no meio. São mais 4! Repara que o **Norte** ou o **Sul** vem sempre **primeiro** no nome.

> [!TIP] **Para saberes mais** 🌱 Sabias que a palavra **«Oriente»** quer dizer Este? É por lá que o Sol nasce, e por isso, quando descobres onde ficam os pontos cardeais, dizes que te estás a **«orientar»**! 🧭 As pessoas antigas viravam-se para o Nascente para se situarem — daí vem a palavra que hoje usamos quando alguém «se orienta» e sabe para onde ir. 🌍
