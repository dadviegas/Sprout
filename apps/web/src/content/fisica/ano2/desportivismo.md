# Ganhar e perder com desportivismo 🤝

> [!NOTE] **O que vais aprender** 👀 Vais aprender o que é o **fair-play** (jogo limpo): respeitar as regras, os colegas e os adversários — e saber ganhar **e** perder. 🤝

Nos jogos e desportos, às vezes ganhamos, às vezes perdemos. O mais importante não é o resultado — é **como** jogamos! 🌟

## O que é o fair-play? ⚖️

Fair-play é uma palavra inglesa que quer dizer **jogo limpo**. É tratar toda a gente bem, mesmo no calor do jogo:

## Um exemplo passo a passo 🔍

Imagina que estás a jogar à apanhada e a tua equipa **perde** mesmo no fim. O que fazes?

```steps
[
  { "title": "1. Respira fundo", "body": "perder dá um nó na barriga — está tudo bem sentir isso 😮‍💨" },
  { "title": "2. Nada de birra", "body": "não atires coisas nem chames nomes a ninguém 🚫" },
  { "title": "3. Vai ter com quem ganhou", "body": "diz \"boa, jogaram muito bem!\" 👏" },
  { "title": "4. Aperto de mão", "body": "um aperto de mão ou um abraço fecha o jogo com alegria 🤝" },
  { "title": "5. Pensa na próxima", "body": "o que podes treinar para correr mais depressa? 🏃" }
]
```

> **Truque:** no fim de um jogo, dá um **aperto de mão** ou um "bom jogo!" ao adversário. É o que fazem os verdadeiros campeões. 🤝

> [!TIP] **Para saberes mais** 🌱 Nos jogos a sério há um **árbitro** que faz cumprir as regras. Respeitar o árbitro, mesmo quando não concordamos, também é fair-play! Até nos Jogos Olímpicos há uma medalha especial só para quem mostra mais desportivismo. 🟨
