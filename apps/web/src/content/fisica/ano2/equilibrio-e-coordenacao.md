# Equilíbrio e coordenação 🤹

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é o **equilíbrio** (não cair!) e a **coordenação** (mãos e olhos a trabalhar juntos), e como treiná-los. 🤹

O teu corpo sabe fazer coisas incríveis quando treina! Duas delas são o equilíbrio e a coordenação. 🌟


## Um exemplo passo a passo 🔍

Vamos treinar o equilíbrio a fazer de **flamingo** 🦩. Segue os passos:

```steps
[
  { "title": "1. Pés juntos", "body": "fica direito, com os pés lado a lado 🧍" },
  { "title": "2. Escolhe um ponto", "body": "olha para uma marca fixa na parede à tua frente 👀" },
  { "title": "3. Levanta um pé", "body": "dobra um joelho e tira esse pé do chão 🦵" },
  { "title": "4. Abre os braços", "body": "braços abertos ajudam-te a não cair, como asas 🕊️" },
  { "title": "5. Conta até 10", "body": "se conseguires, troca de pé e tenta outra vez! 🔁" }
]
```

> **Truque:** para equilibrar melhor, olha para um **ponto fixo** à tua frente. Os olhos ajudam o corpo a não cair! 👀

> [!TIP] **Para saberes mais** 🌱 Dentro dos teus **ouvidos** há uma parte especial cheia de líquido que te diz se estás direito ou torto — é o teu "sensor de equilíbrio". Por isso é que ficas tonto quando andas às voltas: o líquido continua a mexer-se! 🌀
