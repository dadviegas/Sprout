# Equilíbrio e coordenação 🤹

> [!NOTE] **O que vais aprender** 👀 Vais perceber o que é o **equilíbrio** (manteres-te firme sem cair) e a **coordenação** (várias partes do corpo a trabalhar juntas), onde os usas todos os dias e como treiná-los a brincar. 🤹

O teu corpo sabe fazer coisas incríveis quando treina! Ficar num pé só, andar em cima de um muro baixinho, apanhar uma bola no ar… tudo isto usa duas super-habilidades escondidas: o **equilíbrio** e a **coordenação**. E o melhor é que se treinam a brincar! 🌟

## Um exemplo passo a passo 🔍

Vamos treinar o equilíbrio a fazer de **flamingo** 🦩. Segue os passos com calma:

```steps
[
  { "title": "1. Pés juntos", "body": "fica direito, com os pés lado a lado 🧍" },
  { "title": "2. Escolhe um ponto", "body": "olha para uma marca fixa na parede à tua frente 👀" },
  { "title": "3. Levanta um pé", "body": "dobra um joelho e tira esse pé do chão 🦵" },
  { "title": "4. Abre os braços", "body": "braços abertos ajudam-te a não cair, como asas 🕊️" },
  { "title": "5. Conta até 10", "body": "respira devagar e conta; se vacilares, pousa o pé e tenta outra vez 🔢" },
  { "title": "6. Troca de pé", "body": "agora o outro pé — os dois lados precisam de treino! 🔁" }
]
```

> **Truque:** para equilibrares melhor, olha para um **ponto fixo** à tua frente e aperta a barriga. Os olhos e os músculos do meio do corpo ajudam-te a não cair! 👀

> [!TIP] **Para saberes mais** 🌱 Dentro dos teus **ouvidos** há uns canais minúsculos cheios de líquido — é o teu "sensor de equilíbrio". Quando andas às voltas e paras, o líquido continua a mexer-se e o corpo pensa que ainda rodas: por isso ficas **tonto**! Os bailarinos e os ginastas treinam para enganar essa tontura, fixando os olhos num ponto a cada volta. 🌀
