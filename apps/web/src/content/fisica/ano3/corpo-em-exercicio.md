# O que o exercício faz ao corpo 💪

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que acontece **dentro do teu corpo** quando fazes exercício — e porque isso é tão bom para ti! ❤️

Quando corres ou saltas, o teu corpo faz mil coisas ao mesmo tempo, sem tu dares conta. É como uma equipa toda a trabalhar junta para te manter a mexer. Vamos espreitar lá dentro! 🔬

## A pulsação: sentir o coração 🫀

Sabias que consegues **sentir** o coração a trabalhar? Põe dois dedos no pescoço ou no pulso: aquilo que bate é a **pulsação**. Quanto mais te esforças, mais depressa ela bate.

```meters
[
  { "label": "😴 A dormir", "value": 2, "max": 10, "tone": "ok" },
  { "label": "🚶 A andar", "value": 5, "max": 10, "tone": "ok" },
  { "label": "🏃 A correr", "value": 9, "max": 10, "tone": "warn" }
]
```

> **Truque:** o coração é um **músculo**! E, como qualquer músculo, fica mais forte com treino — por isso o exercício faz tão bem. ❤️💪

## Um exemplo passo a passo 🔍

Imagina que vais correr no recreio. Vamos seguir o que acontece dentro de ti, passo a passo:

```steps
[
  { "title": "1. Começas a correr", "body": "os músculos das pernas começam a trabalhar e pedem mais energia 🦵" },
  { "title": "2. O coração acelera", "body": "bate mais depressa para enviar sangue aos músculos ❤️" },
  { "title": "3. Respiras mais fundo", "body": "os pulmões apanham mais ar, com o oxigénio de que precisas 🫁" },
  { "title": "4. Começas a suar", "body": "o corpo aquece e o suor sai para te arrefecer 💦" },
  { "title": "5. Paras e acalmas", "body": "aos poucos o coração abranda e ficas bem, cansado e contente 😄" }

```

> [!TIP] **Para saberes mais** 🌱 Quando te esforças muito, os músculos pedem mais **oxigénio**. Por isso respiras mais depressa: estás a apanhar o ar de que precisam para trabalhar! E o coração de um menino que treina chega a bater mais devagar em repouso — porque ficou forte e faz tudo com menos esforço. 🫁❤️
