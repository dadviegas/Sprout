# O que o exercício faz ao corpo 💪

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que acontece **dentro do teu corpo** quando fazes exercício — e porque isso é tão bom para ti! ❤️

Quando corres ou saltas, o teu corpo faz mil coisas ao mesmo tempo, sem tu dares conta. Vamos espreitar! 🔬

## Porque faz bem 🌟

```steps
[
  { "title": "Coração forte", "body": "o exercício torna o coração mais forte ❤️" },
  { "title": "Ossos e músculos", "body": "crescem saudáveis e firmes 🦴" },
  { "title": "Cabeça feliz", "body": "mexer liberta 'alegria' no cérebro 😄" }

```

> **Truque:** o coração é um **músculo**! E, como qualquer músculo, fica mais forte com treino — por isso o exercício faz tão bem. ❤️💪

> [!TIP] **Para saberes mais** 🌱 Quando te esforças muito, os músculos pedem mais **oxigénio**. Por isso respiras mais depressa: estás a apanhar o ar de que precisam para trabalhar! 🫁
