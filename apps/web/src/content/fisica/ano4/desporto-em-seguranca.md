# Desporto em segurança 🦺

> [!NOTE] **O que vais aprender** 👀 Vais aprender a fazer desporto **sem te magoares**: aquecer, usar o equipamento certo, beber água e ouvir o teu corpo. 🦺

Fazer desporto é ótimo — mas com **segurança**. Assim diverte-te e ficas inteiro para a próxima! 😄

## Aquecer e arrefecer: porquê? 🔥❄️

O corpo é como um carro num dia de frio: precisa de "ligar o motor" devagar antes de acelerar — e de abrandar antes de parar.

## Um exemplo passo a passo 🔍

A Matilde vai dar uma volta de bicicleta ao parque. Vê como ela se prepara com segurança, do início ao fim:

```steps
[
  { "title": "1. Equipamento", "body": "põe o capacete e aperta-o bem debaixo do queixo 🪖" },
  { "title": "2. Aquecer", "body": "marcha no lugar e roda os braços para acordar os músculos 🔥" },
  { "title": "3. Água por perto", "body": "leva uma garrafa de água e bebe nas pausas 💧" },
  { "title": "4. Ouvir o corpo", "body": "sente uma dor estranha no joelho — para logo e avisa o pai 🛑" },
  { "title": "5. Arrefecer", "body": "no fim pedala bem devagar e alonga as pernas 😌" }
]
```

> **Truque:** dor **ligeira** de músculo cansado é normal; dor **forte** ou de repente é sinal de **parar**. Ouve o teu corpo! 🛑

> [!TIP] **Para saberes mais** 🌱 O **capacete** pode parecer uma chatice, mas protege a parte mais importante: a **cabeça** e o **cérebro**, que comandam tudo no teu corpo. Os atletas profissionais usam-no sempre que é preciso — e tu também deves! 🪖
