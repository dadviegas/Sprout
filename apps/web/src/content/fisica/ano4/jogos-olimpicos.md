# Os Jogos Olímpicos 🏅

> [!NOTE] **O que vais aprender** 👀 Vais conhecer os **Jogos Olímpicos** — a maior festa do desporto do mundo —, o significado dos **anéis** e de onde vieram. 🏅

De quatro em quatro anos, atletas de quase todos os países juntam-se para competir nos **Jogos Olímpicos**. É a maior festa do desporto! 🌍

## Um exemplo passo a passo 🔍

Imagina uma final dos **100 metros** de atletismo. Vê como se decidem as medalhas, passo a passo:

```steps
[
  { "title": "1. À partida", "body": "os atletas preparam-se nos blocos e esperam pelo sinal 🚦" },
  { "title": "2. A corrida", "body": "correm o mais depressa que conseguem, 100 metros a direito 🏃" },
  { "title": "3. A chegada", "body": "quem cruzar a meta em 1.º ganha o ouro 🥇" },
  { "title": "4. 2.º e 3.º", "body": "o segundo leva a prata 🥈 e o terceiro o bronze 🥉" },
  { "title": "5. O pódio", "body": "os três sobem ao pódio e ouve-se o hino do campeão 🎶" }
]
```

> **Truque:** **ouro** é o 1.º lugar, **prata** o 2.º, **bronze** o 3.º. Pensa no pódio: o do meio (ouro) é o mais alto! 🥇

> [!TIP] **Para saberes mais** 🌱 Os primeiros Jogos Olímpicos aconteceram há mais de **2700 anos**, na **Grécia** antiga! Por isso a chama olímpica parte sempre de lá. Também existem os **Jogos Paralímpicos**, para atletas com deficiência — igualmente cheios de campeões! 🇬🇷🔥
