# In the classroom 🏫

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer em inglês as **coisas da tua sala de aula** — caneta, lápis, livro, mochila — e ainda a perceber o que a **teacher** pede: *Sit down!*, *Look!*, *Listen!*. No fim, já te sentes em casa numa aula em inglês! ✏️📚

Olá! 👋 Imagina que entras numa sala de aula em Inglaterra. Vês uma mochila, um lápis, um livro, um quadro grande na parede… São as mesmas coisas que tens na tua escola, só que têm **nomes em inglês**! Vamos descobri-los um a um. Pega no teu lápis (no teu *pencil*!) e vamos lá! ✏️😄

## O que diz a teacher? 🗣️

Na aula, a **teacher** (professora) diz frases curtinhas para tu fazeres coisas. Estas são as mais importantes — ouve e imagina-te a fazê-las! 🎈

```keyvalue
[
  {
    "k": "Sit down! 🪑",
    "v": "Senta-te!",
    "lang": "en-US"
  },
  {
    "k": "Stand up! 🧍",
    "v": "Levanta-te!",
    "lang": "en-US"
  },
  {
    "k": "Open your book! 📖",
    "v": "Abre o livro!",
    "lang": "en-US"
  },
  {
    "k": "Listen! 👂",
    "v": "Ouve!",
    "lang": "en-US"
  },
  {
    "k": "Look! 👀",
    "v": "Olha!",
    "lang": "en-US"
  }
]
```

> [!TIP] **Sit down** e **stand up** são contrárias: *sit down* é para baixo (sentar) e *stand up* é para cima (levantar). Pensa: *up* é para cima! ⬆️⬇️

## Um exemplo passo a passo 🔍

Imagina que a teacher quer que abras o teu livro. Ela diz *«Open your book!»*. Vamos perceber o que cada bocadinho quer dizer, com calma. 🧐

```steps
[
  { "title": "1. Ouve a teacher", "body": "A professora diz: Open your book! 👂", "icon": "👂" },
  { "title": "2. 'Open' quer dizer abrir", "body": "Open = abre (abrir alguma coisa) 📖", "icon": "📖" },
  { "title": "3. 'Your' quer dizer o teu", "body": "Your = o teu, a tua 🙂", "icon": "🫵" },
  { "title": "4. 'Book' quer dizer livro", "body": "Book = livro 📚", "icon": "📚" },
  { "title": "5. Junta tudo", "body": "Open your book! = Abre o teu livro! ✅ E agora abres mesmo o livro! 🎉", "icon": "✅" }
]
```

> **Truque:** liga cada palavra inglesa a uma coisa que vês mesmo na tua sala — aponta para ela com o dedo e diz a palavra em inglês! Aponta para a caneta e diz «pen», para a cadeira e diz «chair». Assim nunca te esqueces! 👉

> [!TIP] **Para saberes mais** 🌱 Em inglês britânico (de Inglaterra) a borracha chama-se **rubber**, mas em inglês americano (dos Estados Unidos) diz-se **eraser**! É a mesma coisa, só com dois nomes diferentes. 🇬🇧🇺🇸
