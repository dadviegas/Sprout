# Colours 🌈

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer as **cores em inglês** — *colours* — e a perguntar e responder **"What colour is it?"** (Que cor é?). No fim já consegues dizer a cor das tuas coisas favoritas! 🎨

Olá, pequeno artista! 👋 O mundo está cheio de cores: o céu azul, a relva verde, o sol amarelo. Em inglês, as cores chamam-se **colours**. Hoje vamos pintar tudo com palavras novas — vais ver que é divertidíssimo! 🖍️

## As cores principais 🎨

Estas são as cores que vais ouvir mais vezes. Olha para cada bolinha e repete a palavra em voz alta! 🗣️

```keyvalue
[
  { "k": "Red 🔴", "v": "vermelho — como um morango 🍓" },
  { "k": "Blue 🔵", "v": "azul — como o céu ☁️" },
  { "k": "Yellow 🟡", "v": "amarelo — como o sol ☀️" },
  { "k": "Green 🟢", "v": "verde — como a relva 🌿" },
  { "k": "Orange 🟠", "v": "laranja — como a fruta laranja 🍊" },
  { "k": "Purple 🟣", "v": "roxo — como uma uva 🍇" }
]
```

> [!NOTE] A palavra **orange** é mágica: serve para a **cor laranja** *e* para a **fruta laranja**! 🍊

> [!TIP] **Black** e **white** são opostos: o **preto** é a cor mais escura e o **branco** a mais clara! ⚫⚪

## Como perguntar e responder 💬

Em inglês, perguntamos a cor de uma coisa assim. É muito fácil — só tens de juntar a pergunta com a resposta! 🤝

```compare
[
  { "title": "Perguntar ❓", "rows": [
    { "label": "What colour is it?", "value": "Que cor é?" },
    { "label": "What colour is the apple?", "value": "Que cor é a maçã? 🍎" }
  ] },
  { "title": "Responder ✅", "rows": [
    { "label": "It is red.", "value": "É vermelho/vermelha.", "highlight": true },
    { "label": "It is green.", "value": "É verde 🟢", "highlight": true }
  ] }
]
```

> [!NOTE] Para dizer a cor de uma coisa, começas sempre por **"It is..."** (É...) e depois dizes a cor. Por exemplo: **It is blue!** 🔵

## Um exemplo passo a passo 🔍

Imagina que vês uma **maçã vermelha** 🍎 e queres dizer a sua cor em inglês. Vamos fazer juntos, com calma!

```steps
[
  { "title": "1. Olha bem para o objeto", "body": "Tens uma maçã na mão. Que cor tem? Vermelha! 🍎", "icon": "👀" },
  { "title": "2. Lembra-te da cor em inglês", "body": "Vermelho em inglês é red. 🔴", "icon": "🔴" },
  { "title": "3. Começa pela frase mágica", "body": "Para dizer a cor começamos por It is... (É...).", "icon": "💬" },
  { "title": "4. Junta tudo", "body": "It is red! 🎉", "icon": "🧩" },
  { "title": "5. Responde à pergunta", "body": "What colour is the apple? → It is red! Conseguiste! ✅", "icon": "✅" }
]
```

> **Truque:** liga cada cor a uma coisa que adoras: **red** = morango 🍓, **yellow** = sol ☀️, **green** = relva 🌿, **blue** = céu ☁️. Quando vires a coisa, lembras-te logo da cor em inglês! 🧠

> [!TIP] **Para saberes mais** 🌱 Quando juntas o **azul** (blue) com o **amarelo** (yellow), nasce o **verde** (green)! E **red** + **blue** dá **purple** (roxo). As cores também se misturam em inglês — experimenta com as tintas! 🎨
