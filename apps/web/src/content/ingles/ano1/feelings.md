## "How are you?" — como estás? 💬

A pergunta mais importante de hoje! **"How are you?"** quer dizer **"Como estás?"**. E para responder começas sempre por **"I am..."** (Eu estou...). Também podes dizer **"I'm..."**, que é a mesma coisa mais curtinha! 🙂

```keyvalue

  { "k": "How are you? 🤔", "v": "Como estás? (a pergunta)" },
  { "k": "I am happy. 😀", "v": "Estou feliz." },
  { "k": "I am sad. 😢", "v": "Estou triste." },
  { "k": "I'm tired. 😴", "v": "Estou cansado. ('I'm' é igual a 'I am')" },
  { "k": "I'm hungry. 🍽️", "v": "Estou com fome." }
]
```

> [!NOTE] Repara: dizes sempre **"I am..."** (ou **"I'm..."**) para falares de TI. *I am happy!* 😀 *I'm scared!* 😨

## Um exemplo passo a passo 🔍

Imagina que um amigo inglês te pergunta *«How are you?»* e tu estás muito feliz porque é o teu aniversário! 🎂 Como respondes? Vamos com calma! 😄

```steps
[
  { "title": "1. Ouve a pergunta", "body": "O amigo diz: How are you? = Como estás? 🤔", "icon": "🤔" },
  { "title": "2. Vê como te sentes", "body": "Estás muito contente! Feliz em inglês é happy 😀", "icon": "😀" },
  { "title": "3. Começa por I'm", "body": "Para falares de ti começas por I'm (que é I am) 🙂", "icon": "🗣️" },
  { "title": "4. Junta a palavra", "body": "I'm + happy = I'm happy! 😀", "icon": "🧩" },
  { "title": "5. Diz a frase", "body": "I'm happy! 😀 (Estou feliz!) Boa, respondeste em inglês! 🎉", "icon": "🎉" }
]
```

> **Truque:** junta a **cara** à **palavra**! Quando vês 😀 pensas logo *happy*; quando vês 😢 pensas logo *sad*. A carinha ajuda-te a lembrar a palavra! 😄

> [!TIP] **Para saberes mais** 🌱 Em inglês dizemos *«I AM happy»* — e o engraçado é que o "am" vem do verbo **"to be"**, que serve para **"ser"** E para **"estar"**! É a mesma palavra para as duas coisas. Por isso *I am happy* pode ser "eu sou feliz" ou "eu estou feliz". Um verbo, dois trabalhos! 🤩
