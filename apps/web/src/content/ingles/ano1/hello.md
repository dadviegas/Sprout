# Hello! Greetings 👋

Em inglês dizemos **olá** de uma forma diferente! Vamos aprender a cumprimentar. 😀

```keyvalue
[
  { "k": "Hello! 👋", "v": "Olá!" },
  { "k": "Hi! 🙋", "v": "Oi! (mais informal)" },
  { "k": "Goodbye! / Bye! 👋", "v": "Adeus!" },
  { "k": "Thank you! 🙏", "v": "Obrigado(a)!" }
]
```

## Como estás?

- **How are you?** → Como estás?
- **I'm fine, thank you!** 😊 → Estou bem, obrigado!

> [!TIP] Carrega no 🔊 nas perguntas para ouvires as palavras. Repete em voz alta! 🗣️
