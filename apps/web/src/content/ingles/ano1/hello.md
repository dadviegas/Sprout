# Hello! Greetings 👋

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **cumprimentar em inglês** — dizer olá e adeus, perguntar **«How are you?»**, dizer o teu nome e ser **simpático** com palavras mágicas como *please* e *thank you*. 🌟

Olá! 👋 Sabias que em inglês as pessoas dizem **«Hello!»** em vez de «Olá»? Hoje vais aprender a cumprimentar como um verdadeiro inglês. Vais ver: é fácil, é divertido e podes treinar com a tua família em casa! Carrega no 🔊 para ouvir cada palavra e repete em voz alta. 🗣️

## Dizer olá e adeus 👋

Quando encontras alguém, dizes **olá**. Quando te vais embora, dizes **adeus**. Em inglês há palavras para cada momento — ouve bem como soam!

```keyvalue
[
  { "k": "Hello! 👋", "v": "Olá! (a forma mais usada)" },
  { "k": "Hi! 🙋", "v": "Oi! (mais informal, com amigos)" },
  { "k": "Goodbye! 👋", "v": "Adeus! (a forma completa)" },
  { "k": "Bye! / Bye-bye! 👋", "v": "Adeusinho! (curtinho e amigável)" },
  { "k": "See you! 😊", "v": "Até logo! / Vemo-nos depois!" }
]
```

## Bom dia, boa tarde, boa noite ☀️🌙

Em inglês também cumprimentamos de forma diferente conforme a **hora do dia**. Repara: usamos *good* (bom/boa) e depois a parte do dia!

```compare

    { "label": "Good morning!", "value": "Bom dia! (de manhã)" },

    { "label": "Good evening!", "value": "Boa noite! (quando chegas)" },
    { "label": "Good night!", "value": "Boa noite! (quando vais dormir 😴)", "highlight": true }
```

## Como estás? How are you? 😊

Depois de dizer olá, costumamos perguntar **como está** a outra pessoa. Em inglês perguntamos **«How are you?»** e respondemos com um sorriso!

```keyvalue
[
  { "k": "How are you? 🙂", "v": "Como estás?" },
  { "k": "I'm fine, thank you! 😊", "v": "Estou bem, obrigado(a)!" },
  { "k": "I'm happy! 😄", "v": "Estou feliz!" },
  { "k": "And you? 🔄", "v": "E tu?" }
]
```

## As palavras mágicas ✨

Ser **simpático** é muito importante! Em inglês há três palavras mágicas que mostram boa educação. Usa-as sempre!

```steps
[
  { "title": "Please 🙏", "body": "Por favor — pedes uma coisa com educação: \"Water, please!\"", "icon": "heart" },
  { "title": "Thank you 🌟", "body": "Obrigado(a) — dizes quando alguém te ajuda ou te dá algo", "icon": "heart" },
  { "title": "You're welcome 😊", "body": "De nada — respondes quando alguém te agradece", "icon": "heart" },
  { "title": "Sorry 🙇", "body": "Desculpa — dizes quando fazes algo sem querer", "icon": "heart" }
]
```

## Dizer o teu nome 🪪

Quando conheces alguém, dizes como te chamas. É a primeira coisa que se aprende numa língua nova!

```keyvalue
[
  { "k": "What's your name? 🙋", "v": "Como te chamas?" },
  { "k": "My name is… 😊", "v": "O meu nome é… (e dizes o teu nome!)" },
  { "k": "I'm… 🙂", "v": "Eu sou… (mais curtinho)" },
  { "k": "Nice to meet you! 🤝", "v": "Muito prazer! (gosto de te conhecer)" }
]
```

## Um exemplo passo a passo 🔍

Imagina que encontras um amigo inglês de manhã, na escola. Como o cumprimentas e te apresentas? Vamos com calma! 🧐

```steps
[
  { "title": "1. Vê a hora do dia", "body": "É de manhã, por isso dizes: \"Good morning!\" ☀️" },
  { "title": "2. Diz olá", "body": "Sorris e dizes: \"Hello!\" 👋" },
  { "title": "3. Pergunta como está", "body": "\"How are you?\" — Como estás? 🙂" },
  { "title": "4. Diz o teu nome", "body": "\"My name is Tomás.\" — O meu nome é Tomás. 🪪" },
  { "title": "5. Sê simpático", "body": "No fim dizes: \"Nice to meet you!\" 🤝 e sorris! 😊" }
]
```

> **Truque:** para te lembrares dos cumprimentos do dia, pensa em **good + parte do dia**: *good* **morning** (manhã), *good* **afternoon** (tarde), *good* **night** (noite). É sempre «good» + a hora! 🕐

> [!TIP] **Para saberes mais** 🌱 Em inglês há uma diferença engraçada: **«Good evening»** diz-se quando **chegas** à noite (a cumprimentar), mas **«Good night»** diz-se quando te vais **deitar** ou despedir à noite. É como dizer «boa noite a chegar» e «boa noite a sair»! 🌙😴
