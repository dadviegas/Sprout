# Numbers 1–10 🔢

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **contar de 1 a 10 em inglês**, a dizer cada número em voz alta e a perguntar *"How many?"* (quantos são?). Conta connosco! 🗣️

Olá, contador! 👋 Já sabes contar em português: um, dois, três… Agora vamos aprender a contar na **língua inglesa**! Vais ver que é divertido e que muitas palavras parecem uma canção. Prepara os teus dedos das mãos — temos exatamente **10**, um para cada número! ✋🤚

## Quantos são? "How many?" 🍎

Quando queres saber a quantidade de uma coisa em inglês, perguntas **"How many?"** (quantos são?). Depois contas e respondes com o número.

## Conta os animais 🐾

Vamos treinar a contar! Olha quantos animais há em cada linha e diz o número em inglês.

```meters
[
  { "label": "🐶 dogs", "value": 3, "max": 10, "tone": "ok" },
  { "label": "🐱 cats", "value": 5, "max": 10, "tone": "ok" },
  { "label": "🐤 birds", "value": 7, "max": 10, "tone": "ok" },
  { "label": "🐟 fish", "value": 10, "max": 10, "tone": "ok" }
]
```

> [!NOTE] 3 dogs = **three**, 5 cats = **five**, 7 birds = **seven**, 10 fish = **ten**! 🎉

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *"How many balloons? 🎈🎈🎈🎈"* Vamos descobrir a resposta com calma.

```steps
[
  { "title": "1. Ouve a pergunta", "body": "\"How many?\" quer dizer: quantos são? 🧐" },
  { "title": "2. Conta um a um", "body": "aponta para cada balão: 1… 2… 3… 4 🎈🎈🎈🎈" },
  { "title": "3. O número é 4", "body": "contaste quatro balões ✋" },
  { "title": "4. Diz em inglês", "body": "4 em inglês é \"four\" 🔊" },
  { "title": "5. Resposta", "body": "\"Four balloons!\" — quatro balões! ✅🎈" }
]
```

> **Truque:** o número **5** é fácil de lembrar — é a tua mão toda aberta! ✋ "five" = 5 dedos. E o **10** são as **duas mãos**: "ten" 🙌

> [!TIP] **Para saberes mais** 🌱 Depois do **ten (10)** vem o **eleven (11)** e o **twelve (12)** — e a partir do **thirteen (13)** muitos números terminam em **-teen**: thir**teen**, four**teen**, fif**teen**… É como a palavra "teenager" (adolescente)! 😄
