## Como falar dos animais 💬

Saber o nome é bom, mas o mais fixe é **fazer frases**! Em inglês usamos *I have a…* para dizer que temos um animal, e *It is a…* para dizer o que é.

```keyvalue
[
  {
    "k": "I have a dog 🐶",
    "v": "Tenho um cão",
    "lang": "en-US"
  },
  {
    "k": "I have a cat 🐱",
    "v": "Tenho um gato",
    "lang": "en-US"
  },
  {
    "k": "It is a bird 🐦",
    "v": "É um pássaro",
    "lang": "en-US"
  },
  {
    "k": "What animal is it? 🤔",
    "v": "Que animal é? (a pergunta)",
    "lang": "en-US"
  },
  {
    "k": "I like lions 🦁",
    "v": "Eu gosto de leões",
    "lang": "en-US"
  },
  {
    "k": "Big / small",
    "v": "grande / pequeno 📏",
    "lang": "en-US"
  }
]
```

> [!TIP] Quando há **mais do que um** animal, em inglês juntamos um **s** no fim: one cat → two **cats** 🐱🐱; one dog → three **dogs** 🐶🐶🐶. Fácil!

## Um exemplo passo a passo 🔍

Imagina que queres apresentar o teu animal de estimação a um amigo inglês. Tens um cão grande chamado Rex. Vamos montar a frase juntos! 🐶

```steps

  { "title": "3. Junto o animal", "body": "I have a dog! (Tenho um cão!) ✨", "icon": "🐾" },
  { "title": "4. Descrevo o cão", "body": "O Rex é grande = big. Digo: It is big! (É grande!)", "icon": "📏" },
  { "title": "5. Frase completa", "body": "I have a dog. It is big! 🐶 Boa, apresentaste o Rex em inglês! 🎉", "icon": "🎉" }
]
```

> **Truque:** para te lembrares dos sons em inglês, pensa que **dog → woof**, **cat → meow** e **cow → moo**. O som da **cow** (moo) parece o nosso "muuu" da vaca — é quase igual! 🐄

> [!TIP] **Para saberes mais** 🌱 Alguns animais mudam de forma esquisita no plural! Um **mouse** 🐭 (rato) → dois **mice** (não é "mouses"!). E um **sheep** 🐑 (ovelha) escreve-se **igual** no plural: one sheep, two sheep! E o **fish** 🐟 também: one fish, two fish. Que animais brincalhões! 😄
