## Um exemplo passo a passo 🔍

Imagina que tens fome e queres uma maçã. Vamos montar a frase, peça a peça! 🧩

```steps
[ { "title": "1. Sinto o que tenho", "body": "Tenho fome, por isso digo: I'm hungry! 🍽️", "icon": "🍽️" }, { "title": "2. Escolho a comida", "body": "Quero uma maçã. Maçã = apple. 🍎", "icon": "🍎" }, { "title": "3. Digo que gosto", "body": "Para pedir com gosto: I like apples! (Eu gosto de maçãs!) 😍", "icon": "😍" }, { "title": "4. Junto tudo", "body": "I'm hungry. I like apples! Boa — já pediste em inglês! 🎉", "icon": "🎉" } ]
```

> **Truque:** **I like** = "gosto" com um grande sorriso 😍; **I don't like** tem o *don't*, que é o "NÃO". E lembra-te: **hungry** rima com "comer" (fome 🍽️) e **thirsty** com "ter sede" (água 💧).

> [!TIP] **Para saberes mais** 🌱 Quando há **muitas** de uma coisa, em inglês juntamos um **-s** no fim: apple → apple**s**, banana → banana**s**. Mas **water**, **milk** e **rice** não levam "s", porque não se contam um a um — dizemos *some water* (alguma água) 💧. Curioso, não é?
