# 🍎 Food & drinks

Olá! Hoje vais aprender a falar de comida e bebida em inglês. Vais ver que é muito fácil e ainda fica a tua barriguinha contente! 😋

## As palavras da comida 🍞

Em inglês, cada comida e bebida tem o seu nome. Vamos conhecer cinco amigos da cozinha!


```keyvalue

```

## Um exemplo passo a passo 🔍

Imagina que tens fome e queres uma maçã. Vamos montar a frase!

```steps
[ { "title": "Sinto fome", "body": "Digo: I'm hungry! (Tenho fome!)" }, { "title": "Escolho a comida", "body": "Quero uma maçã = apple." }, { "title": "Digo que gosto", "body": "I like apples! (Eu gosto de maçãs!)" }, { "title": "Junta tudo", "body": "I'm hungry. I like apples! 🍎 Boa, já pediste em inglês!" } ]
```

## Truque 🪄

Pensa assim: **I like** = "Eu adoro" com um sorriso 😍; **I don't like** tem o "don't" que faz "não". Don't = não! E lembra-te: **hungry** é de comer (fome 🍽️) e **thirsty** é de beber (sede 💧).

## Vamos aplicar 🧩

A Maria tem sede e adora leite. Como é que ela diz em inglês?

```steps
[ { "title": "Ela tem sede", "body": "I'm thirsty! (Tenho sede!)" }, { "title": "O que ela quer", "body": "Leite = milk." }, { "title": "Ela gosta", "body": "I like milk! (Eu gosto de leite!) 🥛" }, { "title": "Frase completa", "body": "I'm thirsty. I like milk! Conseguiste ajudar a Maria! 🎉" } ]
```

> [!TIP] **Para saberes mais** 🌱 Quando há muitas de uma coisa, em inglês juntamos um **s** no fim: apple → apples (maçãs), cake → cakes (bolos). Mas water e milk não levam "s", porque não se contam um a um!
