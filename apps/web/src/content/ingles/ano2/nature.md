# Nature 🌳

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer em inglês as coisas bonitas da natureza, como árvores, flores, o sol e o mar!

Olá, pequeno explorador! 🌿 Lá fora há tanta coisa fantástica: árvores altas, flores coloridas, o sol que brilha e o mar que faz ondas. Hoje vais aprender a dar nome a tudo isso em inglês. Ouve bem cada palavra e repete comigo!

## A água e a praia 🌊

A natureza também tem muita água! Vamos aprender estas duas palavras especiais.

```keyvalue
[
  { "k": "sea 🌊", "v": "mar" },
  { "k": "beach 🏖️", "v": "praia" }
]
```

Quando vais à **beach** (praia), brincas na areia e mergulhas no **sea** (mar). Que divertido! 🏖️🌊

## Dizer como são 🎨

Em inglês podemos descrever as coisas com cores. Usamos a palavrinha **is** (é). Olha como é fácil!

```compare
[
  { "title": "The tree is green 🌳", "rows": [
    { "label": "A árvore é verde", "value": "tree = árvore" },
    { "label": "is", "value": "é" },
    { "label": "green", "value": "verde", "highlight": true }
  ] },
  { "title": "The sun is yellow ☀️", "rows": [
    { "label": "O sol é amarelo", "value": "sun = sol" },
    { "label": "is", "value": "é" },
    { "label": "yellow", "value": "amarelo", "highlight": true }
  ] }
]
```

Vês? Dizes a coisa, depois **is**, depois a cor. Experimenta: *The flower is pink* (a flor é cor-de-rosa)! 🌸

## Um exemplo passo a passo 🔍

Vamos descrever o céu juntos, com muita calma. 🌙

```steps
[
  { "title": "1. Olha para o céu", "body": "vês a lua. Em inglês, lua é moon 🌙", "icon": "🌙" },
  { "title": "2. Começa pela coisa", "body": "começas a frase assim: The moon...", "icon": "💬" },
  { "title": "3. Junta o 'is'", "body": "is quer dizer é. The moon is...", "icon": "🧩" },
  { "title": "4. Diz a cor", "body": "white quer dizer branco 🤍", "icon": "🎨" },
  { "title": "5. Frase completa", "body": "The moon is white! 🌕 Boa, descreveste a lua! 🎉", "icon": "🎉" }
]
```

> **Truque:** agrupa por sítio! No **céu** ficam *sun, moon, star e cloud*. Na **terra** ficam *tree, flower, river e mountain*. Assim lembras-te de tudo num instante! ☁️🌳

> [!TIP] **Para saberes mais** 🌱 Algumas palavras da natureza parecem-se com o português porque vêm de uma língua antiga, o latim! O inglês **river** lembra «rio» e **flower** lembra «flor». Chamam-se palavras parecidas, ou *cognatas*, e ajudam-te a adivinhar o que significam! 🤓
