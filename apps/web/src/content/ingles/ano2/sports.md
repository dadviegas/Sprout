# Sports ⚽🏀

> [!NOTE] **O que vais aprender** 👀 Vais aprender o nome dos **desportos** em inglês — futebol, natação, corrida e muito mais — e a dizer *I like football!* (Gosto de futebol!) e *I can swim!* (Sei nadar!). No fim, já contas qual é o teu desporto favorito! 🏃⚽

Gostas de correr, de jogar à bola ou de nadar na piscina? 😄 Hoje vamos pôr o corpo a mexer… mas tudo **em inglês**! Vais ver que dizer *football*, *swimming* ou *running* é tão fácil que daqui a nada já falas dos teus desportos como um campeão. Toca a aquecer, vamos lá! 💪

## "I like..." — dizer o que gostas 💚

A frase mais importante de hoje! **"I like..."** quer dizer **"Gosto de..."**. É assim que dizes qual o desporto de que gostas mais.

```keyvalue
[
  { "k": "I like football. ⚽", "v": "Gosto de futebol." },
  { "k": "I like swimming. 🏊", "v": "Gosto de natação." },
  { "k": "I like dancing. 💃", "v": "Gosto de dança." },
  { "k": "What's your favourite sport? 🤔", "v": "Qual é o teu desporto favorito?" }
]
```

> [!TIP] Se **não** gostas de uma coisa, dizes **"I don't like..."** — *I don't like running.* (Não gosto de corrida.) 🙂

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Gostas de natação e já sabes nadar. Como o dizes em inglês?»* Vamos resolver com calma! 🏊

```steps
[
  { "title": "1. Qual é o desporto?", "body": "É natação. Natação em inglês = swimming 🏊", "icon": "🏊" },
  { "title": "2. Diz que gostas", "body": "Para 'gosto de' começo com I like... → I like swimming. 💚", "icon": "💬" },
  { "title": "3. Diz o que sabes fazer", "body": "Para 'sei/consigo' uso I can... 💪", "icon": "💪" },
  { "title": "4. Junta o verbo", "body": "nadar é swim → I can swim. 🏊", "icon": "🧩" },
  { "title": "5. Frase completa", "body": "I like swimming. I can swim! ✅ Boa, foste um campeão! 🎉", "icon": "🎉" }
]
```

> **Truque:** muitos desportos em inglês acabam em **-ing** quando falamos da atividade! Vê: swim → swimm**ing** 🏊, run → runn**ing** 🏃, cycle → cycl**ing** 🚴, dance → danc**ing** 💃. Se ouvires "-ing", é boa pista de que estás a falar de um desporto! 🎵

> [!TIP] **Para saberes mais** 🌱 Em inglês usamos **verbos diferentes** com cada desporto! Dizemos **PLAY football** ⚽ (jogar à bola) e **PLAY tennis** 🎾, mas **GO swimming** 🏊 (ir nadar) e **GO cycling** 🚴, e ainda **DO gymnastics** 🤸 (fazer ginástica). Play, go, do — cada desporto pede o seu verbo!
