# Clothes 👕

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer as **roupas** em inglês e a contar o que vestes com a frase mágica **"I'm wearing..."**. No fim, sabes descrever a tua roupa toda! 👕👖👟

What are you wearing today? 😄 De manhã, antes de saíres de casa, escolhes a tua roupa, não é? Hoje vais saber dizer **o nome de cada peça em inglês** — e até falar do tempo, porque no frio vestimos roupa diferente do calor! Vamos a isso, vai ser fácil. 🧥☀️

## "I'm wearing..." — dizer o que vestes 👗

A frase mais importante de hoje! **"I'm wearing..."** quer dizer **"Estou a usar / a vestir..."**. É assim que dizes a tua roupa.

```keyvalue
[
  { "k": "I'm wearing a t-shirt.", "v": "Estou a usar uma t-shirt. 👕" },
  { "k": "She's wearing a dress.", "v": "Ela está a usar um vestido. 👗" },
  { "k": "He's wearing shoes.", "v": "Ele está a usar sapatos. 👟" },
  { "k": "What are you wearing?", "v": "O que estás a vestir? 🤔" }
]
```

> [!TIP] Para falares de TI usas **I'm wearing**. Para uma menina (ela) dizes **She's wearing**. Para um menino (ele) dizes **He's wearing**. 🙂

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«O João tem vestida uma t-shirt e calças. Como o dizes em inglês?»* Vamos resolver com calma!

```steps
[
  { "title": "1. Vê quem é", "body": "É o João, um menino. Para 'ele' usamos He's wearing 🧒", "icon": "👦" },
  { "title": "2. Conta as peças", "body": "Ele tem 2 peças: uma t-shirt e umas calças (trousers) 👕👖", "icon": "🔢" },
  { "title": "3. Diz a primeira", "body": "He's wearing a t-shirt... 👕", "icon": "👕" },
  { "title": "4. Junta com 'and'", "body": "'and' quer dizer 'e'. ...and trousers. 👖", "icon": "➕" },
  { "title": "5. Frase completa", "body": "He's wearing a t-shirt and trousers. ✅ Boa!", "icon": "✅" }
]
```

> **Truque:** lembra-te que **"wear"** soa como **"vê ar"** — imagina que vestes o ar à tua volta! E peças com **duas partes** (trousers, shoes, shorts, socks) andam sempre aos **pares**, por isso ficam no plural. 👖👟

> [!TIP] **Para saberes mais** 🌱 Em inglês há palavras diferentes na Inglaterra e nos Estados Unidos! Os ingleses dizem **trousers** para calças, mas os americanos dizem **pants**. E **jumper** (camisola de lã) em inglês americano é **sweater**. A mesma língua, palavras diferentes! 🇬🇧🇺🇸
