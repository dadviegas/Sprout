# My house 🏠

> [!NOTE] **O que vais aprender** 👀 Vais aprender a falar da tua casa em inglês: o nome das **divisões** (rooms), os **móveis** (furniture) e a dizer o que há lá dentro com **There is** e **There are**. No fim, vais saber descrever o teu quarto todo sozinho! 🛏️

Olá! 🏠 A tua casa é o teu cantinho preferido, não é? Tem o quarto onde dormes, a cozinha onde cheira tão bem e o sofá fofinho da sala. Hoje vamos dar um nome em inglês a tudo isso! No fim, vais conseguir mostrar a tua casa a um amigo inglês e dizer o que há em cada divisão. Vais ver que é fácil e muito divertido! 🎉

## The rooms 🚪

Cada divisão da casa tem um nome em inglês. Vamos conhecer as principais e ouvir como se dizem!

```soundcards

```

> Sabias que muitas divisões têm o **room** (que quer dizer "sala/quarto") dentro do nome? **Bed**room = quarto da **cama**. **Bath**room = sala do **banho**. **Living** room = sala de **viver**! 🧠

## There is / There are 🔢

Para dizer o que **há** numa divisão usas duas expressões mágicas. A diferença é só o número de coisas!

```compare

  {
    "title": "There are",
    "highlight": true,

    "rows": [
      {
        "label": "Quando usar?",
        "value": "para MUITAS coisas (plural)"
      },
      {
        "label": "Exemplo",
        "value": "There are two chairs. 🪑🪑"

      {
        "label": "Negativa",

  }

```

> Repara: com **There is** usamos **a** (a bed, a table). Com **There are** dizemos o **número** (two chairs, three windows). 🔢

## Where is it? Preposições 📍

Para dizeres ONDE está uma coisa, usas pequenas palavras chamadas **preposições**. São super úteis!

```keyvalue
[
  {
    "k": "in 📦",
    "v": "dentro de — The cat is in the box.",
    "lang": "en-US"
  },
  {
    "k": "on ⬆️",
    "v": "em cima de — The book is on the table.",
    "lang": "en-US"
  },
  {
    "k": "under ⬇️",
    "v": "debaixo de — The ball is under the bed.",
    "lang": "en-US"
  },
  {
    "k": "next to ➡️",
    "v": "ao lado de — The chair is next to the door.",
    "lang": "en-US"
  }
]
```

> [!TIP] **on** e **in** parecem-se mas são diferentes! **ON** = em **cima** (the cat is on the sofa 🐱). **IN** = lá **dentro** (the cat is in the box 📦). 🐈

## Um exemplo passo a passo 🔍

Vamos descrever uma cozinha (kitchen) do princípio ao fim!

```steps
[
  { "title": "1. Olha o que há", "body": "Na cozinha há 1 mesa (table) e 3 cadeiras (chairs). 👀", "icon": "🍳" },
  { "title": "2. Uma coisa? Usa There is", "body": "É só 1 mesa, então: There is a table.", "icon": "🍽️" },
  { "title": "3. Muitas coisas? Usa There are", "body": "São 3 cadeiras, então: There are three chairs.", "icon": "🪑" },
  { "title": "4. Diz onde estão", "body": "As cadeiras estão à volta da mesa: The chairs are next to the table.", "icon": "📍" },
  { "title": "5. Junta tudo", "body": "In the kitchen, there is a table and there are three chairs. 🎉", "icon": "✅" }
]
```

> **Truque:** **IS** é curtinho, como **um** (singular). **ARE** é maior, como **muitos** (plural). Conta as coisas: 1 → there **is**; 2, 3, 4… → there **are**. 🎯

> [!TIP] **Para saberes mais** 🌱 Em inglês há casas com nomes especiais! Uma casa de campo pequena e fofa chama-se **cottage** 🏡, um prédio alto com muitos andares é um **block of flats** 🏢 (e cada apartamento é um **flat**), e uma casa grande e chique é uma **mansion** 🏰. Qual gostarias de ter?
