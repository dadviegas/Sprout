# Toys 🧸

> [!NOTE] **O que vais aprender** 👀 Vais aprender os nomes dos teus **brinquedos** em inglês e a dizer **«I have a…»** (eu tenho) e **«I like…»** (eu gosto). Vamos brincar enquanto aprendemos! 🎮

Olha à tua volta: tens uma **bola**, um **urso de peluche**, talvez um **carrinho** ou um **puzzle**? Em inglês, esses brinquedos têm nomes engraçados de dizer. Vou ensinar-te um a um — e no fim já vais saber pedir e mostrar os teus brinquedos como um verdadeiro pequeno inglês! Diz comigo em voz alta, que assim aprende-se melhor. 🗣️✨

## I have a… / I like… 🎈

Agora vamos juntar as palavras numa frase. É muito simples:

```keyvalue
[
  { "k": "I have a ball.", "v": "Eu tenho uma bola. ⚽" },
  { "k": "I like my teddy bear.", "v": "Eu gosto do meu urso de peluche. 🧸" },
  { "k": "This is my car.", "v": "Este é o meu carro. 🚗" },
  { "k": "It's a robot!", "v": "É um robô! 🤖" }
]
```

> **I have a…** quer dizer **«Eu tenho um/uma…»**. Diz: *I have a kite!* 🪁

## A minha caixa de brinquedos 📦

Quantos brinquedos de cada? Em inglês contamos: *one, two, three…* Olha esta caixa:

```meters

  { "label": "⚽ balls", "value": 2, "max": 6, "tone": "ok" },
  { "label": "🚗 cars", "value": 4, "max": 6, "tone": "ok" },
  { "label": "🧸 teddy bears", "value": 1, "max": 6, "tone": "warn" },
  { "label": "🧩 puzzles", "value": 3, "max": 6, "tone": "ok" }

```

> [!TIP] Para falar de **muitos**, junta um **«s»** no fim: *one car* → *two cars*; *one ball* → *three balls*. 🔢

## Um exemplo passo a passo 🔍

Imagina que vês um **urso de peluche** numa loja e queres dizer em inglês *«Eu tenho um urso de peluche»*. Vamos montar a frase juntos:

```steps
[
  { "title": "1. Começa por «I»", "body": "«I» quer dizer «Eu». Lê-se ái 🙋", "icon": "🙋" },
  { "title": "2. Junta «have a»", "body": "«have a» quer dizer «tenho um/uma» 🤲", "icon": "🤲" },
  { "title": "3. Diz o brinquedo", "body": "urso de peluche em inglês é «teddy bear» 🧸", "icon": "🧸" },
  { "title": "4. Junta tudo", "body": "I have a teddy bear. = Eu tenho um urso de peluche ✅", "icon": "🗣️" }
]
```

> **Truque:** lembra-te sempre da ordem **I + have a + brinquedo**. É como um comboio: primeiro a locomotiva (**I have a**) e depois a carruagem (o brinquedo). 🚂

> [!TIP] **Para saberes mais** 🌱 Em inglês, alguns brinquedos têm dois nomes! O **papagaio de papel** é *kite*, mas no Natal as crianças inglesas pedem *toys* (brinquedos) ao **Father Christmas** — é assim que eles chamam ao **Pai Natal**! 🎅🎁
