# Comparatives 📏

> [!NOTE] **O que vais aprender** 👀 Vais aprender a comparar coisas em inglês — dizer quem é maior, mais alto ou mais rápido!

Já reparaste que adoramos comparar? O elefante é maior do que o rato, tu és mais alto do que um bebé... Em inglês há um truque mágico para comparar: juntamos **-er** ao adjetivo e usamos a palavra **than** (do que). Vamos descobrir! 🌟

## A regra mágica: -er 🪄

Para comparar com adjetivos curtos, juntamos **-er** no fim. É como dar um "empurrãozinho" à palavra!

```keyvalue
[
  { "k": "big → bigger 🐘", "v": "grande → maior" },
  { "k": "small → smaller 🐭", "v": "pequeno → mais pequeno" },
  { "k": "tall → taller 📏", "v": "alto → mais alto" },
  { "k": "fast → faster 🏃", "v": "rápido → mais rápido" }
]
```

Vês? Só temos de acrescentar **-er** no fim do adjetivo. **big** vira **bigger**, **tall** vira **taller**! 🪄

## A palavra "than" 🆚

Quando comparas duas coisas, usas a palavra **than**, que quer dizer **"do que"**.

```compare
[
  { "title": "Inglês 🇬🇧", "rows": [
    { "label": "An elephant is bigger than a mouse", "value": "🐘 > 🐭", "highlight": true },
    { "label": "A cheetah is faster than a turtle", "value": "🐆 > 🐢" }
  ] },
  { "title": "Português 🇵🇹", "rows": [
    { "label": "Um elefante é maior do que um rato", "value": "🐘 > 🐭", "highlight": true },
    { "label": "Uma chita é mais rápida do que uma tartaruga", "value": "🐆 > 🐢" }
  ] }
]
```

A receita é sempre a mesma: **adjetivo + -er + than**. Por exemplo, **taller than** (mais alto do que) ou **faster than** (mais rápido do que)! 🆚

## Mais comparações ⏫

Vamos ver mais adjetivos curtos que ganham **-er** para comparar:

```keyvalue
[
  { "k": "old → older 👴", "v": "velho → mais velho" },
  { "k": "young → younger 👶", "v": "novo → mais novo" },
  { "k": "tall → taller 🦒", "v": "alto → mais alto" },
  { "k": "slow → slower 🐢", "v": "lento → mais lento" }
]
```

O teu avô é **older than** tu (mais velho do que tu), e tu és **younger than** o teu avô (mais novo do que o teu avô)! 👴👶

## Os teimosos: good e bad 😮

Atenção! Alguns adjetivos são teimosos e **não** seguem a regra do **-er**. Mudam completamente. Estes chamam-se irregulares:

```compare
[
  { "title": "Adjetivo 🔤", "rows": [
    { "label": "good 👍", "value": "bom" },
    { "label": "bad 👎", "value": "mau" }
  ] },
  { "title": "Comparativo ⏫", "rows": [
    { "label": "better", "value": "melhor 👍", "highlight": true },
    { "label": "worse", "value": "pior 👎", "highlight": true }
  ] }
]
```

Vê bem: **good** não vira "gooder"! Vira **better** (melhor). E **bad** vira **worse** (pior). Estes dois tens de decorar — são especiais! 😮

## Um exemplo passo a passo 🔍

Vamos comparar uma girafa e um cão, em inglês!

```steps
[
  { "title": "1. Escolhe o adjetivo", "body": "Queres dizer que a girafa é mais alta. Alto em inglês = tall 📏", "icon": "📏" },
  { "title": "2. Junta -er", "body": "É um adjetivo curto, por isso juntas -er: tall → taller (mais alto)", "icon": "🪄" },
  { "title": "3. Usa than", "body": "than quer dizer 'do que': taller than", "icon": "🆚" },
  { "title": "4. Frase completa", "body": "A giraffe is taller than a dog! 🦒 (A girafa é mais alta do que o cão!) ✅", "icon": "✅" }
]
```

> **Truque:** Para comparar, faz a receita mágica: **adjetivo curto + -er + than**. Diz baixinho "taller than", "faster than" — soa sempre a comparação! 🪄

> [!TIP] **Para saberes mais** 🌱 Com adjetivos **longos**, o inglês não usa -er. Em vez disso, põe **more** à frente: **more beautiful** (mais bonito), **more interesting** (mais interessante). E quando algo é o melhor de todos, usamos o **superlativo**: **the biggest** (o maior), **the best** (o melhor)! 🏆
