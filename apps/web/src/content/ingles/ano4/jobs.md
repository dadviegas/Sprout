# Jobs 👩‍🏫

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer muitas **profissões** em inglês, a perguntar **"What's your job?"** e a responder **"I am a..."**. No fim já sabes apresentar o que cada pessoa faz! 💼

## Um exemplo passo a passo 🔍

Imagina uma senhora que apaga fogos. Vamos dizer isso em inglês, devagarinho!

```steps
[ { "title": "Quem é?", "body": "É uma senhora, então usamos She (ela).", "icon": "👧" }, { "title": "É?", "body": "Juntamos is → She is.", "icon": "🔗" }, { "title": "Não esqueças o 'a'", "body": "Antes da profissão pomos sempre 'a' → She is a.", "icon": "✨" }, { "title": "O quê?", "body": "Ela apaga fogos = firefighter (bombeira).", "icon": "🚒" }, { "title": "Junta tudo", "body": "She is a firefighter! Boa, conseguiste!", "icon": "🎉" } ]
```

> **Truque:** menino → **He**, menina → **She**. Depois é sempre **is a** + a profissão. He / She... **is a**... pronto! Fácil como contar 1-2-3. 🎯

> [!TIP] **Para saberes mais** 🌱 Alguns nomes de profissões mudam quando há **muitos**: um **firefighter**, dois **firefighters**; um **teacher**, três **teachers**. Basta juntar um **-s** no fim, tal como em português juntamos um **-s** a "bombeiros"! E sabias que **"police"** já significa muita gente, por isso não leva **a**? Dizemos **"He is a police officer"**. 👮
