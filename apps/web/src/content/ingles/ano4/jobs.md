# Jobs 👩‍🏫

Olá! Vamos aprender a dizer profissões em inglês. 😄 Vais ver que é super fácil e até já conheces algumas!

## As profissões em inglês 💼

Cada profissão tem o seu nome em inglês. Olha para estas cinco e ouve como se dizem!

```soundcards
{ "title": "Jobs 👷", "items": [ {"label":"teacher","say":"teacher","hint":"professor(a)"}, {"label":"doctor","say":"doctor","hint":"médico(a)"}, {"label":"farmer","say":"farmer","hint":"agricultor(a)"}, {"label":"firefighter","say":"firefighter","hint":"bombeiro(a)"}, {"label":"cook","say":"cook","hint":"cozinheiro(a)"} ] }
```

Para dizer o que alguém é, usamos **He is a...** (Ele é...) ou **She is a...** (Ela é...).

```keyvalue
[ { "k": "He is a doctor.", "v": "Ele é médico. 👨‍⚕️" }, { "k": "She is a teacher.", "v": "Ela é professora. 👩‍🏫" } ]
```

## Um exemplo passo a passo 🔍

Imagina uma senhora que apaga fogos. Vamos dizer isso em inglês!

```steps
[ { "title": "Quem é?", "body": "É uma senhora, então usamos She (ela)." }, { "title": "É?", "body": "Juntamos is → She is." }, { "title": "O quê?", "body": "Ela apaga fogos = firefighter (bombeira)." }, { "title": "Junta tudo", "body": "She is a firefighter! 🚒 Boa, conseguiste!" } ]
```

## Truque 🪄

Pensa assim: **menino → He**, **menina → She**. Depois é sempre **is a** + a profissão. Fácil como contar 1-2-3! 🎉

## Vamos aplicar 🧩

Vamos descrever pessoas reais. Olha para cada pista e diz a frase!

```steps
[ { "title": "Um senhor que cozinha 👨‍🍳", "body": "Senhor → He. He is a cook!" }, { "title": "Uma senhora que dá aulas 👩‍🏫", "body": "Senhora → She. She is a teacher!" }, { "title": "Um senhor com tratores na quinta 🚜", "body": "Senhor → He. He is a farmer!" } ]
```

> [!TIP] **Para saberes mais** 🌱 Quando perguntas a profissão de alguém, dizes: **"What's your job?"** (Qual é o teu trabalho?). A resposta é **"I am a..."** (Eu sou...)!
