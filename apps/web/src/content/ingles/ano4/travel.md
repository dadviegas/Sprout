# Travel & transport ✈️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a dizer os **meios de transporte** em inglês — avião, comboio, autocarro, carro — e a frase mágica *«I go by train»* (vou de comboio). No fim, já sabes contar como vais para todo o lado! 🚂🚌🚗

Já pensaste em todas as maneiras de viajar? 🌍 Podes ir de avião lá pelo céu, de barco pelo mar, de comboio sobre os carris… ou simplesmente a pé! Hoje vais aprender o nome de cada um destes transportes **em inglês** — e vais ver que é tão fácil que daqui a pouco já planeias uma viagem inteira! Apertem os cintos, que vamos descolar! 🛫

## Os sítios da viagem 🏨

Quando viajas, passas por sítios especiais! Apanhas o avião no **aeroporto** e o comboio na **estação**. E onde dormes? No **hotel**! 😴

```keyvalue

  { "k": "airport ✈️", "v": "aeroporto (onde apanhas o avião)" },
  { "k": "station 🚉", "v": "estação (onde apanhas o comboio)" },

  { "k": "hotel 🏨", "v": "hotel (onde dormes na viagem)" }

```

> [!NOTE] Repara: o avião é *plane* (curtinho) ou *aeroplane* (a versão comprida). E o sítio onde ele para é o *airport* — ouve o «air» (ar) lá dentro, porque o avião voa pelo ar! ✈️

## "by" ou "on foot"? 🚶

Atenção a uma exceção engraçada! Com transportes dizes sempre **by** (by car, by bus...), mas quando vais **a pé** dizes **on foot** — nunca «by foot»! Compara os dois lados:

> [!TIP] Atenção: dizemos *I go on foot* (vou a pé), **nunca** «by foot»! O pé (foot) é o único que não usa «by». 🦶

## Um exemplo passo a passo 🔍

Imagina que vais visitar a tua avó e apanhas o comboio. Como dizes *«Vou de comboio»* em inglês? Vamos resolver com calma! 🚂

```steps
  { "title": "2. Começo a frase", "body": "Para dizer como vou, começo com: I go... (Vou...)", "icon": "💬" },
  { "title": "3. Junto o 'by'", "body": "Com transportes usamos sempre by (de): I go by...", "icon": "🔤" },
  { "title": "4. Acrescento o transporte", "body": "I go by train. (Vou de comboio.) ✨", "icon": "🚂" },
  { "title": "5. Frase completa", "body": "I go by train. 🚂 Boa, já sabes contar a tua viagem em inglês! 🎉", "icon": "🎉" }

```

> **Truque:** em inglês dizes sempre **"by" + transporte** (by car, by bus, by train), como se «by» quisesse dizer «em cima de». Mas a pé é a grande exceção: dizes **on foot**! Lembra-te: tudo «by», menos o pé que é «on foot». 🦶

> [!TIP] **Para saberes mais** 🌱 Cuidado com o inglês britânico e o americano! O autocarro é *bus* nos dois 🚌, mas o comboio é *train* 🚂. Já o **metro** muda: no Reino Unido chama-se *underground* (ou *the Tube* em Londres!) e nos Estados Unidos chama-se *subway*. A mesma língua, palavras diferentes! 🇬🇧🇺🇸
