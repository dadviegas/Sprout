# What time is it? ⏰

What time is it? Vamos aprender a dizer as **horas** em inglês! 🕐

## O'clock — horas certas

Para as horas certas, dizemos o número + **o'clock**.

```keyvalue
[
  { "k": "1:00", "v": "it's one o'clock 🕐" },
  { "k": "3:00", "v": "it's three o'clock 🕒" },
  { "k": "7:00", "v": "it's seven o'clock 🕖" }
]
```

## See the clock 🕐

Brinca com o relógio e ouve as horas:

```clock
{ "mode": "play", "hour": 3, "minute": 0, "title": "What time is it?" }
```

## Half past — e meia

Para a meia hora, dizemos **half past** + a hora.

> 2:30 = it's **half past two** 🕝 · 6:30 = it's **half past six**

> [!TIP] "What time is it?" = "Que horas são?". A resposta: *It's ... o'clock.* ⏰
