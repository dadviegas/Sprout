# What time is it? ⏰

> [!NOTE] **O que vais aprender** 👀 Vais aprender a perguntar e a dizer as **horas em inglês** — desde as horas certas (*o'clock*) até ao *half past*, *quarter past* e *quarter to*. No fim, sabes responder à pergunta mágica: *What time is it?* 🕐

Olha para um relógio: dois ponteiros e doze números. Em inglês, dizer as horas é como contar uma pequena história em cada momento do dia. Quando alguém te perguntar *"What time is it?"*, vais saber responder com um sorriso! Vamos começar devagarinho. 🙂

## O'clock — horas certas 🕐

Quando o ponteiro grande está no **12**, é uma **hora certa**. Em inglês, dizemos o número + a palavra **o'clock**.

```keyvalue
[
  { "k": "1:00", "v": "it's one o'clock 🕐" },
  { "k": "3:00", "v": "it's three o'clock 🕒" },
  { "k": "7:00", "v": "it's seven o'clock 🕖" },
  { "k": "10:00", "v": "it's ten o'clock 🕙" },
  { "k": "12:00", "v": "it's twelve o'clock 🕛" }
]
```

> [!TIP] Só usamos **o'clock** nas horas certas (quando os minutos são :00). Nunca dizemos "half o'clock"! 🙃

## Half past — e meia 🕧

Quando o ponteiro grande está no **6**, já passou **meia hora**. Em inglês dizemos **half past** (que quer dizer "meia passada") + a hora que já passou.

```keyvalue
[
  { "k": "2:30", "v": "it's half past two 🕝" },
  { "k": "6:30", "v": "it's half past six 🕡" },
  { "k": "9:30", "v": "it's half past nine 🕤" },
  { "k": "12:30", "v": "it's half past twelve 🕧" }
]
```

> [!WARNING] Cuidado! Em **half past two** dizemos a hora que **já passou** (as 2), não a seguinte. 2:30 = half past **two**. ⏳

## Quarter past & quarter to — e um quarto 🕓

Um relógio é como uma laranja partida em 4 pedaços. Cada pedaço são **15 minutos** — um **quarter** (um quarto).

```compare
[
  { "title": "Quarter past ⏩ (depois da hora)", "rows": [
    { "label": "3:15", "value": "it's quarter past three", "highlight": true },
    { "label": "Quando?", "value": "15 minutos DEPOIS da hora certa" },
    { "label": "Ponteiro grande", "value": "está no número 3 do relógio" }
  ] },
  { "title": "Quarter to ⏪ (para a hora seguinte)", "rows": [
    { "label": "3:45", "value": "it's quarter to four", "highlight": true },
    { "label": "Quando?", "value": "faltam 15 minutos PARA a hora seguinte" },
    { "label": "Ponteiro grande", "value": "está no número 9 do relógio" }
  ] }
]
```

> [!NOTE] **Past** = "passa" (já passou da hora). **To** = "para" (falta para a hora seguinte). 3:45 já está quase nas 4, por isso é *quarter **to** four*. 🧭

## A pergunta e a resposta 💬

Em inglês, perguntamos e respondemos sempre da mesma maneira. Decora estas frases — vais usá-las muitas vezes!

```keyvalue
[
  { "k": "What time is it?", "v": "Que horas são? ❓" },
  { "k": "It's ... o'clock.", "v": "São ... horas certas 🕐" },
  { "k": "It's half past ...", "v": "São ... e meia 🕧" },
  { "k": "It's quarter past ...", "v": "São ... e um quarto ⏩" },
  { "k": "It's quarter to ...", "v": "Falta um quarto para as ... ⏪" }
]
```

## Um exemplo passo a passo 🔍

Imagina que o relógio marca **7:45** e alguém pergunta *"What time is it?"*. Vamos descobrir a resposta com calma.

```steps
[
  { "title": "1. Olha para os minutos", "body": "estão em :45. Isso são 45 minutos — quase a hora seguinte! 🧐", "icon": "clock" },
  { "title": "2. Past ou to?", "body": "passou da meia hora, por isso usamos TO (para a hora seguinte) ⏪" },
  { "title": "3. Quantos minutos faltam?", "body": "de :45 para :00 faltam 15 minutos = um quarter ⏳" },
  { "title": "4. Qual é a hora seguinte?", "body": "depois das 7 vêm as 8 — por isso dizemos 'to eight' 🕗" },
  { "title": "5. Resposta", "body": "It's quarter to eight! ✅", "icon": "star" }
]
```

> **Truque:** olha só para o **ponteiro grande**. Se está no lado **direito** do relógio (a descer), usas **past**. Se está no lado **esquerdo** (a subir), usas **to**. 🕐➡️past · ⬅️to🕐

> [!TIP] **Para saberes mais** 🌱 Os ingleses dividem o dia em duas metades: **a.m.** (da meia-noite ao meio-dia) e **p.m.** (do meio-dia à meia-noite). Por isso, 8 da manhã é *8 a.m.* e 8 da noite é *8 p.m.* — assim ninguém se engana entre o pequeno-almoço e o jantar! 🌅🌙
