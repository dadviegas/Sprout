# Family & friends 👪

> [!NOTE] **O que vais aprender** 👀 Vais alargar a tua família em inglês — tios, primos, sobrinhos — e aprender os **possessivos** (*my, your, his, her*) e o **genitivo com 's** (*Ana's brother*) para dizeres de quem é cada pessoa. Também vais falar dos teus **amigos**! 💗

Já sabes dizer *mother*, *father*, *sister* e *brother*. 👏 Agora vamos conhecer a **família alargada** e — o truque mais útil de todos — como dizer **«o irmão da Ana»** ou **«a minha avó»** em inglês. Carrega no 🔊 e repete em voz alta!

## O truque do 's (genitivo) ✨

Em português dizes «o irmão **da** Ana». Em inglês viras tudo ao contrário: dizes **«Ana's brother»** — o nome da dona **primeiro**, depois **'s**, depois a coisa!

```steps
[
  { "title": "1. Quem é o dono?", "body": "A Ana → escreve o nome: Ana", "icon": "🔍" },
  { "title": "2. Cola o 's", "body": "Ana → Ana's (quer dizer «da Ana»)", "icon": "✨" },
  { "title": "3. Diz a coisa", "body": "Ana's brother = o irmão da Ana 👦", "icon": "🗣️" },
  { "title": "4. Mais um", "body": "my dad's car = o carro do meu pai 🚗", "icon": "ok" }
]
```

> **Truque:** lê o **'s** como **«de»** mas ao contrário. *Tom's dog* → lês da direita para a esquerda: «dog… of… Tom» = o cão **do** Tom! 🐶

## Um exemplo passo a passo 🔍

Olhas para uma fotografia e queres dizer: **«Esta é a mãe do meu primo»**. Como dizes em inglês? Vamos por partes! 🧐

```steps
[
  { "title": "1. Começa a apresentar", "body": "«This is…» (Esta é…) 🗣️", "icon": "🗣️" },
  { "title": "2. De quem é a mãe?", "body": "Do meu primo → my cousin → my cousin's 🧒", "icon": "✨" },
  { "title": "3. Diz a pessoa", "body": "mother (mãe) 👩", "icon": "👩" },
  { "title": "4. Frase completa", "body": "This is my cousin's mother. 🎉", "icon": "ok" }
]
```

> [!TIP] **Para saberes mais** 🌱 Quando o dono está no **plural** e já acaba em **-s**, só pões um **apóstrofo**, sem outro s: *my parents' house* (a casa dos meus pais) 🏠. E há palavras de família com **in-law** (por afinidade): **mother-in-law** é a sogra e **brother-in-law** é o cunhado! 😮
