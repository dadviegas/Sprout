## Contáveis e incontáveis: a / an / some 🔢

Aqui está o truque do 5.º ano! Algumas comidas podes **contar** uma a uma (1 maçã, 2 maçãs) — são **contáveis**. Outras não se contam assim (não dizes «2 arrozes»!) — são **incontáveis**.

```compare
[
  { "title": "Contáveis (conta-se) 🔢", "rows": [
    { "label": "an apple", "value": "uma maçã 🍎", "highlight": true },
    { "label": "a banana", "value": "uma banana 🍌" },
    { "label": "two eggs", "value": "dois ovos 🥚🥚" }
  ] },
  { "title": "Incontáveis (não se conta) 🌊", "rows": [
    { "label": "some rice", "value": "arroz 🍚", "highlight": true },
    { "label": "some milk", "value": "leite 🥛" },
    { "label": "some water", "value": "água 💧" }
  ] }
]
```

> **Truque:** se podes pôr um número à frente (2 apples) → usa **a / an**. Se é uma «massa» que não se conta (rice, milk, water) → usa **some**. E lembra-te: **an** antes de som de vogal (**an** apple 🍎), **a** antes de consoante (**a** banana 🍌)! 🅰️

## Um exemplo passo a passo 🔍

Estás num café em Londres e queres pedir **uma água e uma maçã**, com educação. Como dizes? 🧐

```steps
[
  { "title": "1. Começa com educação", "body": "«Can I have…, please?» 🙋", "icon": "🔍" },
  { "title": "2. Água é incontável → some", "body": "some water 💧", "icon": "🌊" },
  { "title": "3. Maçã é contável + vogal → an", "body": "an apple 🍎", "icon": "🔢" },
  { "title": "4. Frase completa", "body": "Can I have some water and an apple, please? 🎉", "icon": "ok" }
]
```

> **Truque:** antes de pedires, faz a pergunta mágica — **«Conta-se?»** Se sim → *a/an*; se não → *some*. E começa **sempre** com *«Can I have…, please?»* para seres bem-educado! 🙏

> [!TIP] **Para saberes mais** 🌱 Para perguntar **quantidade**, o inglês usa duas palavras diferentes: **«How many…?»** para contáveis (*How many apples?* — quantas maçãs? 🍎) e **«How much…?»** para incontáveis (*How much water?* — quanta água? 💧). E sabias que **«breakfast»** quer dizer literalmente *break + fast* = «quebrar o jejum»? É a refeição que quebra o jejum da noite! 🌙➡️🍳
