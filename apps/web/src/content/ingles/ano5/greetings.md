# Greetings & introductions 👋

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **cumprimentar** e a **apresentar-te** em inglês como um crânio: dizer olá conforme a hora do dia, perguntar e responder **«How are you?»**, dizer o teu nome e apresentar outras pessoas. No 5.º ano damos um passo a mais — cumprimentos **formais** e **informais** e respostas com mais cor! 🌟

Já sabes dizer *«Hello!»* — boa! 👏 Agora vais aprender a escolher o cumprimento **certo** para cada situação: com um amigo no recreio falas de uma maneira, com o diretor da escola falas de outra. É como ter roupa para brincar e roupa para uma festa! 🎩👕 Carrega no 🔊 para ouvir e repete em voz alta.

## How are you? Como estás? 😊

Depois do olá, perguntamos como a pessoa está. E agora já podes responder de **muitas** maneiras — não só *«I'm fine»*!

```soundcards
{
  "title": "How are you? — perguntas e respostas",
  "items": [
    { "label": "How are you?", "say": "How are you?", "hint": "Como estás? 🙂" },
    { "label": "How are you doing?", "say": "How are you doing?", "hint": "Como vais indo? 😃" },
    { "label": "I'm fine, thanks.", "say": "I'm fine, thanks", "hint": "Estou bem, obrigado(a). 😊" },
    { "label": "I'm great!", "say": "I'm great", "hint": "Estou ótimo(a)! 🤩" },
    { "label": "Not bad.", "say": "Not bad", "hint": "Mais ou menos / nada mau. 🙂" },
    { "label": "And you?", "say": "And you?", "hint": "E tu? 🔄" }
  ]
}
```

> Repara: respondes e **devolves** a pergunta com **«And you?»** — é simpático e mantém a conversa a andar! 🔄

## Apresentares-te a ti e aos outros 🪪

Numa língua nova, a primeira coisa é dizer o nome. Depois aprendes a apresentar **outras** pessoas com *«This is…»*.

```keyvalue
[
  { "k": "What's your name? 🙋", "v": "Como te chamas?" },
  { "k": "My name is… / I'm… 😊", "v": "O meu nome é… / Eu sou…" },
  { "k": "Nice to meet you! 🤝", "v": "Muito prazer!" },
  { "k": "This is my friend Ana. 👫", "v": "Esta é a minha amiga Ana." },
  { "k": "Where are you from? 🌍", "v": "De onde és?" },
  { "k": "I'm from Portugal. 🇵🇹", "v": "Sou de Portugal." }
]
```

## Um exemplo passo a passo 🔍

Imagina que chegas à escola **de manhã** e queres apresentar-te a um colega novo, o Tom, e dizer-lhe de onde és. Vamos com calma! 🧐

```steps
[
  { "title": "1. Vê a hora", "body": "É de manhã → \"Good morning!\" ☀️", "icon": "sun" },
  { "title": "2. Diz olá e pergunta o nome", "body": "\"Hi! What's your name?\" 🙋", "icon": "🗣️" },
  { "title": "3. Diz o teu nome", "body": "\"My name is Leo. Nice to meet you!\" 🤝", "icon": "🪪" },
  { "title": "4. Diz de onde és", "body": "\"I'm from Portugal. Where are you from?\" 🌍", "icon": "🌍" },
  { "title": "5. Despede-te", "body": "\"See you later, Tom!\" 👋", "icon": "heart" }
]
```

> **Truque:** decora a **escada do encontro** — **olá → nome → prazer → de onde → adeus**. É sempre a mesma ordem, como subir 5 degraus! 🪜

> [!TIP] **Para saberes mais** 🌱 Em inglês muito formal (numa carta ou email), começa-se com **«Dear Mr Smith»** (Caro Sr. Smith) e termina-se com **«Best regards»** (Com os melhores cumprimentos). E sabias que **«How do you do?»** não é mesmo uma pergunta? Antigamente respondia-se… com a mesma frase, **«How do you do?»** — só para ser educado! 🎩
