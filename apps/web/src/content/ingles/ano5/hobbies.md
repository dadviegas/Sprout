# Hobbies & free time 🎮

> [!NOTE] **O que vais aprender** 👀 Vais aprender a falar dos teus **passatempos** e do que fazes no **tempo livre** em inglês: jogar, ler, dançar, andar de bicicleta… Vais usar **play / go / do** com hobbies (cada um para o seu tipo!) e dizer de que gostas com *I like + -ing*. 🎮

O que fazes quando não estás na escola? 🤔 Jogas, lês, dás pontapés numa bola, danças no quarto? 💃 Esses são os teus **hobbies** (passatempos)! Hoje vais aprender a contá-los todos em inglês — e a regra dos três verbos mágicos *play*, *go* e *do*. Carrega no 🔊 e repete!

## Play, go ou do? A regra dos 3 verbos 🪄

Aqui está o truque mais útil! Em inglês, os hobbies juntam-se a **um destes três verbos** — e há uma pista para saber qual:

```steps
[
  { "title": "PLAY — jogos com bola ou regras ⚽", "body": "play football, play tennis, play chess, play the guitar 🎸", "icon": "🎮" },
  { "title": "GO — hobbies que acabam em -ing 🏃", "body": "go swimming, go cycling, go running, go shopping 🛍️", "icon": "➡️" },
  { "title": "DO — desportos individuais e atividades 🥋", "body": "do judo, do gymnastics, do homework, do puzzles 🧩", "icon": "✅" }
]
```

> **Truque:** **PLAY** para jogos de equipa e bola ⚽, **GO** para os que acabam em **-ing** (go swimm**ing**) 🏊, e **DO** para o resto (do judo) 🥋. *Play-go-do* — diz três vezes e nunca mais te enganas! 🪄

## Um exemplo passo a passo 🔍

Queres dizer: **«Gosto de andar de bicicleta ao fim de semana»**. Como montas a frase, com o verbo certo? 🧐

```steps
[
  { "title": "1. Qual é o hobby?", "body": "andar de bicicleta → cycling (acaba em -ing) 🚲", "icon": "🔍" },
  { "title": "2. Que verbo? É -ing → GO", "body": "Para falar de fazer: go cycling ➡️", "icon": "➡️" },
  { "title": "3. Diz que gostas: like + -ing", "body": "I like cycling 💗", "icon": "💗" },
  { "title": "4. Junta o quando", "body": "I like cycling at the weekend. ✅", "icon": "ok" }
]
```

> **Truque:** quando **falas de fazer** o hobby, usa **play/go/do**; quando **dizes que gostas**, usa **like + -ing**. *I **go** swimming* (faço) e *I **like** swimming* (gosto)! 🏊

> [!TIP] **Para saberes mais** 🌱 Há uma diferença engraçada entre **hobby** e **free time**: um **hobby** é algo que fazes muitas vezes e de que gostas mesmo (colecionar cromos, tocar guitarra 🎸); **free time** é só «tempo livre», qualquer momento em que não tens nada para fazer. E sabias que o plural de **hobby** é **hobbies** (com -ies), tal como *study → studies*? 😮
