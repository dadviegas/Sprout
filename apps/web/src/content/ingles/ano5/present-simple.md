# Present simple 🔁

> [!NOTE] **O que vais aprender** 👀 Vais dominar o **present simple** — o tempo verbal das **rotinas** e das coisas que são **sempre verdade**. Vais aprender o famoso **-s da 3.ª pessoa** (*he plays*), as negativas com **don't / doesn't** e as perguntas com **do / does**. É a engrenagem mais útil do inglês! 🔁

Quando falas de uma coisa que fazes **todos os dias** ou que é **sempre verdade** — *«eu jogo futebol»*, *«o Sol nasce a este»* — usas o **present simple**. É o tempo verbal nº 1 do inglês! 🥇 Parece ter regras, mas todas cabem num truque. Carrega no 🔊 e vamos a isto!

## Quando se usa? 🤔

O present simple serve para **três** coisas. Olha:

```keyvalue
[
  { "k": "Rotinas 🔁", "v": "I play football every day. (jogo todos os dias)" },
  { "k": "Verdades sempre 🌍", "v": "The sun rises in the east. (o Sol nasce a este)" },
  { "k": "Gostos e opiniões 💗", "v": "I like pizza. (gosto de piza)" }
]
```

## O truque-estrela: o -s da 3.ª pessoa ⭐

Aqui está o coração da lição! Quando o sujeito é **he, she ou it** (ele, ela, ou uma coisa/animal), o verbo ganha um **-s** no fim. Só nestes três!

```compare

    { "label": "I play", "value": "🎮" },
    { "label": "We eat", "value": "🍽️" },
    { "label": "They read", "value": "📖" }
  ] },
  { "title": "Com -s (he/she/it) ⭐", "rows": [
    { "label": "He plays", "value": "🎮", "highlight": true },
    { "label": "She eats", "value": "🍽️", "highlight": true },
    { "label": "It rains", "value": "🌧️", "highlight": true }

```

> **Truque:** lembra-te do feitiço **«HE, SHE, IT — don't forget the -S!»** 🪄 Sempre que o sujeito for *he/she/it*, cola um **-s** no verbo. É a única vez que muda!

## Atenção aos verbos especiais 👀

Alguns verbos não levam só **-s** na 3.ª pessoa — levam **-es** ou mudam o **-y**. Olha:

```steps
[
  { "title": "Acaba em -o, -ch, -sh, -ss, -x → +es", "body": "go → goes 🚶, watch → watches 📺, brush → brushes 🪥", "icon": "🔤" },
  { "title": "Acaba em consoante + y → -ies", "body": "study → studies 📚, fly → flies ✈️", "icon": "✨" },
  { "title": "Acaba em vogal + y → só +s", "body": "play → plays 🎮, say → says 🗣️", "icon": "ok" },
  { "title": "O super-especial: have → has", "body": "I have / She has 🍎 (este tens de decorar!)", "icon": "heart" }
]
```

## Negativas: don't e doesn't 🚫

Para dizer que **NÃO** fazes algo, usas um ajudante: **don't** (= do not) ou **doesn't** (= does not). E atenção: depois de **doesn't** o verbo **perde** o -s (o -s já foi para o *doesn't*)!

```compare
[
  { "title": "don't (I/you/we/they) 🙅", "rows": [
    { "label": "I don't play", "value": "não jogo" },
    { "label": "They don't eat fish", "value": "não comem peixe 🐟", "highlight": true }
  ] },
  { "title": "doesn't (he/she/it) ⭐", "rows": [
    { "label": "He doesn't play", "value": "ele não joga" },
    { "label": "She doesn't eat fish", "value": "ela não come peixe 🐟", "highlight": true }
  ] }
]
```

> Repara: *She **doesn't** play* — **play** sem -s! O -s saltou para o **doesn't**. Só um -s por frase! 1️⃣

## Perguntas: Do...? e Does...? ❓

Para **perguntar**, começas a frase com **Do** ou **Does**:

```keyvalue
[
  { "k": "Do you like pizza? 🍕", "v": "Gostas de piza? → Yes, I do. / No, I don't." },
  { "k": "Does he play tennis? 🎾", "v": "Ele joga ténis? → Yes, he does. / No, he doesn't." },
  { "k": "Where do you live? 🏠", "v": "Onde vives?" },
  { "k": "What does she eat? 🍽️", "v": "O que come ela?" }
]
```

## Um exemplo passo a passo 🔍

Queres dizer: **«A minha irmã estuda inglês»**. Como aplicas o present simple? 🧐

```steps
[
  { "title": "1. Qual é o sujeito?", "body": "«A minha irmã» = my sister → é como «she» (3.ª pessoa) 👧", "icon": "🔍" },
  { "title": "2. Logo, leva -s!", "body": "É he/she/it → o verbo muda. Lembra: HE, SHE, IT + S! ⭐", "icon": "✨" },
  { "title": "3. Que verbo? study", "body": "study acaba em consoante + y → vira studies 📚", "icon": "🔤" },
  { "title": "4. Frase completa", "body": "My sister studies English. ✅", "icon": "ok" }
]
```

> **Truque-resumo:** faz sempre **3 perguntas** — *É he/she/it?* (se sim, **-s**). *É negativa?* (usa **doesn't** e tira o -s). *É pergunta?* (começa por **Does**). Três interruptores e acertas sempre! 🎛️

> [!TIP] **Para saberes mais** 🌱 Há um verbo ainda mais teimoso do que *have*: o verbo **to be**! Ele nem precisa de *do/does* para as negativas e perguntas. Dizes *«She **isn't** happy»* e *«**Are** you happy?»* — sem *doesn't*, sem *do*! O *to be* faz as coisas à maneira dele. 😎
