# Daily routines ⏰

> [!NOTE] **O que vais aprender** 👀 Vais contar o teu dia inteiro em inglês, dizer **a que horas** fazes cada coisa e — o salto do 5.º ano — usar os **advérbios de frequência** (*always, usually, sometimes, never*) para dizeres com que frequência fazes algo. ⏰

Todos os dias repetes uma rotina: acordas, lavas os dentes, vais à escola, jantas, dormes… 🌞🌙 Já sabes muitas destas ações em inglês. Hoje vais aprender a dizê-las **com horas** e a contar **quantas vezes** fazes cada uma. Carrega no 🔊 e repete!

## Quantas vezes? Advérbios de frequência 🔁

Estas palavrinhas dizem **com que frequência** fazes algo — de «sempre» a «nunca». Pensa numa **régua** de cheio (100%) a vazio (0%):

```meters
[
  { "label": "always — sempre", "value": 100, "max": 100 },
  { "label": "usually — normalmente", "value": 80, "max": 100 },
  { "label": "often — muitas vezes", "value": 60, "max": 100 },
  { "label": "sometimes — às vezes", "value": 35, "max": 100 },
  { "label": "never — nunca", "value": 0, "max": 100 }
]
```

> **Onde se põem?** Estas palavras vão **antes do verbo**: *I **always** brush my teeth* (lavo **sempre** os dentes), *I **never** eat snails* (**nunca** como caracóis 🐌). Antes do verbo, como um aviso! ⚠️

## Como uma semana se reparte 📊

Imagina o João: numa semana de escola (5 dias), em quantos dias faz cada coisa? Vê o gráfico e ouve!

```chart
{ "type": "bar", "title": "Dias por semana (de 5)",
  "labels": ["wake up early", "do homework", "play games"], "data": [5, 4, 2],
  "unit": "dias",
  "say": "O João acorda cedo todos os 5 dias, faz os trabalhos de casa em 4 dias e joga em 2 dias." }
```

> Acordar cedo todos os dias = **always** (5/5). Fazer os TPC quase sempre = **usually** (4/5). Jogar poucos dias = **sometimes** (2/5)! 📊

## Um exemplo passo a passo 🔍

Queres dizer: **«Às vezes vejo televisão às 8»**. Como montas a frase, com a frequência no sítio certo? 🧐

```steps
[
  { "title": "1. Escolhe a frequência", "body": "«às vezes» = sometimes 🔁", "icon": "🔍" },
  { "title": "2. Põe-na antes do verbo", "body": "I sometimes watch… (a palavra vai à frente do verbo) ⚠️", "icon": "🗣️" },
  { "title": "3. Diz a ação", "body": "watch TV (ver televisão) 📺", "icon": "📺" },
  { "title": "4. Junta a hora com at", "body": "I sometimes watch TV at 8. ✅", "icon": "ok" }
]
```

> **Truque:** decora a ordem **SUJEITO → frequência → VERBO → resto**. A palavra de frequência fica sempre **a abraçar o verbo pela frente**: *I **never** late!*… não — *I am **never** late!* (com to be vai depois). Mas com os outros verbos vai **antes**! 🤗

> [!TIP] **Para saberes mais** 🌱 Há uma regrinha especial: com o verbo **to be** (am/is/are), os advérbios de frequência vão **depois**! Dizes *«I am **always** happy»* (estou **sempre** feliz) e não *«I always am»*. Mas com todos os outros verbos vão **antes**: *«I **always** play»*. O *to be* é o rebelde da turma! 😎
