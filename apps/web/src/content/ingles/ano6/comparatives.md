# Comparatives & superlatives 📏

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **comparar** coisas em inglês — o **comparativo** (*taller, bigger* = mais alto, maior) com **than**, e o **superlativo** (*the tallest, the biggest* = o mais alto de todos) com **the**. Vais ver a regra dos adjetivos **curtos** (-er/-est) e dos **longos** (more/most), e os **irregulares** teimosos. 📏🏆

Adoramos comparar coisas: *«O meu cão é maior que o teu!»*, *«Este é o filme mais engraçado de sempre!»* 😂 Em inglês, há duas ferramentas — o **comparativo** (compara **dois**) e o **superlativo** (o melhor de **todos**). Carrega no 🔊 e vamos comparar!

## Comparar dois: o comparativo com «than» 🆚

Para comparar **duas** coisas, transformas o adjetivo e juntas **than** (= «do que»). Para adjetivos **curtos** (1 sílaba), colas **-er**:

## O melhor de todos: o superlativo com «the» 🏆

Para dizeres que é **o melhor de TODOS** (não só de dois), pões **the** à frente e o adjetivo ganha **-est**:

> **Truque das terminações:** **-ER** tem um **R** de «**R**ivais» (comparas **dois**), e **-EST** tem o **EST** de «o m**EST**re / o melhor de todos» 👑. E o superlativo leva **sempre the** à frente: *the tallest*. Decora: *-er + than* / *the + -est*!

## Adjetivos longos: more e most 📚

Para adjetivos **compridos** (2 sílabas ou mais, como *beautiful, expensive, interesting*), **não** se cola -er/-est — seria uma palavra enorme! Em vez disso, usas **more** (comparativo) e **the most** (superlativo):

```keyvalue
[
  { "k": "more beautiful than 🌸", "v": "mais bonito do que (não 'beautifuller'!)" },
  { "k": "the most beautiful 🌸", "v": "o mais bonito de todos" },
  { "k": "more expensive than 💰", "v": "mais caro do que" },
  { "k": "the most interesting 🤩", "v": "o mais interessante de todos" }
]
```

> **Truque do tamanho:** **palavra curta → tu trabalhas** (colas -er/-est). **Palavra longa → o «more/most» trabalha** por ti. 😅 Pensa: ninguém quer dizer *«beautifullest»* — é demasiado comprido! Por isso a palavra longa pede ajuda ao *more/most*.

## Um exemplo passo a passo 🔍

Tens 3 montanhas e queres dizer: **«O Evereste é a montanha mais alta do mundo.»** Comparativo ou superlativo? 🧐

```steps
[
  { "title": "1. Quantas comparas? Todas! → superlativo", "body": "«mais alta do mundo» = de todas → superlativo 🏆", "icon": "🔍" },
  { "title": "2. tall é curto → -est", "body": "tall → tallest 📏", "icon": "🔤" },
  { "title": "3. Superlativo leva «the»!", "body": "the tallest ✅", "icon": "👑" },
  { "title": "4. Frase completa", "body": "Everest is the tallest mountain in the world. 🏔️", "icon": "ok" }
]
```

> **Truque-resumo:** faz **2 perguntas** — *Comparo DOIS ou de TODOS?* (dois → comparativo + *than*; todos → superlativo + *the*). *A palavra é curta ou longa?* (curta → -er/-est; longa → more/most). Duas perguntas e acertas! 🎛️

> [!TIP] **Para saberes mais** 🌱 Para dizeres que duas coisas são **iguais**, há uma estrutura gira: **as … as** (= «tão … como»)! 🤝 *«My bag is as heavy as yours»* (a minha mochila é tão pesada como a tua). E na negativa, *«not as … as»* significa «menos … que»: *«I'm not as tall as my brother»* (não sou tão alto como o meu irmão = sou mais baixo). É a terceira forma de comparar — a da **igualdade**! ⚖️
