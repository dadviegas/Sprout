# Future plans (going to) 🔮

> [!NOTE] **O que vais aprender** 👀 Vais aprender a falar do **futuro** em inglês com **going to** — para **planos** e **intenções** (*I'm going to visit my grandma*). Vais ver a fórmula **to be + going to + verbo**, as negativas e perguntas, e a diferença entre **going to** (planos) e **will** (decisões na hora). Olha para o futuro! 🔮🗓️

O que vais fazer no fim de semana? E nas próximas férias? 🗓️ Para falar dos teus **planos** — as coisas que já decidiste fazer — o inglês usa **going to**. É a bola de cristal da gramática! 🔮 Carrega no 🔊 e repete em voz alta.

## A fórmula do futuro 🧩

**Going to** tem três peças: o verbo **to be** (am/is/are) + **going to** + o **verbo principal** na base. Olha em ação:

## As três peças encaixam 🔧

O **to be** muda conforme o sujeito (tal como no present continuous!); o resto fica sempre igual: **going to + verbo base**.

> **Truque:** já sabes o **to be** do present continuous — é o **mesmo**! 🎯 A única diferença é que aqui colas **«going to» + o verbo** a seguir. Pensa: *am/is/are* (igual) + **going to** + o que vais fazer. Reaproveitas o que já sabes!

## Negativas e perguntas: mexe no «to be» 🎯

Boa notícia outra vez: como tem o *to be*, **não** precisas de *do/does*! Para a negativa, pões **not**; para a pergunta, **trocas** o *to be* para a frente.

## Going to vs. will: planos vs. decisões na hora 🆚

Este é o segredo do 6.º ano! Há **duas** formas de futuro, e usam-se em momentos diferentes:

```compare
[
  {
    "title": "going to 🗓️ (plano já decidido)",
    "rows": [
      {
        "label": "I'm going to visit Paris.",
        "value": "Já planeei, tenho bilhetes ✈️",
        "highlight": true
      },
      {
        "label": "We're going to have a party.",
        "value": "Já está combinado 🎉"
      }
    ],
    "lang": "en-US"
  },
  {
    "title": "will ⚡ (decisão na hora)",
    "rows": [
      {
        "label": "It's hot. I'll open the window.",
        "value": "Decidi agora mesmo 🪟",
        "highlight": true
      },
      {
        "label": "OK, I'll help you!",
        "value": "Decisão no momento 🤝"
      }
    ],
    "lang": "en-US"
  }
]
```

> **Truque do detetive 🕵️:** pergunta-te — *já tinha plano?* Se **sim** (já pensado, combinado) → **going to**. Se **decidi agora**, neste segundo → **will**. *Going to* é o plano que **já estava na agenda** 🗓️; *will* é a faísca da decisão **instantânea** ⚡!

## Um exemplo passo a passo 🔍

Queres dizer: **«Para a semana, ela vai aprender a nadar.»** (é um plano!) Como montas? 🧐

```steps
[
  { "title": "1. É um plano futuro → going to", "body": "«para a semana» (next week) + plano = going to 🗓️", "icon": "🔍" },
  { "title": "2. Escolhe o to be: She → is", "body": "He/She/It usa is 🔧", "icon": "✨" },
  { "title": "3. Cola «going to» + verbo base", "body": "going to learn (verbo na base!) 🏊", "icon": "🧩" },
  { "title": "4. Frase completa", "body": "Next week, she is going to learn to swim. ✅", "icon": "ok" }
]
```

> **Truque-resumo:** faz **3 perguntas** — *É um plano futuro?* (se sim, going to). *Que to be?* (am/is/are, como no continuous). *Verbo na base?* (going to + verbo, sempre!). Três passos e o futuro fica certo! 🎛️

> [!TIP] **Para saberes mais** 🌱 Há ainda **uma terceira** maneira de falar do futuro — e é a mais surpreendente! Para planos com **hora e data marcadas** (como uma consulta ou um voo), os ingleses usam o... **present continuous**! 😲 Dizes *«I'm meeting the doctor at 4 o'clock tomorrow»* (vou ter consulta amanhã às 4). Parece presente, mas fala do **futuro**! Usa-se quando o plano está tão certinho que já está «a acontecer» na agenda. 🗓️⏰
