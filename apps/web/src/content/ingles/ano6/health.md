## Dar conselhos: o verbo SHOULD 💡

Aqui está a estrela da lição! **Should** quer dizer **«devias»** — serve para dar **conselhos**. É super fácil: **should + verbo base**, igual para todos os sujeitos!

```steps
[
  { "title": "Conselho positivo: should", "body": "You should rest. 😴 (Devias descansar.) / You should drink water. 💧", "icon": "💡" },
  { "title": "Conselho negativo: shouldn't", "body": "You shouldn't eat so much candy. 🍬 (Não devias comer tantos doces.)", "icon": "🚫" },
  { "title": "O verbo fica na BASE", "body": "should rest (não 'should to rest' nem 'should rests'!) ✅", "icon": "ok" },
  { "title": "Pedir conselho", "body": "What should I do? 🤔 (O que devo fazer?)", "icon": "🔍" }
]
```

> **Truque do should:** depois de *should*, o verbo vai **«nu»** — sem *to*, sem *-s*, sem *-ed*. 🩳 *You should **rest*** (não *to rest*, não *rests*). E é igual para *I, you, he, she* — todos! O *should* é um verbo simpático que não complica. 😌

## Um exemplo passo a passo 🔍

O teu amigo diz *«I have a headache»* 🤯. Que conselho lhe dás em inglês? 🧐

```steps
[
  { "title": "1. Mostra que percebeste", "body": "«Oh no! You don't look well.» 🤒", "icon": "🔍" },
  { "title": "2. Dá um conselho com should", "body": "«You should rest.» 😴 (verbo base!)", "icon": "💡" },
  { "title": "3. Dá um conselho do que NÃO fazer", "body": "«You shouldn't watch TV.» 📺🚫", "icon": "🚫" },
  { "title": "4. Conselho final", "body": "«And you should drink water.» 💧 Feel better! 🤗", "icon": "ok" }
]
```

> **Truque-resumo:** quando alguém se queixa, responde em **2 passos** — primeiro **percebe a dor** (have a …ache / … hurts), depois **dá o conselho** (You should… / You shouldn't…). É assim que se ajuda em inglês! 🤝

> [!TIP] **Para saberes mais** 🌱 O **should** faz parte de uma família especial de verbos chamados **modal verbs** (verbos modais) — como *can, must, may, will*. Têm todos uma magia em comum: **nunca** levam *-s* na 3.ª pessoa (*she can*, não *she cans*) e o verbo a seguir fica **sempre na base** (sem *to*). Por isso dizes *«She **should** go»* e *«He **can** swim»* — limpinho, sem -s e sem *to*! São os verbos mais bem-comportados do inglês. 🎩✨
