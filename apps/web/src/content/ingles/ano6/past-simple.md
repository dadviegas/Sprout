# Past simple ⏪

> [!NOTE] **O que vais aprender** 👀 Vais dominar o **past simple** — o tempo das coisas que **já aconteceram** (*I played, I went*). Vais aprender o **-ed** dos verbos regulares, os verbos irregulares mais importantes (que tens de decorar!), e as negativas e perguntas com o ajudante **did**. ⏪🕰️

Tudo o que aconteceu **ontem**, **na semana passada** ou **há muito tempo** vai para o **past simple**. *«I played football yesterday»*, *«We went to the beach»*. É a máquina do tempo do inglês! 🕰️ Há dois caminhos — os verbos **regulares** (fáceis) e os **irregulares** (que se decoram). Carrega no 🔊 e vamos viajar ao passado!

## O caminho fácil: verbos regulares + -ed ✅

Para a maioria dos verbos, é só colar **-ed** no fim. Funciona para **todos os sujeitos** — não há aqui o -s da 3.ª pessoa!

> **Truque para os irregulares:** não há atalho — **decora aos pares**, como um rap! 🎤 *«go-went, have-had, see-saw, eat-ate, make-made.»* Diz em voz alta várias vezes e fica na cabeça. São poucos mas aparecem em quase todas as frases!

## Negativas e perguntas: o super-ajudante DID 🦸

Aqui está a magia do past simple: para negativas e perguntas usas **did** — e o verbo principal **volta ao presente** (sem -ed nem mudança)! O *did* já guarda o passado por ti.

```compare
[
  { "title": "Negativa: didn't + verbo base 🚫", "rows": [
    { "label": "I didn't play.", "value": "Não joguei (não 'didn't played'!)", "highlight": true },
    { "label": "She didn't go.", "value": "Ela não foi (não 'didn't went'!)" }
  ] },
  { "title": "Pergunta: Did + verbo base ❓", "rows": [
    { "label": "Did you play?", "value": "Jogaste? → Yes, I did. / No, I didn't.", "highlight": true },
    { "label": "Where did she go?", "value": "Onde é que ela foi?" }
  ] }
]
```

> **Atenção, armadilha!** ⚠️ Quando aparece o *did/didn't*, o verbo **perde o passado** — volta à forma base. *Did you go?* (não *did you went?*), *She didn't eat* (não *didn't ate*). O **did** já é o passado por ele e pelo verbo todo! Só um passado por frase. 1️⃣

## Um exemplo passo a passo 🔍

Queres dizer: **«Eles não foram à escola ontem.»** Como montas? 🧐

```steps
[
  { "title": "1. É passado? Sim! → past simple", "body": "«ontem» (yesterday) é a pista ⏪", "icon": "🔍" },
  { "title": "2. É negativa → usa didn't", "body": "qualquer sujeito: didn't 🚫", "icon": "🚫" },
  { "title": "3. Depois de didn't, verbo BASE", "body": "go (não went!) → didn't go 🚶", "icon": "⚠️" },
  { "title": "4. Frase completa", "body": "They didn't go to school yesterday. ✅", "icon": "ok" }
]
```

> **Truque-resumo:** faz **3 perguntas** — *É passado?* (procura *yesterday, last week, ago, in 2010*). *É afirmativa?* (então -ed ou irregular). *Tem did/didn't?* (então verbo base, sem passado!). 🎛️

> [!TIP] **Para saberes mais** 🌱 O **-ed** lê-se de **três** maneiras diferentes em inglês! 🔊 Depende do som anterior: *played* soa **/d/**, *watched* soa **/t/** (seco!), e *wanted* soa **/id/** (uma sílaba extra!). Repara que *wanted* tem **duas** sílabas — *wan-ted* — porque o verbo já acabava em **-t/-d**. Os ingleses fazem isto sem pensar; tu vais começar a notar! 👂✨
