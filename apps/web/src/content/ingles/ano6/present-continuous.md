# Present continuous 🏃

> [!NOTE] **O que vais aprender** 👀 Vais dominar o **present continuous** — o tempo verbal das coisas que estão a acontecer **agora mesmo** (*I am running*). Vais aprender a fórmula mágica **to be + verbo-ing**, as regras do **-ing**, as negativas e as perguntas, e a diferença entre *present continuous* e *present simple*. 🏃‍♀️💨

Imagina que ligas uma câmara e descreves o que está a acontecer **neste preciso momento**: *«Estou a correr! O cão está a ladrar! A chuva está a cair!»* Para isto, o inglês usa o **present continuous**. É o tempo do **agora**, do **em direto**. 📹 Carrega no 🔊 e repete em voz alta!

## A fórmula mágica ✨

O present continuous tem sempre **duas peças**: o verbo **to be** (am / is / are) + o verbo principal com **-ing**. Nunca te esqueças da primeira peça!

## As duas peças encaixam assim 🧩

O **to be** muda conforme o sujeito; o **-ing** cola-se sempre ao verbo principal. Olha o encaixe:

```compare
[
  { "title": "to be (a 1.ª peça) 🔧", "rows": [
    { "label": "I am", "value": "→ I am playing 🎮", "highlight": true },
    { "label": "He / She / It is", "value": "→ She is singing 🎤" },
    { "label": "You / We / They are", "value": "→ They are dancing 💃" }
  ] }

```

> **Truque:** o present continuous é um **sandwich** 🥪 — **to be** em baixo, **-ing** em cima, e o verbo no meio. Se faltar uma das fatias, não é sandwich! *I __ playing* sem o *am* está errado; *I am play* sem o *-ing* também. Precisas das **duas**!

## As regras do -ing 🔤

Quase sempre é só colar **-ing** ao verbo. Mas há três casinhos especiais para não tropeçares:

## Negativas e perguntas: é só mexer no «to be»! 🎯

A grande boa notícia: aqui **não** precisas de *do/does*! Para a negativa, pões **not** depois do *to be*. Para a pergunta, **trocas** o *to be* para o início.

```compare

    { "label": "I am not playing", "value": "Não estou a jogar (I'm not)", "highlight": true },

    { "label": "They are not running", "value": "Não estão a correr (aren't)" }
  ] },
  { "title": "Pergunta: to be à frente ❓", "rows": [
    { "label": "Are you playing?", "value": "Estás a jogar? → Yes, I am.", "highlight": true },
    { "label": "Is she eating?", "value": "Ela está a comer? → No, she isn't." },

```

> Repara: o verbo principal **nunca muda** nas perguntas e negativas — só mexes no *to be*! *Is she eat**ing**?* — o *-ing* fica sempre. 😌

## Agora vs. todos os dias: continuous vs. simple 🆚

Este é o segredo do 6.º ano! O **present simple** é para **rotinas** (todos os dias); o **present continuous** é para **agora** (neste momento). A mesma pessoa, dois tempos diferentes:

```compare
[
  { "title": "Present simple 🔁 (sempre / rotina)", "rows": [
    { "label": "I play football every day.", "value": "Jogo todos os dias ⚽" },
    { "label": "She reads at night.", "value": "Ela lê à noite 🌙", "highlight": true }
  ] },
  { "title": "Present continuous 🏃 (agora)", "rows": [
    { "label": "I am playing football now.", "value": "Estou a jogar agora ⚽" },
    { "label": "She is reading right now.", "value": "Ela está a ler agora mesmo 📖", "highlight": true }
  ] }
]
```

> **Truque do detetive 🕵️:** procura as **palavras-pista**! Vês *now, right now, at the moment, look!, listen!* → é **continuous** (-ing). Vês *every day, usually, always, on Mondays* → é **simple**. As palavras dizem-te o tempo!

## Um exemplo passo a passo 🔍

Queres dizer: **«Ela está a nadar na piscina.»** Como montas a frase? 🧐

```steps
[
  { "title": "1. É agora? Sim! → continuous", "body": "«está a nadar» = ação a acontecer neste momento ⏰", "icon": "🔍" },
  { "title": "2. Escolhe o to be: She → is", "body": "He/She/It usa is 🔧", "icon": "✨" },
  { "title": "3. Põe o verbo com -ing: swim → swimming", "body": "uma vogal + consoante (m) → dobra: swimming 🏊", "icon": "🔤" },
  { "title": "4. Frase completa", "body": "She is swimming in the pool. ✅", "icon": "ok" }
]
```

> **Truque-resumo:** faz sempre **3 perguntas** — *É agora?* (se sim, continuous). *Que to be?* (am/is/are). *Como fica o -ing?* (regra normal, tira -e, ou dobra). Três passos e a frase sai certinha! 🎛️

> [!TIP] **Para saberes mais** 🌱 Há verbos que **quase nunca** levam -ing — chamam-se **stative verbs** (verbos de estado). São verbos de sentir e pensar, não de *fazer*: *like, love, want, know, understand, need*. Por isso não dizemos *«I am wanting»* nem *«I am knowing»* — dizemos *«I want»* e *«I know»*, mesmo a falar do agora! Estes verbos descrevem um **estado**, não uma ação em movimento. 🧠✨
