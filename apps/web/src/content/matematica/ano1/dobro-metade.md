# Dobro e metade ✌️

O **dobro** é ter duas vezes a mesma coisa. A **metade** é repartir em duas partes iguais. Vamos brincar! 🎉

## O que é o dobro? 🐰🐰

O **dobro** é juntar uma coisa com outra igual. É como teres um brinquedo... e ganhares outro igual!

Tens 3 🍓. O dobro são **3 + 3 = 6** 🍓🍓🍓🍓🍓🍓.

Repara: o dobro é sempre **maior**. ⬆️

## O que é a metade? 🍪✂️

A **metade** é partir uma coisa em **duas partes iguais** e ficar com uma.

Tens 6 🍪. Repartes para dois amigos, em partes iguais: cada um fica com **3** 🍪🍪🍪. Essa é a metade!

> A metade é sempre **mais pequena**. ⬇️ Dobro e metade são contrários, como subir e descer! 🎢

## Truque 🪄

Para o **dobro**, soma o número **a ele mesmo** (duas vezes igual): dobro de 5 → 5 + 5.

Para a **metade**, pensa: *"Que número, somado com ele mesmo, dá este?"* Metade de 8 → 4 + 4 = 8, logo é **4**! 😎
