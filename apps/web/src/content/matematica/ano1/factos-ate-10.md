# Os factos amigos: somas até 10 🤝

> [!NOTE] **O que vais aprender** 👀 Vais treinar as somas pequeninas até saberes **de cor**: os **amigos do 10** (pares que fazem 10), os **dobros** (2 + 2, 3 + 3…) e os **quase-dobros** (3 + 4 é o dobro de 3, mais 1). São os teus **factos amigos** — quem os sabe, faz contas à velocidade de um foguetão! 🚀

Sabes como os jogadores de futebol treinam o mesmo remate muitas vezes até sair sem pensar? ⚽ Com as contas é igual: estas somas pequeninas vão aparecer **toda a vida**, por isso vamos treiná-las até saltarem da tua boca sozinhas!

## Os amigos do 10 👫

Dois números que juntos fazem **10** são **amigos do 10**. Olha para a caixa de dez: o que está cheio + o que está vazio dá sempre 10!

> [!TIP] Usa os dedos! Levanta **7 dedos** 🖐️✌️ — os dedos **deitados** são os que faltam para 10: **3**. Os teus dedos sabem sempre os amigos do 10!

## Os dobros ✌️

Um **dobro** é um número somado **com ele próprio**. Os dobros têm um som especial — parecem um eco! 2 + 2… 3 + 3… São facílimos de decorar:

## Os quase-dobros 🪜

E se a conta for **3 + 4**? Repara: o 4 é o 3 **mais 1**! Então 3 + 4 é o **dobro de 3, mais 1**:

```math
{ "expr": "3 + 4 = 3 + 3 + 1 = 7", "say": "três mais quatro é o dobro de três, mais um: sete" }
```

```math
{ "expr": "4 + 5 = 4 + 4 + 1 = 9", "say": "quatro mais cinco é o dobro de quatro, mais um: nove" }
```

Sabes o dobro? Então sabes o quase-dobro — é só dar **mais um passinho**! 🐾

## Um exemplo passo a passo 🔍

Quanto é **6 + 4**? Vamos pensar como um campeão dos factos:

```steps
[
  { "title": "1. Olha bem para a conta", "body": "6 + 4… estes dois cheiram-me a amigos! 👃", "icon": "👀" },
  { "title": "2. Pergunta: fazem 10?", "body": "na caixa de dez, 6 cheios deixam 4 vazios ✔️", "icon": "🔟" },
  { "title": "3. Responde sem contar", "body": "6 + 4 = 10 — saiu logo, sem contar pelos dedos! ⚡", "icon": "⚡" },
  { "title": "4. Festeja", "body": "és amigo dos amigos do 10! 🎉", "icon": "🎉" }
]
```

> **Truque:** antes de contar pelos dedos, faz as **duas perguntas mágicas**: ① *são amigos do 10?* ② *é um dobro (ou um quase-dobro)?* Quase todas as somas até 10 caem numa destas famílias — e a resposta sai logo! 🪄

> [!TIP] **Para saberes mais** 🌱 Os amigos do 10 crescem contigo: se 3 + 7 = 10, então **30 + 70 = 100**! São os **amigos do 100** — as mesmas caras, só que vestidas de dezenas. Os truques que aprendes hoje vão funcionar com números grandes para sempre. 😎
