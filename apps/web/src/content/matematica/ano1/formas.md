# Formas geométricas 🔺⬜⚫

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **formas geométricas** — o círculo, o quadrado, o triângulo e o retângulo — contar os seus **lados** e os seus **bicos**, e descobri-las escondidas em tudo o que está à tua volta! 🔍

Olha bem à tua volta… vês? As **formas** estão em todo o lado! A roda de um carrinho, a tua janela, uma fatia de pizza, a porta do teu quarto. Hoje vais virar um **caçador de formas** 🕵️ e aprender a reconhecê-las só de olhar. Vem comigo, vai ser divertido! 🎈

## Lados e bicos (vértices) 📐

Para reconhecer uma forma, contamos os **lados** (as linhas direitinhas à volta) e os **bicos** (os cantinhos onde os lados se juntam). Os grandes chamam aos bicos **vértices** — fica a saber essa palavra! 😉

> [!NOTE] Num quadrado e num triângulo, o número de **lados** é igual ao número de **bicos**. Conta um, já sabes o outro! 🤓

> [!TIP] Um quadrado é um retângulo muito especial: aquele em que todos os lados ficaram do mesmo tamanho! 🤩

## Os sólidos à tua volta 🎲⚽🥫

As formas do papel são **lisas**. Mas há formas que se **pegam na mão** — são os **sólidos**! Conhece já os três mais famosos:

```keyvalue
[
  { "k": "Cubo 🎲", "v": "como um dado ou uma caixa — tem cantos e fica quieto" },
  { "k": "Esfera ⚽", "v": "como uma bola — é toda redonda e rola para todo o lado" },
  { "k": "Cilindro 🥫", "v": "como uma lata — redondo dos lados, liso em cima e em baixo" }
]
```

E sabias que podes **juntar formas para fazer desenhos**? Um quadrado com um triângulo em cima faz uma **casinha** 🏠; um retângulo com dois círculos em baixo faz um **autocarro** 🚌. Compor formas é como brincar com peças!

> [!NOTE] **Truque:** se rola, é redondo (esfera ou cilindro deitado); se fica quieto, tem cantos (cubo). Empurra com o dedo e descobre! 👉

## Um exemplo passo a passo 🔍

Imagina que vês uma forma e perguntas: *«Que forma é esta? Tem 3 lados.»* Vamos descobrir juntos! 🧐

```steps
[
  { "title": "1. Olha bem para a forma", "body": "vê se é redonda ou se tem cantos (bicos) 👀", "icon": "👀" },
  { "title": "2. Tem bicos?", "body": "sim, tem cantos — então não é um círculo ✋", "icon": "🔺" },
  { "title": "3. Conta os lados", "body": "1… 2… 3 lados direitinhos 🖐️", "icon": "🔢" },
  { "title": "4. Conta os bicos", "body": "1… 2… 3 bicos — igual ao número de lados 📐", "icon": "📐" },
  { "title": "5. Resposta", "body": "3 lados e 3 bicos? É um triângulo! 🔺✅", "icon": "✅" }
]
```

> **Truque:** conta sempre pela ponta dos dedos! Um triângulo cabe em **3 dedos**, um quadrado em **4 dedos**. Se não consegues contar bicos nenhuns porque é todo redondo… é um **círculo**! 🖐️

> [!TIP] **Para saberes mais** 🌱 Olha bem para um dado 🎲: cada lado dele é… um **quadrado**! Os sólidos são feitos das formas planas que já conheces — chamam-se as **faces** do sólido. No 2.º ano vais contar as faces, as beirinhas (arestas) e os bicos (vértices) de todos os sólidos!
