## Procura à tua volta 🔍

- O **Sol** é um **círculo** ☀️
- Uma **janela** é um **quadrado** 🪟
- Uma **fatia de pizza** é um **triângulo** 🍕
- Uma **porta** é um **retângulo** 🚪

> [!TIP] **Para saberes mais** 🌱 As formas também existem **a 3 dimensões** (a sério, que se pegam!): uma bola é uma **esfera** ⚽, um dado é um **cubo** 🎲 e um gelado tem a ponta em **cone** 🍦. As planas são lisas; estas são "fofas", ocupam espaço!
