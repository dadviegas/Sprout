## O número que vem a seguir

Os números andam sempre pela mesma ordem, como uma fila:

```steps
[
  { "title": "1, 2, 3...", "body": "Os primeiros amigos da fila." },
  { "title": "4, 5, 6...", "body": "Vamos a meio!" },
  { "title": "7, 8, 9, 10", "body": "Chegámos ao 10! 🎉" }
]
```

> [!NOTE] Depois do **3** vem o **4**. Depois do **9** vem o **10**.
