# Somar e subtrair ➕➖

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que **somar é juntar** e **subtrair é tirar**, vais conhecer os sinais **+**, **−** e **=**, e vais aprender truques fixes para fazer contas de cabeça! ✨

Imagina que tens uns chocolates numa mão e o teu amigo te dá mais alguns. Quantos ficas a ter ao todo? Isso é **somar**! E se comeres um? Ficas com menos — isso é **subtrair**. Hoje vamos brincar com fruta, balões e uma rã saltitona para perceberes tudo sem esforço. Vamos a isto, campeão! 🐸🎈

## Somar é juntar ➕

Quando juntas coisas, estás a **somar**. Pões um grupo ao pé do outro e contas tudo junto. O sinal **+** lê-se **«mais»** e quer dizer *junta tudo*. 🤝

  { "k": "O sinal +", "v": "lê-se «mais» — diz-te para juntares 🤝" },

```

Tens 🍎🍎 e chega mais 🍎. Juntas tudo e ficas com **3 maçãs**: escreve-se **2 + 1 = 3**.

## Subtrair é tirar ➖

Quando tiras coisas, estás a **subtrair**. Tinhas um grupo e ficaste com menos. O sinal **−** lê-se **«menos»** e quer dizer *tira*. 😋

  { "k": "O sinal −", "v": "lê-se «menos» — diz-te para tirares ✂️" },
  { "k": "Fica sempre menos", "v": "depois de tirar, o número é mais pequeno ⬇️" },
  { "k": "Exemplo", "v": "4 🍌 − 1 🍌 = 3 🍌 (comeste uma banana!) 😋" }

```

Tens 🍌🍌🍌🍌 e comes 🍌. Ficam **3 bananas**: escreve-se **4 − 1 = 3**.

## Somar e subtrair são amigos 🤝

Somar e subtrair andam de mãos dadas: uma faz o contrário da outra! Se somas e depois tiras o mesmo número, voltas ao princípio. Olha lado a lado:

> [!TIP] Truque dos amigos: se **3 + 2 = 5**, então **5 − 2 = 3**. A subtração desfaz a soma, como apagar um desenho! ✏️

## A reta numérica: a rã saltitona 🐸

A **reta numérica** é uma fila de números. Para **somar**, a rã salta para a **frente** (para a direita). Para **subtrair**, salta para **trás** (para a esquerda). Conta os saltos!

```numberline
{ "min": 0, "max": 10, "start": 2, "step": 1, "title": "2 + 3: salta 3 vezes para a frente e chegas ao 5" }
```

Começa no **2**, dá **3 saltos** para a frente: 3, 4, 5 — paras no **5**! Então **2 + 3 = 5**. 🐸

## A caixa do 10 ➕

A **caixa de dez** (tenframe) ajuda-te a ver os números com os olhos. Quando enches a caixa toda, tens **10** — uma **dezena** cheia! 🔟

```tenframe
{ "count": 7, "emoji": "🟢", "title": "7 cheios e 3 vazios: faltam 3 para chegar a 10" }
```

Vê: tens **7** e a caixa só fica cheia com **10**. Faltam **3** para encher: **7 + 3 = 10**. Estes pares que dão 10 chamam-se **amigos do 10**! 👫

## Um exemplo passo a passo 🔍

Vamos resolver juntos: *«Tens 4 balões 🎈 e a tua mãe dá-te mais 3. Quantos ficas a ter?»*

```steps
[
  { "title": "1. Lê com calma", "body": "tens 4 balões e vais RECEBER mais 3 — vais ganhar, por isso é somar ➕", "icon": "🎈" },
  { "title": "2. Começa pelo maior", "body": "guarda o 4 na cabeça e conta a partir dele 🧠", "icon": "🧠" },
  { "title": "3. Conta para a frente", "body": "4… depois 5, 6, 7 (deste 3 saltos) 🐸", "icon": "🐸" },
  { "title": "4. Escreve a conta", "body": "4 + 3 = 7 ✍️", "icon": "✍️" },
  { "title": "5. Resposta", "body": "ficas com 7 balões! 🎈🎉", "icon": "🎉" }
]
```

> **Truque:** começa sempre pelo **número maior** e conta para a frente o número mais pequeno. Para **4 + 3**, guarda o **4** e conta «5, 6, 7». É muito mais rápido do que contar tudo desde o 1! 🚀

> [!TIP] **Para saberes mais** 🌱 Quando somas, podes **trocar a ordem** dos números que o resultado não muda: **2 + 5** dá o mesmo que **5 + 2** (ambos dão 7)! Os matemáticos chamam a isto a **propriedade comutativa** — uma palavra grande para uma ideia simples: na soma, a ordem não importa. Mas atenção: na **subtração** a ordem já importa! 🔄
