# Pares e ímpares 🔢

Sabias que os números gostam de fazer pares, como ao dar a mão? 🤝 Hoje vais descobrir quais é que conseguem... e quais ficam com um a sobrar!

## O que são pares e ímpares?

Imagina que tens uns docinhos e queres dividir com um amigo, um para cada um. 🍬🍬

- Se **não sobra nenhum**, o número é **PAR**. Toda a gente fica feliz! 😄
- Se **sobra um sozinho**, o número é **ÍMPAR**. Esse fica à espera de par. 🙃

Os números **pares** acabam sempre num destes algarismos: **0, 2, 4, 6, 8**.
Os números **ímpares** acabam em: **1, 3, 5, 7, 9**.

## Truque 🪄

Não precisas de fazer pares de cada vez! **Olha só para o ÚLTIMO algarismo** do número.

- Acaba em **0, 2, 4, 6, 8** → é **PAR**. 👫
- Acaba em **1, 3, 5, 7, 9** → é **ÍMPAR**. 🙋

Por exemplo, o **24** acaba em **4** → é par. O **37** acaba em **7** → é ímpar. Rápido como um foguetão! 🚀
