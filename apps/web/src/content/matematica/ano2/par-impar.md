# Pares e ímpares 🔢

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que torna um número **par** ou **ímpar**, aprender um truque rápido para saber só de olhar, e ver que os pares e os ímpares aparecem por todo o lado — até nos teus dedos! ✋

Sabias que os números gostam de fazer pares, como ao dar a mão? 🤝 Alguns conseguem juntar-se todos, dois a dois, e não fica ninguém de fora. Outros têm sempre um amiguinho que fica à espera, sozinho. Vem comigo descobrir quais são quais — vais ver que é muito mais fácil do que parece! 🚀

## O que são pares e ímpares?

Imagina que tens uns docinhos e queres dividir com um amigo, um para cada um. 🍬🍬 Fazes grupinhos de **2**.

- Se **não sobra nenhum**, o número é **PAR**. Toda a gente fica com par! 😄
- Se **sobra um sozinho**, o número é **ÍMPAR**. Esse fica à espera. 🙃

## Um exemplo passo a passo 🔍

Vamos descobrir se o **8** é par ou ímpar, juntando 8 morangos aos pares. 🍓

```steps
  { "title": "3. Sobrou algum?", "body": "Não sobrou nenhum morango sozinho. Boa!", "icon": "✅" },
  { "title": "4. Responde", "body": "Como não sobra nada, o 8 é PAR. E repara: o 8 acaba em 8. ✅", "icon": "👫" }

```

> **Truque:** não precisas de fazer pares de cada vez! **Olha só para o ÚLTIMO algarismo** do número. Acaba em **0, 2, 4, 6, 8** → é **PAR** 👫. Acaba em **1, 3, 5, 7, 9** → é **ÍMPAR** 🙋. O **24** acaba em 4 → par. O **37** acaba em 7 → ímpar. Rápido como um foguetão! 🚀

> [!TIP] **Para saberes mais** 🌱 Aqui vai um segredo dos números: se **somares dois pares** (2 + 4 = 6) dá sempre PAR! E se **somares dois ímpares** (3 + 5 = 8) também dá par. Mas um par + um ímpar (2 + 3 = 5) dá sempre ímpar. Experimenta com os dedos e vê a magia acontecer! 🤓✨
