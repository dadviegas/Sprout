# Simetria e eixos 🦋

> [!NOTE] **O que vais aprender** 👀 Vais descobrir a **simetria** — quando uma metade de uma figura é o **espelho** da outra — e a linha onde dobramos para as metades coincidirem: o **eixo de simetria**! 🪞

Olha para uma borboleta 🦋: a asa da direita é igualzinha à asa da esquerda, mas virada ao contrário, como se houvesse um espelho no meio. A isto chamamos **simetria**, e está escondida por todo o lado — no teu rosto, num coração ❤️, numa folha de árvore. Vem comigo descobrir esta magia das metades iguais! ✨

## O que é a simetria 🪞

Uma figura tem **simetria** quando uma metade é o **espelho** da outra. Se pudesses **dobrar** a figura ao meio, as duas partes ficavam exatamente **uma em cima da outra**, sem nada a sobrar! 🤝

## Um exemplo passo a passo 🔍

Vamos descobrir se a letra **A** tem simetria. Vem dobrar comigo! ✂️

```steps
[
  { "title": "1. Imagina a dobra", "body": "põe uma linha a direito, mesmo no meio do A, de cima a baixo. 📏", "icon": "📏" },
  { "title": "2. Dobra ao meio", "body": "imagina que dobras o A por essa linha, juntando os dois lados. 🤝", "icon": "🤝" },
  { "title": "3. Vê se coincide", "body": "o lado esquerdo cai exatamente em cima do lado direito — igualzinho! 🪞", "icon": "🪞" },
  { "title": "4. Conclui", "body": "as metades coincidem, logo o A É simétrico! Essa linha é o eixo de simetria. 🎉", "icon": "✅" }
]
```

> **Truque:** para testar a simetria, imagina que **dobras a figura ao meio** 🤝 — se as duas metades ficam **exatamente em cima uma da outra**, é **simétrica**! Se sobrar alguma coisa ou ficar torto, não é. É só dobrar com a imaginação! 🪞

> [!TIP] **Para saberes mais** 🌱 O número de eixos **muda com a figura**! O **triângulo equilátero** (com os três lados iguais) tem **3 eixos**, o **quadrado** tem **4**, e o **círculo** tem **infinitos** eixos de simetria — porque podes dobrá-lo por **qualquer** linha que passe pelo centro! ♾️🤓
