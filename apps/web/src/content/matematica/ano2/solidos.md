# Sólidos geométricos 🧊

Há formas que se pegam, que ocupam espaço e que rolam ou ficam quietas! São os **sólidos geométricos**. Vamos conhecê-los? 😄

## Sólidos que se pegam ✋

As formas planas (como o quadrado ou o círculo) são lisas, vivem numa folha. Mas os **sólidos** são a 3 dimensões: têm altura, largura e profundidade. Dá para os agarrar! 🙌

Olha à tua volta, eles estão por todo o lado:

```

Alguns **rolam** (esfera, cilindro, cone) porque têm partes redondas. Outros ficam **quietos** (cubo, prisma) porque só têm lados direitos. 🛑

## Truque 🪄

Pergunta sempre **uma coisa só**: "Isto rola?" 🎳

- **Se rola** → tem parte redonda → é esfera, cilindro ou cone.
- **Se fica quieto** → só tem cantos e lados direitos → é cubo ou prisma.

Depois é fácil: bola = esfera, lata = cilindro, gelado = cone, dado = cubo, caixa comprida = prisma. Já sabes mais do que pensas! 🌟

> O João foi às compras com a mãe. No saco trazia: **1 bola** de futebol ⚽, **1 lata** de tomate 🥫 e **1 gelado** de cone 🍦. Quantos sólidos do saco conseguem **rolar**?

  { "title": "Escolher", "body": "Todos estes têm partes redondas, por isso todos rolam! Conta: 1 + 1 + 1." },
  { "title": "Responder", "body": "São 3 sólidos que rolam. ✅ Confirma: nenhum deles é cubo nem prisma, e todos têm curvas!" }

```

> [!TIP] **Para saberes mais** 🌱 Os lados planos de um sólido chamam-se **faces**. O cubo tem **6 faces**! E os bicos onde elas se juntam chamam-se **vértices**. 🤓
