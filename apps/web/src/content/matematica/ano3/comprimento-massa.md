# Comprimento e massa 📏

Para saber **quão comprido** ou **quão pesado** é algo, usamos **medidas**. 📏⚖️

## Comprimento — quão comprido? 📏

Medimos o comprimento em **metros (m)** e **centímetros (cm)**.

```keyvalue
[
  { "k": "1 metro (m)", "v": "= 100 centímetros (cm)", "icon": "ruler" },
  { "k": "Um lápis", "v": "≈ 15 cm" },
  { "k": "Uma porta", "v": "≈ 2 m" }
]
```

> Para coisas **pequenas** usa **cm** (um dedo). Para **grandes** usa **m** (a sala). 📐

## Massa — quão pesado? ⚖️

Medimos a massa (o peso) em **quilogramas (kg)** e **gramas (g)**.

```keyvalue
[
  { "k": "1 quilograma (kg)", "v": "= 1000 gramas (g)" },
  { "k": "Um pacote de açúcar", "v": "≈ 1 kg 🍚" },
  { "k": "Uma maçã", "v": "≈ 150 g 🍎" }
]
```

> [!TIP] Usamos **réguas** e **fitas métricas** para o comprimento, e **balanças** para a massa. ⚖️📏
