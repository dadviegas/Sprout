# A divisão ➗

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que **dividir** é repartir em partes **iguais**, conhecer os nomes de cada número da divisão e usar a tabuada ao contrário para encontrares o resultado num instante. 🍪

Imagina que tens um saco de bolachas e queres dar a mesma quantidade a cada amigo, sem ninguém ficar a ganhar mais. É exatamente isso que a divisão faz: **reparte com justiça**! E o melhor é que tu já sabes quase tudo — porque dividir é só a multiplicação a andar para trás. Vamos lá? 🎉

## Dividir é repartir em partes iguais ✂️

Quando divides, pegas num total e separas em **grupos do mesmo tamanho**. Não pode ficar um grupo maior do que outro — tem de ser **justo**.

```steps

  { "title": "Quantos grupos?", "body": "São 3 amigos, então fazemos 3 grupos iguais 👫👦", "icon": "🤝" },
  { "title": "Reparte uma a uma", "body": "uma para ti, uma para ti, uma para ti… até acabarem 🔁", "icon": "🔁" },

]
```

> **12 ÷ 3** lê-se *«doze a dividir por três»* e quer dizer: «reparte 12 por 3 grupos iguais». Ficam **4** em cada grupo.

> [!NOTE] Há duas maneiras de escrever a mesma divisão: **12 ÷ 3 = 4** ou com o sinal de dois pontos, **12 : 3 = 4**. As duas querem dizer a mesma coisa! ✍️

## A divisão e a multiplicação são amigas 🤝

Uma ajuda a verificar a outra — são operações **inversas**. Por isso, se souberes a tabuada, já sabes dividir!

> **12 ÷ 3 = 4**, porque **4 × 3 = 12** ✔️ Para confirmar uma divisão, faz a multiplicação ao contrário!

## Estratégias espertas: partir o dividendo 🧩

E uma divisão grande, como **135 ÷ 5**? O truque é **partir o número que vais repartir** em bocados amigos da tabuada — divide cada bocado e junta no fim. Pensa primeiro, depois revela:

```steps

  { "title": "1. Olha para a conta", "body": "135 ÷ 5… o 135 não está na tabuada! Mas 135 = 100 + 35 🧐", "icon": "👀" },
  { "title": "2. Divide o bocado grande", "body": "100 ÷ 5 = 20 (duas notas de 50 em moedas de 5!) 💯", "icon": "➗" },
  { "title": "3. Divide o bocado pequeno", "body": "35 ÷ 5 = 7 (está na tabuada: 5 × 7 = 35) ✋", "icon": "➗" },
  { "title": "4. Junta os dois", "body": "20 + 7 = 27 → 135 ÷ 5 = 27 🎉", "icon": "➕" },
  { "title": "5. Confirma", "body": "27 × 5 = 135 ✔️ Está certo!", "icon": "✅" }
] }
```

```math
{ "expr": "135 ÷ 5 = 100 ÷ 5 + 35 ÷ 5 = 27", "say": "cento e trinta e cinco a dividir por cinco: cem a dividir por cinco dá vinte, trinta e cinco a dividir por cinco dá sete, vinte mais sete são vinte e sete" }
```

> [!NOTE] Escolhe bocados que a tabuada conheça: para dividir por 5, parte em **100, 50, 35, 20**… Outro exemplo: 96 ÷ 4 = 80 ÷ 4 + 16 ÷ 4 = 20 + 4 = **24**. 🧩

## Um exemplo passo a passo 🔍

Vamos resolver juntos: *«A professora tem 20 lápis 🖍️ para guardar em 5 caixas iguais. Quantos lápis ficam em cada caixa?»*

```steps
[
  { "title": "1. Lê com atenção", "body": "temos 20 lápis (o total) e 5 caixas iguais (os grupos) 🧐", "icon": "🧐" },
  { "title": "2. Escolhe a operação", "body": "como vamos REPARTIR em grupos iguais, é uma DIVISÃO: 20 ÷ 5 ➗", "icon": "➗" },
  { "title": "3. Pensa na tabuada ao contrário", "body": "«5 vezes quanto dá 20?» → 5 × 4 = 20 🪄", "icon": "🪄" },
  { "title": "4. Já tens a resposta", "body": "20 ÷ 5 = 4 lápis em cada caixa 🖍️", "icon": "🖍️" },
  { "title": "5. Confirma", "body": "4 × 5 = 20 ✔️ Está certo! 🎉", "icon": "✅" }
]
```

> **Truque:** sempre que vires uma divisão, transforma-a numa pergunta de tabuada: **15 ÷ 5 = ?** vira *«5 vezes quanto dá 15?»* → **3**! Se souberes as tabuadas, já sabes todas as divisões. 🧠

> [!TIP] **Para saberes mais** 🌱 Há um truque para saber se um número se divide certinho por **outro, sem sobrar resto**: um número divide-se por **2** se for **par** (acaba em 0, 2, 4, 6 ou 8); divide-se por **5** se acabar em **0 ou 5**; e divide-se por **10** se acabar em **0**. Isto chamam-se *critérios de divisibilidade* — e vais usá-los muito nos próximos anos! 🔢
