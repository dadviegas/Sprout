# Números até 1000 💯

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **ler, escrever, comparar e ordenar** números até 1000, a perceber o valor de cada algarismo (centenas, dezenas e unidades) e a decompor números como um verdadeiro detetive! 🕵️

Já contas até 100? Boa! Agora vamos ainda mais longe — até **mil**! 🚀 Não te assustes com os números grandes: é tudo uma questão de juntar grupos em **gavetas**. Quando perceberes o truque das gavetas, vais ler qualquer número num instante. Vamos a isto! 😄

## As três gavetas: centenas, dezenas e unidades 🗄️

Um número grande é como uma cómoda com **três gavetas**. Cada gaveta tem o seu lugar e o seu nome:

```keyvalue
[
  { "k": "Unidade (U)", "v": "1 peça solta 🟦" },
  { "k": "Dezena (D)", "v": "10 unidades juntas = 10 🔟" },
  { "k": "Centena (C)", "v": "10 dezenas juntas = 100 💯" }
]
```

No número **345**, cada algarismo está na sua gaveta:

> **3** centenas + **4** dezenas + **5** unidades = **345** 🎉

A **posição** do algarismo é que manda no seu valor! O mesmo **3** pode valer muito ou pouco — depende do lugar onde está. 📍

```compare
[
  { "title": "O 3 no 345", "rows": [ {"label":"gaveta","value":"centenas"}, {"label":"vale","value":"300"} ] },
  { "title": "O 3 no 35", "highlight": true, "badge": "outro lugar", "rows": [ {"label":"gaveta","value":"dezenas"}, {"label":"vale","value":"30"} ] }
]
```

## Ler e escrever por extenso ✍️

Para ler um número, lê **da esquerda para a direita**, gaveta a gaveta. Repara como se diz cada número:

```keyvalue
[
  { "k": "100", "v": "cem 💯" },
  { "k": "200", "v": "duzentos" },
  { "k": "365", "v": "trezentos e sessenta e cinco 📅" },
  { "k": "500", "v": "quinhentos" },
  { "k": "1000", "v": "mil 🎉" }
]
```

Cuidado com a palavrinha **«e»**: dizemos «trezentos **e** vinte **e** sete» (327), com um «e» entre cada gaveta. E lembra-te: a seguir a cem dizemos **cento**: 100 é *cem*, mas 150 é *cento e cinquenta*. 🙂

## Decompor um número 🧩

**Decompor** é separar o número nas suas gavetas. É como desmontar um brinquedo para ver as peças por dentro!

```steps
[
  { "title": "Escreve o número", "body": "Vamos decompor o 472." },
  { "title": "Separa as gavetas", "body": "4 centenas, 7 dezenas, 2 unidades." },
  { "title": "Escreve o valor de cada uma", "body": "400 + 70 + 2." },
  { "title": "Confirma", "body": "400 + 70 + 2 = 472 ✅ Está certo!" }
]
```

E também podemos fazer o contrário — **compor**: juntar 600 + 30 + 8 e obter **638**. 🛠️

## Comparar e ordenar 📏

Para saber qual número é **maior** (>) ou **menor** (<), começa sempre pela gaveta da **esquerda** (as centenas):

```steps
[
  { "title": "Compara as centenas", "body": "Em 528 e 491, o 5 é maior que o 4. Logo 528 > 491." },
  { "title": "Empate nas centenas?", "body": "Em 374 e 358, ambos têm 3 centenas. Passa às dezenas: 7 > 5, logo 374 > 358." },
  { "title": "Empate nas dezenas?", "body": "Aí decides pelas unidades. A gaveta da esquerda manda sempre primeiro!" }
]
```

```compare
[
  { "title": "Por ordem crescente ⬆️", "rows": [ {"label":"do menor","value":"209"}, {"label":"depois","value":"450"}, {"label":"ao maior","value":"781"} ] },
  { "title": "Sinais a saber", "highlight": true, "rows": [ {"label":"maior que","value":"> 🐊"}, {"label":"menor que","value":"<"}, {"label":"igual a","value":"="} ] }
]
```

> O sinal **>** é como uma boquinha de crocodilo: abre sempre para o número **maior**! 🐊

## A reta numérica 🔢

Os números até 1000 também vivem numa **reta**: à esquerda os pequenos, à direita os grandes. Saltar de **100 em 100** ajuda-te a saber onde fica cada número.

## Um exemplo passo a passo 🔍

A Matilde está a guardar cromos. Tem **4 caixas** com 100 cromos cada, **2 saquinhos** com 10 cada e **6 cromos** soltos. Quantos cromos tem ao todo?

```steps
[
  { "title": "Lê e vê os dados", "body": "4 caixas de 100, 2 saquinhos de 10, 6 soltos." },
  { "title": "Liga ao que sabes", "body": "Cada caixa é uma centena, cada saquinho é uma dezena, os soltos são unidades." },
  { "title": "Faz a conta", "body": "4 centenas = 400 · 2 dezenas = 20 · 6 unidades = 6 → 400 + 20 + 6." },
  { "title": "Responde e confirma", "body": "A Matilde tem 426 cromos! ✅ Lê-se: quatrocentos e vinte e seis." }
]
```

> **Truque:** conta os algarismos! Se o número tem **3 algarismos**, começa logo nas **centenas**. Assim, no **508** vês de imediato: 5 centenas, 0 dezenas, 8 unidades = **500 + 0 + 8**. O zero quer dizer «esta gaveta está vazia» 🙂.

> [!TIP] **Para saberes mais** 🌱 A seguir ao 1000 continua tudo igual, só com uma gaveta nova à esquerda: o **milhar**! 1 milhar = 10 centenas = 1000. Por isso, **1245** lê-se «mil duzentos e quarenta e cinco» = 1 milhar + 2 centenas + 4 dezenas + 5 unidades. 🚀
