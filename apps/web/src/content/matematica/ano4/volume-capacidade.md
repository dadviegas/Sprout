# Volume e capacidade 🧴

Quanto cabe dentro de uma garrafa? E quanto espaço ocupa uma caixa? Vamos descobrir! 🧴💧

## O que cabe lá dentro 💧

A **capacidade** é quanto líquido cabe dentro de um recipiente (uma garrafa, um copo, um balde).

Medimos a capacidade em **litros (l)** e **mililitros (ml)**.

```keyvalue
]
```

> O **mililitro** é pequenino (uma gota). O **litro** é grande (uma garrafa). Mil mililitros juntos fazem 1 litro!

## Truque 🪄

Para passar de **litros para ml**, é só **acrescentar 3 zeros** (porque 1 l = 1000 ml)!

> 3 litros → 3**000** ml. 5 litros → 5**000** ml. Fácil! 🪄

E ao contrário? Para passar de **ml para litros**, **tiras 3 zeros**: 4000 ml → 4 litros.
