# Expressões e equações 🟰

> [!NOTE] **Matéria extra — já é uma espreitadela ao 7.º ano!** 🚀 Este tema saiu do programa do 6.º ano (passou para o 3.º ciclo), por isso não aparece nos testes deste ano. Mas se tiveres curiosidade, ficas com avanço!

> [!NOTE] **O que vais aprender** 👀 O que é uma **incógnita** (uma letra que esconde um número!), a diferença entre uma **expressão** e uma **equação**, e a resolver equações simples mantendo a **balança** sempre equilibrada. No fim, descobres o número secreto de qualquer enigma matemático! 🔍⚖️

E se te dissesse que a matemática tem **enigmas com letras**? «Um número mais 3 dá 10 — que número é?» 🤔 Essa letra misteriosa chama-se **incógnita**, e descobrir quanto vale é resolver uma **equação**. É como ser detetive: segues as pistas até apanhar o número escondido. Pega na lupa! 🕵️

## Expressão ou equação? 🟰

Uma **expressão** é uma conta com um resultado (como `3 + x`). Uma **equação** tem um **sinal de igual** que diz que os **dois lados valem o mesmo** — e há uma **incógnita** (letra) para descobrir.

## A equação é uma balança ⚖️

O segredo está aqui: o sinal **=** é o **fulcro de uma balança**. Os dois lados estão **equilibrados**. Se mexeres num lado, tens de fazer **exatamente o mesmo** no outro — senão a balança desequilibra!

```steps
[
  { "title": "x + 3 = 10", "body": "imagina uma balança: à esquerda x + 3, à direita 10 ⚖️", "icon": "⚖️" },
  { "title": "Queres o x sozinho", "body": "tens de tirar o +3 do lado esquerdo", "icon": "🎯" },
  { "title": "Tira 3 dos DOIS lados", "body": "x + 3 − 3 = 10 − 3", "icon": "🔄" },
  { "title": "Fica…", "body": "x = 7 🎉 (a balança continua equilibrada!)", "icon": "✅" }
]
```

> **Truque da operação inversa:** para libertar a incógnita, fazes a **operação contrária**. Se está a **somar**, **subtrais**; se está a **multiplicar**, **divides**. E sempre dos **dois lados**! 🔄

## Confirmar a solução ✔️

Um bom detetive **confirma**! Pega no valor que encontraste e mete-o no lugar da letra. Se os dois lados ficarem iguais, acertaste!

```steps
[
  { "title": "Achei x = 7 em x + 3 = 10", "body": "vou confirmar 🔍", "icon": "🕵️" },
  { "title": "Substitui", "body": "7 + 3 = 10", "icon": "🔁" },
  { "title": "Confere", "body": "10 = 10 ✅ verdadeiro!", "icon": "✅" }
]
```

> [!WARNING] O que fazes a um lado, fazes ao **outro** — sempre! Se tiras 3 só de um lado, a balança **tomba** e a igualdade deixa de ser verdadeira. ⚖️🚫 Regra de ouro: **os dois pratos andam juntos**.

## Um exemplo passo a passo 🔍

*«Pensei num número. Multipliquei-o por 3 e juntei 2, e deu 14. Em que número pensei?»* Vamos transformar em equação e resolver! 🧩

```steps
[
  { "title": "1. Traduz para letras", "body": "«número» = n → 3 × n + 2 = 14", "icon": "✍️" },
  { "title": "2. Desfaz o +2", "body": "tira 2 dos dois lados: 3 × n = 12", "icon": "➖" },
  { "title": "3. Desfaz o ×3", "body": "divide os dois lados por 3: n = 4", "icon": "➗" },
  { "title": "4. Confirma", "body": "3 × 4 + 2 = 12 + 2 = 14 ✅", "icon": "✅" },
  { "title": "5. Resposta", "body": "o número era 4! 🎉", "icon": "🎉" }
]
```

> **Truque da ordem inversa:** para resolver, **desfaz as operações pela ordem CONTRÁRIA** àquela em que foram feitas. No problema primeiro multiplicou-se e depois somou-se — por isso desfazes **primeiro a soma** e **depois a multiplicação**. É como descalçar: tiras o sapato antes da meia! 🧦👟

> [!TIP] **Para saberes mais** 🌱 A palavra **«álgebra»** vem do árabe **«al-jabr»**, que quer dizer «**reunir as partes partidas**» — exatamente o que fazes ao juntar termos e equilibrar os dois lados! 🏛️ Foi um sábio chamado **al-Khwarizmi** (cujo nome deu origem à palavra «**algoritmo**»!) que, há mais de 1200 anos, escreveu o primeiro grande livro de equações. E sabias que o sinal **=** só foi inventado em **1557**, por Robert Recorde? Ele escolheu duas linhas paralelas «porque nada pode ser mais igual». ✌️ No 3.º ciclo vais resolver equações bem mais espertas — mas a balança é sempre a mesma! ⚖️
