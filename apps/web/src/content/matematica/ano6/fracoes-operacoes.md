# Multiplicar e dividir frações ✖️

> [!NOTE] **O que vais aprender** 👀 A **multiplicar** uma fração por outra (é mais fácil do que somar!), o segredo do **inverso** de uma fração, e a **dividir** frações com o truque «vira-e-multiplica». No fim, resolves problemas a sério com partes de partes — como «metade de meio bolo». 🍰🔄

Já somas e comparas frações. Agora vem a parte **surpreendente**: multiplicar frações é até **mais simples** que somar, porque **não** precisas de denominador comum! E dividir? Tem um truque tão divertido que parece magia. Aperta o cinto, que isto é fácil e fica giro. 🚀

## Multiplicar: cima com cima, baixo com baixo ✖️

A regra é direta: **multiplicas os numeradores** (em cima) e **multiplicas os denominadores** (em baixo). Sem denominador comum, sem voltas!

A palavra **«de»** é a pista secreta: «**metade de um terço**» quer dizer **1/2 × 1/3**. Multiplicar frações é **tirar uma parte de uma parte** — e por isso o resultado fica **mais pequeno**!


> [!WARNING] Surpresa: ao multiplicar duas frações próprias, o resultado é **menor** que as duas! 🤔 Faz sentido: «metade de meio bolo» é menos que meio bolo. Multiplicar **nem sempre** faz crescer — só com frações é que encolhe!

## O truque de cortar antes 🔪

Antes de multiplicar, podes **simplificar em cruz** para teres números mais pequenos. Se um número de cima e um de baixo têm um divisor comum, corta logo!

## O inverso de uma fração 🔄

O **inverso** de uma fração é a mesma fração **de pernas para o ar** — trocas o de cima com o de baixo. O inverso de **3/4** é **4/3**. Quando multiplicas uma fração pelo seu inverso, dá sempre **1**!

## Dividir frações: vira-e-multiplica 🪄

Aqui está o truque mais famoso das frações! Para **dividir** por uma fração, **multiplicas pelo inverso** dela. Ou seja: mantém a primeira, **vira a segunda** e troca o ÷ por ×.

```steps
[
  { "title": "1/2 ÷ 1/4", "body": "mantém o 1/2; vira o 1/4 → fica 4/1", "icon": "🔄" },
  { "title": "Troca ÷ por ×", "body": "1/2 × 4/1", "icon": "✖️" },
  { "title": "Multiplica", "body": "1 × 4 = 4 e 2 × 1 = 2 → 4/2", "icon": "🧮" },
  { "title": "Simplifica", "body": "4/2 = 2 → cabem 2 quartos em meia pizza! 🍕", "icon": "✅" }
]
```

```math
{ "expr": "1/2 ÷ 1/4 = 2", "say": "um meio a dividir por um quarto é igual a dois" }
```

> **Truque para nunca esqueceres:** **«Conserva, vira, multiplica»** (KCF: Keep, Change, Flip). Mantém a 1.ª, muda o sinal, vira a 2.ª. Repete baixinho e fica para sempre! 🎵

## Um exemplo passo a passo 🔍

*«A mãe fez **3/4** de um tabuleiro de brownies. Quer cortá-los em pedaços de **1/8** do tabuleiro cada um. Quantos pedaços dá?»* É uma divisão de frações! 🍫

```steps
[
  { "title": "1. O que se pergunta", "body": "quantos 1/8 cabem em 3/4 → 3/4 ÷ 1/8", "icon": "❓" },
  { "title": "2. Conserva, vira, multiplica", "body": "3/4 × 8/1", "icon": "🔄" },
  { "title": "3. Multiplica", "body": "3 × 8 = 24 e 4 × 1 = 4 → 24/4", "icon": "🧮" },
  { "title": "4. Simplifica", "body": "24/4 = 6", "icon": "✨" },
  { "title": "5. Resposta", "body": "dá 6 pedaços de brownie! 🍫🎉", "icon": "🎉" }
]
```

> **Truque mental:** dividir por uma fração **menor que 1** dá um resultado **maior**! Faz sentido: cabem **muitos** pedacinhos de 1/8 dentro de 3/4. Dividir não faz sempre encolher — depende do tamanho da fatia! 🧠

> [!TIP] **Para saberes mais** 🌱 Por que é que «vira-e-multiplica» **funciona**? Dividir por 1/4 é perguntar «quantos quartos cabem aqui?» — e em **cada** inteiro cabem **4** quartos, por isso multiplicas por 4! O inverso (4/1) é exatamente «quantos cabem em 1». 🤓 No próximo ciclo vais ver que isto liga às **frações dentro de frações** (frações compostas) e à **divisão de números racionais** — mas o truque é sempre o mesmo: conserva, vira, multiplica! 🔄
