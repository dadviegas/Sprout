# Os símbolos dos Açores 🦅

> [!NOTE] **O que vais aprender** 👀 Vais conhecer os **símbolos** dos Açores: a **ave** que deu o nome às ilhas, a **bandeira** com as suas **9 estrelas**, o **hino**, o **brasão** e as cores que toda a gente reconhece. Uma estrela por cada ilha! ⭐

Cada terra tem **símbolos** — coisas especiais que dizem logo «isto é daqui!». A bandeira, uma flor, uma canção… Os Açores têm muitos, e cada um conta uma história bonita. Vamos descobri-los juntos? 🌋💙

## O açor — a ave do nome 🦅

Sabias que as ilhas têm o nome de uma **ave**? Conta-se que os primeiros marinheiros que chegaram viram aves grandes a voar e chamaram às ilhas **«Açores»**. O **açor** é uma **ave de rapina**, com bico curvo e olhos muito bons para caçar.

## Um exemplo passo a passo 🔍

Imagina que vês uma bandeira ao longe e queres saber se é a dos Açores. Como é que descobres com certeza?

```steps
  { "title": "2. Procura uma ave", "body": "há um açor (uma ave de rapina) ao centro? Boa pista! 🦅" },
  { "title": "3. Conta as estrelas", "body": "vês estrelas douradas em arco? Conta-as devagar... 1, 2, 3... ⭐" },
  { "title": "4. Deu 9?", "body": "se contaste 9 estrelas, é mesmo a bandeira dos Açores! 🎉" }

```

> **Truque:** 9 ilhas → **9 estrelas** na bandeira. É só contar pelos dedos das duas mãos menos um! ✋✋ E lembra-te: **A**çores começa por **A** de **A**ve. 🦅

> [!TIP] **Para saberes mais** 🌱 O **priolo** é um passarinho que **só existe nos Açores**, na ilha de São Miguel — não há em mais lado nenhum do mundo! Esteve quase a desaparecer e foi salvo com muito cuidado, plantando árvores onde ele come. Por isso se diz que é um **símbolo vivo** dos Açores. 🐦💚
