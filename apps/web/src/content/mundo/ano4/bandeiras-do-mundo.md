# Bandeiras do mundo 🏳️

> [!NOTE] **O que vais aprender** 👀 Vais descobrir para que servem as **bandeiras** e conhecer algumas bandeiras famosas do mundo! 🌍

Cada país tem a sua **bandeira** — um desenho de cores que o representa. É como o "símbolo" de cada país. 🎌

## Um exemplo passo a passo 🔍

Vês uma bandeira **branca** com uma **bola vermelha** no meio. De que país será? Vamos descobrir!

```steps
[
  { "title": "1. Olha para o fundo", "body": "é todo branco, sem riscas 🤍" },
  { "title": "2. Olha para o meio", "body": "tem um círculo vermelho, redondinho 🔴" },
  { "title": "3. Pensa no que parece", "body": "o círculo vermelho parece o Sol ☀️" },
  { "title": "4. Lembra-te do truque", "body": "que país é 'a terra do sol nascente'? O Japão!" },
  { "title": "5. Resposta", "body": "é a bandeira do Japão 🇯🇵" }
]
```

> **Truque:** a bandeira do **Japão** é fácil — branca com uma **bola vermelha** no meio, que é o **sol**. Por isso lhe chamam "a terra do sol nascente"! ☀️

> [!TIP] **Para saberes mais** 🌱 Há mais de **190 países** no mundo, e cada um tem a sua bandeira! Algumas regiões também têm — como os **Açores**, com o **açor** (uma ave de rapina) e as **9 estrelas**, uma por cada ilha. 🦅⭐
