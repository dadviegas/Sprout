# Ler as primeiras frases 📖

Já consegues juntar letras e fazer palavras. Agora vamos juntar palavras e ler frases! 🎉

## O que é uma frase?

Uma frase é um grupo de palavras que diz uma ideia completa. 🙂

Olha bem para estas duas regras mágicas de uma frase:

```keyvalue
[ { "k": "Começa com letra MAIÚSCULA", "v": "A primeira palavra usa uma letra grande, como um chapéu na cabeça 🎩" }, { "k": "Acaba com ponto final", "v": "O ponto é o sinal de que a frase terminou. É um STOP ⛔" } ]
```

Quando lês, juntas as palavras devagarinho, uma a uma, e depois dizes a frase toda de seguida.

## Um exemplo passo a passo 🔍

Vamos ler esta frase juntos: **O gato bebe leite.**

```steps
[ { "title": "Vê o chapéu", "body": "A primeira palavra é 'O' e começa com letra grande. Boa! É o início da frase 🎩" }, { "title": "Lê palavra a palavra", "body": "O... ga-to... be-be... lei-te. Devagarinho, sem pressa 🐢" }, { "title": "Junta tudo", "body": "Agora lê de seguida: 'O gato bebe leite'. Já soa a frase! 😺" }, { "title": "Vê o STOP", "body": "No fim está o ponto. A frase acabou aqui ⛔" } ]
```

## Truque 🪄

Lembra-te: **CHAPÉU no início, STOP no fim.** 🎩 ... ⛔

A primeira palavra tem sempre letra grande e a frase acaba sempre com um ponto. Se vires estes dois sinais, é uma frase!

## Vamos aplicar 🧩

Vamos descobrir o que diz a frase e que imagem combina com ela.

A frase é: **A bola é vermelha.**

```steps
[ { "title": "Lê devagar", "body": "A... bo-la... é... ver-me-lha." }, { "title": "Junta e percebe", "body": "'A bola é vermelha'. A frase fala de uma bola e diz a cor dela 🔴" }, { "title": "Escolhe a imagem", "body": "Qual combina? Uma bola vermelha ⚽🔴, claro! Não é uma maçã nem um carro." } ]
```

> [!TIP] **Para saberes mais** 🌱 Há frases que não acabam em ponto! Quando perguntas algo, usas o ponto de interrogação: «Onde está o gato?» Esse sinal é o **?**
