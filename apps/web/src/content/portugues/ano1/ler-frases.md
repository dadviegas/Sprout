# Ler as primeiras frases 📖

> [!NOTE] **O que vais aprender** 👀 Vais aprender o que é uma **frase**, como ela começa e como termina, e vais ler as tuas primeiras frases juntando palavras devagarinho. 🎉

Já consegues juntar letras e fazer palavras. Agora vem a parte mais divertida: juntar palavras e ler **frases**! Uma frase conta-te uma coisa, como um mini-recado. Vamos descobrir como se lê uma, passo a passo. 🐢💬

## O que é uma frase? 💬

Uma frase é um grupo de palavras que diz uma **ideia completa**. Quando lês a frase toda, ela faz sentido sozinha. 🙂

```keyvalue
[ { "k": "Palavra", "v": "uma só ideia: gato, bola, corre 🐱" }, { "k": "Frase", "v": "muitas palavras juntas que dizem algo completo: «O gato corre.» 💬" }, { "k": "Ideia completa", "v": "depois de ler, já percebes o que aconteceu 🙂" } ]
```

Repara: «gato» sozinho não te diz nada. Mas «**O gato corre.**» já é uma frase, porque conta uma ideia inteira!

## As duas regras mágicas 🎩

Toda a frase bem escrita tem um **chapéu** no início e um **STOP** no fim. São as duas regras mágicas que tens de procurar sempre.

```keyvalue
[ { "k": "Começa com letra MAIÚSCULA", "v": "a primeira palavra usa uma letra grande, como um chapéu na cabeça 🎩" }, { "k": "Acaba com ponto final", "v": "o ponto é o sinal de que a frase terminou. É um STOP ⛔" }, { "k": "Tem espaços", "v": "entre cada palavra há um espacinho, para não ficar tudo colado 👐" } ]
```

> [!NOTE] Se vires uma letra grande no início e um ponto no fim, é uma frase a sério! ✅

## Ler palavra a palavra 🐢

Para ler bem, não tens pressa. Lês cada palavra devagar e só depois dizes a frase toda de seguida. Vê como se faz com **O pato nada.**


## Os sinais do fim da frase ❓❗

## O que a frase nos conta 🔎

Quando lês uma frase, ela diz-te coisas: **quem** faz, **o que** faz e às vezes **como** é. Lê com atenção e vais perceber tudo o que a frase quer dizer.

```keyvalue
[ { "k": "Quem?", "v": "em «A Ana salta.», quem salta é a Ana 🙋" }, { "k": "O que faz?", "v": "em «A Ana salta.», o que ela faz é saltar 🤸" }, { "k": "Como é?", "v": "em «A bola é vermelha.», a frase diz a cor da bola 🔴" } ]
```

## Um exemplo passo a passo 🔍

Vamos ler juntos esta frase e descobrir tudo o que ela diz: **O cão come o osso.**

```steps
[ { "title": "1. Vê o chapéu", "body": "A primeira palavra é «O», com letra grande. É o início da frase 🎩", "icon": "🎩" }, { "title": "2. Lê devagar", "body": "O... cão... co-me... o... os-so. Sílaba a sílaba 🐢" }, { "title": "3. Junta tudo", "body": "«O cão come o osso.» Lê de seguida, sem parar 🐶" }, { "title": "4. Quem? O que faz?", "body": "Quem? O cão. O que faz? Come o osso 🦴" }, { "title": "5. Vê o STOP", "body": "No fim há um ponto. A frase terminou ⛔" } ]
```

> **Truque:** lembra-te de **CHAPÉU no início, STOP no fim.** 🎩 ... ⛔ Letra grande na primeira palavra e um ponto no fim — se vires os dois sinais, é mesmo uma frase!

> [!TIP] **Para saberes mais** 🌱 Quando juntas duas ou mais frases sobre a mesma coisa, fazes um **texto**! Por exemplo: «O gato dorme. Depois acorda. Tem fome.» São três frases que, juntas, contam uma pequena história. 📚
