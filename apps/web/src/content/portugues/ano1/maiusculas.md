# Letra grande e pequena 🔠

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que cada letra tem duas formas — uma **grande** e uma **pequena** — e aprender as regras simples para saberes quando usar cada uma. 🙂

Olá! 👋 Sabias que cada letra tem duas formas? Uma **grande** e uma **pequena**! São como dois irmãos da mesma família: têm o mesmo nome, mas um é maior do que o outro. Hoje vais ficar a saber exatamente quando usar cada uma — vais ver que é mesmo fácil! 😄

## As duas formas da mesma letra

Cada letra é como tu: tem uma **roupa de festa** (a grande) e uma **roupa do dia a dia** (a pequena). É a mesma letra, só muda o tamanho!

A letra grande chama-se **maiúscula**. A letra pequena chama-se **minúscula**.

A maioria das letras que escrevemos são **minúsculas**. As **maiúsculas** aparecem em alturas especiais — e já vais aprender quais! ✨

## Quando usamos a maiúscula 🚪

Há regras simples. Usamos a letra **grande** nestes momentos:

> [!NOTE] Os nomes de pessoas, cidades e países chamam-se **nomes próprios**. Começam SEMPRE por letra grande, estejam onde estiverem na frase! 👑

## O resto é tudo minúscula 🔡

## O ponto final manda voltar à maiúscula 🔵

Quando uma frase acaba, pomos um **ponto final** (.). A frase seguinte começa outra vez com letra **grande**. O ponto é o sinal de "para" — e a maiúscula é o sinal de "começa de novo"!

## Um exemplo passo a passo 🔍

Vamos escrever esta frase com as letras certas: *"a maria gosta de gelado"*.

```steps
[
  { "title": "Vê o início da frase", "body": "a frase começa com 'a'. Como é o início, fica GRANDE: 'A'.", "icon": "🚀" },
  { "title": "Procura nomes de pessoas", "body": "aqui há um nome: 'maria'. Nomes de pessoas começam por letra GRANDE: 'Maria'.", "icon": "👧" },
  { "title": "O resto é tudo pequena", "body": "as palavras 'gosta', 'de' e 'gelado' são normais, ficam pequenas.", "icon": "🔡" },
  { "title": "Lê a frase certa", "body": "A Maria gosta de gelado. ✅ Boa!", "icon": "🍦" }
]
```

> **Truque:** a letra grande é uma **porta** 🚪! Abre a **porta da frase** (a primeira letra) e a **porta do nome** (pessoas, cidades, países). Não há porta? Então é letra pequena! 😉

> [!TIP] **Para saberes mais** 🌱 Os **dias da semana** (segunda, terça...) e os **meses** (janeiro, março...) escrevem-se com letra **pequena** em português! É diferente do inglês, onde levam letra grande. Mas atenção: o **nome da tua escola** ou de uma festa, como o **Natal**, levam letra grande! 🎄
