# Palavras do dia a dia 🗂️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a arrumar as palavras do dia a dia em grupinhos por tema — os campos lexicais!

Sabias que as palavras gostam de andar em grupinhos? As que falam do mesmo tema ficam juntas, como brinquedos arrumados na caixa certa. Vem comigo descobrir esses grupinhos!

## O que é um campo lexical? 🧺

Um **campo lexical** é um grupinho de palavras que falam todas do **mesmo tema**. É como uma caixa onde guardas só as palavras que combinam.

```keyvalue
[
  { "k": "Tema 🏫", "v": "a escola: quadro, caderno, lápis" },
  { "k": "Tema 👨‍👩‍👧", "v": "a família: mãe, pai, avó" },
  { "k": "Tema 🧍", "v": "o corpo: cabeça, mão, pé" },
  { "k": "Tema 🌈", "v": "as cores: vermelho, azul, verde" }
]
```

## O campo da escola 🏫

Estas palavras vivem todas na **escola**. Quando ouves uma delas, já sabes onde estás!

```keyvalue
[
  { "k": "quadro 🖼️", "v": "onde a professora escreve" },
  { "k": "caderno 📓", "v": "onde escreves e desenhas" },
  { "k": "mochila 🎒", "v": "onde levas as tuas coisas" },
  { "k": "lápis ✏️", "v": "com que escreves e pintas" },
  { "k": "recreio 🤸", "v": "onde brincas com os amigos" }
]
```

## A família e o corpo 👨‍👩‍👧

Há um campo para as pessoas da tua **família** e outro para as partes do teu **corpo**. Repara como cada palavra fica na caixa certa!

```compare
[
  {
    "title": "Dois campos, duas caixas",
    "rows": [
      { "label": "Família 👨‍👩‍👧", "value": "mãe, pai, irmão, avó, tio", "highlight": true },
      { "label": "Corpo 🧍", "value": "cabeça, olhos, boca, mão, pé" }
    ]
  }
]
```

## As cores 🌈

As **cores** também são um campo lexical. Olha à tua volta: quantas consegues ver?

```stats

  { "label": "vermelho 🍎", "value": "🔴", "hint": "a cor de um morango" },
  { "label": "azul 💧", "value": "🔵", "hint": "a cor do céu limpo" },
  { "label": "amarelo ☀️", "value": "🟡", "hint": "a cor do sol" },
  { "label": "verde 🌳", "value": "🟢", "hint": "a cor das folhas" },
  { "label": "cor-de-rosa 🌸", "value": "🌷", "hint": "a cor de muitas flores" }

```

## Um exemplo passo a passo 🔍

Vamos arrumar a palavra **mochila** na caixa certa.

```steps
[
  { "title": "Diz a palavra", "body": "mochila! Pensa onde a usas.", "icon": "🎒" },
  { "title": "Pergunta o tema", "body": "De que tema fala? Levas a mochila para a escola!", "icon": "🤔" },
  { "title": "Arruma na caixa", "body": "É do campo da escola, ao lado de caderno e lápis.", "icon": "🧺" }
]
```

> **Truque:** para arrumar uma palavra, pergunta sempre **"de que tema fala?"** — e põe-na na caixa desse tema.

> [!TIP] **Para saberes mais** 🌱 Um campo lexical pode juntar palavras de tipos diferentes! No tema "praia" cabem nomes (areia), o que as coisas são (molhado) e o que fazemos (nadar). Tudo sobre o mesmo tema!
