# As primeiras palavras 🔡

> [!NOTE] **O que vais aprender** 👀 Vais juntar **sílabas** para formar as tuas **primeiras palavras**, contar as palmas de cada palavra e descobrir com que **letra** começam. 🎉

Já conheces as **vogais** (A, E, I, O, U) e algumas **sílabas**. Agora vem a parte mais divertida: quando juntas as sílabas, nasce uma **palavra** que diz mesmo alguma coisa! É como encaixar peças de um puzzle 🧩 até aparecer um **PATO** 🦆 ou uma **BOLA** ⚽. Vamos a isso, devagarinho? 🐢

## Juntar sílabas faz palavras 🧩

Cada **sílaba** é um pedacinho de som. Quando juntas dois pedacinhos, formas uma palavra:

```steps
[
  { "title": "PA + TO", "body": "= PATO 🦆 — dá duas palmas: PA-TO 👏👏", "icon": "🦆" },
  { "title": "BO + LA", "body": "= BOLA ⚽ — BO-LA, duas palmas 👏👏", "icon": "⚽" },
  { "title": "CA + SA", "body": "= CASA 🏠 — CA-SA, duas palmas 👏👏", "icon": "🏠" },
  { "title": "ME + SA", "body": "= MESA 🍽️ — ME-SA, duas palmas 👏👏", "icon": "🍽️" }
]
```

> [!TIP] Lê devagar, sílaba a sílaba: **PA-TO**. Depois lê mais depressa: **PATO**! 🐢➡️🐇

## Um exemplo passo a passo 🔍

Vamos formar a palavra **BOLA** ⚽ do princípio ao fim, com calma.

```steps
[
  { "title": "1. Olha as peças", "body": "temos duas sílabas: BO e LA 🧩", "icon": "🧩" },
  { "title": "2. Lê a primeira", "body": "BO — abre bem a boca: «bô» 👄", "icon": "👄" },
  { "title": "3. Lê a segunda", "body": "LA — agora «lá» 🗣️", "icon": "🗣️" },
  { "title": "4. Junta devagar", "body": "BO… LA… 🐢", "icon": "🐢" },
  { "title": "5. Lê depressa", "body": "BOLA! ⚽ Duas palmas: BO-LA 👏👏", "icon": "⚽" }
]
```

> **Truque:** lê sempre a palavra **duas vezes** — a primeira bem **devagar**, sílaba a sílaba; a segunda **depressa**, tudo de seguida. Da segunda vez ouves logo a palavra inteira! 🐢➡️🐇

> [!TIP] **Para saberes mais** 🌱 Algumas palavras têm só **uma sílaba**, como **SOL** ☀️ ou **PÃO** 🍞 — chamam-se **monossílabos**. Outras são compridas e têm **três** sílabas, como **BO-NE-CA** 🪆 ou **SA-PA-TO** 👟. Quantas mais palmas, mais comprida é a palavra! 👏👏👏
