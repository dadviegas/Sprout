# As primeiras palavras 🔡

Já sabes as **vogais** e as **sílabas**. Agora vamos **juntar sílabas** para formar **palavras**! 🎉

## Juntar sílabas faz palavras

Quando juntas duas sílabas, nasce uma palavra:

> **PA** + **TO** = **PATO** 🦆
>
> **BO** + **LA** = **BOLA** ⚽
>
> **CA** + **SA** = **CASA** 🏠

Toca para ouvir cada palavra: 👂


> [!TIP] Lê devagar, sílaba a sílaba: **PA-TO**. Depois lê mais depressa: **PATO**! 🐢➡️🐇
