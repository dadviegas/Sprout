# Rimas e lengalengas 🎵

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é uma **rima**, como duas palavras podem acabar com o **mesmo som**, e vais brincar com **lengalengas** que se dizem a cantar. É música feita de palavras! 🎶

Sabias que as palavras também podem fazer música? 🎤 Quando duas palavras acabam com o **mesmo som**, dizemos que elas **rimam**. As rimas estão nas canções, nas lengalengas e nos poemas que tu já cantas sem pensar. Hoje vais ser um caçador de rimas! Ouve bem o **fim** de cada palavra, porque é aí que a magia acontece. ✨

## O que é uma rima? 🎵

Uma **rima** é quando duas palavras acabam com o **mesmo som**. Repara: não precisam de começar igual nem de ser do mesmo tamanho — só o **bocadinho do fim** é que tem de soar igual.

> [!NOTE] Para saber se duas palavras rimam, fecha os olhos e diz só o **fim** delas: *-ato… -ato…* Se soa igual, rimam! 👂

## Rima ou não rima? 🤔

Cuidado com a partida! Há palavras que **parecem** rimar mas não rimam. O que conta é mesmo o **som do fim**, não as letras do princípio.

## Uma lengalenga 🎤

As **lengalengas** são versinhos divertidos, cheios de rimas, feitos para **dizer e repetir** a brincar. Diz esta a bater as palmas:

> *Um, dois, feijões com arroz,*
> *três, quatro, feijões no prato,*
> *cinco, seis, falar inglês,*
> *sete, oito, comer biscoito!* 🍪

> [!TIP] Bate as palmas no ritmo da lengalenga. Sentes a música das palavras? 👏🎵

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«O que rima com SINO?»* Vamos descobrir juntos, com calma.

```steps

  { "title": "1. Diz a palavra", "body": "diz SI-NO em voz alta, devagarinho 🔔", "icon": "🗣️" },
  { "title": "2. Ouve só o fim", "body": "o fim soa assim: …-INO 👂", "icon": "👂" },
  { "title": "3. Procura palavras com esse som", "body": "menino, pepino, ladino… todas acabam em -INO 👦🥒", "icon": "🔎" },
  { "title": "4. Confirma", "body": "SI-NO e ME-NI-NO acabam igual: rimam! ✅", "icon": "✅" },
  { "title": "5. Resposta", "body": "SINO rima com MENINO 🔔👦", "icon": "🎉" }
]
```

> **Truque:** tapa o **princípio** da palavra com o dedo e lê só o **fim**. Se duas palavras acabam igual, rimam! 🤫👂

> [!TIP] **Para saberes mais** 🌱 Quando juntas várias frases que rimam, fazes um **poema**! Os poetas escrevem poemas com rimas para as palavras soarem bonitas, como numa canção. Muitas canções que tu cantas são poemas postos em música. 🎶📖
