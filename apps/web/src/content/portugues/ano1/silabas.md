# As sílabas 👏

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que as palavras são feitas de **bocadinhos** chamados **sílabas**, aprender a **batê-las com palmas** e a contar quantas tem cada palavra. 🎵

Sabias que dentro de cada palavra há bocadinhos? Quando dizes uma palavra devagar, ela parte-se em pedaços, como uma laranja em gomos! 🍊 Cada bocadinho é uma **sílaba**. E o melhor é que tu já sabes encontrá-las: é só **bater palmas**! Vamos a isso? 👏

## As vogais mandam nas sílabas 🅰️

Em cada sílaba há sempre uma **vogal**. As vogais são as cinco letras mágicas: **a, e, i, o, u**. Se procurares as vogais, encontras os bocadinhos!


## Um exemplo passo a passo 🔍

Vamos descobrir juntos quantas sílabas tem a palavra **BONECA** 🪆. Faz comigo, devagarinho!

```steps

  { "title": "2. Parte em bocadinhos", "body": "diz devagar: BO… NE… CA 🐢", "icon": "🐢" },
  { "title": "3. Bate uma palma em cada bocadinho", "body": "BO (palma) NE (palma) CA (palma) 👏👏👏", "icon": "👏" },
  { "title": "4. Conta as palmas", "body": "foram 3 palmas ✋", "icon": "✋" },
  { "title": "5. A resposta", "body": "BO-NE-CA tem 3 sílabas! ✅", "icon": "✅" }
]
```

> **Truque:** se ficares com dúvidas, **encosta a mão por baixo do queixo** e diz a palavra. Cada vez que o queixo desce e toca na mão, é uma sílaba! 🤚 Funciona sempre.

> [!TIP] **Para saberes mais** 🌱 A sílaba mais forte da palavra, aquela que dizes com mais força, chama-se **sílaba tónica**. Em **BO-NE-CA** dizes mais forte o **NE** — é a tónica! As outras, mais fraquinhas, são as **átonas**. Vais aprender melhor estas palavras nos próximos anos. 💪
