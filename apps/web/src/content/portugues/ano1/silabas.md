# As sílabas 👏

Uma palavra é feita de bocadinhos chamados **sílabas**. Cada batida de palmas é uma sílaba! 👏

> **BO-LA** → 2 palmas → 2 sílabas
> **BA-NA-NA** → 3 palmas → 3 sílabas 🍌
