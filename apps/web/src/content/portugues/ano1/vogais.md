# As vogais 🅰️🅴🅸🅾🆄

As **vogais** são 5 letras muito importantes: **a, e, i, o, u**. 🎵

Cantam-se assim, bem alto: **AAA — EEE — III — OOO — UUU**! 🎤

Toca em cada vogal para a **ouvir**: 👂
