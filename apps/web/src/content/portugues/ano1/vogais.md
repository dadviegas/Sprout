# As vogais 🅰️🅴🅸🅾🆄

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as **5 vogais** — a, e, i, o, u — ouvi-las bem alto, descobri-las dentro das palavras e ver como elas ajudam a falar e a ler. 🎵

Olá! Hoje vamos cantar as **vogais**. Elas são só **cinco** letrinhas, mas são muito especiais: estão escondidas em quase todas as palavras que dizes! Sem elas, não conseguias falar. Respira fundo e canta comigo, bem alto: **AAA — EEE — III — OOO — UUU**! 🎤

## Quais são as vogais 🅰️

As vogais são apenas **cinco**: **a, e, i, o, u**. Toca em cada uma e diz o nome de um amigo ou animal que comece por ela! 🐝🐘🏝️🥚🍇

## Vogais e consoantes 🔤

O alfabeto tem **muitas letras**. As **5 vogais** sopram sozinhas, com a boca aberta. Todas as **outras** letras são **consoantes** — precisam de uma vogal por perto para se ouvirem bem. 🤝

## Cada vogal tem um som 🎤

Olha bem para a **boca** quando dizes cada vogal. Ela muda de forma! No **A** abre-se muito; no **U** fica em biquinho. Experimenta ao espelho! 🪞

## Vogais dentro das palavras 🔎

As vogais escondem-se no **princípio**, no **meio** e no **fim** das palavras. Vamos descobri-las! As vogais estão em **MAIÚSCULAS** para as veres melhor. 👀

```keyvalue
[
  { "k": "ASA", "v": "começa com A e tem A no fim 🦋" },
  { "k": "PÉ", "v": "tem a vogal E lá dentro 🦶" },
  { "k": "BOLA", "v": "tem O e A 🔴" },
  { "k": "LUA", "v": "tem U e A 🌙" },
  { "k": "GATO", "v": "A no meio e O no fim 🐱" }
]
```

> [!NOTE] Conta as vogais da palavra **BANANA** 🍌: tem **três** A! São elas que fazem a palavra cantar: ba-na-na. 🎶

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Qual é a vogal que falta na palavra G_TO, o animal que mia?»* 🐱 Vamos descobrir juntos, com calma.

```steps
[
  { "title": "1. Lê o que tens", "body": "vês as letras G _ T O, com um buraco no meio 🕳️", "icon": "👀" },
  { "title": "2. Diz em voz alta", "body": "o animal que mia é o GATO — ga... to 🐱", "icon": "🔊" },
  { "title": "3. Ouve o buraco", "body": "entre o G e o T ouves o som «A»: GA 🎵", "icon": "👂" },
  { "title": "4. Escolhe a vogal", "body": "o som «A» é a vogal A ✏️", "icon": "🅰️" },
  { "title": "5. Resposta", "body": "GATO! A vogal que faltava era o A ✅", "icon": "🎉" }
]
```

> **Truque:** sempre que não souberes que vogal pôr, **diz a palavra bem devagar e bem alto**. A vogal que cantas mais é a que tens de escrever! 🎤

> [!TIP] **Para saberes mais** 🌱 Em português há vogais **abertas** e **fechadas**: o **é** de «pé» é aberto e o **ê** de «mês» é fechado. Por isso usamos uns chapeuzinhos chamados **acentos** (á, é, ê, ó, ô) — eles ensinam a boca a abrir mais ou menos. Vais aprendê-los melhor mais para a frente! 🎩
