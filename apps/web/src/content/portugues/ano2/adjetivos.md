# Como é? Os adjetivos 🌈

> [!NOTE] **O que vais aprender** 👀 Vais descobrir as palavras mágicas que dizem **como são** as coisas — grande, bonito, azul, rápido!

Sabias que há palavras que servem só para descrever? 🎨 São as palavras que dizem **como é** cada coisa: se é grande ou pequena, se é azul ou amarela, se é rápida ou devagar. A essas palavras chamamos **adjetivos**. Vem comigo descobrir!

## O que é um adjetivo? 👀

Um **adjetivo** é a palavra que diz **como é** o nome — é a sua qualidade. Diz se uma coisa é grande, bonita, fria, simpática...

Olha: o **gato** é um nome. Mas como é o gato? É **preto**! A palavra **preto** é o adjetivo. 🐈‍⬛

```keyvalue
[
  { "k": "grande 🐘", "v": "diz o tamanho" },
  { "k": "azul 💙", "v": "diz a cor" },
  { "k": "rápido 🏎️", "v": "diz a velocidade" },
  { "k": "simpático 😊", "v": "diz como é por dentro" }
]
```

## O adjetivo anda com o nome 🤝

O adjetivo gosta de andar de mãos dadas com o nome! Junta-se ao nome para o descrever melhor.

Repara como o nome ganha vida quando lhe juntas um adjetivo:

```keyvalue
[
  { "k": "uma flor 🌸", "v": "uma flor bonita" },
  { "k": "um cão 🐶", "v": "um cão fiel" },
  { "k": "o céu ☁️", "v": "o céu azul" },
  { "k": "a sopa 🍲", "v": "a sopa quente" }
]
```

## Concordar: combinar com o nome 🧦

O adjetivo é educado: muda para **combinar** com o nome! Se o nome é menino (rapaz), o adjetivo fica no masculino; se é menina, fica no feminino. E se forem muitos, o adjetivo também fica no plural!

```compare

  {
    "title": "Um gato preto vira família",
    "rows": [

      { "label": "gatas pretas", "value": "🐈🐈 muitas", "highlight": true }
    ]
  }
]
```

## Caçar adjetivos 🔎

Para descobrir o adjetivo, faz uma perguntinha ao nome: **como é?** A resposta é quase sempre o adjetivo!

```steps
[
  { "title": "Encontra o nome", "body": "Na frase 'A casa amarela', o nome é 'casa'.", "icon": "🏠" },
  { "title": "Pergunta: como é?", "body": "Como é a casa? É amarela!", "icon": "❓" },
  { "title": "Encontraste!", "body": "'Amarela' é o adjetivo — diz a cor da casa.", "icon": "💛" }
]
```

## Um exemplo passo a passo 🔍

Vamos encontrar o adjetivo na frase **O balão vermelho voa alto**! 🎈

```steps
[
  { "title": "Procura o nome", "body": "O nome é 'balão' — é a coisa de que falamos.", "icon": "🎈" },
  { "title": "Pergunta ao nome", "body": "Como é o balão? É vermelho!", "icon": "❓" },
  { "title": "Marca o adjetivo", "body": "'Vermelho' diz como é o balão: é o adjetivo!", "icon": "❤️" },
  { "title": "Confere a concordância", "body": "Balão é masculino, por isso é 'vermelho', não 'vermelha'.", "icon": "✅" }
]
```

> **Truque:** para encontrares o adjetivo, pergunta ao nome **"como é?"**. A palavra que responde é o adjetivo! 🕵️

> [!TIP] **Para saberes mais** 🌱 Mais tarde vais aprender que os adjetivos têm **graus** — podes dizer que algo é *mais alto*, *tão alto como* ou *altíssimo*! Mas isso fica para os anos seguintes. Por agora basta saberes que o adjetivo descreve e combina com o nome. 📏
