# Artigos: o, a, um, uma 🪄

> [!NOTE] **O que vais aprender** 👀 Vais conhecer umas **palavrinhas mágicas** — o, a, um, uma — que vêm **antes do nome** e nos dizem se é menino ou menina, um ou muitos, e se já o conhecemos ou não. 🪄

Sabias que há palavrinhas que andam sempre à frente dos nomes, como ajudantes? 🤝 Quando dizes «**o** cão» 🐶 ou «**uma** flor» 🌸, essas pequeninas — **o, a, um, uma** — são os **artigos**. Elas chegam primeiro e preparam o nome que vem a seguir. Vem comigo descobrir como funcionam! 🔍

> [!NOTE] O artigo combina sempre com o nome: dizemos «**a** casa» 🏠 e nunca «**o** casa». Eles têm de andar a condizer! 🤝

## Artigos definidos: o, a, os, as ✅

Usamos **o, a, os, as** quando falamos de algo que **já conhecemos** ou que é **único**. É aquele certinho, aquele que já sabes qual é!

## Artigos indefinidos: um, uma, uns, umas ❓

Usamos **um, uma, uns, umas** quando falamos de algo **qualquer**, que ainda **não sabemos qual é**. É um qualquer, não aquele certo!

## Um exemplo passo a passo 🔍

Vamos escolher o artigo certo para a frase: «Vi ___ gato no jardim que era o nosso!» 🐱

```steps
[
  { "title": "1. Olha para o nome", "body": "o nome é GATO — é menino e está sozinho (1 só) 🐱", "icon": "🔎" },
  { "title": "2. Já conheço ou não?", "body": "a frase diz «que era o nosso» → eu JÁ SEI qual é! ✅", "icon": "🤔" },
  { "title": "3. Definido ou indefinido?", "body": "como já sei qual é, uso um artigo DEFINIDO ✅", "icon": "🎯" },
  { "title": "4. Escolhe o género e número", "body": "menino + 1 só → o artigo certo é «o» 👦", "icon": "👈" },
  { "title": "5. Lê a frase completa", "body": "Vi O gato no jardim que era o nosso! 🎉", "icon": "✅" }
]
```

> **Truque:** lembra-te assim — **o/a = já sei qual é** ✅ (aquele certinho!) e **um/uma = é um qualquer** ❓ (não sei qual). Se já conheces, usa o/a; se é um à toa, usa um/uma! 🪄

> [!TIP] **Para saberes mais** 🌱 Os artigos fazem parte de uma família maior chamada **determinantes** — são todos os ajudantes que vêm antes do nome. E há uma magia: às vezes os artigos **juntam-se** a outras palavrinhas e formam **contrações**! Olha: **de + o = do** (a casa **do** João 🏠), **em + a = na** (estou **na** escola 🏫) e **a + o = ao** (vou **ao** parque 🌳). Duas palavras que viram uma! 🤓
