# Contar e recontar uma história 🗣️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **recontar** uma história pelas tuas palavras, pela **ordem certa** — princípio, meio e fim —, a falar das **personagens** e do **sítio** onde tudo aconteceu. 🗣️

Sabes aquela história de que gostas tanto e que pedes para ouvir outra vez? Recontar é **seres tu** a contá-la! Não precisas de decorar palavra por palavra. Só precisas de te lembrar do que aconteceu e contar **pela ordem certa**, com a tua voz e a tua alegria. Vamos lá descobrir o segredo? 🌟

## Pela ordem certa 🔢

Uma boa história tem sempre **três partes**, como uma viagem: a partida, o caminho e a chegada. Conta sempre desta ordem!

```steps
[
  { "title": "1.º — o princípio", "body": "apresentas quem são as personagens e onde estão 🌅", "icon": "🌅" },
  { "title": "2.º — o meio", "body": "contas o que aconteceu: o problema, a aventura, a parte mais emocionante 🌪️", "icon": "🌪️" },
  { "title": "3.º — o fim", "body": "dizes como tudo terminou e como ficaram as personagens 🎉", "icon": "🎉" }
]
```

## Um exemplo passo a passo 🔍

Vamos recontar juntos a história **«A Lebre e a Tartaruga»** 🐢🐇. Repara como seguimos a ordem certa!

```steps
[
  { "title": "1. Quem e onde", "body": "Era uma vez uma lebre muito rápida e uma tartaruga muito lenta, num campo verde 🌳", "icon": "🐇" },
  { "title": "2. O problema", "body": "A lebre gozava com a tartaruga por ser lenta. Então combinaram uma corrida! 🏁", "icon": "⚡" },
  { "title": "3. O meio", "body": "A lebre correu muito e, como ia à frente, deitou-se a dormir uma sesta 😴", "icon": "🌪️" },
  { "title": "4. A surpresa", "body": "De repente, a tartaruga, devagarinho mas sem parar, passou à frente! 🐢", "icon": "👀" },
  { "title": "5. O fim", "body": "Por fim, a tartaruga ganhou. A lição? Quem é devagar mas não desiste, chega lá! 🎉", "icon": "🏆" }
]
```

> **Truque:** se baralhares a ordem, a história fica sem sentido. Conta sempre do **princípio para o fim** — e usa as mãos: um dedo para o princípio, dois para o meio, três para o fim! ✋➡️

> [!TIP] **Para saberes mais** 🌱 Quase todas as histórias do mundo têm a mesma forma: alguém quer uma coisa, aparece um **problema**, e no fim o problema resolve-se. A isto chama-se **estrutura narrativa**. Quando aprenderes a vê-la, vais reconhecê-la em todos os livros e até nos filmes! 🎬
