# Contar e recontar uma história 🗣️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **recontar** uma história pelas tuas palavras, pela **ordem certa** — princípio, meio e fim. 🗣️

Recontar é contar outra vez uma história que ouviste ou leste. Parece fácil, mas há um segredo: **a ordem certa**! 🔢

## Pela ordem certa 🔢

```steps
[
  { "title": "1.º — o princípio", "body": "quem são e onde estão as personagens 🌅" },
  { "title": "2.º — o meio", "body": "o que aconteceu (o problema, a aventura) 🌪️" },
  { "title": "3.º — o fim", "body": "como terminou tudo 🎉" }
]
```

## Palavras que ajudam ✨

```keyvalue
[
  { "k": "Primeiro…", "v": "para começar 🥇" },
  { "k": "Depois… / A seguir…", "v": "para o que vem a meio ➡️" },
  { "k": "No fim… / Por fim…", "v": "para terminar 🏁" }
]
```

> **Truque:** se baralhares a ordem, a história fica sem sentido. Conta sempre **do princípio para o fim**! ➡️

> [!TIP] **Para saberes mais** 🌱 Recontar com as **tuas** palavras (sem decorar) mostra que **percebeste** mesmo a história — é assim que os professores veem que compreendeste. 🧠
