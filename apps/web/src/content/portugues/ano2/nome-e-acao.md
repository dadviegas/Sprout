# Nome e ação 🏃

As palavras têm trabalhos diferentes. Hoje conhecemos os **nomes** e os **verbos**. 📛

## O nome dá nome às coisas 📛

Um **nome** (ou substantivo) é a palavra que dá nome a **pessoas**, **animais**, **coisas** e **lugares**.

```keyvalue
  { "k": "Animais", "v": "gato, pato, leão 🐱", "icon": "paw" },
  { "k": "Coisas", "v": "bola, mesa, livro ⚽" },
  { "k": "Lugares", "v": "escola, praia, casa 🏠", "icon": "home" }
]
```

## O verbo diz a ação 🏃

Um **verbo** diz o que alguém **faz**: correr, comer, saltar, dormir.

> A **menina** *(nome)* **corre** *(verbo)*. 🏃‍♀️
>
> O **cão** *(nome)* **ladra** *(verbo)*. 🐶

```steps
[
  { "title": "Pergunta: quem ou o quê?", "body": "a resposta é o NOME (a menina)" },
  { "title": "Pergunta: o que faz?", "body": "a resposta é o VERBO (corre)" }
]
```

> [!TIP] Truque: o **verbo** é a palavra da **ação**. Se podes *fazer*, é verbo! 🏃 saltar, ler, pintar...
