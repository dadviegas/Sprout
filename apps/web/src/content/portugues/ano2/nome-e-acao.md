# Nome e ação 🏃

> [!NOTE] **O que vais aprender** 👀 Vais descobrir as palavras que dão **nome** às coisas (os **nomes**) e as palavras que dizem o que se **faz** (os **verbos**). No fim, vais saber encontrá-las dentro de qualquer frase! 📛🏃

Sabias que cada palavra de uma frase tem um **trabalho**? Umas servem para dar **nome** ao mundo à tua volta — o gato, a escola, a Maria. Outras dizem **o que acontece** — correr, comer, saltar. Hoje vais ficar a conhecer estas duas grandes amigas: o **nome** e o **verbo**. Vais ver que é fácil e até divertido! 🎉

## O nome dá nome às coisas 📛

Um **nome** (também se chama **substantivo**) é a palavra que dá nome a **pessoas**, **animais**, **coisas** e **lugares**. Se podes apontar para isso ou dizer «isto é um…», é um nome!

## Nomes próprios e nomes comuns 🔤

Há dois tipos de nomes. O **nome comum** serve para todos iguais (um *menino* qualquer). O **nome próprio** é o nome só daquele e escreve-se sempre com **letra grande** (maiúscula): a **Maria**, o **Rex**, **Lisboa**.

> [!NOTE] Os nomes próprios começam sempre por **letra maiúscula**: **Ana**, **Porto**, **Tejo**. Os teus nomes e os dos teus amigos são nomes próprios! 🙂

## Singular e plural: um ou muitos? 🔢

Um nome pode falar de **um** (singular) ou de **muitos** (plural). Para muitos, quase sempre juntamos um **-s** no fim.

```keyvalue
[
  { "k": "um gato", "v": "muitos gato**s** 🐱🐱" },
  { "k": "uma flor", "v": "muitas flor**es** 🌸🌸" },
  { "k": "um pão", "v": "muitos pã**es** 🍞🍞" },
  { "k": "um animal", "v": "muitos anima**is** 🐾" }
]
```

## O verbo diz a ação 🏃

Um **verbo** diz o que alguém **faz** ou o que acontece: correr, comer, saltar, dormir, pensar. É a palavra que põe a frase a mexer! 

> A **menina** *(nome)* **corre** *(verbo)*. 🏃‍♀️
>
> O **cão** *(nome)* **ladra** *(verbo)*. 🐶
>
> A **chuva** *(nome)* **cai** *(verbo)*. 🌧️

## Um exemplo passo a passo 🔍

Vamos descobrir o **nome** e o **verbo** na frase: *«O peixe nada na água.»* 🐟

```steps
[
  { "title": "1. Lê a frase devagar", "body": "«O peixe nada na água.» Lê outra vez em voz alta 🗣️", "icon": "📖" },
  { "title": "2. Pergunta: quem ou o quê?", "body": "Quem faz a ação? O PEIXE — então 'peixe' é o NOME 🐟", "icon": "🐟" },
  { "title": "3. Pergunta: o que faz?", "body": "O peixe NADA — 'nada' é a ação, por isso é o VERBO 🏊", "icon": "🏊" },
  { "title": "4. Há mais nomes?", "body": "'água' também é um nome (uma coisa) 💧", "icon": "💧" },
  { "title": "5. Resposta", "body": "Nomes: peixe e água. Verbo: nada ✅", "icon": "✅" }
]
```

> **Truque:** o **verbo** é a palavra da **ação** — se podes *fazer* isso, é verbo! 🏃 (saltar, ler, pintar). O **nome** responde à pergunta *«quem ou o quê?»*. 📛

> [!TIP] **Para saberes mais** 🌱 Os nomes podem ser **masculinos** (o gato, o sol) ou **femininos** (a gata, a lua). Reparas que dizemos **o** ou **a** à frente? Essa palavrinha (o **artigo**) ajuda-te a saber o género do nome! 🌞🌙
