# Poemas e lengalengas 🎵

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é um **poema**, o que são **versos**, **estrofes** e **rimas**, e brincar com **lengalengas** e **trava-línguas** cheios de música! 🎵

A poesia é **brincar com as palavras e com os sons**. Quando lês um poema em voz alta, parece que as palavras dançam e cantam! 🎶 Muitos poemas têm **rima** — palavras que acabam com o mesmo som — e por isso são tão giros de dizer. Vem brincar comigo! 🥳

> Conta as linhas: são **4 versos**. E ouve — **gato** rima com **sapato**! 👞

## Como descobrir uma rima 🔊

Para saberes se duas palavras rimam, **fecha os olhos e ouve só o fim** de cada uma:

```compare

```

> [!TIP] Rimar **não** é começar pela mesma letra! *Bola* e *bota* começam igual, mas **não rimam** — o fim é diferente. O que conta é sempre o **som do fim**. 🔚

## Trava-línguas: difíceis de dizer 😝

Um **trava-línguas** é uma frase armadilha — tão difícil de dizer depressa que a língua quase fica presa! Tenta dizer estes **três vezes seguidas, bem rápido**:

```keyvalue
[
  { "k": "O rato roeu...", "v": "'O rato roeu a rolha da garrafa do rei da Rússia' 🐀" },
  { "k": "Três pratos...", "v": "'Três pratos de trigo para três tigres tristes' 🐯🐯🐯" },
  { "k": "O Pedro...", "v": "'O Pedro pregou um prego na porta preta' 🔨" }
]
```

> [!WARNING] Cuidado: ao dizer depressa, é fácil trocar os sons e dar uma gargalhada! 😆 É mesmo isso que torna o trava-línguas tão divertido.

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Qual destas palavras rima com FLOR: amor, casa ou bola?»* Vamos descobrir com calma!

```steps
[
  { "title": "1. Ouve o fim de FLOR", "body": "a palavra FLOR acaba no som -OR 🔊", "icon": "👂" },
  { "title": "2. Ouve o fim de AMOR", "body": "a-MOR também acaba em -OR... igual! ✅", "icon": "🎯" },
  { "title": "3. Ouve o fim de CASA", "body": "ca-SA acaba em -ASA → diferente ❌", "icon": "🚫" },
  { "title": "4. Ouve o fim de BOLA", "body": "bo-LA acaba em -OLA → diferente ❌", "icon": "🚫" },
  { "title": "5. Resposta", "body": "FLOR rima com AMOR, porque as duas acabam em -OR 🌸❤️", "icon": "🏆" }
]
```

> **Truque:** para descobrir se duas palavras rimam, diz-as devagar e **bate palmas só na última parte**: *bo-LA*, *mo-LA* — se as palmas soam igual, rimam! 👏

> [!TIP] **Para saberes mais** 🌱 Em muitos poemas, as rimas aparecem **alternadas**: o 1.º verso rima com o 3.º, e o 2.º rima com o 4.º. Os poetas escrevem essa ordem com letras — **A B A B**. Quando cresceres, vais aprender a desenhar o esquema das rimas de qualquer poema! ✍️
