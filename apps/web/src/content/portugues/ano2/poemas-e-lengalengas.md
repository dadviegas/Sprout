# Poemas e lengalengas 🎵

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é um **poema**, o que são **versos** e **rimas**, e brincar com **lengalengas** e **trava-línguas**! 🎵

A poesia é brincar com as palavras e com os sons. Muitos poemas têm **rima** — palavras que acabam com o mesmo som. 🎶

## Versos e rimas ✨

```keyvalue
[
  { "k": "Verso", "v": "cada linha de um poema 📏" },
  { "k": "Rima", "v": "palavras com o mesmo som no fim: gato / pato 🐱🦆" },

```

> Exemplo: *"O **gato**\nsubiu ao **sapato**"* — **gato** rima com **sapato**! 👞

## Lengalengas e trava-línguas 😝

```steps
[
  { "title": "Lengalenga", "body": "uma rima divertida para dizer e repetir 🎵" },
  { "title": "Trava-línguas", "body": "uma frase difícil de dizer depressa 😝" },
  { "title": "Exemplo", "body": "'O rato roeu a rolha da garrafa do rei da Rússia' 🐀" }
]
```

> **Truque:** para descobrir se duas palavras rimam, ouve só o **fim**: *bola* e *mola* acabam igual → rimam! 🔊

> [!TIP] **Para saberes mais** 🌱 As lengalengas e trava-línguas ajudam mesmo a falar melhor — treinam a tua boca e a tua língua a dizer os sons com clareza! 👅
