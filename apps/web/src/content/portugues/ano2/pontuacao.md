# Sinais de pontuação ❓❗

> [!NOTE] **O que vais aprender** 👀 Vais descobrir os **sinais de pontuação** — pequenos sinais que ajudam a ler bem, a fazer pausas e a saber se uma frase pergunta, conta ou grita! 🚦

Sabes aquelas pausas que fazes quando lês em voz alta? E quando levantas a voz para perguntar? Quem manda nisso são os **sinais de pontuação**! Eles são como os **sinais de trânsito** das frases: dizem-te quando **parar**, quando **fazer uma pausinha**, quando **perguntar** e quando **ficar espantado**. Sem eles, as frases ficavam todas atrapalhadas. Vamos conhecê-los! 🚦😄

## Os sinais que terminam a frase 🛑

Toda a frase tem de acabar com um sinal. Estes três são os "sinais de fim de frase": dizem-te como ler até ao fim.

```keyvalue
[
  { "k": "Ponto final .", "v": "a frase acabou — para e respira 🙂", "icon": "🛑" },
  { "k": "Ponto de interrogação ?", "v": "estás a perguntar alguma coisa", "icon": "❓" },
  { "k": "Ponto de exclamação !", "v": "surpresa, alegria, susto ou um grito", "icon": "❗" }
]
```

A seguir a um destes sinais começa uma frase nova — por isso a próxima palavra leva **letra maiúscula**! 🔤

## A mesma frase, três sentidos 🤔

O mais giro é que a **mesma frase** muda de significado só por causa do sinal. Lê estas em voz alta e ouve a tua voz mudar:

```compare
[
  { "title": "Está a chover…", "rows": [
    { "label": "Está a chover.", "value": "estou só a contar 🌧️" },
    { "label": "Está a chover?", "value": "estou a perguntar 🤔" },
    { "label": "Está a chover!", "value": "estou espantado! 😲", "highlight": true }
  ] }
]
```

Vês? O mesmo grupo de palavras, mas a voz sobe na pergunta e fica forte na exclamação. O sinal é que manda! 🎵

## A vírgula: a pausa pequenina ✋

A **vírgula** não acaba a frase — só faz uma **pausa curtinha** lá no meio, para a frase respirar. Usamos a vírgula em três sítios muito comuns:

```steps
[
  { "title": "Em listas", "body": "para separar coisas: 'Comprei pão, leite, ovos e fruta.' 🛒", "icon": "✋" },
  { "title": "Ao chamar alguém", "body": "'Ó Maria, anda cá!' — a vírgula separa o nome de quem chamamos 📣", "icon": "🗣️" },
  { "title": "Numa pausa para respirar", "body": "'Quando cheguei a casa, fui logo brincar.' 🏠", "icon": "🌬️" }
]
```

> [!WARNING] Cuidado: a vírgula **nunca** separa o nome do que ele faz. Não se escreve "O cão, ladra." — escreve-se "O cão ladra." 🐶

## Mais dois sinais para conheceres 💬

Quando já fores lendo livros, vais encontrar estes dois. São fáceis e muito úteis!

```keyvalue
[
  { "k": "Dois pontos :", "v": "anunciam algo a seguir — uma lista ou o que alguém disse 👉", "icon": "📋" },
  { "k": "Travessão —", "v": "mostra que uma personagem começou a falar num diálogo 💬", "icon": "🗨️" },
  { "k": "Reticências …", "v": "a frase fica em suspenso, como se faltasse algo 🤫", "icon": "⏳" }
]
```

Por exemplo: *A mãe disse:* *— Vem jantar!* Os **dois pontos** anunciam a fala e o **travessão** mostra que é a mãe a falar. 🍽️

## Um exemplo passo a passo 🔍

Imagina esta frase sem sinal nenhum: *"Já comeste o lanche"*. Que sinal devemos pôr no fim? Vamos pensar juntos! 🧐

```steps
[
  { "title": "1. Lê a frase devagar", "body": "'Já comeste o lanche' — repara nas palavras 👀", "icon": "🔤" },
  { "title": "2. Pergunta: o que estou a fazer?", "body": "estou a contar, a perguntar ou a gritar de espanto? 🤔", "icon": "❓" },
  { "title": "3. Ouve a tua voz", "body": "se a voz sobe no fim, é uma PERGUNTA 📈", "icon": "🎵" },
  { "title": "4. Escolhe o sinal", "body": "quero saber se já comeu — logo, é pergunta: leva ? ❓", "icon": "✏️" },
  { "title": "5. Resposta", "body": "'Já comeste o lanche?' — e a próxima palavra começa por maiúscula ✅", "icon": "🎉" }
]
```

> **Truque:** antes de pores o sinal, lê a frase em voz alta. Se a voz **sobe** → é **?** · se a voz fica **forte e excitada** → é **!** · se a voz fica **calma** → é **.** 🎤

> [!TIP] **Para saberes mais** 🌱 Há línguas, como o **espanhol**, que põem um sinal de pergunta **ao contrário** no início da frase: ¿Cómo estás? Assim o leitor já sabe, logo no princípio, que vem aí uma pergunta! Em português só pomos no fim. 🌍
