# Sinais de pontuação ❓❗

Os sinais de pontuação são como **sinais de trânsito** das frases: dizem-nos quando parar, perguntar ou ficar surpreendidos! 🚦

```keyvalue
[
  { "k": "Ponto final .", "v": "a frase acabou. Para!", "icon": "🛑" },
  { "k": "Ponto de interrogação ?", "v": "estamos a perguntar", "icon": "❓" },
  { "k": "Ponto de exclamação !", "v": "surpresa, alegria ou grito", "icon": "❗" },
  { "k": "Vírgula ,", "v": "uma pausa pequenina", "icon": "✋" }
]
```

## Vê a diferença

- *Está a chover.* → estou a contar uma coisa. 🌧️
- *Está a chover?* → estou a perguntar. 🤔
- *Está a chover!* → estou espantado! 😲

A mesma frase muda de sentido só por causa do sinal!

## Vamos praticar 🎈

```quiz
{
  "id": "pt2-pont-pratica",
  "questions": [
    { "q": "Que sinal usamos para PERGUNTAR?", "layout": "grid",
      "options": [ { "t": ".", "emoji": "🛑" }, { "t": "?", "emoji": "❓", "correct": true }, { "t": "!", "emoji": "❗" } ],
      "explain": "O ponto de interrogação (?) pergunta." },
    { "q": "'Que giro!' mostra...", "layout": "grid",
      "options": [ { "t": "uma pergunta" }, { "t": "surpresa/alegria", "correct": true }, { "t": "uma pausa" } ],
      "explain": "O ! mostra emoção forte." }
  ]
}
```

> [!NOTE] Toda a frase termina com um sinal: **.** ou **?** ou **!**
