# Singular e plural 👥

> [!NOTE] **O que vais aprender** 👀 Vais descobrir como saber se uma palavra fala de **uma coisa só** ou de **muitas**, e como transformar o **singular** em **plural** sem te enganares. ✨

Olha à tua volta: tens **um** lápis ou **muitos** lápis? **Uma** maçã ou **três** maçãs? As palavras também sabem dizer "um" ou "muitos" — só precisam de mudar um bocadinho no fim! Vem comigo que isto é mais fácil do que parece. 😄

## Um ou muitos? 🔢

Quando falamos de **uma só coisa**, a palavra está no **singular**. Quando falamos de **mais do que uma**, está no **plural**.

```keyvalue
]
```

## A regra mágica: juntar -s ✨

Quase todas as palavras fazem o plural de uma maneira muito simples: **juntam um -s no fim**! É como dar uma companhia à palavra. 🤝

```keyvalue

```

## Quando acaba em -r, -z ou -s 🔤

Algumas palavras precisam de mais ajuda. Se acabam em **-r** ou **-z**, juntamos **-es** (e não só **-s**).

## As palavras especiais em -ão 🍞

As palavras que acabam em **-ão** são as mais traquinas: cada uma muda de um jeito diferente! Há três caminhos:

```keyvalue
[
  { "k": "pão", "v": "pães 🍞 (muda para -ães)" },
  { "k": "cão", "v": "cães 🐶 (muda para -ães)" },
  { "k": "mão", "v": "mãos ✋ (muda para -ãos)" },
  { "k": "leão", "v": "leões 🦁 (muda para -ões)" },
  { "k": "balão", "v": "balões 🎈 (muda para -ões)" }
]
```

> [!WARNING] Cuidado! O plural de **pão** é **pães**, e não "pãos". E **mão** fica **mãos**. Estas palavras decoram-se com jeitinho. 😉

## Algumas não mudam nada 😮

Há palavras que já acabam em **-s** e ficam iguais no singular e no plural! Só percebemos pela palavra que vem antes (**o** ou **os**).

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Qual é o plural de FLOR?»* Vamos descobrir juntos, com calma. 🧐

```steps
[
  { "title": "1. Olha para o fim da palavra", "body": "FLOR acaba em -R 🌸", "icon": "🔎" },
  { "title": "2. Lembra-te da regra do -r", "body": "as palavras que acabam em -r juntam -ES, não só -s", "icon": "💡" },
  { "title": "3. Junta as letras", "body": "FLOR + ES = FLORES", "icon": "✏️" },
  { "title": "4. Diz em voz alta", "body": "«uma flor» → «muitas flores» — soa bem! 🗣️", "icon": "👂" },
  { "title": "5. Resposta", "body": "o plural de FLOR é FLORES ✅", "icon": "🎉" }
]
```

> **Truque:** primeiro **olha para a última letra** da palavra. Se for uma **vogal** (a, e, o…), junta só **-s**. Se for **-r** ou **-z**, junta **-es**. Se for **-ão**, é uma palavra especial — para com cuidado! 🚦

> [!TIP] **Para saberes mais** 🌱 Algumas palavras só existem no **plural**, porque são feitas de duas partes que andam sempre juntas: os **óculos** 👓, as **calças** 👖 e as **tesouras** ✂️. Nunca dizemos "um óculo" nem "uma calça" — são sempre muitos! 😄
