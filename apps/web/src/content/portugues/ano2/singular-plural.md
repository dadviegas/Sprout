# Singular e plural 👥

Uma coisa ou muitas? É isso que o **singular** e o **plural** nos dizem! 

## Um = singular · Muitos = plural

- **Singular** = **um** só: 🐱 *o gato*
- **Plural** = **mais do que um**: 🐱🐱🐱 *os gatos*

Quase sempre, o plural faz-se juntando um **-s** no fim:

```keyvalue
[
  { "k": "gato", "v": "gatos 🐱🐱" },
  { "k": "bola", "v": "bolas ⚽⚽" },
  { "k": "casa", "v": "casas 🏠🏠" },
  { "k": "livro", "v": "livros 📚" }
]
```

## Quando acaba em -ão, muda mais

Algumas palavras especiais mudam o fim:

> **pão** → **pães** 🍞 · **cão** → **cães** 🐶 · **mão** → **mãos** ✋

> [!TIP] Se podes dizer "**um**", é singular. Se podes dizer "**muitos**" ou "**dois**", é plural! 👆✌️
