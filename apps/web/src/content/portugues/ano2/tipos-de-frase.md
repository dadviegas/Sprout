# Frases que perguntam e que exclamam ❓

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que as frases têm "humores" diferentes: umas **contam**, outras **perguntam**, outras **gritam de emoção** e outras **dão ordens**. E vais aprender a reconhecê-las só de olhar para a pontuação no fim! 🔤

Sabias que as frases também têm sentimentos? 😀 Umas falam baixinho a contar uma coisa, outras levantam a voz a perguntar, outras saltam de alegria e outras pedem qualquer coisa. O segredo para descobrir cada uma está mesmo no **fim da frase**: na pontuação! Vem comigo descobrir os **quatro tipos de frase**. 🚀

## Os quatro tipos de frase ✨

Cada tipo de frase tem um trabalho diferente. Olha bem para o sinal de pontuação no fim — ele diz-te logo qual é!

```keyvalue
  { "k": "Exclamativa  !", "v": "Mostra emoção: alegria, susto ou espanto. Termina em ponto de exclamação. Ex.: Que gato giro! 🎉" },
  { "k": "Imperativa  . ou !", "v": "Dá uma ordem, um conselho ou um pedido. Ex.: Fecha a porta. / Vem cá! 🙏" }
]
```

Repara: o ponto final (.) é sereninho, o ponto de interrogação (?) tem um ganchinho de curiosidade, e o ponto de exclamação (!) é direitinho como quem grita de emoção!

## A frase que pergunta ❓

A frase **interrogativa** serve para fazer perguntas. Termina sempre em **?** e muitas vezes começa por uma palavra-pergunta.

```keyvalue
[
  { "k": "Quem?", "v": "Pergunta por uma pessoa. Ex.: Quem comeu o bolo? 🍰" },
  { "k": "O quê / Que?", "v": "Pergunta por uma coisa. Ex.: O que estás a fazer? 🧩" },
  { "k": "Onde?", "v": "Pergunta por um lugar. Ex.: Onde está a minha bola? ⚽" },
  { "k": "Quando?", "v": "Pergunta por um tempo. Ex.: Quando vamos à praia? 🏖️" },
  { "k": "Porquê?", "v": "Pergunta por um motivo. Ex.: Porque estás triste? 🤔" }
]
```

> [!NOTE] Quando lês uma pergunta em voz alta, a tua voz **sobe** no fim, como se estivesses à espera de uma resposta. Experimenta com «Tu queres gelado?» 🍦

## A frase que grita de emoção ❗

A frase **exclamativa** mostra o que sentimos: alegria, surpresa, susto, medo ou admiração. Termina sempre em **!** e muitas vezes começa por **Que…** ou **Como…**.

## A frase que dá ordens 🙏

A frase **imperativa** serve para dar uma **ordem**, um **conselho** ou um **pedido**. Pode terminar em ponto final (.) ou em ponto de exclamação (!) quando é mais forte.


## Um exemplo passo a passo 🔍

Vamos descobrir o tipo desta frase, com calma: **«Tu queres gelado?»**

```steps
[
  { "title": "Lê a frase em voz alta", "body": "«Tu queres gelado?» — repara como a tua voz sobe no fim, como quem espera resposta.", "icon": "🔊" },
  { "title": "Procura a pontuação", "body": "No fim está um ? — o ponto de interrogação.", "icon": "❓" },
  { "title": "Pensa no que a frase faz", "body": "Está a fazer uma pergunta a alguém.", "icon": "🤔" },
  { "title": "Decide o tipo", "body": "Tem ? e está a perguntar. É uma frase interrogativa! ✅", "icon": "✅" },
  { "title": "Compara com outra", "body": "«Adoro gelado!» — aqui a voz salta de alegria e tem !. Essa é exclamativa! 🍦", "icon": "🍦" }
]
```

> **Truque:** pensa na pontuação como uma **carinha**: o **.** é a boca quietinha (estou a contar), o **?** é a sobrancelha levantada (estou a perguntar) e o **!** é a boca aberta a gritar (estou cheio de emoção!). E lembra-te: lê sempre em voz alta — a voz **desce** no `.`, **sobe** no `?` e **dispara** no `!`. 🎭

> [!TIP] **Para saberes mais** 🌱 Existe ainda um quinto humor: a frase **negativa**! É quando dizemos que algo **não** acontece, usando palavras como *não*, *nunca* ou *nada*. Por exemplo: «Eu **não** gosto de couves.» Repara que ela continua a ser declarativa — só ganhou um "não". A frase contrária, sem o "não", chama-se **afirmativa**: «Eu gosto de couves.» 🥦
