# Frases que perguntam e que exclamam ❓

Sabias que as frases também têm "humores"? 😀 Umas contam coisas, outras perguntam e outras gritam de emoção!

## As três frases mágicas

Olha bem para o final de cada frase. A pontuação diz-te logo que tipo de frase é!

```keyvalue
[
  { "k": "Frase que conta (declarativa) .", "v": "Diz uma coisa, calminha. Ex.: O gato dorme. 😺" },
  { "k": "Frase que pergunta (interrogativa) ?", "v": "Faz uma pergunta. Ex.: Onde está o gato? 🤔" },
  { "k": "Frase que exclama (exclamativa) !", "v": "Mostra emoção: alegria, susto, espanto. Ex.: Que gato giro! 🎉" }
]
```

Repara: o ponto final (.) é sereno, o ponto de interrogação (?) tem um ganchinho de curiosidade, e o ponto de exclamação (!) é direitinho como quem grita!

Vamos descobrir o tipo de cada frase, uma de cada vez.

```steps
  { "title": "Decide o tipo", "body": "Tem ? e está a perguntar. É uma frase interrogativa! ✅" },
  { "title": "Compara com outra", "body": "«Adoro gelado!» — aqui a voz salta de alegria e tem !. É exclamativa! 🍦" }
]
```

## Truque 🪄

Pensa na pontuação como uma carinha:
- **.** = boca quietinha → estou a contar.
- **?** = sobrancelha levantada → estou a perguntar.
- **!** = boca aberta a gritar → estou cheio de emoção!

Lê sempre em voz alta: a tua voz desce no `.`, sobe no `?` e dispara no `!`.
