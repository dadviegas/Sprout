# Aumentativo e diminutivo 🔍

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que o mesmo **nome** pode crescer ou encolher só por trocar o fim! Aprendes o **aumentativo** (para coisas **grandes**), o **diminutivo** (para coisas **pequenas** ou com **carinho**) e a não cair numa armadilha: nem tudo o que acaba em **-ão** é aumentativo. ✨

Imagina que tens uma lupa mágica 🔍. Apontas para um **gato** 🐈 e — *puf!* — vira um **gatão** enorme. Apontas outra vez e vira um **gatinho** fofinho. Em Português, a tua «lupa» são uns pedacinhos que se colam no fim das palavras. São os **graus do nome**! 🪄

## Os três tamanhos de um nome 📏

O mesmo nome pode aparecer em **três graus**: o **normal** (tamanho de todos os dias), o **aumentativo** (quando é **grande**) e o **diminutivo** (quando é **pequeno** ou dito com **carinho**).

## O diminutivo: tudo fica pequenino (ou fofinho) ⬇️

Para fazer o **diminutivo**, juntamos **-inho** ou **-zinho**. Serve para dizer que algo é **pequeno**... mas também serve para falar com **carinho**! Quando chamas **avozinha** 👵 à tua avó, não é por ela ser pequena — é por gostares muito dela. ❤️

```keyvalue
[
  { "k": "casa → casinha 🏠", "v": "uma casa pequenina" },
  { "k": "gato → gatinho 🐱", "v": "um gato bebé, fofinho" },
  { "k": "flor → florzinha 🌼", "v": "uma florzinha delicada" },
  { "k": "avó → avozinha 👵", "v": "aqui é carinho, não tamanho! ❤️" }
]
```

> **Truque da lupa 🔍:** pergunta sempre *«é grande ou pequeno?»* Se for **grande**, a palavra acaba em **-ão** (aumentativo). Se for **pequeno** ou **com carinho**, acaba em **-inho/-zinho** (diminutivo). Grande → **-ão**; pequeno → **-inho**. 🪄

## Cuidado com a armadilha do -ão! ⚠️

Aqui está o segredo dos espertos: **nem tudo o que acaba em -ão é aumentativo!** Há palavras que já **nascem** com -ão. **Pão** 🍞 não é uma «pã grande», e **mão** ✋ não é uma «mã grande» — são palavras normais que por acaso terminam em -ão.

> [!WARNING] **A pergunta mágica:** *«Existe a palavra mais pequena lá dentro?»* Em **gatão** existe **gato** ✅ — é aumentativo. Em **pão** não existe nenhuma **«pã»** 🚫 — então é só um nome normal!

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«**Portão** é o aumentativo de quê?»* Vamos descobrir com calma. 🧠

```steps
  { "title": "4. Resposta", "body": "sim! portão é o aumentativo de PORTA 🎉", "icon": "🎯" }

```

E ao contrário? Para fazer o **diminutivo de cão**, juntamos **-zinho**: **cãozinho** 🐶. Para **bola**, juntamos **-inha**: **bolinha** ⚽. Experimenta tu no treino a seguir!

> [!TIP] **Para saberes mais** 🌱 Estes pedacinhos que se colam no fim das palavras chamam-se **sufixos**. O **-ão** é um sufixo aumentativo e o **-inho** é um sufixo diminutivo. E há mais: o **-zito** (cãozito) e o **-ola** também fazem diminutivos! O Português tem uma caixa cheia de peças para deixar as palavras maiores ou mais pequeninas. 🧱
