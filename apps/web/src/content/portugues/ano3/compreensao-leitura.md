# Compreender o que leio 🔍

Ler é fácil. Mas perceber o que lemos é a magia! 🪄 Vou ensinar-te a descobrir tudo o que um texto esconde.

## Ler com olhos de detetive 🕵️

Quando lês um texto, és um detetive à procura de pistas! As pistas mais importantes respondem a estas perguntas:

```keyvalue
[
  { "k": "Quem?", "v": "as personagens do texto 🧒" },
  { "k": "Onde?", "v": "o lugar onde acontece 🏠" },
  { "k": "Quando?", "v": "o tempo: dia, noite, manhã ⏰" },
  { "k": "Porquê?", "v": "a razão das coisas acontecerem 💡" }
]
```

Vamos ler este texto curto:

> [!NOTE] **O bolo da avó** 🍰
> Na manhã de sábado, a Inês foi a casa da avó. A avó estava triste porque tinha partido os óculos. Para a animar, a Inês fez um bolo de chocolate. A avó sorriu de orelha a orelha!

## Um exemplo passo a passo 🔍

Vamos descobrir as pistas do texto do bolo, uma de cada vez.

```steps
[
  { "title": "Quem?", "body": "Procuro as personagens. Aparecem a Inês e a avó. Boa, já tens duas!" },
  { "title": "Onde?", "body": "O texto diz: 'foi a casa da avó'. O lugar é a casa da avó." },
  { "title": "Quando?", "body": "Está logo no início: 'Na manhã de sábado'. O tempo é sábado de manhã." },
  { "title": "Porquê (a avó triste)?", "body": "O texto explica: 'porque tinha partido os óculos'. Essa é a razão!" },
  { "title": "Uma inferência", "body": "O texto não diz 'a avó ficou feliz', mas diz que 'sorriu de orelha a orelha'. Logo, eu percebo que ficou contente. Isso é descobrir o que está escondido!" }
]
```

## Truque 🪄

Decora as quatro perguntas mágicas: **Quem, Onde, Quando, Porquê**.

Pista esperta: a palavra **"porque"** no texto aponta quase sempre para a resposta de **Porquê?** 🔎

## Vamos aplicar 🧩

Lê esta frase e encontra as pistas:

> O João correu para casa à noite porque começou a chover.

```steps
[
  { "title": "Quem?", "body": "O João." },
  { "title": "Onde?", "body": "Para casa." },
  { "title": "Quando?", "body": "À noite." },
  { "title": "Porquê?", "body": "Porque começou a chover. Achaste a palavra 'porque'? Era essa a pista!" }
]
```

> [!TIP] **Para saberes mais** 🌱 Quando descobres algo que o texto NÃO diz com palavras, mas que tu percebes pelas pistas, isso chama-se fazer uma **inferência**. És tão esperto como um detetive a sério!
