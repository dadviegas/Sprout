# Compreender o que leio 🔍

> [!NOTE] **O que vais aprender** 👀 Vais aprender a ser um detetive de textos: descobrir as personagens, o lugar e o tempo, perceber o que está escondido nas entrelinhas e até adivinhar o que vai acontecer a seguir. 🕵️

Ler todas as palavras é só metade da magia. A outra metade é **perceber** o que elas querem dizer! 🪄 Às vezes a resposta está mesmo ali, escrita com letras. Outras vezes está escondida e tens de a descobrir com pistas, como um verdadeiro detetive. Vem comigo que eu mostro-te todos os truques. 🔎

## As perguntas mágicas do detetive 🕵️

Quando lês um texto, és um detetive à procura de pistas. As pistas mais importantes respondem sempre a estas perguntas:

```keyvalue
[
  { "k": "Quem?", "v": "as personagens do texto — quem aparece e quem faz as coisas 🧒" },
  { "k": "O quê?", "v": "o que acontece, a ação da história 📖" },
  { "k": "Onde?", "v": "o lugar onde tudo se passa 🏠" },
  { "k": "Quando?", "v": "o tempo: de manhã, à noite, num dia, há muito tempo ⏰" },
  { "k": "Porquê?", "v": "a razão de as coisas acontecerem 💡" }
]
```

Lê este texto curto com atenção — vamos usá-lo várias vezes:

> [!NOTE] **O bolo da avó** 🍰
> Na manhã de sábado, a Inês foi a casa da avó. A avó estava triste porque tinha partido os óculos. Para a animar, a Inês fez um bolo de chocolate. A avó sorriu de orelha a orelha!

## Palavras-pista que abrem portas 🔑

Algumas palavras são pistas escondidas que te dizem o que procurar. Decora estas:

```keyvalue
[
  { "k": "porque / por isso", "v": "anunciam uma RAZÃO → respondem a Porquê? 💡" },
  { "k": "então / a seguir / depois", "v": "marcam a ORDEM dos acontecimentos ⏩" },
  { "k": "mas / porém / no entanto", "v": "avisam que vem uma mudança ou surpresa 🔄" },
  { "k": "de manhã / à noite / no dia seguinte", "v": "dizem-te o TEMPO ⏰" },
  { "k": "em casa / na escola / lá fora", "v": "dizem-te o LUGAR 🏠" }
]
```

## Prever: adivinhar o que vem a seguir 🔮

Um bom leitor não espera quieto — vai **prevendo** o que vai acontecer. Pelas pistas, fazes uma adivinha esperta:

```stats
[
  { "label": "Pista no texto", "value": "Nuvens negras", "hint": "o que se segue? Talvez chuva 🌧️" },
  { "label": "Pista no texto", "value": "O João bocejou", "hint": "talvez vá dormir 😴" },
  { "label": "Pista no texto", "value": "A barriga roncou", "hint": "talvez tenha fome 🍽️" }
]
```

> [!TIP] Prever **não é** adivinhar à sorte: é usar as pistas do texto. Se depois leres e acertaste, ótimo! Se não, mudas a tua ideia — também é assim que os leitores espertos fazem. 🧠

## Um exemplo passo a passo 🔍

Vamos resolver, com calma, esta pergunta sobre o texto do bolo: *«Como é que sabes que a avó ficou feliz, se o texto nunca diz a palavra "feliz"?»*

```steps
[
  { "title": "1. Lê a pergunta toda", "body": "pedem-me como SEI que a avó ficou feliz, mesmo sem a palavra 'feliz' 🧐" },
  { "title": "2. Procuro pistas sobre a avó no fim", "body": "no fim, o texto diz: 'A avó sorriu de orelha a orelha' 😊" },
  { "title": "3. Penso no que isso quer dizer", "body": "quem sorri muito, de orelha a orelha, está contente — eu já sei isso da minha vida 🧠" },
  { "title": "4. Junto as pistas", "body": "a Inês fez um bolo PARA A ANIMAR + a avó sorriu = o plano resultou ✅" },
  { "title": "5. Resposta", "body": "sei que a avó ficou feliz porque sorriu de orelha a orelha. Fiz uma inferência! 🔍" }
]
```

> **Truque:** decora as perguntas mágicas com a frase **«Quem, o Quê, Onde, Quando e Porquê»**. E lembra-te: a palavra **«porque»** no texto aponta quase sempre para a resposta de **Porquê?** 🔎

> [!TIP] **Para saberes mais** 🌱 Quando descobres algo que o texto NÃO escreve, mas que percebes pelas pistas, isso chama-se fazer uma **inferência**. As pessoas crescidas fazem inferências o dia todo: se virem uma chávena vazia e quente, sabem que alguém acabou de beber café, mesmo sem ninguém o dizer! ☕
