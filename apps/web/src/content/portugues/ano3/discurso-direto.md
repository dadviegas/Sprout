# O discurso direto 💬

> [!NOTE] **O que vais aprender** 👀 Vais descobrir como se escrevem as **falas das personagens** numa história! Aprendes o **travessão** (—), os **verbos de dizer** (disse, perguntou, gritou, respondeu) e também os **dois-pontos** com **aspas** «». No fim, sabes a diferença entre **discurso direto** e **discurso indireto**. 🗣️

Sabes quando lês um livro e parece mesmo que ouves as personagens a falar? Isso é o **discurso direto**: é quando escrevemos as **palavras exatas** que uma personagem diz, como se ela falasse à tua frente. 💬

## O travessão entra em ação ✏️

Quando uma personagem fala, começamos a linha com um **travessão** (—). Repara que é um risco **comprido**, não é o traço pequenino das palavras como «guarda-chuva». 😉

> [!NOTE] Há **duas maneiras** de escrever uma fala: com **travessão** (—) ou com **dois-pontos + aspas** («»). As duas estão certas! Nos livros de histórias vês muito o travessão. 📚

## Os verbos de dizer 🗣️

Junto da fala há quase sempre um **verbo de dizer**, que conta **quem** falou e **como** falou. Olha como muda a emoção!

## Um diálogo a sério 🎭

Quando duas personagens falam à vez, é um **diálogo**. Cada vez que **muda quem fala**, começamos uma **linha nova** com travessão. 🔄

```steps
[
  { "title": "Fala a primeira personagem", "body": "— Olá, queres brincar? — perguntou a Maria.", "icon": "💬" },
  { "title": "Linha nova, fala a segunda", "body": "— Sim! Vamos ao parque — respondeu o Tó.", "icon": "💬" },
  { "title": "Outra vez à primeira", "body": "— Boa! Eu levo a bola — gritou a Maria, contente.", "icon": "🎉" }
]
```

> [!NOTE] **Regra de ouro do diálogo:** sempre que **muda quem fala**, salta para uma **linha nova** e põe um **travessão**. Assim ninguém se baralha sobre quem está a dizer o quê! 🔄

## Direto ou indireto? 🔀

O **discurso direto** usa as palavras **exatas** da personagem (com travessão ou aspas). O **discurso indireto** **conta** o que ela disse, sem travessão e sem aspas — costuma usar a palavrinha **que**.

```compare

  ] },
  { "title": "Discurso indireto 📝", "rows": [
    { "label": "Como é", "value": "alguém CONTA o que a personagem disse", "highlight": true },
    { "label": "Sinais", "value": "sem travessão, sem aspas — usa «que»" },
    { "label": "Exemplo", "value": "O Pedro disse que estava cansado." }
  ] }
]
```

> **Truque do detetive 🕵️:** queres saber se é discurso **direto**? Procura o **travessão (—)** ou as **aspas («»)**. Se as palavras estão lá tal e qual a personagem as disse, é **direto**. Se alguém só **conta** com a palavra **«que»**, é **indireto**.

> [!TIP] **Para saberes mais** 🌱 Sabias que os escritores têm imensos verbos de dizer para dar **cor** às falas? Em vez de repetirem sempre «disse», usam **sussurrou** (falar muito baixinho 🤫), **exclamou** (com surpresa ou alegria 😮), **resmungou** (falar a queixar-se 😠) ou **murmurou**. Quanto melhor escolhes o verbo, mais a personagem ganha vida na tua história! ✨
