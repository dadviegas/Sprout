# Escrever um texto ✍️

Escrever uma história é fácil quando segues uma **ordem**: princípio, meio e fim! 📖

## As 3 partes de um texto

```steps
[
  { "title": "Princípio", "body": "apresenta quem e onde (Era uma vez...) 🏰" },
  { "title": "Meio", "body": "o que acontece — a aventura! ⚡" },
  { "title": "Fim", "body": "como acaba a história (E foram felizes...) 🎉" }
]
```

## Dicas para escrever bem ✍️

```keyvalue
[
  { "k": "Maiúscula", "v": "começa as frases com letra grande", "icon": "letters" },
  { "k": "Ponto final", "v": "acaba cada frase com . ❓!" },
  { "k": "Parágrafos", "v": "muda de linha para ideias novas" },
  { "k": "Lê em voz alta", "v": "para ver se faz sentido 🔊", "icon": "speaker" }
]
```

> [!TIP] Antes de escrever, **pensa**: quem é a personagem? Onde está? O que vai acontecer? Depois é só contar! 💭

## Palavras que ajudam a ligar

> **Primeiro... depois... a seguir... por fim.** Estas palavras põem a história em ordem! 🔗

## Vamos praticar 🎈

```quiz
{
  "id": "pt3-texto-pratica",
  "questions": [
    { "q": "Como começa muitas vezes uma história?", "layout": "grid",
      "options": [ { "t": "Era uma vez...", "emoji": "🏰", "correct": true }, { "t": "Fim", "emoji": "🎬" } ],
      "explain": "Muitas histórias começam por 'Era uma vez'." },
    { "q": "Como se começa uma frase?", "layout": "grid",
      "options": [ { "t": "com letra maiúscula", "correct": true }, { "t": "com um número" } ],
      "explain": "As frases começam com maiúscula." }
  ]
}
```
