# Escrever um texto ✍️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **planear**, **escrever** e **rever** um texto com princípio, meio e fim, usar **parágrafos**, **pontuação** e palavras que **ligam** as ideias. No fim, escreves uma história que faz sentido e que se lê bem! 📖

Escrever é como contar uma história a um amigo — só que no papel! 🗒️ Quando segues uma **ordem** e dás tempo a cada parte, o teu texto fica claro e divertido de ler. Não tens de acertar tudo à primeira: os bons escritores **planeiam**, depois **escrevem** e, no fim, **leem outra vez** para melhorar. Vamos a isto! 🚀

## As 3 partes de um texto 📚

Todo o texto tem três partes, como um sanduíche: o pão de cima, o recheio e o pão de baixo. 🥪

```steps
[
  { "title": "Princípio (introdução)", "body": "apresenta QUEM é a personagem, ONDE está e QUANDO acontece. É aqui que dizes 'Era uma vez...' 🏰", "icon": "castle" },
  { "title": "Meio (desenvolvimento)", "body": "é a parte maior! Conta o PROBLEMA e a aventura — o que acontece, passo a passo ⚡", "icon": "bolt" },
  { "title": "Fim (conclusão)", "body": "mostra COMO tudo se resolve e como acaba a história. 'E foram felizes...' 🎉", "icon": "flag" }
]
```

> [!NOTE] O **meio** é quase sempre a parte mais comprida, porque é onde tudo acontece! O princípio e o fim podem ser curtinhos. 😉

## Antes de escrever: o plano 🗺️

Os escritores não começam logo a escrever — primeiro **pensam** e fazem um plano. Responde a estas perguntas na tua cabeça (ou num rascunho):

```keyvalue
[
  { "k": "Quem? 🧒", "v": "quem são as personagens da tua história" },
  { "k": "Onde? 🌳", "v": "o lugar onde tudo acontece (uma floresta, a escola, o mar...)" },
  { "k": "Quando? 🕐", "v": "de dia, de noite, no Verão, há muito tempo..." },
  { "k": "O que acontece? ⚡", "v": "o problema e a aventura que vais contar" },
  { "k": "Como acaba? 🎉", "v": "o final da história" }
]
```

> [!TIP] Pensar primeiro poupa tempo depois! Um bom plano é meio texto escrito. 💭

## Frases, maiúsculas e pontuação ✒️

Uma frase é uma ideia completa. Para o leitor perceber, há regras de ouro:

```keyvalue
[
  { "k": "Maiúscula no início", "v": "toda a frase começa com letra grande 🔠", "icon": "letters" },
  { "k": "Ponto final ·", "v": "acaba uma frase normal: 'O gato dorme.'" },
  { "k": "Ponto de interrogação ?", "v": "quando perguntas: 'Onde está o gato?'" },
  { "k": "Ponto de exclamação !", "v": "quando há surpresa ou emoção: 'Que susto!'" },
  { "k": "Vírgula ,", "v": "faz uma pausa pequena ou separa uma lista: 'maçãs, peras e uvas'" }
]
```

> [!WARNING] Sem pontuação, tudo se mistura e ninguém percebe! A pontuação é como os sinais de trânsito do texto: diz onde parar e onde abrandar. 🚦

## Parágrafos: arrumar as ideias 📐

Um **parágrafo** é um grupo de frases sobre a MESMA ideia. Quando mudas de ideia, mudas de **linha** e deixas um pequeno espaço no início. Assim o texto fica arrumado e fácil de ler.

```compare
[
  { "title": "Sem parágrafos 😵", "rows": [
    { "label": "Aspeto", "value": "tudo colado, uma muralha de palavras" },
    { "label": "Ler", "value": "cansa os olhos e perde-se o fio" }
  ] },
  { "title": "Com parágrafos 😊", "rows": [
    { "label": "Aspeto", "value": "ideias separadas, cada uma no seu bloco", "highlight": true },
    { "label": "Ler", "value": "fácil de seguir e mais bonito 👀" }
  ] }
]
```

## Palavras que ligam as ideias 🔗

Estas palavrinhas mágicas (chamam-se **conectores**) põem a história em ordem e ligam as frases umas às outras:

```keyvalue
[
  { "k": "Para começar", "v": "Primeiro... · No início... · Era uma vez... 🏁" },
  { "k": "Para continuar", "v": "Depois... · A seguir... · Então... · De repente... ➡️" },
  { "k": "Para acrescentar", "v": "Também... · Além disso... ➕" },
  { "k": "Para acabar", "v": "Por fim... · No final... · E foram felizes... 🎬" }
]
```

## Rever: o segredo dos bons textos 🔍

Escrever é só metade do trabalho. Depois de acabares, **lê em voz alta** e verifica:

```steps
[
  { "title": "Lê em voz alta", "body": "se tropeças numa frase, é sinal de que pode melhorar 🔊", "icon": "speaker" },
  { "title": "Vê a pontuação", "body": "todas as frases têm maiúscula e ponto no fim? ✒️", "icon": "check" },
  { "title": "Vê a ordem", "body": "tem princípio, meio e fim? Faz sentido a história? 📖", "icon": "list" },
  { "title": "Corrige", "body": "muda o que não soa bem e acrescenta o que falta ✏️", "icon": "edit" }
]
```

## Um exemplo passo a passo 🔍

Vamos escrever, juntos, uma mini-história a partir desta ideia: *«Um cão perde-se no parque.»* 🐶

```steps
[
  { "title": "1. Faço o plano", "body": "Quem: o cão Bobi e a menina Rita. Onde: o parque. Problema: o Bobi foge atrás de um gato 🐱", "icon": "list" },
  { "title": "2. Escrevo o princípio", "body": "'Era uma tarde de sol. A Rita levou o seu cão Bobi ao parque.' (maiúscula no início, ponto no fim) 🏰", "icon": "castle" },
  { "title": "3. Escrevo o meio", "body": "'De repente, o Bobi viu um gato e fugiu! A Rita procurou por todo o lado e chamou: — Bobi! Bobi!' ⚡", "icon": "bolt" },
  { "title": "4. Escrevo o fim", "body": "'Por fim, ouviu um latido. O Bobi estava atrás de uma árvore. A Rita abraçou-o, muito feliz!' 🎉", "icon": "flag" },
  { "title": "5. Reviso", "body": "Leio em voz alta, confirmo as maiúsculas e os pontos, e vejo se tem princípio, meio e fim. Está pronto! ✅", "icon": "check" }
]
```

> **Truque:** decora a pergunta mágica **«Quem? Onde? Quando? O quê? Como acaba?»**. Se respondes a estas 5 perguntas, a tua história nunca fica com buracos! 🔑

> [!TIP] **Para saberes mais** 🌱 Quando uma personagem **fala**, usamos um **travessão** (—) no início da fala: *— Bobi, anda cá!* Este sinal chama-se **discurso direto** e serve para mostrar as palavras exatas de quem fala. Vais aprendê-lo melhor mais tarde, mas já podes começar a usá-lo nas tuas histórias! 💬
