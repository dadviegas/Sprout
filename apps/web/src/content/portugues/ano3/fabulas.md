# As fábulas e a moral 🦊

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é uma **fábula** — uma história pequenina, quase sempre com **animais que falam** — e a sua **moral**, o ensinamento sábio que fica no fim. 🦊

Imagina uma história tão curta que cabe num minuto, mas que te ensina algo para a vida toda. É isso que faz uma **fábula**! Tem animais espertos como a raposa, lentos como a tartaruga, trabalhadores como a formiga… e no fim, sempre, uma lição. Vem conhecer estas histórias antigas que ainda hoje nos fazem pensar. 🐢🐜🦊

## O que é a moral? 💡

A **moral** é a frase sábia que aparece no **fim** da fábula. É o ensinamento que o autor quer que tu leves contigo. 💡

```steps
[
  { "title": "A história", "body": "curta, com animais que falam e agem como pessoas 🦊", "icon": "📖" },
  { "title": "Acontece algo", "body": "uma escolha, uma corrida, um problema ou uma esperteza 🌪️", "icon": "⚡" },
  { "title": "A moral", "body": "no fim, o ensinamento: 'mais vale...', 'devagar se vai ao longe...' 💡", "icon": "💡" }
]
```

## Fábula ou conto de fadas? 🤔

## Um exemplo passo a passo 🔍

Vamos ler a fábula **A Lebre e a Tartaruga** e descobrir juntos a moral.

```steps
[
  { "title": "1. Quem são as personagens?", "body": "uma lebre rápida e uma tartaruga lenta — dois animais que falam 🐰🐢", "icon": "🐾" },
  { "title": "2. O que acontece?", "body": "fazem uma corrida; todos pensam que a lebre ganha de certeza 🏁", "icon": "🏁" },
  { "title": "3. A surpresa", "body": "a lebre, tão confiada, para a dormir; a tartaruga continua sem desistir 😴", "icon": "😴" },
  { "title": "4. Como termina?", "body": "a tartaruga chega primeiro à meta e ganha a corrida 🏆", "icon": "🏆" },
  { "title": "5. A moral", "body": "'Devagar se vai ao longe' — com esforço e paciência também se vence ✅", "icon": "💡" }
]
```

> **Truque:** a **moral** está quase sempre **no fim** da fábula e ensina-te como ser melhor. Pergunta-te: *"O que aprendi com esta história?"* — essa resposta é a moral. 🐢

> [!TIP] **Para saberes mais** 🌱 Muitas fábulas que conhecemos foram contadas por um senhor chamado **Esopo**, na Grécia, há mais de **2500 anos** — e ele era um escravo muito sábio! Séculos depois, em França, o **La Fontaine** voltou a escrevê-las em verso. Por isso é que a mesma fábula viajou por todo o mundo. 🇬🇷🇫🇷
