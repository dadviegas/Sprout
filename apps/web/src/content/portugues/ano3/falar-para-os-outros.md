# Falar para os outros 🎤

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **apresentar** uma ideia à turma — falar alto e devagar, olhar para o público e não ter medo! 🎤

Às vezes temos de falar para um grupo: mostrar um trabalho, contar novidades, dar uma opinião. Com alguns truques, corre lindamente! 🌟

## Preparar antes 📝

```steps
[
  { "title": "Pensa no que vais dizer", "body": "as 2 ou 3 ideias mais importantes 💡" },
  { "title": "Treina", "body": "diz em voz alta uma vez, sozinho ou ao espelho 🪞" },
  { "title": "Respira", "body": "antes de começar, respira fundo — acalma! 🌬️" }
]
```

> **Truque:** estar um bocadinho nervoso é **normal** — até os atores ficam! Respira fundo e começa devagar. 🌬️

> [!TIP] **Para saberes mais** 🌱 O corpo também "fala": ficar direito, sorrir e olhar para as pessoas faz com que te ouçam melhor. Chama-se **linguagem do corpo**. 🧍
