# Família de palavras 🌳

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que as palavras vivem em **famílias**, todas com a mesma **raiz**, e como isso te ajuda a perceber e a escrever palavras novas. ✨

Tal como tu tens família, as **palavras** também têm! 🌳 Há palavras que são umas «primas» das outras porque nasceram todas da mesma palavra-base. Quando descobres a família, percebes logo o significado de palavras que nunca tinhas visto — é como ter um superpoder de leitura! 🦸

## A mesma raiz 🌱

Uma **família de palavras** é um grupo de palavras que partilham o mesmo **pedaço inicial**: a **raiz**. A raiz guarda o significado principal, e à volta dela aparecem palavras parecidas.

> Da palavra **flor** 🌸 nascem:
>
> **flor** · **florista** · **floreira** · **florir** · **floresta**

Vês o pedaço **flor** em todas? É a **raiz** da família! 🌳

## Muitas famílias para conheceres 📚

Repara como cada palavra-base gera uma família inteira. A raiz mantém-se quase igual em todas:

```keyvalue
  { "k": "mar 🌊", "v": "marinheiro, maré, marítimo, submarino" },
  { "k": "pão 🍞", "v": "padeiro, padaria, panificadora" },
  { "k": "sapato 👟", "v": "sapateiro, sapataria, sapatilha" },
  { "k": "livro 📚", "v": "livreiro, livraria, livrinho" }

```

> [!NOTE] Às vezes a raiz muda um bocadinho: de **pão** vem **padeiro** e **padaria** (o «ã» transforma-se em «a»). É a mesma família, só com um disfarce! 🎭

## Família ou só parecida? 🕵️

Cuidado! Há palavras que **parecem** da mesma família mas não são. Para pertencerem à mesma família têm de ter a **mesma raiz** E ter **significados ligados**.

> [!WARNING] Não te deixes enganar pelo som! **Pato** e **padaria** começam parecidos, mas **pato** é um animal 🦆 e **padaria** vem de **pão** 🍞. O que conta é a raiz e o significado.

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«A palavra **terreno** é da família de **terra**?»* Vamos descobrir com calma.

```steps
[
  { "title": "1. Encontra a raiz de 'terra'", "body": "a raiz é 'terr-' 🌍", "icon": "🌱" },
  { "title": "2. Procura essa raiz na outra palavra", "body": "terreno → ter-r-e-n-o... tem 'terr-'! ✅", "icon": "🔎" },
  { "title": "3. Vê se o significado está ligado", "body": "terreno é um pedaço de terra — sim, está ligado! 🤝", "icon": "💡" },
  { "title": "4. Decide", "body": "tem a mesma raiz E o mesmo significado de base ✔️", "icon": "🧠" },
  { "title": "5. Resposta", "body": "sim, 'terreno' é da família de 'terra'! 🎉", "icon": "✅" }
]
```

> **Truque:** tapa o início igual das duas palavras com o dedo. Se sobrar a **mesma raiz** e os significados se **derem as mãos**, são da mesma família! 🤝

> [!TIP] **Para saberes mais** 🌱 A parte que se acrescenta à raiz tem nome: chama-se **sufixo** quando vem no fim (flor**ista**, livr**aria**) e **prefixo** quando vem no início (**sub**marino, **des**enterrar). São como peças de Lego que encaixam na raiz para formar palavras novas! 🧱
