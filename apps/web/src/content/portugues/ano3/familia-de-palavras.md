# Família de palavras 🌳

Tal como tu tens família, as **palavras** também têm! Vêm todas da mesma palavra. 🌳

## A mesma raiz

Uma **família de palavras** vem de uma palavra-base e partilha um **pedaço** (a raiz).

> Da palavra **flor** 🌸 nascem:
>
> **flor** · **florista** · **floreira** · **florir** · **floresta**

Vês o pedaço **flor** em todas? É a raiz da família! 🌳

```keyvalue
[
  { "k": "terra 🌍", "v": "terreno, aterrar, enterrar" },
  { "k": "sapato 👟", "v": "sapateiro, sapataria" },
  { "k": "pão 🍞", "v": "padeiro, padaria" }
]
```

> [!TIP] Repara: **padeiro** e **padaria** vêm de **pão**, mas mudam um bocadinho. A família ajuda-te a escrever certo! ✍️

## Para que serve?

Saber a família ajuda a **perceber** palavras novas: se **livraria** vem de **livro**, é o sítio dos livros! 📚
