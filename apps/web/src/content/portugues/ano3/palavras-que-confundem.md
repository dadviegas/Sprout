# Palavras que confundem 🤔

> [!NOTE] **O que vais aprender** 👀 Vais descobrir palavras manhosas que soam quase igual mas se escrevem de formas diferentes — e o truque para nunca mais te enganares!

Sabias que algumas palavras são umas brincalhonas? 😜 Soam iguaizinhas quando as dizes, mas escrevem-se de maneiras diferentes e querem dizer coisas completamente diferentes! Vem comigo desmascarar estas palavras que confundem!

## Homófonos: soam igual, escrevem-se diferente 👂

Os **homófonos** são palavras que **soam igual** mas se **escrevem de forma diferente** — e cada uma quer dizer outra coisa! "Homo" quer dizer igual e "fono" quer dizer som: som igual!

```keyvalue
[
  { "k": "coser 🧵", "v": "juntar com agulha e linha" },
  { "k": "cozer 🍲", "v": "cozinhar na panela" },
  { "k": "à 🚶", "v": "preposição: vou **à** escola" },
  { "k": "há 🐶", "v": "do verbo haver: **há** um cão no jardim" }
]
```

## Mais homófonos manhosos 🕵️

## Homónimos: soam E escrevem-se igual 🪞

Os **homónimos** são ainda mais espertos! Soam igual **e** escrevem-se igual, mas têm significados diferentes. É a mesma palavrinha a fazer dois trabalhos!

```keyvalue
[
  { "k": "banco 🪑", "v": "para te sentares no jardim" },
  { "k": "banco 🏦", "v": "onde se guarda o dinheiro" },
  { "k": "canto 🎤", "v": "quando eu canto uma canção" },
  { "k": "canto 📐", "v": "o canto da sala, o cantinho" }
]
```

## A regra de ouro: usa o contexto 🗝️

Como é que sabes qual escolher? Olha para a **frase toda**! As outras palavras dão-te pistas. A isso chamamos o **contexto** — é o teu detetive secreto! 🕵️

```stats
[
  { "label": "Pista da frase", "value": "Contexto", "hint": "as palavras à volta ajudam a escolher" },
  { "label": "Pensa primeiro", "value": "Significado", "hint": "qual quer dizer o que faz sentido?" },
  { "label": "Só depois", "value": "Escreve", "hint": "agora já sabes qual é a certa!" }
]
```

## Um exemplo passo a passo 🔍

Vamos escolher entre **"à"** e **"há"** na frase: "______ muitos peixes no mar." 🐟

```steps
[
  { "title": "Lê a frase toda", "body": "______ muitos peixes no mar. Há ou à?", "icon": "👀" },
  { "title": "Pensa no significado", "body": "Quero dizer que **existem** muitos peixes. Existir é do verbo **haver**!", "icon": "🤔" },
  { "title": "Escolhe a certa", "body": "**Há** muitos peixes no mar. 🎉 Usei o **há** do verbo haver!", "icon": "✏️" }
]
```

> **Truque:** antes de escreveres, pensa primeiro no **significado** que faz sentido na frase. A palavra certa é a que conta a história verdadeira! 🧠✨

> [!TIP] **Para saberes mais** 🌱 Existem ainda os **parónimos** — palavras **parecidas** mas não iguais, que também se confundem! Por exemplo: **comprimento** (o tamanho de algo) e **cumprimento** (uma saudação, dizer olá), ou **descrição** (descrever) e **discrição** (ser discreto). 🤫
