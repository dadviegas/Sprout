# Pronomes: trocar o nome 🔄

> [!NOTE] **O que vais aprender** 👀 Vais descobrir as palavrinhas mágicas que **substituem os nomes** para não os repetirmos sempre! São os **pronomes pessoais**: **eu, tu, ele, ela, nós, vós, eles, elas**. 🪄

Imagina que dizes: «A Maria foi ao parque e a Maria brincou e a Maria voltou contente.» Que cansaço de tanto repetir «a Maria»! 😅 Para isso existem os **pronomes**: pequenas palavras que **ocupam o lugar do nome** e deixam as frases mais leves. Em vez de repetir «a Maria», dizemos **ela**: «A Maria foi ao parque e **ela** brincou e **ela** voltou contente.» 🪄

## As três pessoas do discurso 🌟

Os pronomes pessoais arrumam-se em **três pessoas**. Repara em quem fala e de quem se fala!

```compare

  ] },
  { "title": "Plural (mais do que uma)", "rows": [
    { "label": "1.ª (quem fala)", "value": "nós 🙋🙋", "highlight": true },
    { "label": "2.ª (com quem falo)", "value": "vós 👉👉" },
    { "label": "3.ª (de quem falo)", "value": "eles, elas 👨‍👩‍👧" }

```

> [!NOTE] **Eu** e **nós** são quem fala. **Tu** e **vós** são quem ouve. **Ele, ela, eles, elas** são de quem falamos. 🗣️👂

## Combinam com o nome 🤝

O pronome tem de ter o mesmo **género** (masculino/feminino) e o mesmo **número** (singular/plural) do nome que substitui.

## Um exemplo passo a passo 🔍

Vamos trocar o nome repetido por um pronome na frase: **«O cão ladrou. O cão correu.»** 🐶

```steps

  { "title": "2. Vê quem é", "body": "o cão é UM e é masculino (de quem falo) 🐶", "icon": "🧩" },
  { "title": "3. Escolhe o pronome certo", "body": "1 + masculino + de quem falo = ele", "icon": "🎯" },
  { "title": "4. Substitui na 2.ª frase", "body": "«O cão ladrou. Ele correu.» ✨", "icon": "🪄" },
  { "title": "5. Lê outra vez", "body": "agora a frase não repete e soa muito melhor! 🎉", "icon": "✅" }
]
```

> **Truque:** antes de escolher o pronome, faz duas perguntas — **é um ou muitos?** e **é menino ou menina?** As respostas dizem-te logo se usas ele, ela, eles ou elas. 🤝

> [!TIP] **Para saberes mais** 🌱 Há pronomes que aparecem **depois** do verbo, ligados por um traço: «A avó **abraçou-me**», «O pai **viu-te**». Esses (-me, -te, -o, -a, -nos) também são pronomes pessoais, mas chamam-se **pronomes de complemento**, porque mostram quem **recebe** a ação. Vais aprendê-los melhor mais à frente! 🤓
