# Sinónimos e antónimos 🔁↔️

Algumas palavras são **amigas** (querem dizer o mesmo) e outras são **contrárias** (querem dizer o oposto)!

## Sinónimos — palavras amigas 🤝

São palavras **diferentes** com **o mesmo significado**.

- *bonito* = *lindo* 😍
- *casa* = *lar* 🏠
- *contente* = *feliz* 😀
- *rápido* = *veloz* 🏎️

## Antónimos — palavras contrárias ↔️

> [!TIP] **Para saberes mais** 🌱 Há palavras que se escrevem igual mas querem dizer coisas diferentes — chamam-se **homónimas**. Por exemplo, **"banco"** pode ser onde te sentas 🪑 **ou** onde se guarda o dinheiro 🏦! O contexto ajuda-te a perceber qual é.
