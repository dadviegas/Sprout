# Sinónimos e antónimos 🔁↔️

> [!NOTE] **O que vais aprender** 👀 Vais conhecer as palavras **amigas** (que querem dizer o mesmo) e as palavras **contrárias** (que querem dizer o oposto), e ainda aprender a trocá-las nas tuas frases. ✨

Sabias que muitas vezes podes dizer a **mesma coisa** com palavras **diferentes**? E que quase todas as palavras têm uma palavra que é o seu **contrário**? Vem comigo descobrir este jogo de palavras — vais ver que é divertido e que te ajuda a escrever cada vez melhor! 🎉

## Sinónimos — palavras amigas 🤝

Os **sinónimos** são palavras **diferentes** que têm **o mesmo significado** (ou um significado muito parecido). São como **amigas** que dizem a mesma coisa de maneiras diferentes!

> [!NOTE] Trocar uma palavra por um sinónimo ajuda-te a **não repetir** sempre a mesma palavra quando escreves. Em vez de «o cão é grande, a casa é grande», podes dizer «o cão é grande, a casa é **enorme**»! ✍️

## Antónimos — palavras contrárias ↔️

Os **antónimos** são palavras com o **significado oposto**, o **contrário** uma da outra. São como duas palavras que estão em pontas diferentes!

## Antónimos com o prefixo *in-* / *des-* 🔧

Há um truque giro: muitas vezes basta juntar um **bocadinho** ao início da palavra (um **prefixo**) para a tornar **contrária**!

```keyvalue

  { "k": "feliz → infeliz", "v": "o prefixo in- diz «não» 🙃" },
  { "k": "certo → incerto", "v": "in- = não certo ❓" },

]
```

## Sinónimo ou antónimo? Não confundas! 🧐

É fácil baralhar os dois. Olha bem para a diferença — é só lembrares-te de **«igual»** ou **«contrário»**:

```compare

```

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Qual é o antónimo de "abrir"?»* Vamos resolver juntos, com calma.

```steps
[
  { "title": "1. Lê a palavra", "body": "a palavra é «abrir» — pensa no que ela quer dizer (abrir a porta) 🚪", "icon": "📖" },
  { "title": "2. Sinónimo ou antónimo?", "body": "pedem o ANTÓNIMO, ou seja, o CONTRÁRIO de abrir ↔️", "icon": "🧐" },
  { "title": "3. Pensa no oposto", "body": "se abres uma porta… o contrário é FECHAR essa porta 🔒", "icon": "💡" },
  { "title": "4. Confirma", "body": "abrir e fechar fazem coisas opostas — encaixa! ✅", "icon": "✔️" },
  { "title": "5. Resposta", "body": "o antónimo de «abrir» é «fechar» 🎉", "icon": "🏆" }
]
```

> **Truque:** pergunta sempre a ti mesmo: **«igual ou contrário?»** Se a outra palavra quer dizer o **mesmo**, é **sinónimo** (amiga 🤝). Se quer dizer o **oposto**, é **antónimo** (contrária ↔️). 📌

> [!TIP] **Para saberes mais** 🌱 Há palavras que se escrevem igual mas querem dizer coisas diferentes — chamam-se **homónimas**. Por exemplo, **«banco»** pode ser onde te sentas 🪑 **ou** onde se guarda o dinheiro 🏦! E há ainda as **homófonas**, que se dizem igual mas escrevem-se diferente, como **«concerto»** (música 🎵) e **«conserto»** (arranjar 🔧). O contexto da frase ajuda-te a perceber qual é!
