# Os sons do «s»: s, ss, ç, c, z 🐍

> [!NOTE] **O que vais aprender** 👀 Vais descobrir um segredo curioso: o som **«sss»** 🐍 pode escrever-se de **cinco** maneiras diferentes — **s, ss, ç, c** e **z** — e há regras espertas para acertar sempre! ✏️

Já reparaste que «**s**apo», «pa**ss**o», «a**ç**úcar», «**c**idade» e «rapa**z**» têm todos o som «sss» 🐍, mas escrevem-se de formas diferentes? É um dos maiores enigmas do português! Mas não te assustes: com algumas regras simples vais resolvê-lo como um detetive. 🕵️

## ss ou s? O segredo das vogais 🔍

O som forte de «sss» **entre duas vogais** escreve-se com **ss**. No início da palavra (ou depois de consoante) basta um **s**.

> [!IMPORTANT] O **ss** nunca aparece no **início** de uma palavra nem depois de uma consoante. Só vive **entre vogais**! 🧱

## ç ou c? Olha a vogal a seguir 👀

O **ç** (cê-cedilha, o c com o «rabinho») e o **c** fazem o mesmo som, mas escolhem-se pela vogal que vem **a seguir**.

> [!NOTE] Regra de ouro: o **ç nunca** anda antes de **e** ou **i**. Aí usamos sempre **c**: *céu*, *cinto*. 🚫

## Um exemplo passo a passo 🔍

Vamos decidir, com calma, como se escreve a palavra que se lê **«a-çú-car»** 🍬.

```steps
[
  { "title": "1. Ouve o som", "body": "tem o som «sss» no meio: a-_ú-car 🐍", "icon": "👂" },
  { "title": "2. Vê a vogal a seguir", "body": "depois do som «sss» vem um «u» (açúcar) 🔤", "icon": "👀" },
  { "title": "3. Aplica a regra", "body": "antes de a, o, u usamos ç → «çu» ✏️", "icon": "🧠" },
  { "title": "4. Confere o início", "body": "não é início de palavra, por isso não é «ss» nem «s» 🟢", "icon": "🔎" },
  { "title": "5. Resposta", "body": "escreve-se AÇÚCAR (com ç)! 🎉", "icon": "✅" }
]
```

> **Truque:** quando ouvires «sss» e não souberes a letra, faz duas perguntas: **«Está entre vogais?»** → talvez ss. **«Que vogal vem a seguir?»** → a/o/u pede **ç**, e/i pede **c**. 🕵️

> [!TIP] **Para saberes mais** 🌱 Cuidado com uma armadilha! O **s** entre vogais nem sempre faz «sss» — muitas vezes faz o som **«zzz»** 🐝, como em «ca**s**a» (lê-se «caza»), «ro**s**a» e «me**s**a». Por isso é que «casa» se escreve com **um** s e «passo» com **dois**: o som é diferente! Os mais crescidos chamam a isto o **«s» sonoro**. 🤓
