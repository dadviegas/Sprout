# Ontem, hoje e amanhã (tempos) ⏳

Sabias que as palavras de ação têm um "relógio"? 🕒 Elas dizem-te SE a ação já aconteceu, está a acontecer ou vai acontecer!

## O verbo viaja no tempo ✈️

O **verbo** é a palavra que mostra uma ação: *comer*, *correr*, *brincar*.

E o verbo pode estar em três tempos:

```keyvalue
[
  { "k": "Passado (ontem)", "v": "a ação JÁ aconteceu. Ex.: ontem comi 🍎" },
  { "k": "Presente (hoje)", "v": "a ação acontece AGORA. Ex.: hoje como 🍽️" },
  { "k": "Futuro (amanhã)", "v": "a ação AINDA vai acontecer. Ex.: amanhã vou comer 🔮" }
]
```

Pensa numa linha do tempo: **ontem** está atrás de ti, **hoje** és tu agora, e **amanhã** está à tua frente! ➡️

Vês? O mesmo verbo muda conforme o tempo: jogou → joga → vai jogar.

## Truque 🪄

Junta uma palavrinha do tempo à frente e ouve como soa:

- **Ontem** + verbo → passado (já foi)
- **Hoje** + verbo → presente (é agora)
- **Amanhã** + verbo → futuro (vai ser)

Se "ontem" combina, é passado. Se "amanhã" combina, é futuro. Fácil! 😎

> [!TIP] **Para saberes mais** 🌱 No futuro, além de "vou comer", também existe uma forma só numa palavra: "comerei". Vais aprendê-la mais para a frente!
