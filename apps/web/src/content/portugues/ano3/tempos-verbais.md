# Ontem, hoje e amanhã (tempos) ⏳

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que cada **verbo** tem um relógio mágico que diz se a ação **já aconteceu**, **acontece agora** ou **ainda vai acontecer** — e vais aprender a reconhecer o passado, o presente e o futuro. 🕒

Sabias que as palavras de ação têm um "relógio"? 🕒 Os **verbos** dizem-te SE a ação já aconteceu, está a acontecer ou vai acontecer. É como uma viagem no tempo, e tu vais ser o capitão da nave! 🚀 Vamos a isso, com calma e a sorrir.

## O verbo é a palavra de ação 🏃

O **verbo** é a palavra que mostra o que alguém **faz**, **é** ou **sente**: *comer*, *correr*, *brincar*, *dormir*, *cantar*.

Se numa frase consegues perguntar *«o que é que ela faz?»*, a resposta é quase sempre o verbo. Experimenta com *«A Maria salta à corda»* — ela **salta**! Encontraste o verbo. 🎉

## O verbo viaja no tempo ✈️

O mesmo verbo pode estar em **três tempos** diferentes. Olha bem:

```keyvalue
[
  { "k": "Passado (ontem)", "v": "a ação JÁ aconteceu e acabou. Ex.: ontem comi 🍎" },
  { "k": "Presente (hoje)", "v": "a ação acontece AGORA, neste momento. Ex.: hoje como 🍽️" },
  { "k": "Futuro (amanhã)", "v": "a ação AINDA não aconteceu, vai acontecer. Ex.: amanhã vou comer 🔮" }
]
```

Imagina uma **linha do tempo**: **ontem** está atrás de ti, **hoje** és tu agora e **amanhã** está à tua frente! ➡️

## Palavras que dão pistas do tempo 🔎

Algumas palavrinhas aparecem na frase e **avisam-te** logo qual é o tempo. São como sinais de trânsito do tempo! 🚦

Quando vês uma destas palavras, já tens metade da resposta! Procura-a sempre primeiro. 🕵️

## Um exemplo passo a passo 🔍

Vamos pôr o verbo *jogar* nos três tempos, com o João a jogar à bola ⚽.

```steps
[
  { "title": "1. Encontra o verbo", "body": "A ação é JOGAR à bola. Esse é o nosso verbo.", "icon": "⚽" },
  { "title": "2. Passado — ontem", "body": "Ontem o João JOGOU à bola. Já acabou! ✅", "icon": "⏪" },
  { "title": "3. Presente — hoje", "body": "Hoje o João JOGA à bola. Está a fazer agora! 🏃", "icon": "▶️" },
  { "title": "4. Futuro — amanhã", "body": "Amanhã o João VAI JOGAR à bola. Ainda não foi! 🔜", "icon": "⏩" }
]
```

Vês? O mesmo verbo muda conforme o tempo: **jogou → joga → vai jogar**. É sempre a mesma ação, mas em momentos diferentes! 🎯

> **Truque:** junta uma palavrinha do tempo à frente do verbo e ouve como soa. Se **"ontem"** combina, é **passado**; se **"hoje"** combina, é **presente**; se **"amanhã"** combina, é **futuro**. Ontem fui, hoje vou, amanhã vou ir — fácil! 😎

> [!TIP] **Para saberes mais** 🌱 No futuro, além de dizermos "vou comer" (com duas palavras), também existe uma forma só numa palavra: **"comerei"**. E no passado há dois tipos: "comi" (acabou) e "comia" (fazia muitas vezes). Vais aprendê-los melhor mais para a frente — chamam-se **tempos verbais**! 📚
