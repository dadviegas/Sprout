# Acentos e ortografia ✍️

**Ortografia** é escrever as palavras **certas**. Os **acentos** ajudam a ler e a perceber. ´^~

## Os acentos

```keyvalue
[
  { "k": "Agudo ´", "v": "som aberto e forte: café, pé, avó" },
  { "k": "Circunflexo ^", "v": "som fechado: avô, você, pês​seg​o" },
  { "k": "Til ~", "v": "som nasal (pelo nariz): pão, mãe, irmã" }
]
```

> O acento pode **mudar tudo**: **avó** 👵 (mulher) e **avô** 👴 (homem)! 🤯
