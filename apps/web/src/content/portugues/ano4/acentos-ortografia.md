# Acentos e ortografia ✍️

> [!NOTE] **O que vais aprender** 👀 Vais descobrir os **acentos** (´ ^ ~), aprender as **regras de ortografia** mais úteis e ficar craque a escrever as palavras **certinhas**, sem erros. ✨

Sabias que um pequeno traço por cima de uma letra pode **mudar tudo**? A **avó** 👵 e o **avô** 👴 só são diferentes por causa de um acento! Escrever bem é como dar um presente bem embrulhado a quem te lê: percebe-se logo o que querias dizer. Vamos lá tornar-te um campeão da ortografia! 🏆

## Os três acentos 🎩

Em português há **três acentos** que se põem por cima das vogais. Cada um manda na letra de maneira diferente.

```keyvalue
[
  { "k": "Agudo ´", "v": "abre o som, forte e aberto: café ☕, pé, avó 👵, está" },
  { "k": "Circunflexo ^", "v": "fecha o som, mais apertado: avô 👴, você, pêssego 🍑, pôr" },
  { "k": "Til ~ (não é acento de som)", "v": "dá som nasal, sai pelo nariz 👃: pão 🍞, mãe, irmã, leão 🦁" }
]
```

> O acento pode **mudar o sentido** da palavra: **avó** 👵 (mulher) e **avô** 👴 (homem); **pôr** (colocar) e **por** (palavra pequena). 🤯

## Quando se usa o acento (palavras agudas) 🔤

As palavras têm uma sílaba que se diz **mais forte** — é a sílaba **tónica**. Muitas vezes é aí que mora o acento. As palavras **agudas** têm a força na **última** sílaba.

> [!TIP] A palavra **«também»** leva acento agudo no **é**: tam**bém**. E **«ninguém»**, **«alguém»** e **«porém»** seguem a mesma regra! ✍️

> [!WARNING] Cuidado com o **g** e o **j**! Antes de **e** e **i**, o som /j/ pode escrever-se com **g** (gelo, girafa 🦒) ou com **j** (já, hoje). Tens de decorar cada palavra. 🧐

## Um exemplo passo a passo 🔍

Imagina que tens de escrever a palavra que se ouve **«kãpu»** (um terreno verde com erva 🌱). Vamos pensar com calma!

```steps
[
  { "title": "1. Ouve a palavra", "body": "diz devagar: cam-po. Tem um som nasal antes de uma letra 👂" },
  { "title": "2. Qual é a letra a seguir?", "body": "vem um 'p'. Lembra-te da regra de ouro! 🤔" },
  { "title": "3. Aplica a regra", "body": "antes de p (e de b) escreve-se sempre m, nunca n ✍️" },
  { "title": "4. Escreve com m", "body": "c-a-m-p-o → campo ✅" },
  { "title": "5. Confere", "body": "lê outra vez: «campo». Está certinho! 🎉" }
]
```

> **Truque:** lembra-te da frase **«Antes de P e B, ponho sempre M»**. P, B e M são todas feitas com os **lábios fechados** — por isso andam juntas! 💋

> [!TIP] **Para saberes mais** 🌱 As palavras dividem-se em **agudas** (força no fim: café), **graves** (força na penúltima: mesa) e **esdrúxulas** (força na antepenúltima: **pás**saro, **mé**dico). Olha o segredo: **TODAS** as palavras esdrúxulas levam acento! Por isso, se a força está três sílabas atrás, mete acento sem medo. 📌
