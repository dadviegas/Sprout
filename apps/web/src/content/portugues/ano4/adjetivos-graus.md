# Adjetivos: comparar qualidades 🌟

> [!NOTE] **O que vais aprender** 👀 Vais descobrir o que é um **adjetivo** e como ele muda de **grau** para **comparar** qualidades — quem é mais alto, tão rápido como, ou o melhor de todos! 🏆

Os adjetivos dizem como são as coisas: alto, rápido, bonito, curioso! 😊 E sabes que mais? Com eles podes **comparar** — descobrir quem é mais alto, quem é igual a quem, ou quem é o número 1 de todos. Vem comigo que isto é mais fácil do que parece! 🚀

## O que é um adjetivo? 🏷️

O **adjetivo** é a palavra que diz uma **qualidade** (ou característica) de alguém ou de alguma coisa. Anda quase sempre ao pé de um **nome**.

Olha: "O cão é **grande**." A palavra *grande* diz como é o cão. É um adjetivo! 🐶

```keyvalue
[
  { "k": "alto", "v": "diz a altura de alguém 🧍" },
  { "k": "rápido", "v": "diz a velocidade de algo 🏃" },
  { "k": "bonito", "v": "diz como algo é à vista 🌷" },
  { "k": "curioso", "v": "diz como é o feitio de alguém 🤔" },
  { "k": "fresco", "v": "diz como está uma coisa 🍃" }
]
```

> [!NOTE] O adjetivo **concorda** com o nome em género e número: o gato preto, a gata pret**a**, os gatos pret**os**. Quando o nome muda, o adjetivo muda com ele! 🔁

## Os três graus do adjetivo 📊

## O grau comparativo: três maneiras ⚖️

Quando comparas **duas coisas**, há três caminhos. Repara na palavrinha que aparece a seguir — ela diz tudo!

```keyvalue
[
  { "k": "Comparativo de superioridade", "v": "**mais** … **(do) que** → 'O leão é mais forte do que o gato.' 💪" },
  { "k": "Comparativo de igualdade", "v": "**tão** … **como** → 'A Ana é tão alta como a Inês.' 🟰" },
  { "k": "Comparativo de inferioridade", "v": "**menos** … **(do) que** → 'O rato é menos forte do que o leão.' 🐭" }
]
```

> [!TIP] Repara no par de palavras: com **mais** e **menos** usas **do que**; com **tão** usas **como**. Andam sempre aos pares! 👯

## O grau superlativo: relativo e absoluto 👑

O **superlativo** mostra a qualidade no seu **máximo**. Tem duas famílias, e é importante não as trocar:

```compare
[
  { "title": "Superlativo relativo 🏆", "rows": [
    { "label": "o que faz", "value": "compara 1 com TODO um grupo" },
    { "label": "forma", "value": "o mais / o menos … de" },
    { "label": "exemplo", "value": "O Rui é o mais rápido da turma." }
  ] },
  { "title": "Superlativo absoluto ⭐", "highlight": true, "rows": [
    { "label": "o que faz", "value": "diz que é MUITO, sem comparar" },
    { "label": "forma (analítica)", "value": "muito + adjetivo → 'muito alto'" },
    { "label": "forma (sintética)", "value": "termina em -íssimo → 'altíssimo'" }
  ] }
]
```

O superlativo absoluto **sintético** acrescenta **-íssimo** ao adjetivo: alto → alt**íssimo**, fácil → facíl**imo**, feliz → felic**íssimo**. Quer dizer exactamente o mesmo que "muito alto". 🤩

## Adjetivos com graus especiais (irregulares) 🌈

Alguns adjetivos não seguem a regra do "mais". Têm formas **próprias** que tens mesmo de decorar:

```compare
[
  { "title": "Em vez de 'mais bom' 👍", "rows": [
    { "label": "comparativo", "value": "melhor", "highlight": true },
    { "label": "superlativo absoluto", "value": "ótimo" }
  ] },
  { "title": "Em vez de 'mais mau' 👎", "rows": [
    { "label": "comparativo", "value": "pior", "highlight": true },
    { "label": "superlativo absoluto", "value": "péssimo" }
  ] },
  { "title": "Em vez de 'mais grande' / 'mais pequeno'", "rows": [
    { "label": "maior", "value": "(de grande)" },
    { "label": "menor", "value": "(de pequeno)" }
  ] }
]
```

> [!WARNING] Nunca digas "mais bom" nem "mais mau"! O certo é **melhor** e **pior**. E é "**maior**", não "mais grande". 🙅

## Um exemplo passo a passo 🔍

Imagina três amigos numa corrida: a Rita, o Tomás e a Bia. Queres dizer tudo sobre a velocidade deles usando o adjetivo *rápido*. Vamos com calma! 🏃‍♀️🏃‍♂️

```steps
[
  { "title": "1. Escolhe o adjetivo", "body": "vamos falar da velocidade, por isso o adjetivo é 'rápido' 🏃", "icon": "🏷️" },
  { "title": "2. Grau normal", "body": "fala de UMA pessoa: 'A Rita é rápida.'", "icon": "1️⃣" },
  { "title": "3. Grau comparativo", "body": "compara DUAS: 'O Tomás é mais rápido do que a Rita.'", "icon": "⚖️" },
  { "title": "4. Superlativo relativo", "body": "compara 1 com o GRUPO: 'A Bia é a mais rápida das três.' 🏆", "icon": "👑" },
  { "title": "5. Superlativo absoluto", "body": "diz que é MUITO, sem comparar: 'A Bia é rapidíssima!'", "icon": "⭐" }
]
```

Vês? O adjetivo é sempre *rápido*, mas muda de grau conforme aquilo que queres dizer. 🌟

> **Truque:** olha para a palavrinha-pista! **Sozinho** → normal. **"que/como"** → comparativo (liga dois). **"de todos / da turma"** → superlativo relativo. **"-íssimo" ou "muito"** → superlativo absoluto. A pista está sempre lá à espreita! 🔎

> [!TIP] **Para saberes mais** 🌱 Alguns superlativos absolutos vêm direto do **latim** e parecem estranhos: de *amigo* faz-se **amicíssimo**, de *fácil* faz-se **facílimo**, e de *célebre* faz-se **celebérrimo**. São formas eruditas — bem chiques! 🎩
