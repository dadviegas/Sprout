# Adjetivos: comparar qualidades 🌟

Os adjetivos dizem como são as coisas: alto, rápido, bonito! 😊 E sabes que mais? Com eles podes **comparar** — descobrir quem é mais alto ou o mais rápido de todos!

## O que é um adjetivo?

O **adjetivo** é a palavra que diz uma **qualidade** de alguém ou de alguma coisa.

Olha: "O cão é **grande**." A palavra *grande* diz como é o cão. É um adjetivo! 🐶

## Um exemplo passo a passo 🔍

Imagina três amigos: a Rita, o Tomás e a Bia. Vamos comparar a altura deles! 📏

```steps
[
  { "title": "Grau normal", "body": "A Rita é alta. (Só falamos de uma pessoa: a Rita.)" },
  { "title": "Grau comparativo", "body": "O Tomás é mais alto que a Rita. (Comparamos DUAS pessoas: Tomás e Rita.)" },
  { "title": "Grau superlativo", "body": "A Bia é a mais alta de todos. (Ela é o número 1 do grupo!)" }
]
```

Vês? O adjetivo é sempre *alto*, mas muda de grau conforme o que queres dizer. 🌟

## Truque 🪄

Decora estas três palavrinhas mágicas:

- **Sozinho?** → grau normal (alto)
- **Que?** → comparativo (mais alto **que**)
- **De todos?** → superlativo (**o** mais alto **de todos**)

Pensa assim: "que" liga dois; "de todos" coroa o campeão! 👑

## Vamos aplicar 🧩

Vamos usar o adjetivo *rápido* para descrever animais numa corrida! 🐆🐢🐇

```steps
[
  { "title": "Lê a situação", "body": "A tartaruga, o coelho e a chita fazem uma corrida." },
  { "title": "Grau normal", "body": "O coelho é rápido." },
  { "title": "Grau comparativo", "body": "O coelho é mais rápido que a tartaruga." },
  { "title": "Grau superlativo", "body": "A chita é a mais rápida de todos! 🏆" }
]
```

Boa! Usaste os três graus numa só corrida! 🎉

> [!TIP] **Para saberes mais** 🌱 Alguns adjetivos têm formas especiais: em vez de "mais bom" dizemos **melhor**, e em vez de "mais mau" dizemos **pior**. Esperto, não é?
