# Histórias e autores portugueses ✍️

> [!NOTE] **O que vais aprender** 👀 Vais conhecer **autores portugueses** que escrevem para crianças, descobrir os **tipos de obra** (conto, poema, banda desenhada) e aprender a encontrar quem fez cada livro. ✍️📚

Sabias que cada livro foi escrito por uma pessoa de verdade? Essa pessoa é o **autor**. Portugal tem autores maravilhosos que escreveram histórias e poemas mesmo a pensar em crianças como tu! Vamos conhecê-los? 🇵🇹💛

## Um exemplo passo a passo 🔍

Imagina esta pergunta: *«Tenho um livro com versos que rimam e uma capa onde diz "Sophia de Mello Breyner". Que tipo de obra é e quem é o autor?»* Vamos resolver com calma.

```steps
[
  { "title": "1. Lê com atenção", "body": "a pergunta dá duas pistas: 'versos que rimam' e um nome na capa 🧐" },
  { "title": "2. Olha para o formato", "body": "se tem versos curtos com rima, então é um POEMA 🎵" },
  { "title": "3. Procura o autor", "body": "o nome na capa é de quem escreveu: Sophia de Mello Breyner ✍️" },
  { "title": "4. Junta as respostas", "body": "é um poema, escrito pela autora Sophia de Mello Breyner ✅" }
]
```

> **Truque:** procura sempre o nome do **autor** na **capa** do livro. Se um livro tem **versos** e **rima**, é poesia; se conta uma **história seguida**, é prosa. 🔍

> [!TIP] **Para saberes mais** 🌱 Há uma lista chamada **Plano Nacional de Leitura (PNL)** que recomenda os melhores livros para cada ano de escola. Algumas obras são tão importantes que se tornaram **clássicos** — livros que pais e filhos leram, como 'A Menina do Mar', já com mais de **60 anos**! A tua biblioteca da escola tem muitos. 📚
