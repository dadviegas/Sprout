# Escrever uma carta e um convite ✉️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a escrever uma **carta** e um **convite** como um verdadeiro escritor: as partes que não podem faltar, o **envelope** e a maneira certa de falar com cada pessoa. 💌

Já alguma vez quiseste contar uma novidade a alguém que está longe? A avó noutra cidade, um primo nos Açores, um amigo que mudou de escola? Uma **carta** leva as tuas palavras até lá! E quando queres chamar os teus amigos para uma festa, escreves um **convite**. Hoje vais ficar a saber tudo. 🌟

## Carta e convite: para que servem? 💌

Tanto a carta como o convite servem para **comunicar** com outra pessoa por escrito. A diferença está naquilo que queres dizer.

```keyvalue
[
  { "k": "Carta", "v": "texto para falar com alguém que está longe: contar novidades, dar notícias, matar saudades 💌" },
  { "k": "Convite", "v": "texto curto para chamar alguém para um evento: anos, lanche, peça de teatro, casamento 🎉" },
  { "k": "Destinatário", "v": "a pessoa a quem escreves (quem vai receber) 📬" },
  { "k": "Remetente", "v": "a pessoa que escreve e envia (és tu!) ✍️" }
]
```

> [!NOTE] Pensa sempre: **A quem escrevo?** À avó falas com muito carinho. A um amigo falas mais à vontade. A uma pessoa que conheces pouco, falas com mais respeito. Mas és sempre simpático! 🙂

## As partes de uma carta ✍️

Uma carta tem sempre as mesmas partes, sempre pela mesma ordem. Decora-as e nunca mais te enganas!

```steps
[
  { "title": "1. Local e data", "body": "no canto de cima escreves de onde e quando escreves: \"Ponta Delgada, 30 de maio de 2026\".", "icon": "📅" },
  { "title": "2. Saudação", "body": "cumprimentas a pessoa com carinho: \"Querida avó,\". Repara na vírgula no fim!", "icon": "👋" },
  { "title": "3. Corpo (mensagem)", "body": "é o coração da carta — contas tudo o que queres dizer, em parágrafos. ✍️", "icon": "💬" },
  { "title": "4. Despedida", "body": "despedes-te com afeto: \"Um beijinho grande, até breve!\".", "icon": "😊" },
  { "title": "5. Assinatura", "body": "escreves o teu nome no fim, para a pessoa saber quem escreveu: \"A tua neta, Maria\".", "icon": "🖊️" }
]
```

## As partes de um convite 🎉

O convite é mais **curto** que a carta. Mas não pode esquecer três perguntas: **O quê? Quando? Onde?**

```steps
[
  { "title": "Saudação", "body": "chamas a pessoa pelo nome: \"Olá, Tomás!\".", "icon": "👋" },
  { "title": "O quê?", "body": "dizes para que é o convite: \"Convido-te para a minha festa de anos.\". 🎂", "icon": "🎉" },
  { "title": "Quando?", "body": "o dia e a hora: \"no sábado, dia 7 de junho, às 15 horas\".", "icon": "🕒" },
  { "title": "Onde?", "body": "o sítio onde é a festa: \"lá em casa, na Rua das Flores, n.º 5\".", "icon": "📍" },
  { "title": "Despedida", "body": "fechas com simpatia e o teu nome: \"Aparece! Um abraço, Rita.\".", "icon": "😊" }
]
```

> [!TIP] Num convite às vezes pede-se uma resposta: escreve-se **R.S.F.F.** (\"Responda, se faz favor\") para saberes quem vai aparecer. Assim a Rita já sabe quantos bolos precisa! 🎂

## O envelope e o selo 📬

Uma carta viaja dentro de um **envelope**. Para chegar ao sítio certo, o envelope precisa de ter algumas coisas.

```keyvalue
[
  { "k": "Destinatário", "v": "à frente, no meio: o nome e a morada de quem vai receber 📮" },
  { "k": "Código postal", "v": "os números que ajudam os carteiros a encontrar a morada (ex.: 9500-150) 🔢" },
  { "k": "Remetente", "v": "atrás ou no canto de cima: o teu nome e a tua morada ✍️" },
  { "k": "Selo", "v": "cola-se no canto de cima à direita — é o \"bilhete\" da carta para poder viajar 📨" }
]
```

> [!NOTE] É o **carteiro** que leva as cartas, de casa em casa. Sem **selo**, a carta não viaja — por isso não te esqueças de o colar! 📬

## Um exemplo passo a passo 🔍

Vamos escrever, juntos e devagar, uma carta da Maria para a avó. Repara em cada parte!

```steps
[
  { "title": "1. Local e data", "body": "no canto de cima: \"Angra do Heroísmo, 30 de maio de 2026\". 📅", "icon": "📅" },
  { "title": "2. Saudação", "body": "com muito carinho: \"Querida avó,\" — e vírgula no fim. 👋", "icon": "👋" },
  { "title": "3. Mensagem", "body": "\"Estou com muitas saudades tuas! Já aprendi a andar de bicicleta sem rodinhas e tirei boa nota a Matemática.\" ✍️", "icon": "💬" },
  { "title": "4. Despedida", "body": "\"Um beijinho grande, até breve!\". 😊", "icon": "😊" },
  { "title": "5. Assinatura", "body": "\"A tua neta, Maria\". Pronto — a carta está completa! 🎉", "icon": "🖊️" }
]
```

> **Truque:** decora as partes da carta com a tua mão. Diz baixinho **\"S-M-D\"**: **S**audação, **M**ensagem, **D**espedida. E lembra-te: a data fica em cima e o teu nome fica no fim! 🖐️

> [!TIP] **Para saberes mais** 🌱 Antes do telemóvel e do email, as cartas eram a única forma de falar com quem estava longe — e demoravam **dias ou semanas** a chegar! Hoje ainda se escrevem cartas a sério: a uma carta enviada pelos correios chama-se **correspondência**, e há até pessoas que colecionam **selos** (essa coleção chama-se **filatelia**). 📮
