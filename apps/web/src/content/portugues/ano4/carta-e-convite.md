# Escrever uma carta e um convite ✉️

Sabes escrever a alguém que está longe? Hoje vais aprender a fazer cartas e convites como um verdadeiro escritor! 🌟

## O que é uma carta e um convite?

Uma **carta** é um texto que escreves para falar com alguém que não está ao pé de ti: a avó, um amigo, um primo. 💌

Um **convite** é um texto curto para chamar alguém para uma festa ou evento: anos, um lanche, uma peça de teatro. 🎉

Os dois servem para **comunicar** com outra pessoa. Por isso têm sempre partes muito parecidas!

```keyvalue
[
  { "k": "Saudação", "v": "como dizes \"Olá\" no início 👋" },
  { "k": "Mensagem", "v": "o que queres mesmo dizer ✍️" },
  { "k": "Despedida", "v": "como te despedes no fim e assinas o nome 😊" }
]
```

> [!NOTE] Pensa sempre: **A quem escrevo?** À avó falas com carinho. A um amigo falas mais à vontade. Mas és sempre simpático! 🙂

## Um exemplo passo a passo 🔍

Vamos escrever uma carta à avó, parte a parte!

```steps
[
  { "title": "1. Saudação", "body": "Começas com um \"olá\" cheio de carinho: \"Querida avó,\"." },
  { "title": "2. Mensagem", "body": "Contas o que queres dizer: \"Estou com muitas saudades tuas! Já aprendi a andar de bicicleta sem rodinhas.\"" },
  { "title": "3. Despedida", "body": "Despedes-te com afeto: \"Um beijinho grande, até breve!\"." },
  { "title": "4. Assinatura", "body": "Escreves o teu nome no fim: \"A tua neta, Maria\". Pronto, a carta está completa! 🎉" }
]
```

## Truque 🪄

Decora as **3 partes** com os dedos da tua mão: 🖐️

1. **S**audação (Olá!)
2. **M**ensagem (o que digo)
3. **D**espedida (Adeus + nome)

Diz baixinho: **"S-M-D, escrever é fácil para mim!"** 😄

## Vamos aplicar 🧩

Vamos fazer um **convite** para a tua festa de anos!

```steps
[
  { "title": "Saudação", "body": "\"Olá, Tomás!\" — chamas o teu amigo pelo nome." },
  { "title": "Mensagem", "body": "Dizes o quê, quando e onde: \"Convido-te para a minha festa de anos, no sábado, às 15h, lá em casa.\"" },
  { "title": "Despedida", "body": "\"Aparece! Um abraço, Rita.\" — e já está o teu convite pronto! 🎂" }
]
```

> [!TIP] **Para saberes mais** 🌱 No fim das cartas a sério, os adultos escrevem a **data** e a **terra** no canto de cima: "Lisboa, 29 de maio de 2026". Assim sabe-se quando e de onde a carta foi enviada!
