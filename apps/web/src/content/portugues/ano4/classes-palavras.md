# Classes de palavras 🧩

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que cada palavra tem o seu **lugar**, como um brinquedo na sua caixa. Aprendes a reconhecer **nomes**, **verbos**, **adjetivos**, **determinantes**, **pronomes**, **quantificadores** e **advérbios** — e a apanhá-los dentro de uma frase! 🕵️

Sabias que todas as palavras da língua portuguesa estão arrumadas em **grupos**? A esses grupos chamamos **classes de palavras**. É como uma grande casa cheia de gavetas: numa gaveta estão os nomes, noutra os verbos, noutra os adjetivos… Quando aprendes a olhar para uma palavra e a guardar na gaveta certa, ler e escrever fica muito mais fácil! Vamos abrir as gavetas uma a uma? 🗄️✨

## As três classes principais 🌟

Estas três são as mais importantes e quase todas as frases as têm. Decora bem estas três e já tens meio caminho andado!

> [!NOTE] Há também os **nomes coletivos**: uma só palavra que já significa um grupo. Por exemplo, **cardume** é um grupo de peixes 🐟, **alcateia** é um grupo de lobos 🐺 e **floresta** é um conjunto de árvores 🌲.

## Verbos: as palavras da ação 🏃

O verbo é a palavra mais viva da frase — é ela que mostra o que está a acontecer. Os verbos **mudam** conforme o tempo: ontem, hoje ou amanhã.

```keyvalue

  { "k": "Presente", "v": "acontece agora: eu salto, tu cantas, ela brinca ⏰" },
  { "k": "Passado (pretérito)", "v": "já aconteceu, ontem: eu saltei, tu cantaste 🕰️" },
  { "k": "Futuro", "v": "ainda vai acontecer, amanhã: eu saltarei, tu cantarás 🚀" },
  { "k": "Infinitivo", "v": "é o nome do verbo, como vem no dicionário: saltar, cantar, brincar 📖" }
]
```

## Determinantes e quantificadores 🔢

Antes de um nome aparecem muitas vezes pequenas palavras que o ajudam. Os **determinantes** apresentam o nome e os **quantificadores** dizem a quantidade.

```keyvalue
[
  { "k": "Determinante artigo definido", "v": "o, a, os, as — falas de algo conhecido: 'o cão' 🐶" },
  { "k": "Determinante artigo indefinido", "v": "um, uma, uns, umas — algo qualquer: 'um cão' 🐕" },
  { "k": "Determinante possessivo", "v": "diz de quem é: meu, teu, nosso, vosso 🧸" },
  { "k": "Quantificador numeral", "v": "diz quantos: três gatos, dez dedos ✋" }
]
```

## Um exemplo passo a passo 🔍

Vamos olhar para uma frase e descobrir a classe de cada palavra: **«O cão preto corre depressa.»** Resolve comigo, com calma. 🐶

```steps
[
  { "title": "1. Lê a frase toda", "body": "primeiro lê devagar: «O cão preto corre depressa.» 👀", "icon": "📖" },
  { "title": "2. Olha para 'O'", "body": "apresenta o nome e podes dizer 'o' ou 'a' → é um determinante artigo", "icon": "🔤" },
  { "title": "3. Olha para 'cão'", "body": "dá nome a um animal → é um nome (comum) 🐶", "icon": "🐶" },
  { "title": "4. Olha para 'preto'", "body": "diz COMO é o cão → é um adjetivo 🎨", "icon": "🎨" },
  { "title": "5. Olha para 'corre'", "body": "mostra a ação, o que o cão faz → é um verbo 🏃", "icon": "🏃" },
  { "title": "6. Olha para 'depressa'", "body": "diz COMO ele corre → é um advérbio 💨", "icon": "💨" }
]
```

> **Truque:** faz três perguntas à palavra! **Dá um nome?** → nome. **Mostra uma ação?** → verbo. **Descreve como é?** → adjetivo. Se nenhuma servir, vê se apresenta o nome (determinante) ou diz como/quando/onde (advérbio). 🕵️

> [!TIP] **Para saberes mais** 🌱 Existem palavras que mudam de classe conforme a frase! A palavra **«cantar»** é um verbo em «eu gosto de **cantar**», mas pode ser um nome em «o **cantar** dos pássaros é lindo». A classe depende sempre da função que a palavra tem **dentro da frase** — por isso lê sempre a frase toda antes de decidir! 🤓
