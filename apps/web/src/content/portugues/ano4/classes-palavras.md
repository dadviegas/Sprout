# Classes de palavras 🧩

As palavras agrupam-se em **classes**, como brinquedos em caixas. As três mais importantes são: **nome**, **verbo** e **adjetivo**.

```keyvalue
[
  { "k": "Nome (substantivo)", "v": "dá nome a coisas, pessoas, animais: gato, escola, Maria 🐱" },
  { "k": "Verbo", "v": "é uma ação: correr, comer, saltar 🏃" },
  { "k": "Adjetivo", "v": "diz como é: bonito, grande, azul 🎨" }
]
```

## Vê numa frase

> O **gato** *preto* **dorme**.

- **gato** → nome (o que é)
- *preto* → adjetivo (como é)
- **dorme** → verbo (o que faz)


> [!TIP] Pergunta: a palavra **dá um nome**? É nome. **Mostra uma ação**? É verbo. **Descreve**? É adjetivo.
