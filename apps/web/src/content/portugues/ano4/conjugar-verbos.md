# Conjugar verbos: presente, passado e futuro ⏳

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **conjugar** qualquer verbo regular: as três conjugações (**-ar, -er, -ir**) com os verbos-modelo **falar, comer e partir**, nos quatro tempos do indicativo — **presente**, **pretérito perfeito**, **pretérito imperfeito** e **futuro**. Com o truque do *radical + terminação*, conjugar fica fácil como montar LEGO! 🧱

Já sabes que os verbos mudam com o tempo: *hoje falo, ontem falei, amanhã falarei* (viste isso no 3.º ano). Agora vais descobrir o **mecanismo**: os verbos regulares são todos montados da mesma maneira, como peças de LEGO. Aprende o molde de UM verbo e ficas a saber conjugar **milhares**! 🤯

## O verbo desmonta-se em duas peças 🧱

Todo o verbo tem um **radical** (a parte que diz o significado) e uma **terminação** (a parte que muda com a pessoa e o tempo).

## Os quatro tempos do ano ⏰

Estes são os quatro tempos do indicativo que vais usar este ano — repara no que cada um conta:

```keyvalue
[
  { "k": "Presente", "v": "acontece AGORA: eu falo, eu como 🕐" },
  { "k": "Pretérito perfeito", "v": "aconteceu e ACABOU: eu falei ontem ✅" },
  { "k": "Pretérito imperfeito", "v": "DURAVA ou era hábito: eu falava todos os dias 🔁" },
  { "k": "Futuro", "v": "VAI acontecer: eu falarei amanhã 🚀" }
]
```

> **Truque do imperfeito vs. perfeito 🎯:** se na frase cabe «**costumava**», é imperfeito (*eu jogava* = costumava jogar). Se cabe «**de repente**» ou «**ontem**», é perfeito (*eu joguei*).

## COMER e PARTIR seguem o mesmo molde 🍎🚪

Muda a vogal da conjugação, mas o mecanismo é igual. Compara o «eu» e o «tu» nos quatro tempos:

```compare

  ] },

    { "label": "Presente", "value": "eu parto, tu partes" },
    { "label": "Perfeito", "value": "eu parti, tu partiste" },
    { "label": "Imperfeito", "value": "eu partia, tu partias", "highlight": true },
    { "label": "Futuro", "value": "eu partirei, tu partirás" }
  ] }
]
```

> **Os três truques de ouro 🥇:**
> 1. **Imperfeito:** verbos em -AR fazem **-ava** (falava); verbos em -ER e -IR fazem **-ia** (comia, partia).
> 2. **Futuro:** pega no **infinitivo inteiro** e cola -ei, -ás, -á, -emos, -ão: falar**ei**, comer**ás**, partir**á**. Nunca falha!
> 3. **Perfeito do «eu»:** -AR dá **-ei** (falei), -ER dá **-i** (comi), -IR dá **-i** (parti).

> [!TIP] **Para saberes mais** 🌱 O futuro «falarei» nasceu mesmo de colar duas palavras: no latim que se falava nas ruas dizia-se *falar hei* («hei de falar») — e de tanto se dizer junto, colou-se em **falarei**! É por isso que o truque do futuro (infinitivo + ei/ás/á) funciona sempre: o infinitivo está literalmente lá dentro. 🏛️
