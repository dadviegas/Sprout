# Frase simples e frase complexa 🔗

> [!NOTE] **O que vais aprender** 👀 Vais aprender a descobrir se uma frase é **simples** (tem só **um verbo**) ou **complexa** (tem **dois ou mais verbos**) — e basta **contar os verbos**! 🔢

Sabias que as frases também podem ser curtinhas ou compridas, como comboios? 🚂 Algumas têm **uma só carruagem** (um verbo) — são as frases **simples**. Outras têm **duas ou mais carruagens** ligadas (dois ou mais verbos) — são as frases **complexas**. Vem comigo contar verbos e descobrir qual é qual! 🔗

## Verbo: a ação da frase 🏃

Para tudo isto, primeiro tens de encontrar o **verbo** — a palavra que diz o que **acontece** ou o que alguém **faz**. Cada verbo é uma **oração** (um pedacinho da frase com a sua própria ação).

## Um exemplo passo a passo 🔍

Vamos descobrir juntos se esta frase é simples ou complexa: **«A Ana estudou muito quando chegou a casa.»** 📚

```steps

  { "title": "3. Conta os verbos", "body": "estudou (1) + chegou (2) = 2 verbos ✋✋", "icon": "🔢" },
  { "title": "4. Vê a conjunção", "body": "as orações ligam-se com «quando» 🪢", "icon": "🪢" },
  { "title": "5. A resposta", "body": "2 verbos → é uma frase COMPLEXA! 🎉", "icon": "✅" }
]
```

> **Truque:** para saber o tipo da frase, **conta os verbos**! 🔢 **Um** verbo = frase **simples**; **dois ou mais** verbos = frase **complexa**. Aponta cada ação com o dedo e levanta um dedo por cada uma. ✋

> [!TIP] **Para saberes mais** 🌱 Nas frases complexas, as orações podem ligar-se de duas maneiras. Quando se juntam por **e** ou **mas** e cada uma vale por si, são **coordenadas** (são companheiras iguais 🤝). Quando uma **depende** da outra, ligada por **porque**, **quando** ou **se**, são **subordinadas** (uma é a chefe e a outra é a ajudante 👑). Vais aprofundar tudo isto no 2.º ciclo! 🤓
