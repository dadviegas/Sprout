# Ouvir, opinar e debater 💬

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **dar a tua opinião** com respeito, a **explicar porquê** com bons argumentos, a **ouvir** quem pensa diferente de ti e a participar num **debate** sem zangares. 💬

Imagina que estás com os teus colegas a decidir o jogo do recreio. Toda a gente quer mandar… e às vezes ninguém se ouve! 😅 Quando aprendes a **dizer o que pensas com calma** e a **escutar os outros**, as conversas ficam mais fáceis e mais justas. A isto chama-se **debater**: trocar ideias com respeito. Pode-se até discordar — sem nunca gritar nem gozar. Vamos a isso! 🤝

## O que é uma opinião 🗣️

Uma **opinião** é aquilo que **tu achas** sobre uma coisa. Não é certa nem errada como uma conta de matemática — mas fica muito mais forte quando explicas **porquê**.

```keyvalue

  { "k": "Facto", "v": "uma coisa verdadeira que se pode provar: 'Hoje está a chover' ☔" },
  { "k": "Opinião", "v": "o que tu achas: 'Eu acho que os dias de chuva são divertidos' 💭" },
  { "k": "Argumento", "v": "a razão que apoia a opinião: '…porque posso saltar nas poças' 🧩" },
  { "k": "Respeito", "v": "ouvir sem gozar nem gritar com quem pensa diferente 🤝" }
]
```

> Repara: o **facto** é igual para todos; a **opinião** pode ser diferente de pessoa para pessoa — e isso é normal! 🙂

## A fórmula de uma boa opinião 🧩

Há uma maneira fácil de dizer a tua ideia para que toda a gente perceba. Usa sempre estas três partes, por esta ordem:

```steps
[
  { "title": "1. Eu acho que…", "body": "começa por dizer a tua opinião com clareza 💭", "icon": "💬" },
  { "title": "2. …porque…", "body": "explica a razão, o teu argumento 🧩", "icon": "🔎" },
  { "title": "3. Por exemplo…", "body": "dá um exemplo para a tua ideia ficar mais forte 🌟", "icon": "🌟" }
]
```

> Exemplo completo: *«Eu acho que devíamos ter mais tempo de leitura **porque** ajuda a inventar histórias. **Por exemplo**, depois de ler já sei muitas palavras novas.»* 💡

## As regras de um bom debate 🎯

Num **debate** várias pessoas dão a sua opinião sobre o mesmo tema. Para correr bem, há combinações que todos seguem. É como num jogo: sem regras, ninguém se diverte!

```keyvalue
[
  { "k": "Falar à vez", "v": "um de cada vez, sem interromper — espera a tua vez ✋" },
  { "k": "Ouvir até ao fim", "v": "deixa o outro acabar antes de responderes 👂" },
  { "k": "Falar baixo e calmo", "v": "uma boa razão vale mais do que gritar 📢❌" },
  { "k": "Olhar para quem fala", "v": "mostra que estás mesmo a ouvir 👀" },
  { "k": "Discordar com respeito", "v": "diz 'não concordo porque…' em vez de 'estás errado!' 🤝" }
]
```

## Ouvir é tão importante como falar 👂

Muita gente pensa que debater é só **falar**. Mas a parte mais difícil — e mais importante — é **ouvir bem**. Quem ouve aprende, percebe melhor e dá respostas mais inteligentes.

```compare

    { "label": "Atitude", "value": "interrompe e quer ter sempre razão" },
    { "label": "Resultado", "value": "ninguém o ouve de volta 😕" }
  ] },
  { "title": "Quem também ouve 👂", "rows": [
    { "label": "Atitude", "value": "escuta, pensa e depois responde", "highlight": true },
    { "label": "Resultado", "value": "aprende mais e é mais respeitado 😊", "highlight": true }

```

> [!TIP] Quando alguém termina de falar, podes começar a tua resposta por *«Concordo contigo em…»* ou *«Percebo o que dizes, mas…»*. Assim mostras que estiveste mesmo a ouvir! 👂

## Frases que ajudam a debater 💬

Há frases mágicas que tornam qualquer debate mais simpático. Guarda estas na cabeça:

## Um exemplo passo a passo 🔍

Imagina que na tua turma estão a debater este tema: *«Devíamos poder trazer um brinquedo de casa para a escola?»* A Rita acha que sim. Vê como ela faz para dar uma opinião forte e ouvir os outros.

```steps
[
  { "title": "1. Pensa antes de falar", "body": "a Rita decide a sua opinião: 'Sim, acho que sim' 💭", "icon": "🧠" },
  { "title": "2. Espera a vez", "body": "levanta o dedo e espera que o colega acabe de falar ✋", "icon": "✋" },
  { "title": "3. Diz a opinião + porquê", "body": "'Eu acho que sim, PORQUE no intervalo podíamos brincar juntos' 🧩", "icon": "💬" },
  { "title": "4. Dá um exemplo", "body": "'Por exemplo, podíamos trocar cromos e fazer mais amigos' 🌟", "icon": "🌟" },
  { "title": "5. Ouve quem discorda", "body": "o João diz que os brinquedos se podem perder; a Rita ouve com calma 👂", "icon": "👂" },
  { "title": "6. Responde com respeito", "body": "'Percebo, João. E se cada um guardasse o seu na mochila?' 🤝", "icon": "🤝" }
]
```

> **Truque:** uma boa opinião tem sempre um **«porque»**. Dizer só *«porque sim»* não convence ninguém! Lembra-te da fórmula **«Eu acho que… porque… por exemplo…»**. 🙂

> [!TIP] **Para saberes mais** 🌱 Quando, num grupo, todos dão a sua opinião e depois **votam** para escolher, a isso chama-se **decisão democrática** — ganha a ideia que tiver mais votos. É assim que se decide em muitos sítios importantes, como a **Assembleia da República**, onde os deputados debatem e votam as leis do nosso país! 🗳️🇵🇹
