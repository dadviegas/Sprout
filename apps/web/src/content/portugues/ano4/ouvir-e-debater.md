# Ouvir, opinar e debater 💬

> [!NOTE] **O que vais aprender** 👀 Vais aprender a **dar a tua opinião** com respeito, a **explicar porquê** e a ouvir quem pensa diferente de ti. 💬

Numa conversa a sério — um **debate** — as pessoas dizem o que pensam e ouvem os outros. Pode-se discordar… sem zangar! 🤝

## Dar uma boa opinião 🗣️

```keyvalue
[
  { "k": "Opinião", "v": "o que tu achas: 'Eu acho que…' 💭" },
  { "k": "Porquê (argumento)", "v": "a razão: '…porque…' 🧩" },
  { "k": "Respeito", "v": "sem gozar nem gritar com quem discorda 🤝" }
]
```

> Exemplo: *"Eu acho que devíamos ter mais recreio **porque** ajuda a concentrar nas aulas."* 💡

## Como debater bem 🎯

```steps
[
  { "title": "Espera a tua vez", "body": "um de cada vez, sem interromper ✋" },
  { "title": "Diz e explica", "body": "a tua opinião + o porquê 🧩" },
  { "title": "Ouve os outros", "body": "podes até mudar de ideias — é permitido! 🔄" }
]
```

> **Truque:** uma boa opinião tem sempre um **"porque"**. Dizer só "porque sim" não convence ninguém! 🙂

> [!TIP] **Para saberes mais** 🌱 Ouvir quem pensa **diferente** torna-te mais esperto: às vezes a outra pessoa sabe algo que tu não tinhas pensado. Mudar de ideias com bons argumentos é de **inteligentes**! 🧠
