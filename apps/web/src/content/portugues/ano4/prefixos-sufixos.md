# Prefixos e sufixos: construir palavras 🧱

> [!NOTE] **O que vais aprender** 👀 Vais virar um **construtor de palavras**! 🏗️ A partir de uma **raiz**, juntas pedacinhos à **frente** (prefixo) ou **atrás** (sufixo) e crias palavras novas — como peças de LEGO. 🧱

Sabias que muitas palavras são feitas de **peças**? 🧩 No meio está a **raiz** (a parte mais importante, que dá o significado). À frente podes juntar um **prefixo** e atrás um **sufixo**. Com a raiz **feliz**, fazes **in**feliz, feliz**mente**, feliz**ardo**… É como construir com LEGO! Vamos a isso? 🏗️

> [!NOTE] As palavras com a mesma raiz são uma **família de palavras**: *livro, livraria, livreiro* vêm todas de **livr-**. 🌳

## Sufixos: peças atrás 👉

O **sufixo** junta-se ao fim e muitas vezes muda a **classe** da palavra ou o seu tamanho.


## Um exemplo passo a passo 🔍

Vamos construir e analisar a palavra **infelizmente** 😟 — peça a peça.

```steps
[
  { "title": "1. Encontra a raiz", "body": "a peça central é FELIZ (o significado base) 💛", "icon": "💛" },
  { "title": "2. Junta o prefixo", "body": "IN + feliz = infeliz (o contrário) 👈", "icon": "👈" },
  { "title": "3. Junta o sufixo", "body": "infeliz + MENTE = infelizmente 👉", "icon": "👉" },
  { "title": "4. Lê o resultado", "body": "in + feliz + mente = infelizmente 🧱", "icon": "🔤" },
  { "title": "5. Conta as peças", "body": "tem 3 peças: prefixo + raiz + sufixo! 🎉", "icon": "✅" }
]
```

> **Truque:** para descobrir a raiz, **tira as peças da frente e de trás** e vê o que sobra. Em «desarrumado», tira **des-** e **-ado** → sobra **arrum** (de arrumar). Encontraste a raiz! 🕵️

> [!TIP] **Para saberes mais** 🌱 Uma palavra pode ter **prefixo E sufixo ao mesmo tempo** à volta da raiz, como **des·leal·dade** (des- + leal + -dade) ou **in·felic·idade**. A esta forma de criar palavras novas com prefixos e sufixos chama-se **derivação**. E quando juntas **duas raízes** numa só palavra — como *guarda* + *chuva* = **guarda-chuva** ☂️ — isso já é **composição**! 🤓
