# Rever e melhorar um texto ✍️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a rever um texto como um escritor: ver se está completo, organizar parágrafos, melhorar frases, trocar palavras repetidas e corrigir pontuação e ortografia.

Escrever não é só pôr palavras no papel. Depois de escrever, vem uma parte muito importante: **rever**. Rever é olhar outra vez para o texto para o tornar mais claro, bonito e correto.

## Checklist de escritor ✅

Antes de entregar, faz esta revisão:

```steps
[
  { "title": "Conteúdo", "body": "respondi ao que era pedido?" },
  { "title": "Ordem", "body": "as ideias estão numa sequência fácil de seguir?" },
  { "title": "Parágrafos", "body": "separei partes diferentes do texto?" },
  { "title": "Palavras", "body": "evitei repetir sempre as mesmas palavras?" },
  { "title": "Correção", "body": "revisei pontuação, maiúsculas e ortografia?" }
]
```

> **Truque:** lê o texto em voz baixa. Se tropeçares numa frase, talvez ela precise de ser dividida ou melhorada.

## Exemplo passo a passo 🔍

Texto inicial:

> Ontem fui ao parque. Eu brinquei. Eu vi patos. Eu gostei.

Revisão:

```steps
[
  { "title": "1. Juntar ideias", "body": "Ontem fui ao parque e brinquei muito." },
  { "title": "2. Evitar repetição", "body": "Vi patos no lago, em vez de repetir 'eu'." },
  { "title": "3. Acrescentar detalhe", "body": "Os patos nadavam devagar." },
  { "title": "4. Texto melhor", "body": "Ontem fui ao parque e brinquei muito. No lago, vi patos a nadar devagar. Gostei muito do passeio." }
]
```

> [!TIP] **Para saberes mais** 🌱 Muitos escritores profissionais reescrevem o mesmo texto várias vezes. Rever não é sinal de erro: é sinal de cuidado.
