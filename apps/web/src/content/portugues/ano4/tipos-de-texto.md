# Tipos de texto 📝

> [!NOTE] **O que vais aprender** 👀 Vais descobrir que os textos não são todos iguais: cada um tem um **objetivo** e umas **pistas** que o denunciam. No fim, vais saber dizer logo se um texto é para **contar**, **descrever**, **informar**, **ensinar a fazer** ou **convencer**! 🕵️

Sabias que, quando abres um livro, um jornal ou até uma caixa de cereais, estás a ler **tipos de texto diferentes**? 📚 Uns servem para te contar uma história, outros para te ensinar a fazer um bolo, e outros para te convencer a comprar algo. Aprender a reconhecê-los é como ganhares super-óculos de detetive: olhas para um texto e descobres logo para que serve! 🔍 Vem comigo. 🙂

## O texto narrativo por dentro 📖

O texto que mais lês na escola é o **narrativo** — é o dos **contos**. Ele tem sempre os mesmos «ingredientes», e se os souberes, percebes qualquer história. 🍲

```keyvalue

  { "k": "Personagens 🧒", "v": "quem aparece na história (a Branca de Neve, o lobo…) 🙂" },
  { "k": "Espaço 🏰", "v": "o lugar onde tudo acontece (a floresta, a aldeia) 🙂" },
  { "k": "Tempo ⏰", "v": "quando acontece («Era uma vez…», «Há muito tempo…») 🙂" },
  { "k": "Ação ⚡", "v": "o que se passa: início, problema e fim (o desenlace) 🙂" },
  { "k": "Narrador 🗣️", "v": "quem conta a história (às vezes é uma personagem, às vezes é alguém de fora) 🙂" }
]
```

> [!NOTE] Uma **fábula** é um texto narrativo muito especial: tem animais que falam e termina sempre com uma **lição** chamada *moral*. Por exemplo, em «A cigarra e a formiga» a moral é que devemos trabalhar a tempo. 🐜

## Um exemplo passo a passo 🔍

Imagina que a professora te dá este bocadinho de texto e pergunta: *«Que tipo de texto é este?»*

> «Primeiro, parte dois ovos para uma taça. Depois, junta a farinha e o açúcar e mistura tudo muito bem.»

Vamos descobrir juntos, com calma. 🧠

```steps
[
  { "title": "1. Pergunta o objetivo", "body": "para que serve este texto? Ele quer contar uma história ou outra coisa? 🤔", "icon": "🎯" },
  { "title": "2. Procura as pistas", "body": "vês as palavras «primeiro», «depois», «junta», «mistura» — são ordens, passo a passo 🔢", "icon": "🔍" },
  { "title": "3. Imagina o que estás a fazer", "body": "estás a seguir passos para fazer algo (um bolo!) — ninguém te conta uma história 🍰", "icon": "🍰" },
  { "title": "4. Compara com os tipos", "body": "não narra, não descreve, não informa de factos… ENSINA a fazer 📋", "icon": "📋" },
  { "title": "5. Resposta", "body": "é um texto INSTRUCIONAL — uma receita! ✅", "icon": "✅" }
]
```

> **Truque:** faz sempre **a pergunta mágica** ao texto: *«Tu queres CONTAR, DESCREVER, INFORMAR, ENSINAR A FAZER ou CONVENCER?»* A resposta diz-te logo o tipo! 🪄

> [!TIP] **Para saberes mais** 🌱 Um mesmo texto pode **misturar** tipos! Por exemplo, dentro de um **conto** (narrativo) o autor pode parar para **descrever** o castelo onde mora o rei (descritivo). A isto chamamos **sequências**: o texto é narrativo, mas tem uma *sequência descritiva* lá dentro. Os escritores fazem isto para a história ficar mais viva! ✨
