# Classes de palavras 🧩

> [!NOTE] **O que vais aprender** 👀 Que todas as palavras vivem arrumadas em **classes** (como brinquedos em caixas). Vais reconhecer **nome, adjetivo, verbo, determinante, quantificador, pronome, advérbio, preposição, conjunção e interjeição** — e descobrir a classe de cada palavra dentro de uma frase. 🕵️🗄️

No 1.º ciclo já abriste algumas gavetas. Agora, no 5.º ano, abres a **casa toda**: há dez classes de palavras, e quando aprendes a olhar para uma palavra e a pôr na gaveta certa, a gramática deixa de ser um bicho-de-sete-cabeças. Vamos a isto! ✨

## Variável ou invariável? 🔀

Há um truque enorme para arrumar as classes: ver se a palavra **muda** (singular/plural, masculino/feminino) ou fica **sempre igual**.

```compare
[
  { "title": "Variáveis (mudam) 🔁", "rows": [
    { "label": "Quais", "value": "nome, adjetivo, verbo, determinante, quantificador, pronome" },
    { "label": "Exemplo", "value": "gato → gatos · bonito → bonita 🐱", "highlight": true }
  ] },
  { "title": "Invariáveis (não mudam) 🚫", "rows": [
    { "label": "Quais", "value": "advérbio, preposição, conjunção, interjeição" },
    { "label": "Exemplo", "value": "'depressa' e 'com' são sempre iguais 🧊", "highlight": true }
  ] }
]
```

> [!NOTE] Cuidado com uma confusão clássica! O **quantificador numeral** diz *quantos* (**três** gatos), enquanto o **determinante** apenas *apresenta* (**os** gatos). E o **advérbio de quantidade** liga-se a um adjetivo ou verbo: «o gato é **muito** bonito». Lê sempre a frase toda para decidir. 🤓

## Um exemplo passo a passo 🔍

Vamos analisar esta frase: **«Ui! O cão preto corre depressa para casa.»** Resolve comigo, palavra a palavra. 🐶

```steps
[
  { "title": "1. 'Ui!'", "body": "exprime uma emoção, está sozinha → interjeição 😲", "icon": "😲" },
  { "title": "2. 'O'", "body": "apresenta o nome 'cão' → determinante (artigo) 🔤", "icon": "🔤" },
  { "title": "3. 'cão'", "body": "dá nome a um animal → nome 🐶", "icon": "🐶" },
  { "title": "4. 'preto'", "body": "diz COMO é o cão → adjetivo 🎨", "icon": "🎨" },
  { "title": "5. 'corre'", "body": "mostra a ação → verbo 🏃", "icon": "🏃" },
  { "title": "6. 'depressa'", "body": "diz COMO ele corre → advérbio 💨", "icon": "💨" },
  { "title": "7. 'para'", "body": "liga 'corre' a 'casa' → preposição 🔗", "icon": "🔗" }
]
```

> **Truque das perguntas:** faz uma pergunta à palavra! **Dá um nome?** → nome. **Mostra ação?** → verbo. **Descreve?** → adjetivo. **Diz quantos?** → quantificador. **Liga duas frases?** → conjunção. **Liga duas palavras?** → preposição. **Salta sozinha com emoção?** → interjeição. 🕵️


> [!TIP] **Para saberes mais** 🌱 A mesma palavra pode mudar de classe conforme a frase! «**Cantar**» é verbo em «gosto de **cantar**», mas é nome em «o **cantar** dos pássaros». E «**que**» é um camaleão: pronome relativo em «o livro **que** li», conjunção em «disse **que** vinha» e até interjeição em «**Que** lindo!». A classe depende sempre da **função na frase** — por isso lê tudo antes de decidir. 🦎
