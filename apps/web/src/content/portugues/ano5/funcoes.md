# Funções sintáticas 🔗

> [!NOTE] **O que vais aprender** 👀 Que numa frase cada grupo de palavras tem um **papel** — uma **função sintática**. Vais aprender a encontrar o **sujeito** (quem faz), o **predicado** (a ação) e os **complementos** (direto, indireto) — e o truque das perguntas para nunca te enganares. 🕵️🔗

Atenção, que isto é diferente das classes! A **classe** diz o que uma palavra **é** (nome, verbo…). A **função sintática** diz o **papel** que ela representa **dentro da frase** — como num teatro: a mesma palavra pode fazer de sujeito numa peça e de complemento noutra. Luz, câmara, ação! 🎬

## Encontrar o sujeito: o truque infalível 🔑

Para descobrir o sujeito, faz a pergunta **«Quem é que…?»** junto ao verbo. A resposta é o sujeito!

```steps
[
  { "title": "Frase", "body": "'Os meninos jogaram à bola.' ⚽", "icon": "⚽" },
  { "title": "Pergunta ao verbo", "body": "Quem é que jogaram? 🤔", "icon": "🤔" },
  { "title": "Resposta = sujeito", "body": "'Os meninos' → é o sujeito! 🦸", "icon": "🦸" }
]
```

> [!NOTE] Há um sujeito escondido! Em «**Fomos** ao cinema», ninguém diz «nós», mas o verbo já o indica: é o **sujeito subentendido** (ou nulo). E o sujeito até pode ser **vários**: em «O Rui **e** a Lia chegaram», o sujeito composto é «O Rui e a Lia». 🕵️

## Os complementos do verbo 🧩

Muitas vezes o verbo precisa de companhia para a frase fazer sentido. Essa companhia são os **complementos**.

Esta é a estrela dos testes do 5.º ano. O segredo está mesmo na pergunta que fazes ao verbo.

## Um exemplo passo a passo 🔍

Vamos analisar a frase toda: **«A avó ofereceu um livro ao neto.»** Encontra cada função comigo. 👵📖

```steps
[
  { "title": "1. Acha o verbo", "body": "qual é a ação? 'ofereceu' 🎁", "icon": "🎁" },
  { "title": "2. Acha o sujeito", "body": "Quem é que ofereceu? → 'A avó' (sujeito) 👵", "icon": "👵" },
  { "title": "3. Acha o predicado", "body": "tudo à volta do verbo: 'ofereceu um livro ao neto' 🏃", "icon": "🏃" },
  { "title": "4. Complemento direto", "body": "ofereceu o quê? → 'um livro' (sem preposição) 📖", "icon": "📖" },
  { "title": "5. Complemento indireto", "body": "ofereceu a quem? → 'ao neto' (com 'a') 👦", "icon": "👦" }
]
```

> **Truque de ouro:** faz duas perguntas ao verbo. Se a resposta vem **sem preposição** («o quê?»), é **complemento direto**. Se a resposta leva **a / ao / à** («a quem?»), é **complemento indireto**. O «a» é o crachá do indireto! 🏷️

> [!TIP] **Para saberes mais** 🌱 Nem todas as frases têm sujeito! Há as **frases impessoais**, em que ninguém faz a ação: «**Choveu** toda a noite» ou «**Há** muitos livros». O verbo **haver** (no sentido de existir) e os verbos do tempo (chover, nevar, trovejar) ficam sempre na 3.ª pessoa do singular e **não têm sujeito** nenhum. A chuva cai… mas não há "quem" a fazer cair! 🌧️
