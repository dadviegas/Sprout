# Escrever uma narrativa ✍️

> [!NOTE] **O que vais aprender** 👀 Como **inventar e escrever** a tua própria história: dar-lhe **começo, meio e fim**, criar personagens, ligar as frases com **conectores**, usar o **diálogo** e fazer uma **revisão** para a deixar brilhante. ✍️✨

Toda a gente tem histórias na cabeça — o difícil é pô-las no papel de forma que os outros gostem de ler. Boa notícia: há uma **receita**. Segue-a e qualquer ideia se transforma numa narrativa a sério. Vamos escrever a tua! 🖊️📖

## A receita da história 🍳

Antes de escreveres a primeira palavra, decide os **ingredientes**. É como preparar tudo antes de cozinhar.

```keyvalue
[
  { "k": "Personagens", "v": "quem? Dá-lhes nome e um feitio: 'a Lia, curiosa e destemida' 🧒" },
  { "k": "Espaço", "v": "onde? Uma floresta, uma escola assombrada, uma nave 🌌" },
  { "k": "Tempo", "v": "quando? De noite, no Verão, há mil anos ⏰" },
  { "k": "Problema", "v": "o quê? Sem problema não há história! Um tesouro perdido, um amigo em apuros 🗝️" }
]
```

## A estrutura: começo, meio e fim 🛤️

Agora arruma os acontecimentos por esta ordem. É o esqueleto de quase todas as histórias do mundo.

```steps
[
  { "title": "Introdução", "body": "apresenta as personagens, o espaço e o tempo, em calma 🌅", "icon": "🌅" },
  { "title": "Desenvolvimento", "body": "surge o problema e as aventuras para o resolver 🎢", "icon": "🎢" },
  { "title": "Conclusão", "body": "o problema resolve-se e a história fecha 🏁", "icon": "🏁" }
]
```

## Cola as frases com conectores 🔗

Uma história não é uma lista de frases soltas. Os **conectores** são a cola que liga tudo e mostra a ordem e as causas.

```keyvalue
[
  { "k": "Para começar", "v": "Era uma vez… · Há muito tempo… · Certo dia… 🌅" },
  { "k": "Para continuar", "v": "Depois… · De repente… · Entretanto… · Mais tarde… ➡️" },
  { "k": "Para mostrar causa", "v": "porque… · por isso… · então… ⚡" },
  { "k": "Para terminar", "v": "Por fim… · Finalmente… · E foram felizes… 🏁" }
]
```

> [!NOTE] Para a história não ficar repetida e sem graça, troca o verbo **«disse»** por outros mais vivos no diálogo: «**gritou**», «**sussurrou**», «**perguntou**», «**respondeu»**, «**exclamou»**. E usa **adjetivos** para pintares as cenas: não é só «uma casa», é «uma casa **velha e escura**». 🎨

## Quando as personagens falam: o diálogo 💬

Em português, a fala das personagens marca-se com **travessão** (—) e muda-se de linha sempre que fala outra pessoa.

```compare
[
  { "title": "Sem diálogo (conta) 📄", "rows": [
    { "label": "Como fica", "value": "A Lia perguntou ao avô se podia ir à gruta e ele disse que sim." }
  ] },
  { "title": "Com diálogo (mostra) 💬", "rows": [
    { "label": "Como fica", "value": "— Avô, posso ir à gruta? — perguntou a Lia. — Podes, mas tem cuidado — respondeu ele.", "highlight": true }
  ] }
]
```

## Um exemplo passo a passo 🔍

*«Escreve uma pequena história a partir desta ideia: um menino encontra um ovo estranho no jardim.»* Vamos construí-la juntos, tijolo a tijolo. 🥚

```steps
[
  { "title": "1. Decide os ingredientes", "body": "o Rui (curioso) · no jardim da avó · numa manhã de Verão · acha um ovo dourado 🥚" },
  { "title": "2. Introdução", "body": "'Naquela manhã, o Rui brincava no jardim da avó quando viu algo a brilhar entre as folhas…' 🌅" },
  { "title": "3. Desenvolvimento (problema!)", "body": "'De repente, o ovo abriu-se e de lá saiu um pequeno dragão assustado. Como o esconder?' ⚡🐉" },
  { "title": "4. Conclusão", "body": "'Por fim, o Rui criou o dragão em segredo e ganhou o amigo mais incrível do mundo.' 🏁" },
  { "title": "5. Revê e melhora", "body": "leio em voz alta, corrijo erros e troco 'disse' por 'exclamou' 🔎" }
]
```

> **Truque do escritor:** segue sempre a regra **«Q.Q.Q.»** — **Q**uem? **Q**uando e onde? **Q**ual o problema? Se respondes a estas três antes de escrever, a tua história já tem esqueleto e não te perdes a meio. 🦴

## Revê antes de entregar ✏️

Escrever é reescrever! Nenhum bom texto sai perfeito à primeira. Passa por esta lista antes de dares por terminado.

```steps
[
  { "title": "Lê em voz alta", "body": "se tropeças a ler, a frase precisa de ser arranjada 🗣️", "icon": "🗣️" },
  { "title": "Tem começo, meio e fim?", "body": "confirma que apresentas, complicas e resolves ✅", "icon": "✅" },
  { "title": "Caça os erros", "body": "ortografia, acentos e pontuação (e os pontos finais!) 🐛", "icon": "🔎" },
  { "title": "Evita repetições", "body": "troca palavras repetidas por sinónimos 🔁", "icon": "🔁" }
]
```

> [!TIP] **Para saberes mais** 🌱 Os escritores a sério chamam **«rascunho»** à primeira versão — e ela quase nunca presta! O segredo não é escrever bem à primeira; é **reescrever** muitas vezes. Diz-se que a autora de *Harry Potter* reescreveu o primeiro capítulo **quinze vezes**. Por isso, não tenhas medo de riscar e mudar: é assim que se faz uma boa história. ✏️🔁
