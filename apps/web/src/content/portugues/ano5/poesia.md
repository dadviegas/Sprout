# O texto poético 🎵

> [!NOTE] **O que vais aprender** 👀 O que faz de um texto um **poema**: os **versos** e as **estrofes**, a **rima** e o **ritmo**, e as imagens mágicas que os poetas usam — a **comparação** e a **metáfora**. No fim, vais saber ler (e até inventar!) poesia. 🎵✨

A poesia é a música feita de palavras. Em vez de contar uma história seguida, o poema **canta**, **brinca com os sons** e pinta imagens na tua cabeça. Cada palavra está ali de propósito, escolhida a dedo. Vamos descobrir os seus segredos! 🎶

## Versos e estrofes: as peças do poema 🧱

Um poema não se escreve em linhas seguidas como um conto. Constrói-se com **versos** e **estrofes**.

## Os sons que combinam: a rima 🎶

A **rima** acontece quando os finais dos versos têm o **mesmo som**. É ela que dá a musicalidade.

```keyvalue
[
  { "k": "Rima", "v": "sons iguais no fim dos versos: 'lua' ↔ 'sua', 'mar' ↔ 'luar' 🌙" },
  { "k": "Verso solto (branco)", "v": "um verso que NÃO rima com nenhum 🆓" },
  { "k": "Ritmo", "v": "a batida do poema, como o tum-tum de uma música 🥁" }
]
```

> [!NOTE] Para descobrires o esquema da rima, marca com **letras** os versos que rimam: os que têm o mesmo som levam a mesma letra. Se o 1.º rima com o 3.º (A) e o 2.º com o 4.º (B), o esquema é **ABAB** — rima cruzada! Se for AABB, é rima emparelhada. 🔤

```steps
  { "title": "3. Procura a rima", "body": "'tocar' rima com 'mar' (verso 2 e 4) 🎶", "icon": "🎶" },
  { "title": "4. Imagem poética", "body": "'A lua É uma bola' → é uma metáfora! ✨", "icon": "✨" },

```

> **Truque comparação vs. metáfora:** procura a palavra **«como»**! Se ela está lá ('forte **como** um leão'), é **comparação**. Se não está e diz que uma coisa **é** mesmo outra ('és um leão'), é **metáfora**. O «como» é a ponte que distingue as duas. 🌉

> [!TIP] **Para saberes mais** 🌱 Quando o poeta dá **vida** a coisas que não estão vivas, isso chama-se **personificação**: «O vento **assobiava**», «As estrelas **piscavam o olho**», «A cidade **dormia**». Os ventos não assobiam e as cidades não dormem — mas o poeta finge que sim para a imagem ganhar magia! É um dos recursos mais bonitos da poesia. 🌬️😴
