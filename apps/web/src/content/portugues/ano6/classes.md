# Classes de palavras (II) 🧩

> [!NOTE] **O que vais aprender** 👀 A dominar as classes mais traiçoeiras: **determinantes** (que apresentam o nome), **pronomes** (que o substituem), **preposições** (que ligam palavras) e **conjunções** (que ligam frases). Vais aprender os seus **subtipos** e a não trocar pronome com determinante — o erro campeão do 6.º ano! 🕵️🗄️

No 5.º ano arrumaste as dez classes de palavras nas gavetas certas. Agora, no 6.º, abres cada gaveta e vês que **dentro há gavetinhas**! Cada classe tem subtipos. Parece muito, mas vais ver que há um truque para cada confusão. Vamos lá! ✨

## Determinantes: quem apresenta o nome 🔤

O determinante vem **antes** do nome e ajuda a apresentá-lo. Há vários subtipos — todos pequenos, todos úteis.

```keyvalue
[
  { "k": "Artigo definido", "v": "o, a, os, as — algo já conhecido: 'O cão ladrou' 🐶" },
  { "k": "Artigo indefinido", "v": "um, uma, uns, umas — algo novo: 'Vi um cão' 🆕" },
  { "k": "Demonstrativo", "v": "este, esse, aquele — mostra onde está: 'aquele livro' 👉" },
  { "k": "Possessivo", "v": "meu, teu, nosso — diz de quem é: 'a minha bola' 🎒" }
]
```

## Pronomes: quem substitui o nome 👧

O pronome **ocupa o lugar** do nome para não o repetir. Cuidado: muitas palavras parecem-se com determinantes!

```keyvalue
[
  { "k": "Pronome pessoal", "v": "eu, tu, ele, nós, me, te, o, a, lhe — 'A Rita corre. Ela voa!' 🏃" },
  { "k": "Pronome possessivo", "v": "o meu, o teu, o nosso — 'A bola é minha' 🎯" },
  { "k": "Pronome demonstrativo", "v": "este, isto, aquilo — 'Quero aquele, não este' 👆" },
  { "k": "Pronome indefinido", "v": "alguém, ninguém, tudo, nada — 'Alguém bateu à porta' 🚪" }
]
```

> [!NOTE] **A grande confusão: determinante OU pronome?** A mesma palavra muda de classe! Se vem **antes de um nome** e o apresenta, é **determinante** («**a minha** *bola*»). Se está **sozinha**, no lugar do nome, é **pronome** («a bola é **minha**»). **Truque:** se podes apagar a palavra a seguir e a frase continua a fazer sentido, era um nome — logo, era determinante. 🔍

## Preposições e conjunções: as palavras-cola 🔗

Estas duas classes são **invariáveis** (nunca mudam) e servem para **ligar**. A diferença é o que ligam.

```compare
[
  { "title": "Preposição 🔗 (liga palavras)", "rows": [
    { "label": "O que liga", "value": "uma palavra a outra, dentro da frase" },
    { "label": "Quais", "value": "de, em, com, para, por, a, sem, sobre", "highlight": true },
    { "label": "Exemplo", "value": "'o livro DE histórias' 📖" }
  ] },
  { "title": "Conjunção 🪢 (liga frases)", "rows": [
    { "label": "O que liga", "value": "uma frase a outra (ou palavras semelhantes)" },
    { "label": "Quais", "value": "e, mas, ou, porque, quando, se, embora", "highlight": true },
    { "label": "Exemplo", "value": "'fiquei em casa PORQUE chovia' 🌧️" }
  ] }
]
```

> **Truque da cola 🪢:** pergunta — **o que é que esta palavra está a colar?** Se cola **duas palavras** («pão **com** manteiga»), é **preposição**. Se cola **duas frases inteiras** («saí **mas** voltei»), é **conjunção**. Conjunção = liga frases; preposição = liga palavras. 🧠

## Contrações: quando a preposição se cola 🤝

Às vezes uma preposição funde-se com um determinante e nasce uma palavra nova — é uma **contração**!

```math
{ "expr": "de + o = do        em + a = na        a + os = aos", "say": "de mais o dá do; em mais a dá na; a mais os dá aos" }
```

> [!TIP] **Para saberes mais** 🌱 Os pronomes pessoais também têm **funções diferentes** consoante o lugar na frase! Em «**Eu** vi o João», o «eu» é quem faz a ação (sujeito). Em «O João viu-**me**», o «me» é quem recebe a ação (complemento). Por isso dizemos «eu» mas «deu-**mo** a mim» — são formas do mesmo pronome, conforme o trabalho que fazem na frase. No 3.º ciclo vais arrumar isto tudo em pronomes *retos* e *oblíquos*. Já estás a espreitar o futuro! 🔮
