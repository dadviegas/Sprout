# Texto descritivo e narrativo 🖼️

> [!NOTE] **O que vais aprender** 👀 A diferença entre **descrever** (pintar um retrato com palavras 🖼️) e **narrar** (contar o que acontece, passo a passo 🎬). Vais conhecer os **elementos da narrativa** (narrador, personagens, espaço, tempo, ação), a **estrutura** (início, desenvolvimento, conclusão) e os truques para tornar um texto **vivo**. ✍️✨

No 5.º ano já contaste histórias. Agora, no 6.º, vais ser um verdadeiro **realizador de cinema com palavras**: ora paras a câmara para mostrares um cenário em pormenor (descrição), ora a pões a andar para a história avançar (narração). Os melhores textos misturam as duas com mestria. 🎥

## Descrever ou narrar? 🔍

Pensa assim: a **descrição** é uma **fotografia** (tudo parado, cheia de pormenores) e a **narração** é um **filme** (acontece algo, há movimento e tempo a passar).

## Os cinco elementos da narrativa 🧩

Toda a história, das mais simples às mais famosas, tem estes cinco ingredientes. Faltar um e a história fica coxa!

```keyvalue
[
  { "k": "Narrador", "v": "quem conta a história (pode estar dentro ou fora dela) 🎙️" },
  { "k": "Personagens", "v": "quem vive a história: principais e secundárias 👥" },
  { "k": "Espaço", "v": "ONDE acontece: a floresta, a escola, um planeta 🗺️" },
  { "k": "Tempo", "v": "QUANDO acontece: de manhã, há muito tempo, no inverno ⏰" },
  { "k": "Ação", "v": "O QUE acontece: a sequência de acontecimentos 🎬" }
]
```

> [!NOTE] **Narrador participante ou não participante?** Se o narrador é uma personagem e fala em **«eu»** («**Eu** abri a porta»), é **participante**. Se conta de fora, em **«ele/ela»** («**Ela** abriu a porta») e sabe tudo, é **não participante** (e muitas vezes **omnisciente** — sabe até o que as personagens pensam!). 🧠

## A estrutura: começo, meio e fim 📐

Uma narrativa bem construída tem três momentos. É como uma montanha-russa: subida, descida vertiginosa e travagem suave. 🎢

## Descrever com cor: o truque dos sentidos 👃👂

Uma boa descrição não diz só o que se **vê** — usa os **cinco sentidos** para o leitor quase poder tocar na cena.

```steps
[
  { "title": "Visão 👁️", "body": "«O mar era de um azul brilhante.»" },
  { "title": "Audição 👂", "body": "«Ouvia-se o sussurro das ondas.»" },
  { "title": "Olfato 👃", "body": "«Cheirava a sal e a maresia.»" },
  { "title": "Tato ✋", "body": "«A areia quente queimava os pés.»" },
  { "title": "Paladar 👅", "body": "«Sentia o gosto salgado nos lábios.»" }
]
```

> **Truque do realizador 🎬:** antes de escreveres, pergunta-te — **«estou a parar para mostrar ou estou a fazer a história andar?»** Se estás a mostrar (cores, cheiros, como é), estás a **descrever**: usa adjetivos. Se estás a fazer andar (e depois… e então…), estás a **narrar**: usa verbos de ação e palavras de tempo. 🕵️

> [!TIP] **Para saberes mais** 🌱 Os escritores usam um truque chamado **«mostrar em vez de contar»** (*show, don't tell*). Em vez de **contar** «o João estava nervoso», **mostram**: «as mãos do João tremiam e ele não parava de olhar para o relógio». O leitor descobre sozinho a emoção — e fica muito mais dentro da história. É a diferença entre alguém te dizer que um gelado é bom e tu provares! 🍦
