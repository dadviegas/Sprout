# Nome, grau e flexão 🔤

> [!NOTE] **O que vais aprender** 👀 Que o **nome** (substantivo) muda de forma — em **género** (masculino/feminino), **número** (singular/plural) e **grau** (normal, aumentativo, diminutivo). Vais conhecer os **subtipos** de nome (comum, próprio, coletivo) e os plurais e femininos que pregam partidas! 🔤🐱

O nome dá nome a tudo o que existe: pessoas, animais, coisas, lugares e até sentimentos. Mas o nome é um **transformista**: muda de roupa conforme o género, o número e o grau. No 6.º ano vais dominar essas transformações — até as mais traiçoeiras! ✨

## Os tipos de nome 🗂️

Antes de mudar de forma, o nome tem **família**. Há quatro subtipos importantes.

> [!NOTE] **Nome coletivo** é magia: uma só palavra que já é um grupo! Um **cardume** é muitos peixes, um **rebanho** são muitas ovelhas, uma **alcateia** são muitos lobos. Não precisas de dizer «grupo de» — a palavra já o diz sozinha. 🐺

## Flexão em número: singular ↔ plural 🔢

Quase sempre juntas um **-s**. Mas as palavras terminadas em **-l, -ão, -m** têm regras próprias!

```keyvalue
[
  { "k": "Regra geral: +s", "v": "livro → livros · casa → casas 📚" },
  { "k": "Termina em -l: -l vira -is", "v": "animal → animais · papel → papéis 🐾" },
  { "k": "Termina em -m: -m vira -ns", "v": "homem → homens · jardim → jardins 🌳" },
  { "k": "Termina em -ão: 3 caminhos", "v": "pão → pães · mão → mãos · balão → balões 🎈" }
]
```

> **Truque dos plurais em -ÃO 🎈:** estes são os mais traiçoeiros! Decora um exemplo de cada caminho — **pão → pães**, **mão → mãos**, **balão → balões**. A maioria faz **-ões** (a mais comum), mas há o grupo do **-ães** e o do **-ãos**. Na dúvida, lê alto e ouve qual soa bem! 👂

> [!TIP] **Para saberes mais** 🌱 Há nomes que parecem mudar de género mas mudam de **significado**! «O **rádio**» (o aparelho) e «a **rádio**» (a estação que emite) não são a mesma coisa. «O **cabeça**» (o chefe) e «a **cabeça**» (a parte do corpo) também não! Estes pares chamam-se **homónimos de género** — pequenas armadilhas que mostram como uma só letra muda tudo. Lê sempre a frase para saberes de qual se fala! 🎯
