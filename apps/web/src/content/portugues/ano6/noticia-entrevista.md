# Notícia e entrevista 📰

> [!NOTE] **O que vais aprender** 👀 Como se constrói uma **notícia** (o título, o lead e o corpo) e quem responde sempre às **6 perguntas mágicas**; e como se faz uma **entrevista** — preparar boas perguntas, ouvir e escrever as respostas. Vais distinguir **facto** de **opinião** como um verdadeiro jornalista! 🗞️🎤

Os jornalistas são os contadores da verdade do mundo. Quando lês uma notícia, alguém saiu à rua, viu, perguntou e escreveu para tu saberes. No 6.º ano vais aprender a ler — e a escrever — como gente do ofício. Pega no bloco de notas! ✏️

## As 6 perguntas mágicas 🔮

Toda a boa notícia responde a seis perguntas. Se faltar uma, fica um buraco na história. Os jornalistas chamam-lhes os **«6 Quês»**.

```keyvalue
[
  { "k": "Quê?", "v": "o que aconteceu — o acontecimento 🎯" },
  { "k": "Quem?", "v": "as pessoas envolvidas 👥" },
  { "k": "Quando?", "v": "o dia, a hora, o momento ⏰" },
  { "k": "Onde?", "v": "o lugar 🗺️" },
  { "k": "Como?", "v": "de que maneira aconteceu 🔧" },
  { "k": "Porquê?", "v": "a causa, a razão ❓" }
]
```

> **Truque das 6 perguntas 🔮:** decora-as como uma lengalenga — **«Quê, Quem, Quando, Onde, Como, Porquê»**. Antes de entregares qualquer notícia, faz-lhe estas seis perguntas. Se respondes a todas, está completa! ✅

## As partes de uma notícia 🧩

A notícia tem uma forma muito certinha. Pensa numa **pirâmide invertida**: o mais importante vem logo no topo, e os pormenores ficam para o fim.

## Facto ou opinião? ⚖️

Esta é a regra de ouro do jornalismo. A notícia conta **factos** (que se podem verificar); a opinião é o que alguém **acha** (e pode mudar de pessoa para pessoa).

```compare
[
  { "title": "Facto ✅ (verifica-se)", "rows": [
    { "label": "O que é", "value": "algo que aconteceu e se prova" },
    { "label": "Exemplo", "value": "«Choveu 30 mm em Lisboa ontem.» 🌧️", "highlight": true }
  ] },
  { "title": "Opinião 💭 (depende de quem fala)", "rows": [
    { "label": "O que é", "value": "o que alguém pensa ou sente" },
    { "label": "Exemplo", "value": "«O dia de ontem foi horrível.» 😒", "highlight": true }
  ] }
]
```

> [!NOTE] Numa notícia, o jornalista deve manter-se **imparcial**: conta os factos sem dizer de que lado está. As opiniões aparecem noutro lugar — nos **artigos de opinião** ou **editoriais** —, sempre bem identificadas. Confundir os dois é o erro número um do mau jornalismo! 🤓

## A entrevista: perguntar bem 🎤

Numa entrevista, um jornalista (**entrevistador**) faz perguntas a alguém (**entrevistado**) para descobrir factos, histórias ou opiniões. O segredo está nas **boas perguntas**.

```steps
[
  { "title": "1. Antes", "body": "estuda o tema e prepara perguntas claras 📚", "icon": "📚" },
  { "title": "2. Pergunta aberta", "body": "começa por 'Como…?', 'Porquê…?' — dá respostas ricas 💬", "icon": "💬" },
  { "title": "3. Escuta", "body": "ouve com atenção e faz perguntas a partir do que ouves 👂", "icon": "👂" },
  { "title": "4. Regista", "body": "anota (ou grava) e escreve com pergunta–resposta 📝", "icon": "📝" }
]
```

> **Truque das perguntas abertas 🔓:** evita perguntas que só dão **«sim» ou «não»**. Em vez de «Gostaste?», pergunta «**O que** mais gostaste e **porquê**?». As perguntas abertas (com *o quê, como, porquê*) abrem a porta a respostas grandes e interessantes! 🚪

## Um exemplo passo a passo 🔍

Vamos transformar uns apontamentos soltos numa notícia em condições. 🗞️

```steps
[
  { "title": "1. Apontamentos", "body": "Sábado · biblioteca da escola · clube de leitura · 40 crianças · ler em voz alta 📒" },
  { "title": "2. Responde aos 6 Quês", "body": "Quê: maratona de leitura · Quem: 40 alunos · Quando: sábado · Onde: biblioteca · Como: em voz alta · Porquê: festa do livro 🔮" },
  { "title": "3. Escreve o título", "body": "«Quarenta crianças leem sem parar na festa do livro» 📰" },
  { "title": "4. Escreve o lead", "body": "«No sábado, 40 alunos juntaram-se na biblioteca da escola para uma maratona de leitura em voz alta.» ⭐" },
  { "title": "5. Notícia pronta!", "body": "Título + lead + corpo com os pormenores = notícia completa ✅" }
]
```

> [!TIP] **Para saberes mais** 🌱 Já ouviste falar de **fake news** (notícias falsas)? São histórias inventadas que parecem verdadeiras e enganam as pessoas, espalhando-se a toda a velocidade na internet. Os jornalistas a sério **verificam tudo em pelo menos duas fontes** antes de publicar. Tu também podes ser detetive: pergunta sempre **«quem disse isto? onde está a prova?»** antes de acreditares — e antes de partilhares! 🕵️📱
