# Poesia e recursos expressivos ✨

> [!NOTE] **O que vais aprender** 👀 Que a poesia é uma forma especial de usar as palavras — com **versos**, **estrofes** e **rima** — e que os **recursos expressivos** (a **comparação**, a **metáfora**, a **personificação**, a **enumeração** e a **onomatopeia**) são os truques de magia que dão cor às palavras. ✨🎩

A poesia é a língua a brincar! Os poetas torcem e enfeitam as palavras para te fazerem **sentir** coisas — e usam ferramentas mágicas chamadas **recursos expressivos**. No 6.º ano vais aprender a reconhecê-las e a usá-las tu mesmo. Vais ver como uma frase normal se transforma em poesia! 🪄

## Os recursos expressivos: a magia das palavras 🎩

Aqui estão os truques que tornam um texto poético. Lê com atenção — vais usá-los muito!

```compare
    { "label": "Exemplo", "value": "'Forte COMO um leão' 🦁", "highlight": true }
  ] },
  { "title": "Metáfora 🎭", "rows": [
    { "label": "O que faz", "value": "compara SEM ligação — diz que uma coisa É outra" },
    { "label": "Exemplo", "value": "'Os teus olhos SÃO duas estrelas' ⭐", "highlight": true }
  ] }
]
```

> **Truque da palavra 'como' 🔑:** a diferença entre comparação e metáfora está numa palavrinha! Se vês **«como», «tal como», «parece»** → é **comparação** («corre **como** o vento»). Se a coisa **é diretamente** a outra, sem «como» → é **metáfora** («ele **é** um vento a correr»). Procura o «como»: aí está a chave! 🗝️

> [!NOTE] **Personificação** é dar a coisas e animais aquilo que só as pessoas fazem: falar, sorrir, chorar, pensar. Quando lês «as ondas **dançavam**» ou «o relógio **gritou** as horas», o poeta está a usar personificação — as ondas não dançam mesmo, mas a imagem fica linda! Procura sempre **uma ação humana** dada a algo que não é humano. 🌊💃

> [!TIP] **Para saberes mais** 🌱 Há recursos baseados só no **som** das palavras! A **aliteração** repete o mesmo som consoante para criar um efeito: «O **r**ato **r**oeu a **r**olha» — ouves o «rrr» a roer? E a **assonância** repete vogais: «**Ó** f**o**rmas**a** Mari**a**». Os poetas usam estes sons de propósito — para a poesia *soar* a chuva, a vento, a galope de cavalo. A poesia não é só para ler com os olhos: é para **ouvir** com os ouvidos! 👂🎶
