# A frase e as suas funções 🔗

> [!NOTE] **O que vais aprender** 👀 Que dentro de cada frase há **personagens com funções**: o **sujeito** (quem faz/de quem se fala), o **predicado** (o que se diz dele), o **complemento direto** e o **complemento indireto**. Vais aprender a fazer **perguntas** para encontrar cada função — como um detetive da gramática! 🕵️🔍

Uma frase não é uma fila de palavras à toa: é uma pequena equipa, e cada palavra tem um **trabalho** (uma função). Quando descobres quem faz o quê, percebes a frase por dentro — e escreves muito melhor. No 6.º ano vais ser o **chefe da equipa**! 👔

## As duas grandes peças: sujeito e predicado 🧩

Toda a frase tem duas partes. Encontra primeiro o **verbo** — ele é a chave que abre tudo!

```compare
  ] },
  { "title": "Predicado 🎬 (o que se diz)", "rows": [
    { "label": "O que é", "value": "o verbo e tudo o que se diz do sujeito" },

```

> **Truque da chave 🔑:** encontra primeiro o **verbo**. Depois pergunta **«Quem é que [verbo]?»** — a resposta é o **sujeito**. Tudo o resto, à volta do verbo, é o **predicado**. Com este truque nunca mais te enganas! 🗝️

## Dentro do predicado: os complementos 🎯

O verbo, muitas vezes, precisa de companhia para a frase fazer sentido. Essa companhia são os **complementos**.

```keyvalue
[
  { "k": "Complemento direto (CD)", "v": "recebe a ação diretamente, sem preposição. Pergunta: 'o quê?' / 'quem?' → 'Comi A SOPA' 🍲" },
  { "k": "Complemento indireto (CI)", "v": "a quem se destina a ação, com preposição 'a'. Pergunta: 'a quem?' → 'Dei o livro AO PEDRO' 🎁" }
]
```

> [!NOTE] **CD ou CI?** O truque está na **preposição**. O complemento direto cola-se ao verbo **sem preposição** («vi **o filme**»). O complemento indireto vem quase sempre com **«a»** e responde a **«a quem?»** («dei um presente **ao avô**»). Substituição esperta: o CD troca-se por **o/a/os/as** («vi-**o**») e o CI por **lhe/lhes** («dei-**lhe**»). 🧠

> [!TIP] **Para saberes mais** 🌱 Nem todas as frases têm sujeito! As **frases impessoais** falam de fenómenos da natureza ou usam verbos como «haver» a indicar existência — e **não há ninguém** a fazer a ação. «**Chove** muito», «**Há** três livros na mesa», «**Faz** frio» não têm sujeito nenhum — chamam-se frases de **sujeito nulo impessoal**. Por isso é errado dizer «*houveram* muitos jogos»: como não há sujeito, o verbo fica sempre no singular — «**houve** muitos jogos»! ⛅
