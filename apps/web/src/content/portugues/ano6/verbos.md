# Conjugar verbos ⏳

> [!NOTE] **O que vais aprender** 👀 A conjugar verbos como um campeão: as **três conjugações** (-ar, -er, -ir), os **tempos** do indicativo (presente, pretéritos e futuro), o **modo imperativo** (dar ordens) e os **verbos irregulares** mais teimosos (ser, ir, ter, fazer). E vais conhecer as **formas nominais** — infinitivo, gerúndio e particípio. ⏳🏃

No 5.º ano já viste que o verbo é um **camaleão** que muda de cor conforme o tempo, a pessoa e o modo. No 6.º vais ficar mesmo bom: vais arrumar os tempos todos do indicativo, dar ordens com o imperativo e domar os verbos rebeldes que não seguem as regras. Vamos treinar! 💪

> [!NOTE] **Perfeito vs. imperfeito**, a dúvida campeã! O **perfeito** é uma ação fechada: «**joguei** ontem». O **imperfeito** durava ou era hábito: «**jogava** todos os dias». **Truque:** se cabe «costumava», é imperfeito. Se cabe «de repente», é perfeito. 🎯

## O imperativo: dar ordens 📢

O **modo imperativo** serve para **mandar, pedir ou aconselhar**. Só existe para «tu», «você», «nós» e «vós» — não há «eu» a dar ordens a si mesmo!

## Verbos irregulares: os rebeldes 🤠

A maioria dos verbos segue um molde certinho (são **regulares**). Mas alguns mudam o radical e fogem às regras — são os **irregulares**. Os mais usados são logo os mais rebeldes!

```keyvalue
[
  { "k": "SER", "v": "eu sou, tu és, ele é, nós somos… (no passado: fui, foste, foi) 🦋" },
  { "k": "IR", "v": "eu vou, tu vais, ele vai… (passado: fui, foste, foi — igual a ser!) 🚀" },
  { "k": "TER", "v": "eu tenho, tu tens, ele tem, nós temos 🤲" },
  { "k": "FAZER", "v": "eu faço, tu fazes (passado: fiz, fizeste, fez) 🔨" }
]
```

> **Truque do 'ser' e 'ir' gémeos 👯:** no pretérito perfeito, **ser** e **ir** são exatamente iguais — «**fui**, foste, foi»! Como saber qual é? Pela frase: «**Fui** à praia» é *ir* (um lugar); «**Fui** o vencedor» é *ser* (uma qualidade). O contexto desfaz a confusão! 🏖️🏆

> [!TIP] **Para saberes mais** 🌱 O português tem uma raridade no mundo das línguas: o **infinitivo pessoal** — um infinitivo que se conjuga! Repara: «É bom **partirmos** cedo», «É bom **partires** cedo». A maioria das línguas (como o inglês) não consegue fazer isto — o infinitivo delas é sempre igual. Este verbo flexível é uma das joias do português, e os linguistas de todo o mundo acham-no fascinante! 💎
