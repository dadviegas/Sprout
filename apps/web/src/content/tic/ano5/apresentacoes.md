# Fazer uma apresentação simples 🖥️

> [!NOTE] **O que vais aprender** 👀 Vais aprender a preparar uma apresentação com poucas ideias por diapositivo, imagens úteis, letra legível e uma fala curta que explica o trabalho.

Uma apresentação não é um texto gigante no ecrã. É um apoio para quem fala e uma ajuda para quem ouve.
